## 2. 좌표계·불변 조건 (⚠️ 어기면 페달링 IK 파손)

모델 로컬 좌표: **+X 전진(동), +Y 위, +Z 좌우(바퀴 축)**. 지면 y=0.

`generate-rider-prototype-glb.mjs`와 `riderGlbPedalPose.ts`가 **좌표를 하드코딩으로 공유**한다. 아래 값은 두 파일에서 동일해야 하며 변경 시 반드시 함께 고친다:

| 상수 | 값 | 의미 |
|---|---|---|
| `pelvis` / `PELVIS` | `[-0.12, 0.8, 0]` | 골반 — 다리 hip 기준 + torso 회전 pivot |
| hip offset | `+0.02, -0.08` | leg 그룹 위치 = pelvis + offset |
| `hipZ` | `±0.068` | 좌우 고관절 Z |
| `knee` / `KNEE_LOCAL` | `[0.04, -0.208, ∓0.022]` | 무릎 pivot (leg 로컬) |
| `ankle` | `[0.065, -0.22, ±0.012]` | 발목 (shin 로컬) |
| crank `bb` / `BB` | `[-0.04, 0.4, 0]` | 크랭크축 |
| `armLen` / `CRANK_ARM_M` | `0.14` | 크랭크 암 길이 |

**노드명 6종**(nodeOverride 대상): `crank`, `leg_l`, `leg_l_shin`, `leg_r`, `leg_r_shin`, `torso`. 이름·구조 변경 금지.

**⚠️ 2-bone IK 분기 규약**(`riderGlbPedalPose.ts` `solveLegIk`): 다리가 다 펴진 상태(`d ≥ maxReach`)에서 `cosHip = 1`(hipOffset=0, 허벅지가 페달 방향으로 직선). 여기를 `-1`로 두면 무릎이 몸 위로 솟아 "정강이가 허리 위로 튀는" 버그 재발(2026-07-19 수정). `evaluateIkSolution`의 해부학 penalty(무릎 hip 위/뒤 감점)도 유지.

**⚠️ 헬멧 규약**(`helmetAssembly`): 헬멧은 머리(r0.071) **상단만** 덮고 하단은 **눈 높이(`headC.y`) 위에서 끝난다** — 얼굴(눈·코·이마 아래) 노출 필수. 쉘을 머리보다 크게·아래로 내리면 "헬멧 인간"(얼굴 삼킴) 재발. 리브+cavity 복잡 구조 금지(검은 비니 됨) — 단순 흰 쉘+벤트 홈이 정본. 선글라스는 작은 렌즈 2장(콧수염 금지).

**전고**: 실측 AABB 전고 ≈ **1.266m**, 길이 ≈ 1.60m. 실제 라이딩 자세(~1.45m)보다 저스케일이라 **레이어에서 `model-scale: 1.15`로 보정**(`glbModelLayer.ts` `RIDER_GLB_LAYER_PAINT`). 스크립트에서 모델을 키우지 말 것 — 스케일은 레이어가 담당.

## 3. 애니메이션 아키텍처

Mapbox `model` 레이어의 **`model-rotation` + nodeOverride + feature-state** 조합. 매 프레임 rAF에서:

1. `MapView.tsx` tick → `resolveGlbPedalPose(phaseRev)` 호출 → `RiderGlbPedalPose` 반환.
2. `glbModelLayer.ts` `syncRiderGlbPedalFeatureState`가 각 노드의 회전을 **feature-state**로 세팅.
3. `RIDER_GLB_LAYER_PAINT`의 `model-rotation` match 식이 `part`별로 해당 feature-state를 읽어 노드에 적용.

### 축 규약 (중요 — 헷갈리기 쉬움)
- **crank / leg / shin**: index 2 = 로컬 **Z축** 회전 (`[0, 0, deg]`). 페달·다리는 XY 평면 스윙.
- **torso**: index 0 = 로컬 **X축** 롤 (`[deg, 0, 0]`). 상체 좌우 록킹.
- **코너링 린**(모델 전체): `models[id].orientation`의 index 0 (진행축 롤). `glbModelLayer.ts` `syncRiderGlbModels`에서 `orientation: [leanDeg, 0, yaw]`. 시각 검증 완료 — 이 축이 맞다.

### 튜닝 상수 (체감 조절은 여기서)
| 값 | 위치 | 현재 | 효과 |
|---|---|---|---|
| `TORSO_SWAY_AMP_DEG` | `riderGlbPedalPose.ts` | `2.2` | 상체 좌우 록킹 진폭(°). 2~3 권장, 과하면 우스꽝 |
| 린 계수 | `MapView.tsx` 린 계산부 | `× 0.22` | heading 변화율(°/s)→린(°) 비례. 급코너 드라마틱 원하면 0.35 |
| 린 상한 | 〃 | `±10` | 최대 기울임(°) |
| 린 시정수 | 〃 | `0.35`초 | 지수 감쇠 부드러움. 작을수록 민첩 |

린은 **본인 라이더(live-self)만** 적용. peer는 `leanDeg` 미지정(0).

### 페달 위상
`liveCrankPhaseRevRef`(0~1)를 speed→RPM으로 매 프레임 누적. 정지/일시정지·`prefers-reduced-motion`이면 위상 정지(스웨이·페달 함께 멈춤).

## 4. 현재까지 완료

### 4.1 형태 전면 재작성 (2026-07-19 세션) — "초등 2학년 → 사람 실루엣"

문제: 절차 생성 프리미티브(균일 원기둥+구체 조립)의 천장. 몸통 통짜 튜브, 팔다리 균일 반경, 관절 끊김.

- **메시 헬퍼 3종 신설** (스크립트 상단):
  - `taperTube(from,to,rFrom,rTo,...)` — 반경이 변하는 원뿔대 + 양끝 반구 cap. 근육·프레임 볼륨의 핵심. `tube()`는 이제 이걸 rFrom=rTo로 호출하는 래퍼.
  - `lathe(profile,...)` — `[y,r]` 프로파일 회전체(LatheGeometry). **매끄러운 연속 곡면**(몸통 등판).
  - `blob(r,color,scale,...)` — 방향별 스케일 타원체. 근육·어깨·머리·헬멧 볼륨.
- **재질 캐싱** — `mat()`이 (색·rough·metal·opacity) 키로 인스턴스 재사용. materials 70→16, 파일 928KB→736KB.
- **몸통** — 튜브 1개 → **하나의 lathe 회전체**(골반 넓음→허리 잘록→어깨 넓음 프로파일, segments 40). blob 덧입힘 방식은 계단·뭉침 생겨 폐기. 어깨 캡 blob로 팔 연결.
- **다리** — 허벅지 taperTube(0.062→0.044) + 대퇴사두 blob, 종아리 taperTube(0.044→0.026) + 장딴지 blob, 발목 관절, `shoeAssembly`(발등+발끝 테이퍼+밑창).
- **팔** — 어깨(0.045)→소매→팔꿈치→손목(0.022) 다단 테이퍼, 반팔 소매(저지색)/맨살 경계, 주먹 blob.
- **헬멧** — 반구+박스 → **슬림 에어로**(shell blob X스케일 1.28 + 뒤로 뻗는 tail blob 2.2 + 이마 brow + 벤트 홈 + 골드 스트라이프). 머리 반경 0.088→0.078로 몸통 대비 비율 축소.

**자체 검증 도구**(스크래치, 재작성 가능): ① `render-silhouette.mjs` — 라이브러리 없이 GLB 정점을 정사영 러스터라이즈 → front/side/rear/q34 PNG(오프스크린 GL·로그인 불필요). ② `rider-viewer.html` — three.js CDN 6뷰 그리드, `public/`에 임시 배치 후 Playwright로 스크린샷(작업 후 삭제). ③ 20장 페달링 분석 `analyze-pedal.mjs`(§4.2).

### 4.1b 프레임·헬멧·IK 실주행 수정 (2026-07-19 2차)

실주행 스크린샷 피드백 3건 수정:

1. **IK 버그 — 정강이가 허리 위로 솟구침** (모델 초기부터 있던 문제). 근본 원인은 `riderGlbPedalPose.ts` `solveLegIk`: 다리가 거의 펴진 상태(`d ≥ maxReach`)에서 `cosHip = -1`(→ hipOffset=π)로 두어 허벅지가 페달 **정반대**로 뻗어 무릎이 몸 위로 솟았다. **`cosHip = 1`(hipOffset=0, 허벅지가 페달 방향 직선)이 정답.** 추가로 `evaluateIkSolution`에 해부학 penalty(무릎이 hip보다 위/뒤로 가면 감점)를 넣어 상사점 근처 이상 분기 억제. 8위상 오프스크린 페달 렌더로 전 위상 정상 확인(정강이 솟음 전멸, max knee.y 0.93→0.76).
2. **프레임 — 실제 로드바이크 다이아몬드 프레임.** 기존 6개 임의 튜브 → 다운튜브/시트튜브/탑튜브/헤드튜브 + 체인스테이·시트스테이·앞포크(각 좌우 2개) + **드롭바 핸들**(탑바→후드→드롭 곡선). 좌표 재설계: 안장(`seatTop`)을 골반(0.8) 아래로 낮춰 라이더가 안장에 앉게, 탑튜브 수평, 휠베이스·헤드튜브 실제 비율. 손(`handPt`)은 드롭바 후드(`barHood`)를 쥔다. **bb만 IK 고정, 나머지 프레임 좌표는 자유.**
3. **헬멧 — 실제 로드 헬멧 + 선글라스.** "우주인/풍선"(둥근 공) → 낮고(y스케일 0.66) 앞뒤로 긴 밀착형 shell + 하단 수평 마감 밴드(`rimBand`) + 벤트 슬롯 4줄 + 뒤 에어로 테이퍼. `sunglassesAssembly` 신설(랩어라운드 어두운 렌즈, `COL.sunglass`).

파일 736KB→802KB(프레임 튜브 증가, frameOpts `radial:10`으로 완화).

### 4.1c LiveOn Soft Cycle Rider v1.0 설계 반영 (2026-07-19 3차)

### 4.1d 레퍼런스 정합 수정 (2026-07-19 4차) — 휠베이스·팔 꺾임·헬멧 밀착

사용자 레퍼런스 이미지 대조 지적 3건:

1. **뒷바퀴가 엉덩이에서 멀리 떨어짐** — `REAR_X -0.5→-0.34`, `FRONT_X 0.52→0.48`(길이 1.60→1.38m). 뒷허브는 BB 뒤 0.30(실제 체인스테이 비율)로, **안장 바로 아래**에 뒷바퀴가 오는 게 정상. headBot도 (0.45,0.56)으로 올려 타이어 간섭 회피.
2. **팔이 위로 꺾임** — 팔꿈치(0.36,0.855)가 어깨→손 직선(chord y≈0.80) **위**에 있었음. (0.33,0.79)로 내려 하향 굽힘(자연 자세). 규칙: 팔꿈치는 chord보다 아래.
3. **헬멧 베레모/공중부양** — 노즈·챙 밴드(rimBand) blob 폐기, 쉘 하나(r0.083, 머리 r0.071 감쌈)를 머리 중심 가까이(+0.018) 배치해 밀착. 뒤 테이퍼는 쉘에 파묻혀 이어지게 축소.

**검증**: 6뷰 + 8위상 페달 렌더로 3건 모두 해소 확인, 노드 6종·tsc 통과.

### 4.1e 헬멧·선글라스 재설계 (2026-07-19 5차) — "헬멧 인간" 탈출

사용자 레퍼런스(LOW POLY AERO VENT HELMET / CYCLING SUNGLASSES) 대조 지적: 헬멧이 얼굴까지 통째로 덮어 **헬멧 자체가 머리·얼굴이 됨**(4/5가 헬멧), 선글라스가 하관을 덮는 거대 콧수염 형상.

**원칙 확정 — "머리에 얹힌 헬멧"**:
- 헬멧은 머리(r0.071) **상단만** 덮는 얇은 쉘. **눈 높이(headC.y) 아래로 절대 안 내려감** → 얼굴(이마 아래·눈·코) 노출 필수.
- 시행착오: 리브+cavity(어두운 벤트 골) 방식 → 검은 비니처럼 됨(폐기). **단순 흰 쉘 하나**(SphereGeometry 상반구 phiLength 0.64, 아래 열림) + 어두운 벤트 홈 4개 + 뒤 테일 + 블루 악센트가 정답(사용자 원칙: 상세보다 형태 정합성·심플).
- 쉘 position을 위·뒤로(`hy+0.045, hx-0.022`) 올려 이마 노출·후두부 덮음(비니 방지).

**선글라스**: 거대 blob(콧수염) → **작은 렌즈 2장**(r0.023, 간격 ±0.022로 좁혀 하나의 안경) + 브릿지 + 관자(temple). 눈 높이(headC.y-0.028)에 정확히.

**검증 도구 추가**: `head-viewer.html`(머리 4방향 클로즈업) — 얼굴 노출·헬멧 얹힘 확인에 필수(전신 6뷰로는 머리 디테일 판독 불가).

**검증**: head-viewer 4뷰 + 전신 6뷰로 얼굴 노출·헬멧 얹힘·선글라스 정상 확인, 노드 6종·tsc·IK 불변식 유지.

### 4.2 20장 페달링 시퀀스 활용 결론

`public/rider/0512*.png` 20장 = **정면(뒤에서 본) 단일시점 단색 실루엣 페달링 시퀀스**. 다각도 없음 → **3D 형태 소스로 불가**. `analyze-pedal.mjs`로 실측: 파일 번호순 = 페달 위상순(footDeltaY 사인 진동), 발높이 peak-to-peak ≈ 전고 8.4%, 무릎 span ≈ 22%, 몸통 aspect(W/H) ≈ 0.36(세로로 길쭉·역삼각형). 이 실측을 **형태 목표**로 삼았고, IK 미세튜닝(§5)에는 아직 미반영.

### 4.3 이전 세션 성과 (유지)
- 스케일 보정 `model-scale 1.15`, `torso` 노드 상체 스웨이, 코너링 린.

**검증(이번)**: `npm run gen:rider-glb` 성공(802KB), 노드 6종 존재, 전고 1.247m(스케일 1.15→1.43m), IK 좌표 불변식(pelvis/bb/knee/ankle/hipZ/armLen) 스크립트↔`riderGlbPedalPose.ts` 완전 일치 확인, `tsc --noEmit` 통과. **형태는 6뷰 오프스크린 렌더, 페달링은 8위상 페달 렌더로 확인**(정강이 솟음 버그 해소). 실주행 스웨이·린 최종 확인은 사용자 몫.

## 5. 후속 과제 (다음 세션 시작점)

우선순위 순:

1. **취향 미세 튜닝(다음 우선)** — 실주행에서 사용자 피드백 받아 조정. 알려진 미세 결함: front 뷰 머리가 여전히 약간 큼(head 반경/헬멧 shell 스케일 down), 손이 핸들바에 정확히 안 얹힘(`armAssembly` handPt), 저지 톤·골드 강도. 모델 변경 시 `npm run gen:rider-glb` + 강력새로고침.
2. **페달링 IK 실측 반영** — §4.2 20장 실측(무릎 span 22%, 발높이 pp 8.4%)을 `riderGlbPedalPose.ts` 상수와 대조해 궤적 자연스럽게 보정. **주의: IK 좌표(pelvis/bb/knee/ankle/hipZ)는 스크립트와 동기라 함께 고쳐야 함**(§2).
3. **파일 크기** — 736KB(목표 600KB). 큰 절감은 메시 병합이라야 하나 GLTFExporter 자동 미지원. 형태 확정되면 (a) 몸통 외 blob segments 소폭 down 또는 (b) 후처리 병합 툴(gltf-transform) 검토. 현 상태도 1회 로드+캐시라 실사용 무방.
4. **peer 라이더 린** — 현재 본인만. peer도 heading 이력으로 린 주려면 `stepPeerDriveAndBuildGeoJson` 출력에 이전 heading 유지 필요.
5. **정지 자세** — 현재 정지 시 페달·스웨이만 멈춤. 발 지면 디딤 등 정지 전용 포즈는 미구현.

## 6. 재현·검증 절차 (새 세션에서)

```bash
# 1. 모델 재생성 (스크립트 수정 후)
cd apps/web && npm run gen:rider-glb   # → public/rider/prototype/rider-lowpoly.glb

# 2. 노드명·전고 검증 (측정 스크립트 필요 시 재작성 — 아래 로직)
#    GLB 파싱: 12B 헤더 + JSON청크(type 0x4E4F534A) + BIN청크.
#    json.nodes[].name 에서 6종 확인, 노드 트리 순회 TRS 누적 → POSITION accessor min/max 8꼭짓점 월드 투영 → AABB.

# 3. 타입체크
cd apps/web && npx tsc --noEmit
```

**시각 검증(로그인 필요)**: 개발서버(현재 :5000) → Guest 진입("시작") → MENU → 퍼블릭 → 짧은 자전거 경로 로드 → 주행 시작. GLB 모드가 아니면(`VITE_RIDER_PROTOTYPE`) 라이더가 legacy/iso2d로 나오니 env 확인.

**주의**: GLB는 정적 자산이라 브라우저가 캐시한다. 확인 시 **강력 새로고침(Ctrl+Shift+R)** 필수.
