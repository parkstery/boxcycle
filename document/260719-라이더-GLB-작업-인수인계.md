# 라이더 GLB 작업 인수인계 (260719)

| 항목 | 내용 |
|------|------|
| 문서 유형 | **작업 인수인계** — 새 세션에서 라이더 GLB 3D 모델·애니메이션 작업을 이어가기 위한 컨텍스트 |
| 작성 | 2026-07-19 |
| 상태 | **진행 중** — 스케일 보정·모델 디테일·스무딩·상체 스웨이·코너링 린까지 완료. 후속 과제는 §5 |

> RTW 라이더는 **GLB 3D 모델**(`rider-lowpoly.glb`)이며, 카메라를 당기면 세계와 함께 스케일된다. "고정 크기 스프라이트 한계"는 `iso2d` 모드 이야기이고 현재 기본 모드(`glb`)에는 해당하지 않는다.

## 2. 좌표계·불변 조건 (⚠️ 어기면 페달링 IK 파손)

모델 로컬 좌표: **+X 전진(동), +Y 위, +Z 좌우(바퀴 축)**. 지면 y=0.

`generate-rider-prototype-glb.mjs`와 `riderGlbPedalPose.ts`가 **좌표를 하드코딩으로 공유**한다. 아래 값은 두 파일에서 동일해야 하며 변경 시 반드시 함께 고친다:

| 상수 | 값 | 의미 |
|---|---|---|
| `pelvis` / `PELVIS` | `[-0.12, 0.8, 0]` | 골반 — 다리 hip 기준 + torso 회전 pivot |
| hip offset | `+0.02, -0.08` | leg 그룹 위치 = pelvis + offset |
| `hipZ` | `±0.068` | 좌우 고관절 Z |
| `knee` / `KNEE_LOCAL` | `[0.04, -0.208, ∓0.022]` | 무릎 pivot (leg 로컬) |
| `ankle` | `[0.065, -0.22, ±0.012]` | 발목 (shin 로컬) |
| crank `bb` / `BB` | `[-0.04, 0.4, 0]` | 크랭크축 |
| `armLen` / `CRANK_ARM_M` | `0.14` | 크랭크 암 길이 |

**노드명 6종**(nodeOverride 대상): `crank`, `leg_l`, `leg_l_shin`, `leg_r`, `leg_r_shin`, `torso`. 이름·구조 변경 금지.

**전고**: 실측 AABB 전고 ≈ **1.266m**, 길이 ≈ 1.60m. 실제 라이딩 자세(~1.45m)보다 저스케일이라 **레이어에서 `model-scale: 1.15`로 보정**(`glbModelLayer.ts` `RIDER_GLB_LAYER_PAINT`). 스크립트에서 모델을 키우지 말 것 — 스케일은 레이어가 담당.

## 3. 애니메이션 아키텍처

Mapbox `model` 레이어의 **`model-rotation` + nodeOverride + feature-state** 조합. 매 프레임 rAF에서:

1. `MapView.tsx` tick → `resolveGlbPedalPose(phaseRev)` 호출 → `RiderGlbPedalPose` 반환.
2. `glbModelLayer.ts` `syncRiderGlbPedalFeatureState`가 각 노드의 회전을 **feature-state**로 세팅.
3. `RIDER_GLB_LAYER_PAINT`의 `model-rotation` match 식이 `part`별로 해당 feature-state를 읽어 노드에 적용.

### 축 규약 (중요 — 헷갈리기 쉬움)
- **crank / leg / shin**: index 2 = 로컬 **Z축** 회전 (`[0, 0, deg]`). 페달·다리는 XY 평면 스윙.
- **torso**: index 0 = 로컬 **X축** 롤 (`[deg, 0, 0]`). 상체 좌우 록킹.
- **코너링 린**(모델 전체): `models[id].orientation`의 index 0 (진행축 롤). `glbModelLayer.ts` `syncRiderGlbModels`에서 `orientation: [leanDeg, 0, yaw]`. 시각 검증 완료 — 이 축이 맞다.

### 튜닝 상수 (체감 조절은 여기서)
| 값 | 위치 | 현재 | 효과 |
|---|---|---|---|
| `TORSO_SWAY_AMP_DEG` | `riderGlbPedalPose.ts` | `2.2` | 상체 좌우 록킹 진폭(°). 2~3 권장, 과하면 우스꽝 |
| 린 계수 | `MapView.tsx` 린 계산부 | `× 0.22` | heading 변화율(°/s)→린(°) 비례. 급코너 드라마틱 원하면 0.35 |
| 린 상한 | 〃 | `±10` | 최대 기울임(°) |
| 린 시정수 | 〃 | `0.35`초 | 지수 감쇠 부드러움. 작을수록 민첩 |

린은 **본인 라이더(live-self)만** 적용. peer는 `leanDeg` 미지정(0).

### 페달 위상
`liveCrankPhaseRevRef`(0~1)를 speed→RPM으로 매 프레임 누적. 정지/일시정지·`prefers-reduced-motion`이면 위상 정지(스웨이·페달 함께 멈춤).

## 4. 현재까지 완료 (이번 세션)

1. **스케일 실측·보정** — AABB 전고 1.263m 확인 → `model-scale 1.15`.
2. **모델 디테일 업** — `MeshBasicMaterial`(무조명) → `MeshStandardMaterial`(조명 반응)이 최대 레버. 바퀴 스포크·허브·디스크, 팔(상완+전완+손), 어깨 볼륨, 헬멧 벤트, 무릎/팔꿈치 관절, 신발+밑창, 골드 물통·스트라이프 추가.
3. **매끈하게** — 튜브 세그먼트 8→16, 구체류 세그먼트 대폭 상향, 저지 roughness 0.7.
4. **상체 스웨이** — `torso` 노드 신설(pivot=pelvis, 상체 전체 포함), 페달 1회전당 좌우 1회 록킹.
5. **코너링 린** — heading 변화율 비례, 지수 감쇠.

**검증**: `npm run gen:rider-glb` 성공(411KB), 노드 6종 존재, 전고 1.266m 유지, `tsc --noEmit` 통과, 실주행에서 스웨이·코너 린(3방향) 시각 확인.

---

## 5. 후속 과제 (다음 세션 시작점)

우선순위 순:

1. **취향 튜닝** — 저지 톤·골드 강도·스웨이/린 강도. §3 상수 테이블에서 조정 후 `npm run gen:rider-glb`(모델 변경 시) 또는 코드만(애니 상수).
2. **더 높은 품질 모델** — 현재 절차 생성 저폴리는 6~7점 목표의 하한. 필요 시 (a) 스크립트를 더 정교화 또는 (b) 외부 CC0 mid-poly 모델 소싱 + IK 노드 리깅 매핑. 후자는 노드명 6종 매핑이 관건.
3. **peer 라이더 린** — 현재 본인만. peer도 heading 이력으로 린 주려면 `stepPeerDriveAndBuildGeoJson` 출력에 이전 heading 유지 필요.
4. **재질 심화** — 저지 노멀/러프니스 텍스처, 헬멧 클리어코트 등(파일 크기·성능 트레이드오프 주의, 목표 600KB 이내).
5. **정지 자세** — 현재 정지 시 페달·스웨이만 멈춤. 발 지면 디딤 등 정지 전용 포즈는 미구현.

## 6. 재현·검증 절차 (새 세션에서)

```bash
# 1. 모델 재생성 (스크립트 수정 후)
cd apps/web && npm run gen:rider-glb   # → public/rider/prototype/rider-lowpoly.glb

# 2. 노드명·전고 검증 (측정 스크립트 필요 시 재작성 — 아래 로직)
#    GLB 파싱: 12B 헤더 + JSON청크(type 0x4E4F534A) + BIN청크.
#    json.nodes[].name 에서 6종 확인, 노드 트리 순회 TRS 누적 → POSITION accessor min/max 8꼭짓점 월드 투영 → AABB.

# 3. 타입체크
cd apps/web && npx tsc --noEmit
```

**시각 검증(로그인 필요)**: 개발서버(현재 :5000) → Guest 진입("시작") → MENU → 퍼블릭 → 짧은 자전거 경로 로드 → 주행 시작. GLB 모드가 아니면(`VITE_RIDER_PROTOTYPE`) 라이더가 legacy/iso2d로 나오니 env 확인.

**주의**: GLB는 정적 자산이라 브라우저가 캐시한다. 확인 시 **강력 새로고침(Ctrl+Shift+R)** 필수.
