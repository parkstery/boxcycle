## 1. 프로젝트 개요 (변하지 않는 축)

RTW는 단순 지도 뷰어가 아니라 **실내 자전거 사용자가 실제 세계 코스를 가상 주행하며 함께 달리는 멀티플레이 플랫폼**이다(상세: [마스터 비전](../260511-RTW-마스터-비전-및-종합계획.md)).

- **핵심 구조 원칙:** Course(정적 코스) / Session(실시간 방) / Presence(위치·속도) **3분할**, `courseId != sessionId`.
- **"생성 ≠ 영구 저장":** UGC 코스는 기본 Disposable, 활동·인기 점수로 승격된 것만 장기 보존.
- **스택:** React 19 + Vite + TypeScript(웹), Firebase(Firestore + Realtime DB + Functions/Node 20), Mapbox GL. 결제는 Stripe(구독).
- **용어:** 사용자 노출 도메인 용어는 **Trailhead / Trail** ([SoT](../260517-제품-용어-Trailhead-Trail.md)). 내부 식별자는 `publicationId` 중심의 [Route Publication 통합 모델](260518-Route-Publication-통합-모델-및-마이그레이션.md).

## 3. 이번 세션(2026-06-29~07-02) 작업

### 3.1 브랜드명 전환 — BOXCYCLE → RTW

사용자 노출 표기 5곳 변경: 브라우저 탭 제목, MENU(trail 메뉴) 버튼, 인증 카드·게스트 진입 카드 브랜드, 가로모드 안내문. **내부 식별자·localStorage 키·Firebase projectId(`boxcycle-dc2df`)는 유지**(기존 사용자 데이터·설정 보존).

### 3.2 경로 UI 표면 재설계 (승인된 3단계)

문제 진단: "경로"를 만지는 표면이 4개(MENU 카탈로그, RouteDock 하단, 지도 핀 팝업, HUD 접속패널)인데 책임이 겹쳐 중복·혼선. 해결 원칙 = **표면당 책임 동사 하나**.

| 표면 | 확정 책임 |
|------|-----------|
| **MENU 드로어** | 고른다(탐색·선택) — 공식/내 경로 카탈로그, 트레일 참가·공개 설정 |
| **지도 핀 팝업** | 만든다 — 수단(차/자전거/도보) 선택 = **즉시 경로 생성** |
| **RouteDock(하단)** | 실행 — 핀 목록·내 경로 저장·Go·삭제·속도 |
| **HUD 접속패널** | 본다(현황) — 접속·동행. MENU 열리면 숨김 |

- **Phase 1 + 정제:** 경로 생성/저장 동사를 정리하고, 최종적으로 **수단·경로생성을 지도 핀 팝업 단독**으로 귀속(사용자 편의: 수단 클릭 순간 생성). RouteDock에서는 수단/생성 제거.
- **토큰 게이트 통일(사용자 결정: 둘 다 차단):** Route Token 잔액 < 1이면 RouteDock·핀 팝업 어느 쪽도 생성 불가. 공유 핸들러 `handleMapRouteProfile`에 라이브 게이트 + 핀 팝업 수단 버튼 비활성·"주행 완료 시 획득" 안내.
- **Phase 2:** 관리자 `심사` 탭을 일반 탭 바에서 분리 → 경로 탭은 **공식경로·내경로 2개**, 심사는 리뷰어 전용 별도 진입점.
- **Phase 3:** MENU 열린 동안 HUD 접속패널 숨김(가림·중복 해소), MENU Trail 섹션 부제 "접속·동행" → "참가·공개 설정".
- **수단 차/자전거/도보 3개 모두 유지:** 자전거로 못 가는 자동차 전용도로를 시뮬레이션으로 달려보는 선택지를 의도적으로 제공.

### 3.3 라이트(흰 배경) 테마

`apps/web/src/panel-light.css` 신설(다크 테마 뒤 **가장 마지막 로드**, 드롭인·되돌리기 용이). 패널 루트에 라이트 팔레트 변수 재정의 + 하드코딩 표면 개별 정리.

- **완료:** MENU 드로어, RouteDock, 경로 카탈로그(RideRoutePanel), TrailHubPanel, **지도 핀 팝업**, 장소검색(placeholder 가독성 수정), 공식코스 목록 모달(기본=밝게/선택=액센트 강조), 관리자 심사 큐.
- **제외(요청):** 지도 위 HUD 칩(브랜드·지표·FAB)은 글래스 유지.

### 3.4 소소한 UI 다듬기

- RouteDock 속도 컨트롤: 'SPEED' → **'SPD(km/h)'**, 라벨을 슬라이더와 같은 줄 왼쪽 배치.
- 내 경로 저장 폼: '경로 이름' 타이틀과 저장·취소 버튼을 한 줄에, 취소 버튼 확대.

> 이번 세션 변경은 모두 **빌드·타입체크 통과**. 작성 시점 기준 **미커밋 상태**.
