## 1. 요약

본 문서가 다루는 구간에서 **Mapbox GL JS**를 사용한 **정적 HTML + 단일 스크립트(`app.js`)** 로 출발·도착 기반 **경로 계산**, **가상 주행 세션**, **3D 지형·건물·카메라 추적**, **고도 프로필**, **지명 검색**, **로컬 즐겨찾기(My routes)** 까지 구현하였다. **백엔드·DB·인증·실시간 멀티유저**는 없으며, 세션·경로 즐겨찾기는 **브라우저 `localStorage`** 에만 저장된다.

**그 구간의 평가:** UX·지도 연동 **검증 목적 달성**. 이후 단계에서는 **Vite+TypeScript+React·Firebase·멀티 유저 검증**으로 전환한다(현재 단계 문서 참고).

## 3. 기술 스택

| 영역 | 사용 기술 | 비고 |
|------|-----------|------|
| UI | HTML5, CSS (`styles.css`) | 좌측 패널 + 지도 + 고도 패널 |

| 고도 | Open-Meteo Elevation API v1 | 샘플 좌표 기반 |
| 영속화 | `localStorage` | 세션 기록, My routes |

## 4. 구현 현황(기능별)

### 4.1 지도·경로

- 출발·도착 좌표 입력(`lng,lat`), 지도 클릭 팝업으로 출발/도착 설정
- **자전거 / 자동차 / 보행** 프로필에 따른 Mapbox Directions 호출
- 경로 GeoJSON 레이어 표시, 거리·예상 시간 요약
- 지도 스타일 선택: streets, outdoors, satellite, satellite-streets

### 4.2 지명 검색

- Mapbox Geocoding 자동완성(근접 `proximity` 반영, 한·영 언어)
- 키보드(화살표/Enter/Escape) 및 마우스 하이라이트 연동

### 4.3 실내 라이딩 세션

- 시작 / 일시정지 / 재개 / 종료
- 가상 속도(km/h) 슬라이더 기반 **경로 상 가상 이동 거리** 누적
- 경과 시간, 가상 거리, 평균 속도 표시
- 종료 시 `localStorage`에 세션 요약 저장(최근 목록 UI)

### 4.4 카메라·3D

- **시간 상수 기반 감쇠(damping)**로 카메라 center/pitch/zoom 평활
- bearing **2단 cascade LPF**(primary/secondary)로 회전 부드럽게 처리
- 후방/전방 30°/좌우 측면 뷰 등 **프리셋 뷰 모드**
- 고 pitch·고 zoom·대각 bearing 시 **리스크 점수**로 자유 카메라 전환(안정화)
- 3D 지형(Mapbox DEM), 3D 건물 레이어, 지형 과장(exaggeration) 슬라이더
- **도로 오버레이** 토글(주행 가능 도로 시각화 보조)

### 4.5 고도(Elevation)

- 경로 좌표 샘플링 후 Open-Meteo로 고도 조회
- SVG 기반 **Elevation Profile** 차트 및 누적 상승(elevation gain) 메타
- 주행 중 진행 위치에 따른 프로필 갱신 연동

### 4.6 My routes(즐겨찾기)

- 이름·출발/도착·프로필·맵 스타일 저장(최대 10건, 동일 구간은 앞으로 갱신)
- 불러오기 시 스타일 전환 후 경로 재계산
- `localStorage` 기반

### 4.7 기타

- `favicon.svg`
- README: 실행 방법, 토큰 설정, 트러블슈팅

## 5. 코드베이스 구조

| 파일·폴더 | 역할 | 대략 규모 |
|-----------|------|-----------|
| `app.js` | 전 기능 집약(지도, API, 세션, UI 이벤트) | **약 1,280줄**(비공백 기준 PowerShell 측정) |
| `index.html` | 레이아웃, CDN 링크, DOM id 정의 | 133줄 |
| `styles.css` | 레이아웃·컴포넌트 스타일 | **약 260줄** |
| `config.example.js` / `config.local.js` | Mapbox 토큰 주입 | 소형 |
| `document/` | 아키텍처·리팩터링·DB 이전 가이드 | 여러 `.md` |
| `README.md` | 사용자 안내 | 일부 내용이 코드 대비 **구식**(아래 7절 참고) |

### 5.1 아키텍처 특성

- **모놀리식 단일 파일**: 유지보수·테스트·멀티 플랫폼(안드로이드) 공유에 불리
- **클라이언트 직접 Mapbox 호출**: 토큰 노출·요금·정책 통제 측면에서 프로덕션 전 **서버 프록시 권장**(내부 문서 `260509-app-js-프론트백엔드-분리-1차리팩터링.md`와 일치)

### 5.2 `index.html`과 `app.js` 불일치(경미)

- `index.html`은 `app.js`를 `type="module"`로 로드하나, **`app.js` 내부에 `import`/`export` 없음** → 브라우저에 따라 동작은 하나(전역 스크립트처럼 실행되는 경우가 많음), **표준 ES 모듈 구조는 아님**. 향후 모듈 분리 시 `main.js` 진입점으로 정리하는 것이 좋음.

## 9. 리스크·기술 부채

1. **`app.js` 단일 파일 비대화** — 기능 추가 시 회귀 위험, 코드 리뷰 비용 증가
