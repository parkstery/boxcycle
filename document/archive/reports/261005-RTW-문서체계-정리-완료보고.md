## 검증과 한계

현재 링크·reference 색인·종료 작업 잔류 검사와 보존 검증은 통과했다. 누락 링크·색인 누락·종료 잔류를 넣었을 때 검사 실패도 확인했다. 이동 전 누락 링크 26건을 baseline으로 보존했고 현재 기준의 3건은 정정했다. 과거 기록 기존 누락 23건으로 전수 검사는 실패(exit 1)하며 이동 회귀는 0건이다. 실제 명령과 결과는 [02 실행 결과](../../ops/20261005-document-system/02-result-document-system.md)와 [03 검수](../../ops/20261005-document-system/03-review-document-system.md)에 기록했다.

Cursor CLI는 실행 직후 `uv_os_get_passwd ENOMEM`으로 종료(code 1)돼 변경을 수행하지 않았다. Codex가 문서 정리·검증을 직접 완료하는 대체 경로를 사용했다. 독립 Developer 검수는 없으며 실제 변경과 자동 검사 근거를 명시한다.

코드·시험이 기존 ops 경로를 입력/출력으로 사용하는 종료 묶음은 제자리에 보존한다. 이 의존을 없애는 fixture·실행 산출물 분리는 별도 코드 작업으로 범위·검증을 정해야 한다. 이번에는 문서 경로 참조 외 앱·시험 동작을 바꾸지 않았다. 커밋·push·merge는 수행하지 않았다.
