# 동행 라이더가 서로 안 보임 — 같은 계정 로그인(버그 아님)

| 항목 | 내용 |
|---|---|
| 문서 유형 | **진단 기록** |
| 작성 | 2026-10-17 · Supervisor (Claude) |
| 상태 | **종결** — 2026-10-16 Chief 다른 계정으로 재시험, 서로 보임 확인("my mistake!") |
| 코드 변경 | 없음 |

## 증상

PC 와 폰으로 같은 트레일을 동시에 주행했는데 서로의 라이더가 보이지 않았다.

## 원인

두 기기가 **같은 계정**으로 로그인되어 있었다. 동행 동기화는 presence 목록에서 **자기 uid 를 건너뛴다** — `syncFromPresence.ts`(392·399행 부근 `myUid` 비교). 같은 uid 의 다른 기기도 "나"로 취급되어 그려지지 않는다. 의도된 동작이다(자기 그림자 방지).

## 다시 "안 보인다"는 보고가 오면 — 확인 순서

1. **두 기기의 계정이 다른가** (가장 먼저).
2. 같은 트레일·같은 세션(코스)인가.
3. `?perflab=1` 떨림 줄에 동행 라이더 행이 생기는가 — 행이 있는데 안 보이면 렌더 쪽, 행 자체가 없으면 presence·네트워크 쪽.
4. 그 다음에야 presence 문서·Firestore 규칙·연결 상태를 본다.

## 남은 판단

같은 계정 다중 기기를 "다른 라이더"로 보여 줄 필요는 현재 없음. 필요해지면 uid 가 아니라 세션/기기 id 기준으로 건너뛰도록 바꿔야 한다(설계 변경).
