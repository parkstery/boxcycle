## 1. 메인 여정 (Primary journey) — **A안 채택**

**한 줄:** 로그인(또는 게스트) → **입문 코스 선택** → 지도에서 경로 확인 → **주행 시작** → (선택) 기록·통계 확인.

| 단계 | 사용자 행동 | UI 진입점 | stage |
|------|-------------|-----------|--------|
| 0 | 앱 열기 | — | `gate` |
| 1 | 게스트 또는 Google | 중앙 AuthGateCard | `gate` → `idle` |
| 2 | (Google만) 닉네임 | AuthGateCard | `gate-nickname` → `idle` |
| 3 | 코스 고르기 | **좌측 MENU → 경로 탭 → 공식·입문** | `idle` |
| 4 | 코스 로드 확인 | 지도 폴리라인 + BL 경로 요약 | `ready-to-start` |
| 5 | 주행 | BR **▶** | `riding` |
| 6 | 종료·결과 | RideSummarySheet | `summary` → `idle` |
| 7 | 통계·최근 기록 | **TR 아바타 → 사용자 시트** | (stage 직교) |

**보조 여정 B (커스텀 경로):** 지도 탭 → 출발·도착 핀 → MENU에서 **경로 생성** → 저장(선택) → ▶.  
B는 입문 이후·고급 사용자용으로 두고, 온보딩 힌트·기본 포커스는 A에 맞춘다.

## 2. 패널 역할 (목표 IA)

| 영역 | 코드 | 담는 것 | 넣지 않을 것 |
|------|------|---------|----------------|
| 지도 | `MapView` | 핀·경로·동행 마커·짧은 지점 팝업 | 긴 폼, 계정 |
| HUD TL | `MapHud` | 브랜드·**지명 검색** 트리거·**같은 Trail 접속자**(Trailhead presence)·동행 요약 | 통계, TTS, **Trail 이탈 전용 버튼 없음** |
| HUD BR | `MapHud` | 주행 FAB | 코스 목록 |
| HUD BC | `MapHud` | 맵 뷰 트리거 | OSRM 심화(고급만) |
| **Route Dock** | `RouteDock` (`AppMapStage`) | **좌하단** — 출발·경유·도착 정지, **SPEED**, **Go**, 경로 저장·삭제 | BLE, TTS, Trail 목록 |
| 지명 검색 | `PlaceSearchPanel` | HUD **「지명」** → 출발·도착·경유 지명 검색 | 코스 카탈로그 |
| 좌측 MENU | `MenuPanel` + `RideRoutePanel` + `TrailHubPanel` | **Trail 목록·합류**, 코스·경로 생성·저장 경로 | **세션 속도·Go**(→ Route Dock), BLE, TTS, BGM |
| 설정 시트 | `RideSettingsSheet` | BLE, TTS, BGM, 배너 | 코스 카탈로그 |
| 맵 뷰 시트 | `MapViewSheet` | 스타일, 카메라, 3D, 줌 | 주행 기록 |
| 사용자 시트 | `UserInfoSheet` | 프로필, 통계, 최근 주행, 로그아웃, Google 연결 | (접속/로비 조작 없음) |

**Trailhead 정책(구 로비, 앱·웹 동일 목표):** 로그인(게스트 포함) 세션 동안 **`lobbySessionActive`(코드명, = Trailhead 활성)** 이면 Firestore Trail presence(`rooms/{id}/members` 등)·관전·퍼블리시는 항상 켜짐. 이탈은 **로그아웃·Trail 전환·주행 종료** 등으로만 처리; 사용자에게 「Trailhead 나가기」 전용 버튼은 제공하지 않는다. 용어: [260517-제품-용어-Trailhead-Trail.md](../260517-제품-용어-Trailhead-Trail.md).

## 3. 기능 ↔ 메뉴 이동표 (P0·2026-06 반영)

| ~~Trailhead 나가기~~ | (제거됨) | **없음** — Trail 전환·로그아웃·주행 종료 시 presence 삭제 |

| 맵 스타일·카메라 | 맵 시트 | 동일 |

## 4. 오버레이 규칙

- **동시에 하나의 큰 패널만:** MENU · 맵 뷰 시트 · 사용자 시트 · 설정 시트 · **지명 검색** — 열 때 나머지는 닫는다.
- **주행 중(`riding`/`paused`):** MENU는 `locked`로 강제 닫힘(기존 유지). **Route Dock**은 `setup`·`ready-to-start`에서만 렌더(속도·경로 UI — 주행 중 표시는 후속 UX 과제).
- **gate / summary:** HUD 트리거 최소화(기존 `MapHud` 정책 유지).

### 4.1 Route Dock (2026-06)

| 항목 | 내용 |
|------|------|
| 위치 | 지도 **좌하단** (`.route-dock-anchor`, Mapbox logo 위) |
| 마운트 | `AppMapStage` → `routeDock` prop |
| 표시 stage | `setup`, `ready-to-start` (`RouteDock.tsx` `visible`) |
| 담당 | 정지 목록, SPEED, Go, 경로 저장·전체 삭제 |
| 주행 잠금 | `editLocked` — 주행 중 핀·저장·삭제 비활성 (`lockRouteWorkspaceDuringRide`) |
| 제거됨 | 하단 거리·시간 요약(2026-06) — HUD TC·경로 미리보기로 대체 |

## 7. 구현 메모 · Trailhead·Trail 목록 (2026-06)

- `useLobbyRoomSession` / `useTrailSession`: `enabled: configured && user` — 탭 활성 시 upsert·하트비트.
- **Trail 목록(MENU):** `useOpenTrails` — `openTrailListings` + `livePublicationRides` CG 병합. **활성 라이더 1명 이상**만 표시. 지난 open trail·0명 listing은 제외. 상세: [용어집 §1-c](../260517-제품-용어-Trailhead-Trail.md), [Firestore 스키마 §3.2.3](260509-Firestore-컬렉션-스키마-초안.md).
- **Trailhead 관전:** `useActiveLiveRideTrailIds` — 지도·월드 오버레이가 주행 Trail ID 카탈로그 보강.
- 로그아웃 시 `deleteLobbyPresence` 및 `signOut`; 코스 허브는 기존대로 `deleteCoursePresence` 병행.
