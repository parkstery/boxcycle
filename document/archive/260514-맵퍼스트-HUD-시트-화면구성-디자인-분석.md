## 1. 설계 목표 요약

1. **맵 퍼스트(Map-first)**  
   지도가 뷰포트 전체를 차지하고, 경로·주행·코칭 관련 UI는 **떠 있는 카드/시트/HUD**로만 얹어 맵 조작성을 최대한 유지한다.

2. **슬롯 기반 HUD**  
   고정 레이아웃 그리드 대신 **화면 모서리·중앙에 의미 있는 슬롯(TL, TC, TR, BL, BC, BR, MC)**을 두고, 단계(stage)에 따라 필요한 위젯만 노출한다.

3. **글래스모피즘(Glassmorphism)**  
   반투명 배경, `backdrop-filter` 블러, 얇은 테두리·그림자로 **맵과의 시각적 연속성**을 유지하면서도 읽기 가능한 대비를 확보한다.

4. **라이딩 잠금(ride lock)**  
   주행 중·일시정지 중에는 **경로 편집·일부 시트**를 막아 실수 입력을 줄인다.

5. **저장과 생성의 분리**  
   경로 **생성**은 자유롭게 반복하고, **내 경로 목록(DB/로컬)** 반영은 **명시적 저장 플로우 + 확인**으로만 수행한다(별도 제품 정책).

## 2. 최상위 DOM·레이아웃 셸

### 2.1 `app-shell--map-first`

`App.css`에서 맵 퍼스트 셸은 다음을 만족한다.

- `position: relative`, `height: 100dvh`, `overflow: hidden` — 한 화면 내에서 스크롤 누수 방지.
- 배경색 `#020617`(슬레이트 950 계열), 기본 텍스트 `#f8fafc`.

### 2.2 `app-map-stage`

- `position: absolute; inset: 0` — 셸 안에서 **풀스크린 스테이지**.
- 자식 순서( `App.tsx` 기준 ):
  1. **`MapView`** — Mapbox GL 맵 본체.
  2. **`MapHud`** — 플로팅 HUD(동일 스테이지 위 오버레이).
  3. (조건부) **Mapillary 거리뷰** 플로팅 카드.

맵과 HUD가 **형제 레이어**이므로, HUD의 `pointer-events` 설계(후술)가 맵 터치/클릭 경험을 좌우한다.

## 3. UI 단계 머신: `useRideUiStage`

파일: `apps/web/src/hooks/useRideUiStage.ts`

**`RideUiStage` 타입:**  
`gate` | `gate-nickname` | `idle` | `setup` | `ready-confirm` | `ready-to-start` | `riding` | `paused` | `summary`

**역할**

- 인증·닉네임 카드, 요약 시트, 주행 상태, 핀/경로 유무를 입력으로 **단일 stage**를 계산한다.
- `MapHud`는 이 stage만 받아 **어떤 슬롯을 보일지** 결정한다.
- `isRideStageLocked` — `riding` / `paused` 일 때 true → `App.tsx`의 `rideLocked`와 연동해 메뉴 잠금·지도 핀 변경 차단 등에 사용.

## 4. MapHud: 8슬롯·포인터 이벤트·일시정지

파일: `apps/web/src/components/maphud/MapHud.tsx`, `MapHud.css`

### 4.1 슬롯 역할 (코드 주석·구현 기준)

| 슬롯 | 위치(대략) | 내용 |
|------|-------------|------|
| **TL** | 좌상 | `BOXCYCLE` 브랜드 = **메뉴(경로 패널)** 오픈 트리거 |
| **TC** | 상중 | 라이딩/일시정지 중 **경과 시간·거리·평균·현재 속도** 칩 |
| **TR** | 우상 | **사용자 정보 시트** 트리거(아바타) |
| **BL** | 좌하 | 핀 진행 칩 / 경로 요약 칩 |
| **BC** | 하중 | 코칭 한 줄(라이딩 중) + **맵 뷰 시트** 트리거 |
| **BR** | 우하 | **메인 FAB**(시작 ▶ / 일시정지 ‖) + (라이딩 중) 종료 ■ |
| **MC** | 화면 중앙 | **경로 생성 확인**, **에러 안내**, **일시정지(재개·변경·종료)** 액션 카드 |

### 4.2 `pointer-events` 패턴

- `.map-hud` 루트: `pointer-events: none` — **빈 영역은 맵으로 이벤트가 통과**.
- `.map-hud > *`: `pointer-events: auto` — **각 슬롯 컨테이너**는 다시 히트 테스트 대상.

이 패턴으로 “HUD가 있어도 맵 드래그 가능”을 노린다.

### 4.3 일시정지 스크림 (`map-hud__scrim`)

- 일시정지 시 전면 어둡게(`rgba(2, 6, 23, 0.42)`) 딤.
- **주의(버그 수정 이력):** 스크림에 `z-index: 1`을 주면 형제 슬롯들이 대부분 `z-index: auto`라 **스크림이 MC·버튼 전체 위에 올라가** 클릭이 전부 막히는 문제가 발생했다.  
  → **스크림에서는 `z-index`를 제거**해, DOM 순서상 뒤에 그려지는 MC·BR 등이 스크림 위에 쌓이도록 수정됨(`MapHud.css` 주석 참고).

### 4.4 시각 스타일

- 칩·버튼·액션 카드에 `backdrop-filter: blur(10px)` 전후, 슬레이트 톤 반투명 배경, `border-radius` 12px/999px 혼용.
- FAB·아이콘 버튼은 그림자·호버 시 배경 강조로 **터치 타겟**을 명확히 함.

## 5. 시트·드로어·모달 계층

### 5.1 `MenuPanel` + `RideRoutePanel` (TL 경로 메뉴)

- `MenuPanel.css`: `z-index: 50`, 좌측 슬라이드 드로어.
- 스크림: 열림 시 `opacity: 1`, 닫기 클릭으로 닫힘.
- 패널 본문: `rgba(15, 23, 42, 0.86)` + `backdrop-filter: blur(14px)` — **다크 글래스**.
- `locked`(라이딩/일시정지): `useEffect`로 열려 있으면 **강제 `onClose`** — 주행 중 메뉴로 경로를 바꾸는 실수 방지.

`RideRoutePanel`은 탭(경로 / 저장된 경로 / 심사 등), 경로 생성, **내 경로로 저장** 플로우, 라이딩·코칭·BGM 설정을 담는 **기능 밀도 높은 폼**이다.

### 5.2 `MapViewSheet` (BC 맵 설정)

- `MapViewSheet.css`: `z-index: 30`, 하단에서 올라오는 **바텀 시트**.
- 맵 스타일(칩), 노선 커버리지(OSRM/Mapillary), 3D, 카메라 팔로우 모드, 줌 슬라이더.
- 라이딩 중에도 열 수 있도록 설계(맵 조작과 직교).

### 5.3 `UserInfoSheet` (TR 사용자)

- `UserInfoSheet.css`: `z-index: 55` — 메뉴(50)보다 위, 인증 게이트(80)보다 아래.
- 우측 슬라이드, 다크 시트 톤, 통계·최근 주행(시트 닫으면 접힘 리셋) 등.

### 5.4 `RideSummarySheet`

- `RideSummarySheet.css`: 루트 `z-index: 25` — HUD(5)보다 위, 메뉴(50)보다 아래인 편이라 **다른 시트와 겹침 정책**을 읽을 때 참고.
- 주행 결과 + ad-hoc **내 경로로 저장** 안내.

### 5.5 `AuthGateCard`

- `AuthGateCard.css`: `z-index: 80` — 로그인/닉네임 단계에서 **맵·HUD 위 풀스크린**.
- 그라데이션 반투명 배경 + 블러, 중앙 **라이트 카드**(`#f8fafc`)로 대비 반전 — **게이트만 읽히게** 하는 의도.

### 5.6 `RotateOverlay`

- `RotateOverlay.css`: `z-index: 200` — 최상단.
- `@media (orientation: portrait) and (max-width: 900px)` 에서만 표시 — **스마트폰 세로 모드 차단**, 가로 UX 유도.

### 5.7 Mapillary 거리뷰 플로팅

- `App.css`: `.mapillary-street-floating` `z-index: 1005` — 시트·HUD 위에 떠 있는 **영상 오버레이**.

## 6. MapView: 맵 위 레이어·글래스 팝업

파일: `MapView.tsx`, `MapView.css`

### 6.1 마커 z-index 스택

- 일반 마커 / 핀 / 라이브 라이더 / 동행 마커 순으로 **레이어 높이를 단계적으로 지정**해 가려짐을 방지.
- Mapbox 기본 팝업은 z-index 미설정인 경우가 있어, **픽업 팝업**에 대해 `.map-view .mapboxgl-popup { z-index: 30 }` 등으로 명시.

### 6.2 지도 클릭 픽 팝업(출발·도착·경과)

- `mapboxgl.Popup`에 `className: map-view__pick-popup`.
- `MapView.css`: 팝업 콘텐츠에 반투명 짙은 배경, `backdrop-filter: blur(16px)`, 라운드, 테두리, 꼬리(tip) 색을 본문과 맞춤.
- 버튼은 필(pill) 형태, 출발/도착/경과(최대 3) 등 **짧은 라벨** + 호버 시 시안/보라/앰버 계열 강조.

### 6.3 경과지 마커

- 커스텀 DOM 마커(번호 원), `map-view__pin-marker`와 함께 쌓임 순서에 포함.

## 7. 색·타이포·접근성 공통 방향

- **다크 UI:** 슬레이트 900~950, 텍스트 `#f8fafc`, 강조 `#38bdf8`(sky).
- **라이트 카드:** 인증 게이트 등 일부 구간은 `color-scheme: light`로 입력·버튼 가독성 확보.
- **safe-area:** HUD 패딩에 `env(safe-area-inset-*)` 반영 — 노치·홈 인디케이터 대응.
- **키보드:** `MenuPanel`, `MapViewSheet`, `UserInfoSheet` 등에서 **Escape**로 닫기 처리.

## 8. 제품 정책과 UI의 연결 (저장)

- 경로 **생성**은 Mapbox Directions 호출로 **메모리·맵 표시만** 갱신.
- **내 경로로 저장**은 이름 입력 후 **`window.confirm`** 등으로 한 번 더 확인한 뒤에만 `saveRouteToFirestore` / `saveRouteToLocal` 호출.
- 문구·버튼 라벨·안내 문단(`ride-panel__save-policy` 등)으로 **“생성 ≠ 저장”**을 화면에 명시.

## 10. 정리

현재 웹 앱의 화면 구성은 **“풀스크린 맵 + 슬롯 HUD + 필요 시만 열리는 글래스 시트”** 패턴으로 정리되어 있다.  
구현상 핵심은 (1) **HUD 루트의 `pointer-events: none` / 자식 `auto`**, (2) **오버레이 z-index가 인터랙션을 덮지 않도록 하는 순서 관리**, (3) **stage와 rideLocked로 노출·입력을 제한**하는 세 가지이며, 일시정지 스크림 사례는 **z-index 한 줄이 UX 전체를 막을 수 있음**을 보여 주는 레슨 learned로 남길 만하다.
