## 실행기 diff

앱 코드·벤치 페이지·시험 파일은 건드리지 않았다. 변경은 `apps/web/scripts/rider-preserve/rider-perf-bench.run.mjs` 뿐. 이 파일은 브랜치에서 untracked 라 `git diff` 는 비어 있다. 추가한 동작:

- `RTW_BENCH_OUT` 가 비어 있으면 출력 폴더는 기존과 같이 `p0`.
- `RTW_BENCH_MODEL` 이 있을 때만 페이지 URL 끝에 `&riderModel=<값>` 을 붙인다. 없으면 URL 문자열은 기존과 같다.
- 시작 로그에 폴더 이름과 모델 값을 한 줄 찍는다.

```diff
 const here = path.dirname(fileURLToPath(import.meta.url));
-const outDir = path.join(here, ".out", "rider14", "p0");
+// RTW_BENCH_OUT: 출력 폴더 이름. 비어 있으면 p0 (기존과 같은 경로).
+const outDir = path.join(here, ".out", "rider14", process.env.RTW_BENCH_OUT || "p0");

 console.log(`base=${BASE}`);
+console.log(`out=${path.basename(outDir)} model=${process.env.RTW_BENCH_MODEL || ""}`);

 function benchUrl(zoom, riders, animate) {
+  const model = process.env.RTW_BENCH_MODEL;
   return (
     `${BASE}/scripts/rider-preserve/rider-perf-bench.html` +
     `?zoom=${zoom}&pitch=67&bearing=-32&riders=${riders}&animate=${animate}` +
+    (model ? `&riderModel=${model}` : "")
   );
 }
```

## 이상 사항

- s5 의 드로우콜 213, 삼각형 53,514, 자산 1,983,526 B 는 P0 과 같다. ms/rider 는 줌마다 다르다. z22 +5.1% (1.524 vs 1.45), z19 −13.9% (1.532 vs 1.78), z17 −3.1%, z15 +5.8%. P0 z19 최대 프레임은 13.7 ms 였고 이번 s5 는 7.3 ms 다.
- 줌 15 지도 몫 드로우콜이 회차마다 1–2콜 움직인다 (P0 1,316, s5 1,318, rider14 a 1,315, b 1,317). 라이더 1명당 콜·삼각형은 정수로 고정이다.
- rider14 자세 비율이 z22·z19 에서 약 84% 다. 절대 `poseMs` 는 s5 와 비슷하다 (z22: s5 552 ms, a 571 ms, b 548 ms / 240프레임). 비율이 오른 것은 전체 제출 시간이 줄어서다. z17·z15 는 P0 과 같이 자세 생략(0%).
- 첫 표시는 나중 회차(b)가 더 짧다. a +6.1%, b −2.6%. 둘 다 +10% 안.
- 스마트폰 실기기 측정은 하지 않았다.
