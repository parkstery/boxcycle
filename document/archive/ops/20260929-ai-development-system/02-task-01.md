# 작업지시 01 — 파일 기반 handoff 시험

- 담당: Cursor CLI Developer
- 상태: `READY_FOR_DEVELOPMENT`
- 허용 범위: 이 묶음에 **`03-result-01.md` 한 파일만 새로 작성**한다.
- 금지: 기존 파일 수정, 앱 코드 수정, Git commit/push, 배포, 추가 자동화, 장시간 대기.

## 할 일

이 지시 파일과 `document/ops/README.md`를 읽고 다음을 `03-result-01.md`에 사실대로 기록한다.

1. 읽은 파일의 정확한 저장소 상대 경로.
2. 이 지시의 허용 범위와 금지 범위를 한두 문장으로 요약.
3. `git status --short`를 실행해 **작업 전 상태**를 기록. 기존 변경을 자신의 변경이라고 주장하지 않는다.
4. 결과 파일을 작성한 뒤 그 파일이 존재하는지 확인하고, 확인 방법과 결과를 기록.
5. 테스트·빌드가 불필요한 이유 또는 실행했다면 실제 명령과 결과.

완료 조건: 결과 파일이 생성되고, 위 다섯 항목이 정확하며, 다른 파일이 Cursor CLI에 의해 변경되지 않는다. 막히면 실패 원인을 결과에 기록한다. Chief 승인 대상은 없다.
