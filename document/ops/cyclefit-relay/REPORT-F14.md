## 2. §2-1 감리 원인 분석 검증 — **맞다. 다만 각도 정의가 나와 달랐다**

감리 §1: *"`ANKLE_BACK` 이동이 각도 변화의 전부이고, 되돌리면 함께 사라진다."*
**검증 결과 맞다.** 되돌린 뒤 축 기울기가 13.31° 로 정확히 복귀했고 다른 잔차는 없다.

### 2-1. 각도 정의 차이 — 결론은 같다

감리 13.31°/15.34° 와 내가 F13 §6-3 에서 보고한 10.31°/12.25° 는 **기준점이 다르다.**

| 정의 | F12/F14 | F13 | 델타 |
|---|---|---|---|
| **감리** — 발목 → **밑창**(발목 아래 22.0) | 13.31° | 15.34° | **+2.03°** |
| **내 F13 보고** — 발목 → 접점 centroid(아래 16.92/17.42) | 10.31° | 12.25° | **+1.95°** |

```
atan(22.00 / 93.03) = 13.31°     atan(22.00 / 80.20) = 15.34°   ← 감리 값 재현
atan(16.92 / 93.03) = 10.31°     atan(17.42 / 80.20) = 12.25°   ← 내 값
```

**둘 다 유효하고 델타(≈2.0°)가 같으므로 원인 분석은 동일하다.**
감리 정의가 "밑창이 페달에 대해 이루는 각"이라 사용자가 본 현상에 더 가깝다 —
그래서 **하네스 계측을 감리 정의로 추가**했다(`[발기울기]` 로그, §3-2).

### 2-2. "되돌리면 저절로 사라진다"도 맞다

별도 각도 보정 로직을 **추가하지 않았다.** `ANKLE_BACK` 복원만으로:

```
[발기울기] L 발목→밑창 22.00mm / 발목앞 93.03mm → 축 기울기 13.31°
[발기울기] R 발목→밑창 22.00mm / 발목앞 93.03mm → 축 기울기 13.31°
[BDC우] 발최저 [−121.006, 107.155, 96.31] / 페달최저 [0, 74, 88] / 수직거리 8.3mm
```

F13 의 18.5mm → **8.3mm** 로 F12 값 복귀. 뒤꿈치 들림이 사라졌다.

## 6. 이견

### 6-1. 각도 정의를 하나로 고정하기를 요청한다

§2-1 대로 "발 기울기"에 두 정의가 공존한다(13.31° vs 10.31°). 이번엔 감리 정의를
하네스에 넣어 통일했지만, **다음부터 각도를 합격 기준으로 쓸 때는 기준점을 명시**해
달라. F12 §7-1 의 몸통각(joints TA 52 vs 렌더 실측 44.66)과 같은 종류의 혼선이다.

### 6-2. 그 외 이견 없다

감리 §1 원인 분석·§2 취소 범위·§2-3 대조표 모두 정확했다. 되돌리기가 "수정"이 아니라
"취소"로 충분하다는 판단도 실측으로 확인됐다 — 별도 보정 로직을 넣지 않았고 넣을 필요도 없었다.
