## 1. 반증 §1-0 — 결과

### 1-1. ① 무릎 양단 캡 — **통과 (진행해도 좋다)**

왼무릎 **하나만** 양단 캡으로 바꾼 임시 GLB(`t1-kneeL.glb`)를 만들어 8위상 × 방위 4에서 쟀다.

| | 무릎 L (적용) | 무릎 R (**미적용 대조군**) |
|---|---|---|
| BEFORE 잘록함 | **42px** | 39px |
| AFTER 잘록함 | **23px** | 39px (불변 ✔ 대조군이 안 움직였다) |

**−45%.** 그림도 §0 표대로 확실히 좋아졌다. 감리 진단(«세그먼트 끝마다 캡»)이 맞다.

### 1-2. ② 반바지 껍질 −15mm — **반증. 이 처방으로는 안 된다**

| | 허리 단차 중앙값 | 최대 |
|---|---|---|
| BEFORE | **22.2mm** (감리 수치와 **일치**) | 76.8mm |
| AFTER (−15mm) | 16.3mm (목표 ≤8mm **미달**) | **83.8mm — 악화** |

**그림이 결정적이다**(`W_OFF15_palette_rear.png`): 반바지가 몸통 껍질 **안으로 들어가** 엉덩이
맨살이 통째로 드러났다. 이유는 실측에 있다 — 반바지가 몸통 밖으로 나온 양은 **대역마다 다르다**:

```
y  60~ 80  중앙값  4.1mm      ← 여기서 15mm 당기면 몸통 속으로 11mm 파묻힌다
y 120~140  중앙값 15.7mm
y 140~160  중앙값 25.3mm
y 180~200  중앙값 28.1mm      ← 턱은 여기다
```

**균일 오프셋은 쓸 수 없다.** 턱은 **윗단(y≳150)에만** 있는데 균일하게 당기면 아랫부분이
몸통을 뚫는다. → §5-1 에 대안을 올린다.

### 1-3. ③ 살색 면 2건의 정체 — 하나는 **위치가 다르다**

`W_BEFORE_src_rear.png` 에서 출처를 색으로 갈랐다(초록=`torso` 껍질 맨살 · 마젠타=F35 절단 뚜껑).

| 감리 관찰 | 실측 정체 | 판정 |
|---|---|---|
| 후방 «반바지 **최상단** 뒤쪽 살색 가로 띠» | **최상단이 아니라 «밑단» 뒤쪽**이다. 반바지 하단이 엉덩이를 못 덮어 **몸통 껍질의 맨살**이 드러난 것(초록) | 현상 있음 · **위치 정정** |

### 1-4. 【중대·반증】 팔꿈치는 «캡 공백» 문제가 아니다 — `arm_l` 이 파편이다

지시 §0-1 이 인용한 *"상완 끝 74.3mm 위 · 전완 시작 63.9mm 위 → 10.4mm 빈다"* 는
`add-joint-caps.mjs` **머리말의 F25 시점 기록**이다. 현 제품 GLB 를 다시 재면 다르다:

```
팔꿈치 L/R   상완 끝 관절+59.8mm · 전완 시작 관절+60.9mm  →  **1.0mm 겹침 (공백 아님)**
무릎 L       허벅지 끝 관절+22.6mm · 정강이 시작 관절−39.6mm  →  공백 62.2mm
무릎 R       허벅지 끝 관절−12.6mm · 정강이 시작 관절−39.6mm  →  공백 27.0mm  ← **좌우가 다르다**
```

그리고 `arm_l` 메시 자체가 사지가 아니다:

```
arm_l        정점 164 · 삼각형 201 · y링 51개인데 **대부분 정점 1~2개**  ← 링이 아니라 파편
             x폭이 0·14·27·36·44·19·58… 로 널뛴다. y −212~−276 구간은 **고립 정점 1개씩**
leg_l_shin   정점  81 · 삼각형 140 · y링 **4개 × 각 20정점** (107→115→90→65mm)  ← 정상 튜브
```

`ISO_arm_l_side.png` 를 보면 **비틀린 얇은 조각**이고, 팔의 부피는 사실상 `arm_l_fore`(479정점)가
그리고 있다. **강체 분해가 상완 가중치 영역을 제대로 못 가져왔다.**
→ 팔꿈치에 캡을 달아도 «로봇»은 안 없어진다. 게이트 14 도 팔꿈치 잘록함을 **0px** 로 잰다
(잘록할 «상완»이 없으니 당연하다). **F36 의 팔꿈치 항목은 재설계가 필요하다** — §5-2.

⚠ **게이트 14 를 만들며 내 지표가 두 번 틀렸다. 기록한다:**
1. 처음엔 «세그먼트 정상폭 − 관절 최소폭» 으로 쟀다 → 사지는 관절로 갈수록 원래 가늘어지므로
   **정상 테이퍼를 결함으로 셌다.** 양단 캡으로 그림이 좋아졌는데 45px→44px 로 안 움직였다
   → **국소 오목함(local dip)** 으로 바꿨다
2. 프로파일 키를 `Math.round(t/step)*step` 으로 찾았는데 표본이 홀수라 **전부 miss → 폭 0 →
   거짓 «단절 74px»** 이 났다. 모든 관절이 똑같이 74px 로 나온 게 단서였다
둘 다 소스 주석에 박아뒀다.

## 5. 이견·권고 (선택은 감리가)

### 5-1. 【권고】 허리 — 균일 오프셋 대신 **윗단만 국소 보정**

| 안 | 내용 | 근거 |
|---|---|---|
| **A. 윗단 링만 안으로 + 아래로 갈수록 0 으로 감쇠**(권고) | y≳150 구간의 반바지 정점만 −18mm 당기고 y 120→150 에서 선형 감쇠 | 턱이 y≥150 에만 있다(§1-2 대역표). 아랫부분을 안 건드리므로 몸통 관통이 없다 |
| B. 저지 밑단을 아래로 연장해 반바지 윗단을 덮는다 | 저지 껍질(몸통 껍질 소속)을 늘린다 | 반바지를 안 건드려 안전하나 실루엣은 커진다 |
| C. 반바지 윗단 링을 저지 밑으로 «말아넣기» | 윗단 정점만 y −25mm · 안으로 −10mm | 실제 옷의 밑단 처리와 같다. A 와 병행 가능 |

**A + C 를 권고**한다. 어느 쪽이든 **±5mm 단위로 훑어 픽셀로 고르는** 절차를 붙이겠다(F35 절단 높이와 동일).

### 5-2. 【이견】 팔꿈치는 이번 지시 범위로는 못 고친다

`arm_l` 이 파편인 이상 캡·오프셋으로는 «로봇»이 안 없어진다. 선택지:

| 안 | 내용 | 비용 |
|---|---|---|
| **A. 상완을 절차적 원통으로 대체**(권고) | `arm_l/r` 메시를 어깨→팔꿈치 캡슐로 교체(팔레트 피부색). 노드·길이·IK 계약 불변 | 중. `add-joint-caps-v2` 의 타원체 생성기를 그대로 쓴다 |
| B. 강체 재분해로 상완 가중치 복구 | `decompose-v2-rider.py` 재실행 | **큼 — F31~F35 성과(발–페달·스텁)를 전부 다시 태운다. 반대한다** |
| C. 이번엔 무릎만 하고 팔꿈치는 이월 | | 0 |

**A 를 권고**하되, 지시 §3 이 「팔 비율·어깨 이음매」를 금지하므로 **감리가 명시적으로 허용해야** 착수한다.

### 5-3. 【이견】 지시 §0-1 A 의 근거 수치는 **F25 시점 기록**이었다

*"팔꿈치 상완 끝 74.3 ↔ 전완 63.9 → 10.4mm 빈다"* 는 `add-joint-caps.mjs` 머리말이고,
그 뒤 F26(발목 분리 재분해)·F34·F35 로 메시가 세 번 바뀌었다. **현재는 1.0mm 겹침**이다.
감리가 무릎에 대해 *"F29 의 24.1mm 를 믿지 말고 다시 재라"* 고 한 것과 **같은 이유가 팔꿈치에도
해당한다** — 지시서가 그 경고를 무릎에만 붙였다.
