## 1. 감리 수치 검산 — **§1-1 진단이 절반만 맞았다**

### 1-1. 【이견】 `torso` 평균 31.4mm 는 큰 영역을 가린다

감리는 `torso` 를 **통째로 427mm²/한 변 29mm** 로 보고 "몸통은 문제없다"고 했다.
**UV 팔레트 색으로 영역을 갈라 재니 다르다:**

```
저지    삼각형  528   삼각형당 873mm²   한 변 44.9mm   ← 목표 초과
팬츠    삼각형  432   삼각형당 626mm²   한 변 38.0mm   ← 목표 초과 · 갑옷의 주범
피부    삼각형 1712   삼각형당 375mm²   한 변 29.4mm
암부    삼각형  450   삼각형당 310mm²   한 변 26.7mm
헬멧빨강 삼각형  324   삼각형당 297mm²   한 변 26.2mm
```

평균 31.4mm 는 피부·암부(1,712+450 삼각형)가 커서 희석된 값이다.
**반바지 38.0mm 는 목표를 27% 넘겼고, 그림에서 갑옷으로 보인 것이 정확히 이 영역이다.**
감리 §1-2 가 "반바지 160정점" 을 짚은 것은 맞았으나, §1-1 의 삼각형 표에는
반영되지 않아 §2-2 대상이 "허벅지 위주"로 읽혔다.

## 2. 한 일

### 2-1. 패브릭 광택 — `set-fabric-roughness.mjs`(신규)

**G 채널만** 바꾼다. R(occlusion)·B(metallic) 불변. UV 하드코딩 없이 **baseColor 색으로** 텍셀을 찾는다.

```
#9e4d48 256텍셀 0.600→0.850   #2c5576 256 0.420→0.850   #b82429 256 0.302→0.850
#163c45 256 0.180→0.850       #8c050a   9 0.380→0.850
피부 #bc9179 — 유지(약간 광택이 정상)
```

정점·지오메트리·노드 불변 확인.

### 2-2. 세분화 — `subdivide-mesh.mjs`(신규) · Loop 1단계

새 정점을 이웃 평균으로 당기는 **진짜 Loop**다(선형 분할 아님).
edge점 3/8+1/8, 기존점 β = (1/n)(5/8 − (3/8 + ¼cos(2π/n))²), 법선 재계산.

| 대상 | 정점 | 삼각형 | **한 변** |
|---|---|---|---|
| `leg_l` 허벅지 | 141 → 535 | 256 → 1,024 | **56.5 → 27.0mm** |
| `leg_r` 허벅지 | 141 → 535 | 256 → 1,024 | **56.5 → 27.0mm** |
| `torso` **반바지 영역만** | 2,899 → 3,547 | 3,794 → 5,090 | 영역 **38.0 → 18.4mm** (torso 전체 31.4 → 27.0mm) |

**`torso` 를 통째로 쪼개면 +8,697 로 예산 3,000 을 3배 초과한다.**
지시 §2-2 "초과하면 대상을 좁혀라" 에 따라 **팔레트 색(`#8c050a`)으로 반바지 432삼각형만** 골랐다.

**부분 세분화의 함정(T-junction)을 두 겹으로 막았다:**
1. 선택 **경계** edge 는 Loop 가중치 대신 **정확한 중점**, 양 끝점은 **고정** → 새 정점이 원래 선분 위에 정확히 놓인다
2. 남는 T-vertex 는 이웃 비대상 삼각형을 **부채꼴 분할**(새 정점 0개)

**실측 검증 — 틈이 벌어지지 않았다:**
```
원본 torso 정점 2,899 · 위치중복(UV seam) 그룹 355
세분화 후 갈라진 seam 그룹 1 · 최대 벌어짐 0.000mm
이동한 기존 정점 218 · 최대 이동 15.16mm   ← 반바지가 둥글게 말린 양
```
