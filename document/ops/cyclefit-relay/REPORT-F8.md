| 지표 | 값 |
|---|---|

## 7. 이견

**1. 무릎 10° 목표 자체를 재검토해야 한다고 본다.**
사용자 방식("BDC 에서 거의 펴다시피, 10°만 굽힌다")은 실제 피팅 절차로 타당하다. 다만
**이 라이더의 다리(730.4mm)는 175cm 표준의 85%** 라, 10° 를 만족하려면 안장이 990mm 대로
가고 그러면 IK 가 도달하지 못한다(발 오차 250mm). 즉 **10° 는 이 모델에서 물리적으로
달성 불가능한 목표**다. 세 선택지 중 하나가 필요하다고 본다:
- ① 목표를 **25~30°**(실제 라이더 표준)로 완화 → 안장 713~705mm 대, 현재 725 와 근접
- ② 라이더 **scale 을 키워** 다리를 늘린다(0.88 → 1.0 이면 다리 830mm)
- ③ **crankLength 를 줄여** BDC 를 올린다(172.5 → 165 이면 BDC z 105.5)
사용자가 ③을 "그 때 고려"라 했으므로, ① 또는 ②가 먼저라고 본다.

**2. 좌골 실측 88mm vs F2 110mm — 정본을 정해야 한다.**
포즈 차이(rest vs 라이딩)로 22mm 벌어진다. `hipDrop` 은 "안장에 앉았을 때" 값이므로
**라이딩 포즈 기준인 F2 110mm 가 더 타당할 수 있다.** 다만 이번 지시가 rest 실측을
명시해 rest 값으로 보고했다. 어느 쪽을 쓸지 감리가 정해주면 F9 에서 반영하겠다.

**3. 역계산에 IK 도달 검증을 붙일 것을 다시 제안한다.**
F6·F8 두 번 모두 "역계산이 낸 높이에 IK 가 도달하지 못하는" 같은 결과가 나왔다.
역계산 직후 **해당 안장 높이로 IK 를 돌려 실측 무릎각을 목표와 대조**하고, 어긋나면
역계산을 채택하지 않는 절차를 넣으면 이런 왕복이 없어진다. F9 에 포함하기를 제안한다.
