### 1-1. 페달 판 — 감리 진단 그대로였다

```
판 월드 법선 = Rz(90 + crankDeg + pedalDeg) · (0,1,0)
현행  pedalDeg = −crankDeg      → 합계 90°  → (−1,0,0)  **수직** ✘
수정  pedalDeg = −crankDeg − 90 → 합계  0°  → ( 0,1,0)  **수평** ✔
```

**판 로컬 법선은 가정하지 않고 실측했다**(§3-1 요구):

```
pedal_l 메시  AABB 70.0 × 20.0 × 50.0mm   → 얇은 축 = y
면 군집(면적순)  3500mm² 법선 [0, 1, 0]   ← 판면
                3500mm² 법선 [0,−1, 0]
                1400mm² 법선 [0, 0, 1]
```

감리 가정 `(0,1,0)` 과 **일치**. 게이트 11 은 노드 계층을 실제 합성해(crank matrix rest
포함) 법선을 구한다 — 4위상 × 좌우 **전부 0.00°**.

## 2. §3-2 밑창 면 특정 — **미착수**

**이유를 정직하게 쓴다: 시간·작업량 배분에 실패했다.** §3-1 을 마치고 게이트 11 을
만들어 앱 확인까지 한 뒤 남은 여유가 부족했다.

감리 §2-2 의 방법(삼각형별 법선·면적 → 아래쪽 면 군집 → 최대 면적 군집을 밑창으로)은
**타당하다고 판단한다.** F28 §2-1 에서 내가 올린 소견과 같은 방향이고,
페달 판 법선을 같은 방식(면적 가중 군집)으로 실측했더니 `[0,1,0]` 이 깔끔하게 나왔다 —
**그 방법이 작동한다는 예비 증거**다.

`S` 좌우 불일치(135.74 / 205.26mm)는 **여전히 미해결**이다.

## 3. §3-3 관절 캡 재설계 — **미착수**

감리 §2-3 의 진단(캡이 세그먼트 끝에서 너무 가늘고 팔꿈치는 아예 안 닿는다)과
해법(관절 중심 구 1개 → **세그먼트 끝마다 그 세그먼트 반경의 캡**)은 **F28 §4 의 내
소견과 정확히 맞물린다.** 옛 라이더가 실제로 그 구조였다는 실측 근거도 있다
(`leg_l` 100+86 · `leg_l_shin` 72+52).

**착수하지 못했다.** 캡 반경을 세그먼트 끝 단면 실측으로 정하고 겹침을 수치로 확인해야
하는데, 그 작업을 시작할 여유가 없었다.
