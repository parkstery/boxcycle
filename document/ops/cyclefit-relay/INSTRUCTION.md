## 1. 감리 진단 — **재질이 아니라 형상이다.** 정량화했다

앞서 감리는 *"광택(roughness) 이 유력하다"* 고 했다. **절반만 맞았다.**
실측하니 **삼각형이 너무 크다** — 그게 주원인이고 광택은 그 위에 얹힌 것이다.

### 1-1. 삼각형 크기 — 허벅지가 몸통의 **3.2배**

```
torso    삼각형 3,794   표면적 1,621,898mm²   삼각형당  427mm²  → 한 변 약 **29mm**
leg_l    삼각형   256   표면적   354,148mm²   삼각형당 1,383mm² → 한 변 약 **53mm**
```

**화면에서 얼마나 큰가**: 사용자 스크린샷에서 라이더 전고 약 430px = 약 **3.9mm/px**.

```
허벅지 삼각형 한 변 53mm  →  약 **14픽셀**    ← 평면 조각이 또렷이 보인다
몸통   삼각형 한 변 29mm  →  약 **7픽셀**
```

**14픽셀짜리 평면 패널들이 이어진 것 — 그것이 "갑옷" 이다.**

### 1-2. 반바지도 같은 문제

```
torso 하부(엉덩이·반바지) 306정점 중 팬츠(#8c050a) **160정점**
```

엉덩이·반바지 전체가 **160정점**이다. 큰 평면 몇 장으로 덮여 있다.

### 1-3. 배제한 것 — 실측으로 확인했다

| 후보 | 실측 | 판정 |
|---|---|---|
| 하드 엣지(분리 노멀)로 각져 보인다 | 반바지 306정점 / 고유위치 306 · 허벅지 141/141 → **분리 0개** | **아님** |
| 금속 재질 | `metallic` 텍스처 B = **0** | **아님** |
| 고관절 이음매 공백 | 허벅지 상단이 몸통 안으로 **251.8mm 파묻힘** | **아님** |
| **광택** | roughness 팬츠 **0.38** · 저지 0.42 (실제 의류 0.80~0.95) | **부차 원인** |
| **삼각형 크기** | 허벅지 한 변 **53mm ≈ 14px** | **주원인** |

### 1-4. 뿌리 — 원본 V2 의 폴리곤 배분

```
원본 V2 전체   5,477정점 / 6,874삼각형
그중 허벅지    141정점 /   256삼각형   (2.6% / 3.7%)
```

원본이 **반바지에 가려지는 허벅지에 폴리곤을 아끼는** 저폴리 모델이다.
우리가 강체로 분해해 노출시키면서 그 거칢이 드러났다. **모델 잘못이 아니라 용도 차이다.**

## 2. 지시 — **1 → 2 → 3 순서. 각 단계마다 사진을 찍어라**

**§1(항구 규율): 게이트와 무관하게 매 단계 촬영한다.** 시간이 부족하면 **3 을 남겨라.**

### 2-1. 【먼저·5분】 패브릭 광택을 낮춘다

팔레트 `rtw_palette_metalrough` 의 **G 채널(roughness)만** 올린다. B(metallic)=0 유지.

```
팬츠 0.38 → 0.85       저지 0.42 → 0.85       피부 0.62 → 유지
```

- 텍스처 1장 교체. 지오메트리·정점·게이트 **불변**임을 확인하라
- **before/after 를 같은 위상·같은 카메라로** 찍어라 ← 이것만으로 얼마나 달라지는지 본다

### 2-2. 【핵심】 허벅지·반바지를 **세분화하고 매끄럽게** 만든다

목표: **삼각형 한 변을 몸통 수준(≈29mm) 이하로.**

- 대상: `leg_l` · `leg_r`(허벅지) + `torso` 의 **하부(엉덩이·반바지) 영역**
- 방법은 네가 정하라. 두 경로가 있다:
  - **(A) GLB 후처리** — `add-joint-caps.mjs` 와 같은 계열의 스크립트로 대상 메시만
    **Loop 세분화 1단계 + 노멀 재계산**. 파이프라인을 다시 안 태워도 된다
  - **(B) 분해 전 Blender 에서** Subdivision Surface 1단계 + Shade Smooth 후 재분해.
    더 매끄럽지만 파이프라인 6단계를 다시 태워야 한다
- **감리 권고는 (A)** — F33 으로 겨우 선 상태를 다시 태우고 싶지 않다.
  (A) 로 부족하면 (B) 를 다음에 한다
- ⚠ **선형 세분화만 하면 각짐이 그대로다.** 새 정점을 이웃 평균 쪽으로 당겨
  **실제로 둥글게** 만들어라(Loop/Catmull-Clark 계열)
- **정점 예산**: 라이더 본체 증가분이 **+3,000 이내**. 초과하면 대상을 좁혀라

### 2-3. 【그 다음】 관절 캡을 세그먼트 끝마다로 재설계 (F29 §2-3 이월)

현재 캡은 **관절 중심에 구 1개**라 세그먼트 끝에서 급격히 가늘어진다:

```
무릎—정강이쪽  캡r 48 @ 거리 39.6 → 그 지점 단면 27.1  vs 정강이 51.2  → **단차 24.1mm**
팔꿈치—전완쪽  캡r 46 @ 거리 63.9 → **캡이 전완에 닿지도 않는다**
```

→ **각 세그먼트의 끝마다 그 세그먼트 반경의 캡**(옛 라이더 방식: leg 100+86 · shin 72+52).
두 캡이 관절에서 **겹치는지 수치로 확인**하고 보고하라.

### 2-4. 【필수】 촬영

| 컷 | 목적 |
|---|---|
| **엉덩이·허벅지 클로즈업** before/after (§2-1, §2-2 각각) | 사용자 판정 정본 |
| 측면 전체 · 정면 전체 (일시정지) | 전체 인상 |
| 무릎·팔꿈치 클로즈업 before/after (§2-3) | 관절 단차 |
| 발–페달 4위상 | **회귀 확인** — F33 성과가 유지되는지 |
