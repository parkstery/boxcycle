## 1. 이견 판정

### 1-1. 【C-2 승인】 `S = 19.69mm` 를 채택한다. `ANKLE_UP = 29.69`

**감리 기준 "30mm 대"가 틀렸다.** 그 수치는 F25 §4-1 의 *"발바닥 최저점 = 발목 아래
28.3mm(뒤꿈치)"* 에서 왔는데, 그건 **기울어진 자세에서의 최저점**이지
**수평 정렬된 밑창 평면까지의 수직거리**가 아니다. 기운 발은 뒤꿈치가 더 내려가므로
28.3 > 19.69 는 **당연하다.**

채택 근거:

```
좌우 S 편차 0.00mm · 밑창 면적 42,910.2mm² 좌우 동일 · 법선 정확히 (0,−1,0)
발 두께 63.82mm 좌우 완전 일치 → 발목이 두께의 31% 지점 (해부학적으로 타당)
```

**`ANKLE_UP = S + 10 = 29.69` 로 간다.** 감리가 정방향 검산했다:

```
                    최대 필요 도달   여유
ANKLE_UP 37.00       712.5mm       17.9mm   (현재)
ANKLE_UP 29.69       719.8mm       10.6mm   ← 다리 합 730.4mm, 도달 가능 ✔
```

**여유가 17.9 → 10.6mm 로 줄지만 도달한다.** 네가 다시 재서 대조하고,
**10.6mm 와 다르면 반증을 먼저 보고**하라.

### 1-2. 【A 승인】 z 7.71mm 는 정렬 문제가 아니다 — **관문 기준이 과했다**

감리가 F31 산출물의 좌우 쌍을 전수 검사했다:

```
leg_*_shin   114.96/264.00/102.08  vs  114.97/264.00/102.08   z 차 0.00mm
arm_*        115.49/326.07/122.10  vs  115.49/326.07/122.10   z 차 0.00mm
arm_*_fore    69.46/377.00/100.87  vs   69.45/377.00/100.87   z 차 0.00mm
leg_*        179.66/452.59/153.11  vs  180.57/487.85/153.04   y 차 35.26mm ← 예전부터
ankle_*      256.30/ 63.82/ 95.23  vs  258.45/ 63.82/102.94   z 차 7.71mm
```

**네 논거가 맞다** — 정렬이 틀렸다면 **y(두께)와 법선이 먼저 깨진다.** 그 둘이
`63.82mm 완전 일치` · `(0,−1,0) 정확`이므로 정렬은 옳다. 남은 z 는 **발 폭**이고,
`leg_*` 의 y 차 35.26mm 처럼 **경계 정점 귀속의 좌우 차이**다(이건 F16 분해 때부터 있었다).

**관문 A 를 정정한다** — 밑창 접지가 의존하는 것은 **y(두께)·법선·`S`** 뿐이다:

```
관문 A(정정)   ankle_* 의 **y(두께) 좌우 ≤2mm** + 법선 + S      ← x·z 는 판정 대상 아님
```

**완화가 아니라 측정 대상을 바로잡은 것이다.** 네 §5 제안과 같은 취지다.

> ⚠ **다만 기록해 둬라**: `leg_*` y 35.26mm · `ankle_*` z 7.71mm 의 좌우 비대칭은
> **미해결 항목**이다. 접지에는 무관하나 언젠가 원본 V2 의 좌우 대칭성을 재야 한다.
> **이번에 조사하지 마라.**

```

                  → merge-rider-into-cycle → rotate-rider-nodes → add-joint-caps

```
