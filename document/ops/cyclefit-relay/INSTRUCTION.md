## 0. 사용자 지시 (원문)

> 신발의 길이, 폭, 두께는 내가 지시한 대로 치수가 줄어들었는데 **내가 지시한 바 없는
> 신발 각도 변화가 생겼다.** 앞에서 지시한 신발에 대한 변경 사항을 **취소한다.
> 원래대로 돌려 놓아라.**

사용자가 `PHASE_0_FOOT_L.png`·`RIDER_ONLY_FRONT.png` 를 직접 보고 지적했다.
**F13-A(신발 3축 축소)를 전면 취소**하라. F13-B(팔)·F13-C(손가락 조사)는 대상이 아니다.

## 1. 감리 원인 분석 — 취소 범위를 정확히 하기 위해

신발 **메시 자체는 지시대로 순수 축소됐다**(고정면 이동 0.000mm, 배율 0.9000 — 개발팀장
실측 정확). 사용자가 지적한 "각도 변화"는 메시 변형이 아니라 **접점 위치가 신발 축소를
따라 이동하면서 생긴 파생 효과**다.

```
접점(ANKLE_BACK) = 발 중심 = 발목 앞 (발길이 × 50%)

F12: 발길이 256.45 → ANKLE_BACK 93.03  → 발목→접점 축 기울기 13.31°
F13: 발길이 230.81 → ANKLE_BACK 80.20  → 발목→접점 축 기울기 15.34°   (+2.0°)
```

발이 짧아지니 "발 중심"이 발목 쪽으로 12.83mm 당겨졌고, 그 결과 발목에서 접점까지
이어지는 축이 더 가팔라져 **뒤꿈치가 들리고 발끝이 페달 쪽으로 기운 것처럼 보였다.**
이건 개발팀장이 F13 §0-2·§6-3 에서 이미 "신발 단축의 기하학적 필연"으로 보고한
바로 그 현상이다 — **당시엔 지시 범위 밖이라 그대로 뒀지만, 사용자는 이걸 원치 않는다.**

**결론: 신발 축소를 되돌리면 이 각도 변화도 함께 사라진다.** 별도로 손볼 것이 없다 —
그래서 이번 지시는 "취소"이지 "수정"이 아니다.

## 2. F14 지시 — F13-A 전면 원상복구

### 2-1. 되돌릴 것

| 파일 | 되돌릴 변경 |
|---|---|
| `apps/web/scripts/rider-cycle-fit/render-all.py` | `shrink_shoes()` 및 그 호출 전부 제거 |
| `apps/web/scripts/rider-preview/export-ik-joints-v2.mjs` | `ANKLE_BACK` **0.08020 → 0.09303** (F12 값으로 복원) |

**F13-B(상완 연장)·F13-C(손가락 조사 기록)는 그대로 둔다.** 사용자는 신발만 지적했다.
`resize_arm_bones()` · `elbow_measure()` · `ARM_ELBOW` · `ARM_ALT_PROPORTIONAL` 렌더는
건드리지 마라.

### 2-2. 방법 — 새로 계산하지 말고 git 이력을 써라

지금 워킹트리는 F11·F12·F13 이 전부 미커밋 상태로 쌓여 있다(`git status` 로 확인하라).
즉 **깨끗한 git diff 로 "신발 관련 부분만" 골라 되돌릴 방법이 마땅치 않다** — 커밋
단위가 아니라 파일 단위로 섞여 있기 때문이다.

**따라서 코드에서 직접 걷어내는 방식으로 하라**:

1. `render-all.py` 에서 `shrink_shoes` 함수 정의와 호출부를 찾아 **삭제**
   (관련 인자 `SHOE_SCALE` 등도 함께 정리)
2. `export-ik-joints-v2.mjs` 의 `ANKLE_BACK` 상수를 **0.09303** 로 되돌리고, 주석도
   F12 기준(발 중심 93.03, 발길이 256.45 의 50%)으로 복원
3. **`ANKLE_UP` 은 37.0 그대로** — 이건 애초에 F13 에서도 바뀐 적이 없다(F13 §6-2)

### 2-3. 검증 — 원상복구가 맞는지 F12 수치와 대조하라

| 항목 | F12(복원 목표) |
|---|---|
| 발길이 | 256.45 |
| 뒤꿈치 / 발끝 | 35.20 / 221.25 |
| `ANKLE_BACK` | 93.03 |
| 발목→접점 축 기울기 | **13.31°** |
| 페달축 위치 | 49.1% |
| BDC 무릎 | 25.93° |
| 발접촉 4위상 | 좌 0.0 / 우 0.0mm |

**전부 F12 REPORT-F12.md 의 수치와 소수점까지 일치해야 한다.** 하나라도 다르면
되돌리다 만 것이니 다시 확인하라.
