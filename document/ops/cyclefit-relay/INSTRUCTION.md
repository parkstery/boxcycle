## 0. 진행 방식 — **현재 창에서 계속한다**

사용자가 새 창 전환을 취소했다.

> **"새 창으로 넘어가는건 불안해서 안되겠다. (…) 현재 진행된 모델 수정 작업의
> 최종버전을 glb로 굽는 계획은 그대로 이 창에서 진행하자."**

**창을 닫지 마라. 지금 문맥 그대로 이어간다.** 인수인계 준비(HANDOFF §7 등)는 이미
해 둔 것으로 충분하니 더 손대지 마라.

당신이 `HANDOFF.md` §5-1·§7·§7-2 에 정리해 둔 내용은 정확하고 유용하다.
**특히 §7-2 재현 명령은 이 지시서 §4 에 그대로 옮겨 왔다.**

## 2. 【최우선】 "예전 모델" 사고를 기계적으로 막는다

사용자가 명시적으로 우려한 지점이다:

> **"개발팀장이 자꾸 예전 모델을 건드리는 문제가 생겨서"**

F15 에서 실제로 났다(감리가 잘못 지시했고 옛 절차적 라이더가 앱에 올라갔다).
**이번엔 주의력이 아니라 검증으로 막는다.**

### 2-1. 두 라이더를 다시 확인하라

| | **올릴 것 (V2)** | **올리면 안 되는 것 (옛 절차적)** |
|---|---|---|
| 출처 | `stylized_cyclist_v2_lod0.glb` + `decompose-v2-rider.py` | `generate-rider-prototype-glb.mjs` 의 라이더 부분 |
| 정점 | **5,477** | 다름 |
| 사지 | 허벅지 **378.40** · 정강이 **352.00** · 상완 **334.83** · 전완 **212.84** | 493 / 493 / 304 / 281 |

`generate-rider-prototype-glb.mjs` 는 **`RTW_RIDER=0` 자전거 전용으로만 쓴다.**
`RTW_RIDER` 를 안 주고 실행하면 옛 라이더가 딸려 나온다 — **그게 F15 사고다.**

### 2-2. 제품 이식 전 **신원 검증 게이트** — 하나라도 실패하면 이식 금지

제품 GLB 를 덮어쓰기 **직전에** 후보 GLB 를 파싱해 아래를 전부 확인하고
**로그에 찍어라.** 통과 못 하면 이식하지 말고 보고하라.

| # | 검사 | 기대값 |
|---|---|---|
| 1 | 노드 이름 | `crank` `torso` `leg_l` `leg_l_shin` `leg_r` `leg_r_shin` `arm_l` `arm_l_fore` `arm_r` `arm_r_fore` **10개 전부** |
| 2 | `skins` / `animations` | **0 / 0** (스킨드면 앱이 못 돌린다) |
| 3 | `leg_*_shin` 로컬 translation | **[0, −378.4, 0]** ±0.5 |
| 4 | `arm_*_fore` 로컬 translation | **[0, −334.8, 0]** ±0.5 |
| 5 | `leg_l` / `leg_r` z 부호 | **+81.4 / −81.4** (앱 `RIG_HIP_L` = glTF +z) |
| 6 | 라이더 정점 합 | **≈ 5,477** (V2 메시 서명) |
| 7 | 옛 라이더 서명 부재 | 절차적 라이더 특유 노드·정점수가 **없어야** 한다 |

**3·4·6 이 V2 인지 옛 모델인지를 가르는 결정적 지표다.**

## 3. F18-R1 작업

### 3-1. joints 재생성 — 현 SSoT 로

F16 산출물(`v2-rider-nodes.glb`)은 파생 방향 전환(`d296372`) **이전** 것이다.
**반드시 다시 굽어라.**

### 3-2. 강체 분해 → 자전거 병합

- `decompose-v2-rider.py` 재실행
- 자전거는 `RTW_RIDER=0` 으로 굽고 거기서 **`crank` 노드**를 가져와 병합
- 결과 노드 **10개**

### 3-3. `riderRig` 사지 길이 정합 — **빠뜨리면 앱에서 발이 뜬다**

앱 IK(`riderGlbPedalPose.pose.mjs`)는 `riderRig.geometry.mjs` 에서 사지 길이를
import 한다. **SSoT 한 곳만 고치면 된다.**

```
THIGH_LEN     0.493 → 0.37840
SHIN_LEN      0.493 → 0.35200
UPPER_ARM_LEN 0.304 → 0.33483
FOREARM_LEN   0.281 → 0.21284
PELVIS_HALF_Z 0.09  → 0.0814
```

하드코딩 복제 금지.

### 3-4. 제품 이식 → 앱 구동

1. §2-2 신원 검증 게이트 통과 확인
2. `.pre-F18.bak` 백업
3. 제품 경로에 이식
4. `cd apps/web && npm run dev` (`.env.local` 에 `VITE_RIDER_PROTOTYPE=glb` 설정됨)
5. **스크린샷 최소 4장**: ① 라이더 전신 ② 발–페달 확대 ③ 손–핸들 확대 ④ 콘솔
6. **주행 중** 크랭크가 돌고 다리가 따라가는지 확인 — **정지 화면만으로 판정 금지**
