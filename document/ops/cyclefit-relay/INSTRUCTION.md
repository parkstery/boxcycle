## 2. F18 지시 — 현 상태를 앱에 올린다

### 2-1. 라이더 — F16 강체 분해를 **현 SSoT 로 재생성**

F16 산출물(`v2-rider-nodes.glb`)은 파생 방향 전환(`d296372`) **이전** 것이다.
`decompose-v2-rider.py` 를 **다시 돌려** 현재 상태로 굽어라.

- 노드 9개 + **`crank` 추가 = 10개**
- 좌/우 매핑 유지: **앱 `_l` 노드 ← V2 `_R` 본**
- 피벗: `leg_*`=고관절 · `*_shin`=무릎 · `arm_*`=어깨 · `*_fore`=팔꿈치 · `torso`=골반

### 2-2. 자전거 — 최종 모델

```
RTW_RIDER=0 RTW_GLB_OUT=<후보경로>/cycle-only.glb node apps/web/scripts/generate-rider-prototype-glb.mjs
```

`geometry.json` 파생이므로 헤드튜브 85 · 시트튜브 560 · 안장 479.8 이 전부 반영된다.
**`crank` 노드는 여기서 가져온다.**

### 2-3. 병합 → 제품 이식

1. 자전거 + 라이더를 하나의 GLB 로. **노드 10개 전부 존재·이름 정확**
2. **후보 경로에서 먼저 검증**
3. 제품 경로 `apps/web/public/rider/prototype/rider-lowpoly.glb` 에 올린다
4. **백업 `.pre-F18.bak` 필수**

### 2-4. `riderGlbPedalPose` 사지 길이 정합 — **빠뜨리면 발이 페달에서 떨어진다**

앱 IK 는 옛 절차적 라이더의 사지 길이를 전제한다. V2 실측으로 맞춰라(F16 §5-1):

```
THIGH_LEN 0.493 → 0.37840      SHIN_LEN  0.493 → 0.35200
UPPER_ARM_LEN 0.304 → 0.33483  FOREARM_LEN 0.281 → 0.21284
PELVIS_HALF_Z 0.09 → 0.0814
```

`riderGlbPedalPose.pose.mjs` 는 `riderRig.geometry.mjs` 에서 import 하므로
**SSoT 한 곳만 고치면 된다.** 하드코딩 복제 금지.

### 2-5. 앱 구동

```
cd apps/web && npm run dev        # .env.local 에 VITE_RIDER_PROTOTYPE=glb 설정됨
```

- **스크린샷 최소 4장**: ① 라이더 전신 ② 발–페달 확대 ③ 손–핸들 확대 ④ 콘솔
- **주행 중** 크랭크가 돌고 다리가 따라가는지 확인. **정지 화면만으로 판정 금지**
- 콘솔 로그 전문 보고
