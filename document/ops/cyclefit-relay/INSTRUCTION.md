**F25 §4-2 의 네 소견이 옳다. 채택한다 — 원인은 발목 관절 부재다.**
이번에 **발목 노드를 추가해 끝낸다.** F25 가 "Blender·메시 재분해 금지" 때문에 멈춘 그 지점을
**이번 지시가 명시적으로 연다.**

### 【중요】 "전에는 되던 것"의 정확한 사실관계 — 보고서에 그대로 쓸 것

사용자가 기억하는 "되던 것"은 **Blender 렌더**(F10-R1~F14: 발–페달 4위상 좌우 0.0mm)다.
그건 **V2 스킨드 아마추어**로 낸 결과이고, 거기엔 `FOOT_*` 본이 따로 있어 **발목이 움직였다.**

**앱에서는 한 번도 된 적이 없다.**

```
Mapbox 는 스키닝 미지원(F15 실측: JOINTS_0·WEIGHTS_0·skins 전부 0건)
  → 강체 분해로 이식        → 그 과정에서 FOOT_*·TOE_* 가 leg_*_shin 에 흡수
  → 발목 관절이 사라졌다     → 발 각도가 정강이에 고정
옛 절차적 라이더도 발목 노드가 없었다(오버라이드 10개에 발이 없다).
그것이 그럴듯해 보인 건 GLB 가 고정 포즈로 구워져 있었기 때문이고,
F22 전까지는 노드 회전이 화면에 아예 반영되지도 않았다.
```

**즉 회귀가 아니라, 이 항목만 아직 이식되지 않은 것이다.** 정직하게 그렇게 보고하라.

### 2-3. 【3·핵심】 발목 노드를 추가해 **발바닥이 페달면과 항상 평행**하게 한다

**메시 재분해를 이번에는 허용한다.** F25 가 멈춘 제약을 해제한다.

#### (a) 분해 — `decompose-v2-rider.py` 의 `GROUPS` 를 고친다

```
현재  "leg_l_shin": ["SHIN_"+BL, "FOOT_"+BL, "TOE_"+BL]
변경  "leg_l_shin": ["SHIN_"+BL]
      "ankle_l":    ["FOOT_"+BL, "TOE_"+BL]      ← 신설. leg_l_shin 의 자식
      (우측 동일)
```

- `PIVOT` 에 `ankle_*` 추가 — 피벗 본은 `FOOT_*`, 방향 정렬은 **다른 노드와 같은 규약**
  (로컬 rest = **−Y**). 규약을 깨면 F21~F22 의 문제가 재발한다
- 자식 원점: `ankle_*` = `leg_*_shin` 로컬 `[0, −SHIN_LEN, 0]` = `[0, −0.352, 0]`
- **정점 총합은 불변이어야 한다**(5,521). 발이 정강이에서 옮겨갈 뿐이다.
  파트 경계 복제 수백 개는 허용 — **3배로 부풀면 F18 의 `from_pydata` 사고 재발이니 중단하라**

> ⚠ **분해 후 파이프라인을 전부 다시 태워라**(순서 준수):
> `decompose` → `remap-palette-uv` → `strip-node-rest` → `merge-rider-into-cycle`
> → `rotate-rider-nodes` → `add-joint-caps`.
> **하나라도 빠뜨리면 색이 죽거나(F20) 90° 돌아가거나(F21) 위치가 틀어진다.**

#### (b) 앱 계약 — 노드 12 → **14개**

- `config.ts` `RIDER_GLB_NODE_OVERRIDE_NAMES` 에 `ankle_l`·`ankle_r` 추가
- feature-state 키 2개(`ankle-l-rotation`·`ankle-r-rotation`) + `glbModelLayer.ts` match 2항
- `riderRig` 에 `FOOT_LEN` 등 필요한 상수를 두되 **`ANKLE_BACK` 93.03 · `ANKLE_UP` 37.0 은
  바꾸지 마라** — F25 §4-1 이 실측으로 맞다고 확인했다

#### (c) 회전 — 발바닥을 **세계 수평**으로 유지한다

페달 상쇄와 같은 원리다. 발은 정강이의 자식이므로 Mapbox 가 **정강이 회전을 물려준다**
(F21 확정: 누적). `ankle_*` 에 **정강이 누적 회전을 상쇄하는 로컬 회전**을 주면
발바닥이 세계 수평이 된다.

```
목표: sole 법선(월드) = [0, 1, 0]   (페달면이 수평이므로)
방법: ankle 로컬 회전 = (정강이 누적 회전)⁻¹ · (발 rest → 수평 자세 회전)
```

**부호·순서는 F22 규약(`R = Ry·Rz·Rx`)으로 직접 유도하고 렌더로 확인하라.**
감리가 값을 지정하지 않는다 — **§2-4 게이트가 정오를 판정한다.**

#### (d) 발목 캡

발목에도 관절 캡을 넣어라(옛 라이더는 52×52×52 였다). 정강이–발 이음매가
각도에 따라 벌어지는 것을 가린다. 크기는 §2-2 와 같은 방식으로 실측해 정하라.

### 2-4. 【필수 게이트】 발–페달 접지를 **수치로** 판정한다

| 9 | **발바닥 최저점 vs 페달 상면** (좌·우 × 4위상) | **±3mm** |

- 기존 1~7 도 그대로 통과해야 한다(정점 수 기대값은 본체 5,521 + 캡 갱신)
