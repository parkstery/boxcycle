담당: Cursor Developer, Codex Supervisor 검수. Chief 명시 구현 요청 승인. 일상 레이아웃 변경으로 별도 결정 불필요.

첨부 화면은 위 미니맵 / 아래 RouteDock이다. 아래 미니맵 / 위 RouteDock으로 교환한다. 좌측 정렬, 하단 안전영역·저작자 여백 유지. RouteDock 접힘·펼침 때 겹치지 않고, HUD 아래 가용 높이를 사용해 기존 미니맵 종횡비·폭 상한을 보존한다. 준비·idle에서는 기존 RouteDock/입문 CTA 동작 유지.

금지: 다른 dirty 변경 수정·되돌리기, 인증·주행 동작 변경, 운영 데이터 접근, 커밋·푸시·배포. branch/HEAD/dirty를 먼저 기록한다.
