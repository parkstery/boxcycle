# Trail 표시·합류 시안

2026-10-30 Chief: 「트레일 표시는 어떻게 하는 게 좋겠어? 트레일 디자인 시안 잡아 봐.」

Codex 직접 조사·제작·눈검수. 시안만, 제품 구현·데이터 의미·고정 규칙 변경 없음.

방향: Trail은 같은 판의 식별자. `Trail 035` 3자리 번호, 지역 이름, 거리, 주행 인원을 계층으로 구분한다. 번호를 운동 성과/거리처럼 과장하지 않는다. 흰색·파랑·남색 숫자·얇은 선 아이콘·연한 파랑 현재행. 초록=주행 상태, 파랑=선택/합류, 회색=비활성. 인원은 해당 Trail의 실제 주행 인원이며 접속자/동행 타인 수와 섞지 않는다.

구성: 지도 위 현재 Trail 식별부(기존 접속 패널의 식별 영역에 적용하는 시각 제안), 메뉴 합류 전(Trailhead), 메뉴 주행 중(호스트 예시). 전체 지도 계기판/순위/코칭/RouteDock 배치는 변경하지 않는다.

기능 계약: ▶로 자동 개설, 생성/나가기/채팅/초대/설정/필터 추가 없음. 왼쪽 메뉴는 Trail 전용(고정42), 반달 핸들 탭 유지(고정14). 공개/비공개는 호스트만. 주행·일시정지 중 타 Trail 합류 비활성, 현재행은 주행 중 정적 표시. Trailhead 복귀도 주행·일시정지 중 비활성. 지역/거리/인원이 없을 때 가짜값 생성 금지. 시안의 모든 값은 예시.

근거: TrailHubPanel.tsx, MapHud.tsx 접속 블록, productTerms.ts·trailDisplayNumber.ts, Ontology 및 Trailhead·Trail 용어 정본.

완료: `trail-states.png` 한 장에 식별부3상태(대기·주행·일시정지), 메뉴 합류전/주행중2상태 생성·저장·눈검수. built-in image_gen, 승인된 체험속도 시안을 스타일 참조. prompt.txt 보존. 주행중 현재 Trail은 파란행+초록 정적상태, 타 Trail은 합류 비활성, 공개설정은 호스트 예시. 캡슐 표시는 기존 접속 패널의 식별부 시각 제안이며 지도에 새 영구 버튼을 추가하거나 접속자 목록을 제거하는 승인 아님. 전체 그림은 확대 비교용으로 실제 폰 크기 검증 미실행. 제품 코드 변경 없으므로 테스트 미실행.
