# 지시02 — 관리자 화면(웹)

2026-10-23 · task · 담당 Claude impl-standard · 감리 Claude · 계약 [01-plan.md](01-plan.md) · 보고 `03-result-02.md`

범위: `apps/web/` 만. `functions/` 는 다른 실행자가 동시에 고친다 — 건드리지 않는다.

1. `src/services/adminDashboardApi.ts` — 현재 사용자의 ID 토큰으로 계약의 GET 을 부르고 응답 타입을 돌려준다. URL 은 기존 `functionsHttpUrl("getAdminDashboard")`. 401/403/네트워크 오류는 한국어 문구의 오류로.
2. `src/components/admin/AdminDashboardSheet.tsx` (+ `.css`) — 기존 시트(`RideSettingsSheet`·`MapViewSheet`)의 틀·닫기·Escape(`components/ui/useEscapeKeyClose`)를 따른다. 내용:
   - 「사용자 지표」 표: 행 = 첫 주행 완료율·72시간 안 재주행·다른 날 재사용·새 도로 비율·계정 수·주행 수, 열 = 전체·게스트·Google. `null` 은 「—」.
   - 「최근」: 오늘·최근 7일 — 가입·주행·거리.
   - 「점검」: 처리 안 된 공개 경로 신청 N건(0 이 아니면 경고색).
   - 하단 한 줄: 「내부 계정 N개 제외 · 주행 인정 기준 Xm·Y초 · 갱신 HH:MM」 + 새로고침 버튼.
   - 열 때 한 번 불러오고 로딩·오류 상태 표시.
   - 폰 가로 800×360 기준 — 표는 작은 글자로 한 화면에, 넘치면 시트 안에서만 세로 스크롤. UI 공간밀도 원칙(document/reference/product/260924-RTW-UI-공간밀도-원칙.md) 준수.
3. 진입: 사용자 정보 시트(`UserInfoSheet`)에 「관리」 버튼 — 기존 `isRouteReviewer(user)` 가 true 일 때만 렌더. 누르면 관리자 시트 열기(App 의 기존 시트 열기/닫기 방식 — `app/useAppSheetNavigation.ts` 를 먼저 읽고 따른다).
4. hover 스타일은 `@media (hover: hover)` 안에만(폰은 탭 뒤 hover 가 남는다).
5. 금지: 다른 시트·지도 동작 변경, 시험·설정·baseline 수정, git commit/push 등. 새 lib 파일을 만들면 `dep-layers.json` 파일 배정에 추가만.

검사(apps/web): `npx tsc -b --noEmit` · `npx eslint <고친 파일>` · `npm run test:quick` · 루트 `node scripts/check-code-tidy.mjs --check`. 화면 캡처 1장(가짜 응답으로 시트 렌더 — e2e 임시 파일은 끝나면 지운다)을 `.out/admin-dashboard-800.png` 로.
