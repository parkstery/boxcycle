# rider15 V3.0 주행 자세와 추가 동작 계획

2026-11-27 · Codex · Hoods 각도 조정 적용, 나머지 동작 활용은 제안

## 현재 기본 주행 자세

기본 모델은 rider15 V3.0 후보 `20261127-160608-8767e93a`다. 별도 자세가 지정되지 않으면 안장에 앉아 핸들 후드를 잡는 `Ride_Hoods`로 달린다. 페달 위상이 다리와 크랭크 자세를 정하며, 현재 Hoods 클립에서는 위상 한 주기에 크랭크가 한 번 돈다. 앱은 앞·뒷바퀴를 같은 주기에 3.2회전시킨다.

차체의 페달링 롤은 원본 클립에서 좌우 각각 1°다. 앱은 Hoods 재생용 클립을 준비할 때 차체 롤을 **좌우 각각 0.2°**로 줄이고, 몸통의 원본 궤적을 복원한 뒤 손목과 발목을 차체 기준 접점에 맞춘다. 한 페달 주기의 좌우 전체 이동 폭은 골반 약 8mm, 가슴 약 13mm, 머리 약 16mm다. 앱 리그와 원본 클립을 257개 위상에서 비교한 결과 몸통의 좌우 위치 차이는 최대 0.004mm, 차체 기준 손목·발 위치 차이는 최대 약 0.011mm였다. 코너 안쪽 기울기와 지형 경사는 지도 레이어에서 별도로 적용한다. 실제 가로 주행 화면에서는 상체와 손·발 움직임을 추가 확인한다.

근거리에서는 애니메이션 리그가 동작한다. 줌 19 미만에서 LOD2가 준비되어 있으면 정적 Hoods 모델을 표시한다. 각도 조정과 아래 동작 계획은 근거리 리그를 기준으로 한다.

## 자세와 동작의 활용

| 동작 | 제안하는 상황 | 발동과 복귀 |
|---|---|---|
| Hoods | 일반 주행 | 기본값. 다른 자세 조건이 끝나면 복귀한다. |
| Aero | 평탄한 구간에서 일정한 속도로 달리거나 페이서를 따라갈 때 | 조건이 일정 시간 이어졌을 때 전환한다. 진입·복귀 기준을 다르게 두어 경계에서 흔들리지 않게 한다. 모델 차체 롤은 약 ±0.6°다. |
| Sprint | 고강도 인터벌에서 실제로 페달을 밟는 짧은 구간 | 파워를 사용할 수 있는 환경에서 먼저 검증한다. 높은 케이던스만으로 발동시키지 않는다. 고강도 구간이 끝나거나 페달링이 멈추면 복귀한다. 모델 차체 롤은 약 ±3°다. |
| 고개 돌리기 · `Head_Left_45`, `Head_Right_45` | 실제 동행이 옆으로 접근하거나 추월할 때 | Hoods에서 상대 방향으로 한 번 재생한다. 같은 상대가 나란히 있는 동안에는 반복하지 않는다. |
| 엄지척 · `LookThumb_Left`, `LookThumb_Right` | 동행에게 인사하거나 답례할 때 | 인사 조작이 정해지면 상대 쪽 클립을 재생한다. |
| 파이팅 · `Fighting_R` | 동행에게 응원할 때 | 응원 조작이 정해지면 오른손 동작을 재생한다. |
| 만세 · `Celebrate_Open` | 경로 완주 | 현재 마일스톤 레이어의 완주 연출을 먼저 검증한다. 향후 주행 리그와 연속 재생을 연결할 때는 Hoods를 거쳐 만세를 한 번 재생한다. |

자세 전환에는 기존 600ms 혼합을 쓰고, 두 자세에 같은 페달 위상을 전달한다. 인사·응원은 Hoods에서만 재생하고, Aero·Sprint 중에 들어온 요청은 지나간 상황에서 뒤늦게 재생되지 않도록 처리한다. 완주와 일반 제스처가 겹치면 완주를 우선한다. 제스처 파일은 필요 시 불러오고, 지연되더라도 완주 표시와 기록이 먼저 완료되게 한다.

## 적용 순서와 확인 기준

1. **완주 만세** — 기존 완주 경로에서 한 번 재생되는지 확인한다. 느린 로드와 실패 상황에서도 완주 표시와 결과 확인이 가능해야 한다.
2. **고강도 인터벌 Sprint** — 구간 진입·종료·일시정지와 센서 데이터 누락을 확인한다. 경계에서 자세가 반복 전환되지 않고 페달·바퀴가 자연스럽게 이어져야 한다.
3. **동행을 향한 고개 돌리기** — 화면 좌우가 아니라 진행 방향을 기준으로 상대를 판별한다. 양쪽 접근, 추월, 같은 상대와 나란히 달리는 상황을 확인한다.
4. **Aero와 사용자가 보내는 제스처** — 실주행 기록을 바탕으로 Aero 전환 기준을 정한다. 인사·응원은 발신 방법과 상대에게도 동작을 보여줄지 정한 뒤 연결한다.

스마트폰 가로 화면에서 기본 Hoods, 자세 전환, 코너·경사, LOD 경계, 완주를 확인한다. 전환 속도·파워 기준과 동행 감지 거리·재발동 간격은 구현 전에 시험 주행으로 정한다.
