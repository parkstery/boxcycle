## 1. 【먼저 확인】 그 되돌림이 제품에서 실제로 나오는가

되돌림은 **속도가 0 까지 램프 감속할 때** 생긴다(P1 · P3). 그런데 제품에서 그 경로가 열려 있는지 의심스럽다.

```
슬라이더 최솟값   5 km/h — 0 을 넣을 수 없다 (S4-8 에서 확인)
정지              일시정지 = phase 전이. integrator 가 예측 없이 처리한다
주행 종료          completed = phase 전이. 마찬가지
```

**착수하자마자 이것부터 답하라.**

```
1-1  제품에서 속도가 0 까지 **램프 감속**하는 경로가 존재하는가?
     (일시정지·완료 같은 phase 전이 말고, 속도 자체가 연속적으로 0 에 수렴하는 경로)
1-2  없다면 P1·P3 의 되돌림은 **도달 불가능한 조건**이다
1-3  속도 변화만 있는 P2·P4 의 역행은 **0 이었다** — 확인하라
```

**1-1 이 「없다」면 이번 판단 자체가 불필요해진다.** 그 사실을 먼저 보고하라.
있다면 그 경로를 적고 §2 로 간다.
