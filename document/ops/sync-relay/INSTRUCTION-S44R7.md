## 3. 판정 — peer 픽셀의 왕복

로컬이 화면에 고정(0.7 px)이므로 **peer 픽셀 X 의 프레임 간 변화가 곧 상대 이동이다.**

```
3-1  peer 픽셀 X 계열의 프레임 간 변화 Δ 를 낸다
3-2  방향 전환 횟수 · 최대 |Δ| · 진폭(peak-to-peak) 을 낸다
3-3  임계 미만도 전부 집계한다. 미터로 환산하지 마라
3-4  self 픽셀 계열도 같이 내라 — 정말 고정인지 이 계열로 확인한다
```

### 3-1. 투영 계열과 대조하라 — 이번의 두 번째 소득

같은 창의 `map.project` 계열(① peer 절대: 반전 16 회 · 최대 5.6 px · 진폭 9.3 px)과 비교하라.

```
픽셀 ≈ 투영     peer 쪽 투영은 믿을 수 있다 — 깨진 것은 local 뿐이었다
픽셀 ≠ 투영     투영 계열 전체를 버려야 한다
```

**어느 쪽이든 큰 정보다.** 결론을 명확히 적어라.

### 3-2. 그리고 답하라

```
peer 마커가 화면에서 실제로 앞뒤로 왕복하는가 — 한다 / 안 한다
한다면 그 폭은 몇 px 이며 self 고정 폭(0.7 px)과 견주어 유의미한가
```
