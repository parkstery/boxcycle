### 0-1. 감리가 이미 확인한 것 — 같은 세션 A/B 가 이미 존재한다

`S3B2-summary.json` 은 기준선 런에 대해서도 z15 지표를 산출해 두었다(`base.cases`).

**이것으로 「다른 날 다른 세션이라 340↔360 이 흔들렸다」는 설명은 이미 약해졌다.**


**이 두 가지를 닫는 것이 이번 지시의 전부다.**

## 1. 할 것 — 세 가지 측정

### 1-1. 적합 해상도 — 360 은 350 과 구별되는가

`s3b2-summarize.mjs` 의 `D_eff` 적합이 쓰는 **탐색 격자(step)** 를 보고서에 명시하고,
**depart 두 런(base·post) 각각**에 대해 목적함수(잔차 RMSE)를 D 축으로 훑어 곡선을 낸다.

```
D = 240 … 480 을 적합이 쓰는 것과 같은 step 으로 전부 평가
각 D 에서   residual RMSE · residual max · 표본 n
최소점 주변 300·320·340·350·360·380 을 표로 따로 뽑는다
```

**판정 재료** — `RMSE(350)` 와 `RMSE(360)` 의 차이가 곡선의 국소 요철보다 작으면
「360 은 350 과 측정으로 구별되지 않는다」가 데이터의 답이다. **그 반대면 구별된다.**
**결론을 미리 정하지 말고 곡선을 그대로 올려라.**

> 적합기가 20 ms 격자를 쓰고 있다면 **350 은 격자 위에 존재하지 않는 값**이다.
> 그 사실 자체를 보고에 적어라. 격자를 바꾸라는 뜻이 **아니다** — 판정은 기존 격자로 한다.

### 1-2. 반복 측정 — 같은 빌드 3 런

**현재 빌드(D-1 적용, HEAD `aca3750`) 그대로** 같은 spec·같은 조건으로 **3 회** 측정한다.

```
조건 고정   skew=0 · 앞 2 s 폐기 · maxDelayMs=3000 · 겹침 ≥0.7
            전제 Δ(A.self) ≥100 m · 창 ≥20 s · workers=1
런마다 보고  z15-depart / z15-cruise 의 D_eff · RMSE · max · 스케일 · 겹침 · 표본 n
```

**산출물을 덮어쓰지 마라.** 런마다 `S3B2R-run{1,2,3}-events.json` 으로 전량 보존한다.
spec 을 고쳐야 한다면 **출력 파일명 env 하나만** 추가한다 — 측정 조건·주행 시나리오·판정
로직은 한 글자도 바꾸지 마라.

**보고 형식은 분포다.** 최소·중앙·최대를 전부 적고, **최악값 기준 §3-2 판정도 함께 적어라.**
좋은 런 하나를 골라 PASS 라고 쓰지 마라.

### 1-3. 기전 후보 — D-1 이 「우연한 지연 보상」을 걷어냈는가 (측정만)

가설: 기존 발행 속도는 depart 램프에서 **실제보다 +29 % 과대**였다(`HANDOFF` §2).
수신 측 외삽은 이 과대 속도로 **앞질러 나가므로**, 파이프라인 지연의 일부를 **우연히 상쇄**한다.
D-1 이 그 과대분을 없애면 **상쇄가 사라져 적합 `D_eff` 가 커질 수 있다** — 잔차는 오히려 개선된다
(실제로 post 의 depart max 는 1.511 → 1.353 으로 나아졌다).

**검증이 아니라 재료 수집이다.** depart 구간에 대해 base / post 를 나란히 낸다.

```
발행 speedMps p50 · 같은 구간 A 실제 진행속도 p50 · 비(발행/실제)
extrapolate 점유율 · cap(1.2 s) 히트율 · ahead(외삽 선행량) p50/p95
잔차의 부호 편향   residual 평균(부호 유지) — 앞선 쪽인지 뒤진 쪽인지
```

**이 수치로 가설을 「확정」이라고 쓰지 마라.** 지지 / 불일치 / 판정불가 중 하나로만 적는다.

## 2. 수용 조건

이번 지시는 **수정이 아니라 측정**이다. PASS 는 「`D_eff` 가 350 이하로 내려갔다」가 아니라

```

나.  §1-2 3 런이 같은 빌드·같은 조건으로 완료되고 전량 보존됐다
다.  §1-3 재료가 base/post 대조표로 제출됐다
라.  귀속 판정이 아래 셋 중 하나로 명시됐다

     A  런 변동 — 같은 빌드 3 런에서 depart D_eff 가 340~360 을 오간다. D-1 인과 아님
     B  D-1 인과 — 3 런이 360 근방에 몰리고 §1-1 곡선이 350/360 을 구별한다
     C  판정불가 — 어느 쪽도 데이터가 지지하지 않는다. 무엇이 더 필요한지 적어라

마.  §3 회귀 가드가 3 런 전부에서 유지됐다
```
