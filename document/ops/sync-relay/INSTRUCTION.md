## 0. S1 판정 — **절반 채택.** 두 가지가 틀렸다

**잘한 것**: 8케이스 완주 · **원시 로그 보존**(`REPORT-S1-raw-logs.json`) · 시계 오차 측정 ·
외삽 근사에 note 를 단 것. 특히 원시 로그를 남긴 덕에 §1-0 을 **앱 구동 없이** 할 수 있다.

### 0-1. 【반려】 z13 4케이스는 측정이 아니라 **합성**이다

`peer-sync-s1.spec.ts:177` `extrapolateSpectator()` 가 5km/h 등속으로 표본을 찍어낸다.
**네 보고서 표의 산술이 증거다:**

```
z15-decel  창 ~6s  → n  29   ✔ 정합
z13-decel  창 ~6s  → n 643   ✘ 21배      z13-pause  창 ~10s → n 862  ✘ 17배
z13-cruise A.self 878.2 가 200줄 고정 · B.disp 는 0.3m/200ms 정확히 등차 = 공식이지 관측이 아니다
```

→ **헤드라인 「최대 residual 392.80 m」은 관측값이 아니다.** 지표표에서 빼고 **「측정 불가」**로 적어라.
note 를 단 것은 정직했으나, **합성값이 PASS/FAIL 열에 오르면 안 된다.**

### 0-2. 【반려】 `D_eff` 800ms 는 **탐색 상한에 걸린 값**이다

스펙이 `maxDelayMs: 800` 으로 탐색하는데 **z15-depart · z15-cruise · z13-depart · z13-cruise
네 개가 정확히 800**. 경계 히트다.

- 참 지연은 **≥800ms 이고 값을 모른다**
- 그 D 에서 잰 `residual` 62.6m 도 **미모델 지연이 섞여 과대**하다 — 순수 흔들림이 아니다
- 방증: `B.age` 가 z15-depart 초반에 **11,575~15,121ms**, z15-cruise stall 구간에 2,788ms

### 0-3. 정정된 실측 기준선 — **S3 목표는 이걸로 잡는다**

**z15-depart · z15-cruise 만 유효**하고 residual max ≈ **93~96 m**. 392 m 가 아니다.
z15-decel · z15-pause 는 **PASS** — 감속·정지는 이미 정상이다. **문제는 「움직일 때」다.**

## 1. 지시

### 1-0. 【필수·먼저·앱 구동 금지】 저장된 로그로 재계산 — 30분

`REPORT-S1-raw-logs.json` 에 `logsA`·`logsB` 원문이 있다. **브라우저를 켜지 마라.**

```
① maxDelayMs 를 5,000 이상으로 올려 D_eff 재탐색. 여전히 상한에 붙으면 10,000 까지
② z13 4케이스는 지표표에서 제외하고 「측정 불가(합성)」로 적는다
③ z15 4케이스의 D_eff · residual 을 정정값으로 확정
```

**반증**: *"상한을 5,000 으로 올렸는데도 `D_eff` 가 800 근처에 머물면 내 §0-2 진단이 틀린 것이다."*
→ 그 경우 **즉시 보고**하고 §1-2 로 넘어가라.

### 1-1. 【필수】 테스트 하네스가 에이전트를 붙잡지 못하게 한다 — 2줄

```
playwright.config.ts   reporter: 'html'
                    →  reporter: [['line'], ['html', { open: 'never' }]]
```

`'html'` 의 기본값 `open: 'on-failure'` 가 **실패 시 리포트 웹서버를 띄우고 블록한다.**
30분 미종료의 원인이다. 그리고 **앞으로 e2e 는 백그라운드로 던지고 산출물 파일만 확인하라 —
포그라운드로 기다리지 마라.**

### 1-2. 【정본】 replay 하네스 — S1 실로그를 입력으로

`peer-sync` 스킬의 replay 하네스를 확장한다. **새 프레임워크 금지, 기존 것 확장.**

- `truth(t)` = A 의 `self` 시계열 · 입력 = `REPORT-S1-raw-logs.json` 의 실패킷
- 지연 모델 base·jitter 는 **§1-0 에서 재산출한 값**을 쓴다(800 고정값 쓰지 마라)
- 시나리오 5종: 출발 램프 · 정속 30 · 감속 · 일시정지 · **저줌(z≤14) 전환**
- 불변식(회귀 고정): `D_eff ≤ 350ms` · `RMSE ≤ 1.0m` · `max ≤ 2.5m`

**수용 게이트 — 이게 S2 의 정본이다**

