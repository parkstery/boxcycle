## 0. S4-10 의 「불가」는 아직 이르다

**S4-10 의 측정은 유효하다. 되돌리지 마라.** 흡수 효과는 확실히 증명됐다.

```
E = 0.3   점프 27.0 px → 1.5 px      18 배 감소 · 게이트4(≤2px) 통과
E = 0.5   점프 43.7 px → 2.2 px      20 배 감소
Y0 생존   흡수 off 43.66 px ≈ 예상 41.7 px      계측 살아 있음
Y6        발행 불변 확인
```

막힌 것은 점프가 아니라 **편향**이다.

```
E=0.3  흡수 off    편향 −0.090 m ✓    점프 27.0 px ✗
E=0.3  τ=0.3       편향 −0.244 m ✗    점프  1.5 px ✓
```

**흡수는 지연이고 지연은 편향이다.** 예측으로 없앤 `v×D` 가 흡수 형태로 돌아왔다.

### 0-1. 그런데 두 축을 안 보고 닫았다

```
① τ 격자가 0.3 초부터다
   E=0.3 τ=0.3 →  편향 0.244 (기준 0.22 를 11 % 초과)
                  점프 1.5 px (허용 2 px 까지 25 % 여유)
   **여유가 반대편에 남아 있다.** τ < 0.3 구간을 안 봤다

② 선보상이 없다
   편향이 **일정한 음수**다. 흡수 지연만큼 앞당겨 예측하면 상쇄된다
       현재   목표 = 예측(now)
       보상   목표 = 예측(now + τ_lead)
   표준 기법이고 이번 모델에 없다
```

**이 둘을 채우고 나서 「불가」를 판단한다.**
