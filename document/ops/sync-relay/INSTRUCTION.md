## 1. 흡수 — 위치를 점프시키지 말고 가속도로 수렴시킨다

```
현재   보정 도착 → 표시 위치를 즉시 목표로 이동           (점프 = E)
제안   보정 도착 → 목표를 갱신하고, 표시 위치는
       **가속도 유계**로 목표를 따라간다                  (점프 = 프레임당 미소량)
```

숫자로 보면 이렇다.

```
0.5 m 를 1 초에 걸쳐 흡수  →  추가 속도 0.5 m/s ≈ 1.8 km/h
                              속도 차이로는 감지 불가 · 점프 0
60 fps 기준 프레임당 8 mm  ≈  0.7 px
```

### 1-1. 가속도 상한

제품 램프를 기준으로 삼아라.

```
RIDE_SPEED_ACCEL_KMH_PER_SEC = 0.741 m/s²
RIDE_SPEED_DECEL_KMH_PER_SEC = 1.852 m/s²
```

**흡수 가속도가 이 값을 넘으면 물리적으로 불가능한 움직임이 된다.**
흡수 전용 상한을 따로 두고 싶으면 **제품 램프 이하**여야 하고 근거를 적어라.

### 1-2. 수신 측 전용이다

**흡수는 표시 계층의 일이다. 발행 로직을 바꾸지 마라.**
E 는 S4-9 그대로 두고, 같은 발행열에 흡수만 얹어 비교한다.

새 지표를 만들 때마다 축퇴로 통과한 사고가 반복됐다(S4-3 ③ · S4-4 axis:none · S4-7 등속 로그).


**흡수 off 에서 점프가 작게 나오면 그 지표로 아무것도 판정하지 마라.**

## 3. 재야 할 것

```
프레임 기준   60 fps (16.7 ms) — 눈이 보는 단위로 잰다
지표          프레임 간 표시 위치 변화의 **초과분** (등속 진행분을 뺀 나머지)
              p50 · p90 · p99 · 최대  (m · px)
```

**등속으로 나아가는 몫은 튐이 아니다.** 그 몫을 빼고 남은 것이 시각적 튐이다. 정의를 보고에 적어라.

### 3-1. 조합표

```
흡수 시간상수 τ_abs = off / 0.3 / 0.5 / 1.0 / 2.0 초
E = 0.3 / 0.5 m
전달 지연 = 0 / 100 / 300 ms          ← S4-9 는 0 만 봤다
```

각 조합에서 낼 것.

```
① 프레임 간 점프 p99 · 최대 (px)      ← 이번 주인공
② 순위 편향 · 역전 비율
③ 실제 최대 위치 오차 (흡수 지연이 더해진 값)
④ 발행 횟수 (흡수는 발행에 영향이 없어야 한다 — 확인용)
```

만족하는 조합이 없으면 그렇게 보고하라 — **「이 방식으로 불가」도 정상 결론이다.**
