## 1. 일시정지는 예측 대상이 아니다

S4-8 이 정지를 「일시정지」로 만들었는데, 그것은 램프를 우회한다.

```ts
input.routeRidePhase === "paused" ? 0 : speedKmh / 3.6
```

**그러나 integrator 는 paused 를 이미 별도 처리한다.**

```ts
if (entity.phase === "paused" || entity.phase === "completed") {
  entity.displayDistM = clampRouteDist(newest.distM, routeLenM);   // 예측하지 않는다
```

**일시정지는 속도 변화가 아니라 상태 전이이고 `phase` 로 즉시 전달된다.**
이번 평가에서 **paused 구간을 예측 오차 집계에서 제외하라.** 그 사실을 보고에 명시하라.

## 3. 【핵심】 고정 T 가 답이 아닐 수 있다 — 둘 다 평가하라

감리가 계산한 것이다. **예측 오차는 속도에 비례한다.**

```
감속으로 정지할 때 최대 오차 ≈ v_last × T

5 km/h  (1.39 m/s)   T=1 → 1.39 m      T=2 → 2.78 m
20 km/h (5.56 m/s)   T=1 → 5.56 m      T=2 → 11.1 m
```

**고정 T 로는 저속에서만 통과하고 고속에서 반드시 깨진다.**
게이트(간격 3 m 의 절반 = 1.5 m)를 속도와 무관하게 만족시킬 수 없다.

그래서 **적응 임계를 1순위 후보로 평가하라.**

```
방식   송신 측이 자기 예측을 돌려, 수신 측이 볼 위치와 실제가 임계 E 를 넘으면 즉시 보낸다
성질   오차가 **구성상** E 로 상한된다. 속도와 무관하다
```

### 3-1. 재야 할 것

```
(가) 고정 T      T = 0.5 / 1 / 2 / 4 초 — 참고용
(나) 적응 임계   E = 0.15 / 0.3 / 0.5 / 1.0 m — **1순위**

각각에 대해
  ① 예측 오차 p50 · p90 · 최대 (m · px, 83.44 px/m)
  ② 순위 편향 · 역전 비율
  ③ **발행 횟수와 평균 발행 주기** — 프로파일별로
  ④ 최악 구간이 어디였는지 (어느 프로파일 · 어느 순간)
```

**(나) 에서 실제 오차가 임계 E 를 넘는지 확인하라.** 넘으면 구현이 틀린 것이다(자가 검산).
