## 1. 왜 단독 주행인가 — 감리가 데이터에서 본 것

S4-4R2 의 계열 집계다.

```
              ① peer 절대    ② local 절대    ③ 상대
C-A 25/25        25 회          51 회          45 회
C-B 32/10         3 회          57 회          13 회
```

**로컬 라이더가 peer 보다 더 많이 뒤집힌다.** 로컬은 peer 동기화 경로를 타지 않는다.
그런데 프레임별 분류는 「카메라 0」을 냈다(표본 3 · 1 프레임, `mixed` 가 기본값).
**집계와 분류가 서로 반대를 가리킨다. 이 모순을 푸는 것이 이번 일이다.**

지금까지 모든 캡처는 **둘이 달렸다.** 두 성분이 항상 섞여 있었다.
**혼자 달리면 peer 성분이 0 이 된다. 남는 흔들림은 전부 투영·카메라다.**

## 2. 실험 — 대조군 하나면 된다

### 2-1. 단독 주행을 찍어라

```
S-A   라이더 1 명 · 25 km/h · leftFlat · 다른 참가자 없음
S-B   라이더 1 명 · 32 km/h · leftFlat · 다른 참가자 없음
```

**같은 Trail·같은 경로·같은 카메라·같은 창 길이·같은 프레임 간격**으로 찍어라.
C-A/C-B 와 비교할 것이므로 **조건이 다르면 비교가 성립하지 않는다.**
아래를 산출물에 반드시 남겨라.

```
routeId · routeLenM · camera · 카메라 거리 · windowMs · displayFrames · medianFrameDtMs
```

산출: `S44R3-S-A-solo-25.json` · `S44R3-S-B-solo-32.json` · 각 `*-summary.json` · `S44R3-shots/`

### 2-2. 판정은 **계열 비교**로 한다 — 프레임 투표를 쓰지 마라

S4-4R2 의 `classifyCameraVsPeer` 는 이번 판정에 쓰지 마라.
`mixed` 가 기본값이라 카메라 성분을 흡수한다.

비교할 것은 이것뿐이다.

| | 2인 (C-A / C-B) | 단독 (S-A / S-B) |
|---|---|---|
| ② local 반전 횟수 | 51 / 57 | ? |
| ② 최대 px | ? | ? |
| ② peak-to-peak px | ? | ? |
| ② 음수 투영 스텝 수 | 33 / 29 | ? |

**C-A/C-B 의 ② 값도 같은 표에 다시 적어라**(기존 산출물에서 읽어 오면 된다. 다시 찍지 마라).

### 2-3. 판정 규칙 — 이대로 적용하라

```
단독 ② 반전이 2인 ② 와 비슷한 수준     →  투영·카메라 확정. peer 동기화 무관
단독 ② 반전이 뚜렷하게 적거나 없다      →  peer 가 있을 때만 화면이 흔들린다는 뜻
                                          (peer 렌더·카메라 추종 대상 변화 등 후속 조사)
그 사이                                 →  두 값을 그대로 제시하고 「미결」로 적어라
```

**「비슷한 수준」·「뚜렷하게 적다」를 눈대중으로 쓰지 마라.** 횟수·최대·진폭 세 값을 모두 제시하고,
비율(단독/2인)을 계산해 적어라.

## 3. 【필수】 계측 생존 증명 — 0 을 결론으로 쓰지 마라

단독 주행에서는 **판정기가 peer 이벤트를 전제로 짜여 있으면 ②가 구조적으로 0 이 나온다.**
그러면 「흔들림 없음」이 아니라 **죽은 계측**이다. S4-4 의 `axis: none` 이 그렇게 나왔다.

착수 전에 이것부터 확인하고 보고하라.

```
3-1  단독 캡처에서 display 이벤트가 실제로 쌓이는가 (displayFrames 비-0)
3-2  local 화면좌표가 프레임마다 들어오는가 (hasLocalScreen: true)
3-3  로컬의 진행축 û 가 peer 없이도 추정되는가
     — û 는 displayDistM 전진 창 회귀다. 로컬 자신의 거리로 추정되어야 한다
3-4  로컬 화면좌표가 창 안에서 실제로 움직였는가 (총 변위 비-0)
```

**3-1~3-4 중 하나라도 실패하면 계측을 먼저 고치고, 그 전에는 판정하지 마라.**
필요하면 판정기가 로컬 단독 계열만으로도 돌게 확장하라 — 계측 확장은 허용된다.
