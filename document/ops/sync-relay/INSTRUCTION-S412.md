## 0. 「불가」는 네 잘못이 아니다 — 감리 게이트가 틀렸다

**S4-11 실행에는 잘못이 없다.** 격자 완주, 계측 일치 증명(S4-10 과 소수점까지 동일),
`accelOk` 정의 분리까지 지시대로 했다. **결과를 되돌리지 마라.**

확정된 성과는 이것이다.

```
게이트4 (점프 p99 ≤ 2 px)     120 / 120 전부 통과
Chief 조건(P3, 5 km/h)         점프 0.04 px — 사실상 0
흡수 가속도                    램프와 정확히 일치 (0.7407 / 1.8519)
선보상(τ_lead)                 효과 없음 — 편향만 뒤집고 점프를 늘린다. 이 축은 버린다
```

막은 것은 **감리가 잘못 정의한 게이트 두 개**다.

### 0-1. 게이트1 — 속도 의존을 무시했다

`0.22 m` 는 **현재 시스템의 5 km/h 편향**이다. 현재 방식의 편향은 `v × D` 라 속도에 비례한다.

```
현재 시스템 (D = 160 ms)     5 km/h 0.222 · 8.5 0.378 · 10 0.445 · 20 0.889 m
```

이 기준으로 보면 실측이 뒤집힌다.

```
              측정 편향   같은 속도 현재 방식   실제 판정
P3  5 km/h     −0.061        0.222            3.6 배 우수
P4  ~8.5       −0.159        0.378            2.4 배 우수
P1  ~10        +0.127        0.445            3.5 배 우수
P2  ~10        −0.244        0.445            1.8 배 우수
```

**네 프로파일 전부 현재보다 좋은데, 한 점의 상수로 실패 판정했다.**

### 0-2. 게이트2 — 역전의 크기를 보지 않았다

P3 는 역전 7.38 % 로 실패했다. 그런데 같은 프로파일의 **프레임당 변화 p99 가 0.04 px** 다.

**프레임당 0.04 px 씩 뒤로 흐르는 것을 「역전」으로 셌다.**
감속 정지에서 예측이 살짝 넘어갔다가 흡수가 부드럽게 되돌리는 정상 동작이고 보이지 않는다.

**개수만 세고 크기를 보지 않는 게이트는 흡수와 양립할 수 없다.**

## 1. 정정 — 기준선을 상수가 아니라 **측정값**으로 바꾼다

### 1-1. 현재 제품 설정을 같은 프로파일에서 재라

```
기준선(BASE) = 현재 제품 설정 그대로
   발행    RTDB 10 Hz (100 ms)
   표시    보간 + PEER_INTERP_DELAY_MS = 160 ms
   같은 P1~P4 프로파일 · 같은 지연 조건
```

**공식으로 추정하지 마라. 돌려서 재라.** 프로파일마다 BASE 의 편향·역전·오차를 낸다.

### 1-2. 게이트 재정의

```
게이트1  |편향|  ≤  |BASE 편향|              (같은 프로파일 · 같은 지연)
게이트2  최대 역행 크기 ≤ BASE 의 최대 역행 크기
         역행 크기 = 연속으로 뒤로 간 구간의 **누적 역행량** (m 와 px 둘 다)
         **개수가 아니라 크기다**
게이트3  최대 위치 오차 ≤ 1.5 m               (변경 없음)
게이트4  프레임 간 점프 p99 ≤ 2 px            (변경 없음 · Chief 「안 보임」)
```

**게이트1·2 는 「현재보다 나쁘지 않다」는 뜻이다.** Chief 의 퇴보 금지선을 그대로 옮긴 것이다.
게이트3·4 는 절대 기준이므로 그대로 둔다.
