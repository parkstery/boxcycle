## 0. 작업 방식이 바뀐다 — 네가 주행 시험을 하지 마라

**Chief 가 직접 시승한다.** 너는 조정 노브를 만들고 기다린다.

```
너      런타임에서 바꿀 수 있는 노브를 만든다 → 후보값 사다리를 제시한다 → 대기
Chief   그 자리에서 값을 바꿔 가며 달린다 → 보이는지 아닌지 알려준다
너      Chief 판정을 기록하고, 선택된 값의 정확도 비용을 하네스로 잰다
```

**재빌드를 요구하는 방식으로 만들지 마라.** 값 하나 바꿀 때마다 빌드를 기다리면 이 방식의 의미가 없다.
URL 파라미터나 디버그 패널로 **한 번 띄운 채 값만 바꿀 수 있어야 한다.**

주행 시험을 네가 반복하지 마라. 만들고, 사다리를 적고, 멈춰서 보고하라.

## 1. 감리가 찾은 것 — 우리는 잘못된 배율에서 재고 있었다

Chief 실사용 화면이다.

```
카메라   좌측     거리 16.0 m
```

**우리 계측은 전부 40 m 였다.**

```
S44R4 · S44R7 · S45     cameraDistanceM: 40
Chief 실사용             16 m
```

Chief 스크린샷의 자전거 길이(약 160 px / 실물 약 1.75 m)로 재면 **약 91 px/m** 다.
우리 창은 29.2 px/m 였다 — **3.1 배**.

```
                    40 m 계측     16 m 환산
R7 (수정 전)         10.8 px       ≈ 34 px
S4-5 (수정 후)        6.06 px      ≈ 19 px
```

**진폭이 준 것은 사실이나, Chief 화면에서는 아직 19 px ≈ 21 cm 다.** 당연히 보인다.
「눈에 안 보임」은 대략 1~2 px, 즉 **세계 좌표로 1~2 cm** 다. **아직 10 배 남았다.**

### 1-1. 그래서 접근을 바꾼다

원인을 하나씩 빼는 방식으로는 1~2 cm 에 도달하기 어렵다.
**출력이 매끄럽도록 보장하는 쪽**으로 간다 — 입력이 지저분해도 화면이 매끄러우면 된다.

## 2. 만들 것 — 런타임 노브

### 2-1. peer 표시 위치 평활

```
노브    peer 의 표시 위치(displayDistM 또는 렌더 직전 위치)에 임계감쇠/EMA 평활을 건다
파라미터  시간상수 τ (ms)
기본값   0 = 현재 동작 그대로 (기본은 반드시 무변화여야 한다)
```

**DEV 게이트를 걸어라.** 프로덕션 기본 동작을 바꾸지 마라.
URL 파라미터 예: `?peerSmoothMs=150` — 이름은 네가 정하되 **한 번 띄운 채 바꿀 수 있게** 하라.

### 2-2. 후보 사다리를 제시하라

```
τ = 0 (현재) · 80 · 150 · 250 · 400 ms
```

이 값들을 Chief 가 순서대로 시험한다. 사다리를 바꾸고 싶으면 근거를 적고 바꿔라.

**τ 가 커질수록 매끄러워지고 반응이 늦어진다.** 그 상충을 Chief 가 눈으로 고르게 하는 것이 목적이다.

### 2-3. 16 m 축척을 한 번 확정하라

Chief 판정을 숫자로 옮기려면 그 창의 px/m 가 필요하다.

```
방법   경로 위 두 지점(예: 10 m 간격)을 16 m 카메라에서 투영해 픽셀 거리를 재거나,
       샷에서 자전거 길이 같은 기지 치수로 산출한다
산출   S46-scale-16m.json — px/m 와 산출 근거
```

**추정하지 말고 재라.** 이 값으로 「몇 px 이면 안 보이는가」를 세계 좌표로 환산한다.

## 3. Chief 시승 절차 — 지시서에 그대로 적어 두라

Chief 가 매번 같은 조건에서 보도록 절차를 고정한다.

```
카메라   좌측 · 거리 16.0 m
속도     양쪽 5 km/h
배치     두 라이더가 거의 나란히
탭       양쪽 visible
관찰     상대 라이더가 앞뒤로 톡톡 튀는가
```

Chief 가 답할 항목은 **셋뿐**이다.

```
① 튐이 보이는가        안 보임 / 약간 / 명확히
② 반응이 굼뜬가        아니오 / 약간 / 눈에 띄게
③ 이 값을 쓸 만한가    예 / 아니오
```

**Chief 에게 코드나 구현을 묻지 마라.** 위 셋만 묻는다.
