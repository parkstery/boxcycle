## 1. 왜 이 실험인가 — Chief 이력이 전제다

개발 초반에 **발행 간격을 넓히고 보간으로 메우는** 방식을 시도했고 실패했다.

```
증상   A 화면에서는 A 가 1등, B 화면에서는 B 가 1등
```

감리가 진단한 메커니즘이다.

```
내 라이더    now 에 그린다
상대         now − D 에 그린다        (보간은 다음 샘플을 기다려야 하므로 D ≥ 발행 간격)

→ 양쪽 다 자기가 v × D 만큼 앞서 보인다

현재     D = 160 ms → 5 km/h 에서 편향 0.22 m     순위가 안 뒤집힌다
옛 시도  발행 1 s → D ≳ 1 s → 편향 1.4 m 이상     나란하면 반드시 뒤집힌다
```

**보간이 문제가 아니라 D 가 발행 간격에 끌려 커지는 것이 문제였다.**

예측(마지막 위치·속도에서 앞으로 적분)은 상대를 `now` 에 그리므로 **D 가 0 이 되고 간격과 무관**해진다.
방향이 반대다. **다만 예측에는 다른 오차가 생긴다** — 그것을 재는 것이 이번 일이다.

```
예측 오차 ≈ ½ × a × T²      완만한 변속이면 작고, 급정거면 크다
```

**덮어쓰지 마라.** 읽기만 한다.

### 2-2. 솎아내기 + 재구성

```
T = 1 / 2 / 4 / 8 초 각각에 대해
  ① 원본 패킷 열에서 T 간격으로만 샘플을 남긴다 (나머지는 버린다)
  ② 남은 샘플로 표시 위치를 재구성한다 — 두 방식 모두
       (a) 현재 방식   보간 + 지연 D = max(160ms, T)      ← 옛 실패의 재현
       (b) 예측 방식   x(t) = x_last + v_last × (t − t_last),  D = 0
  ③ 재구성 위치를 **버려지지 않은 원본 전체**와 비교한다 (정답 = 솎기 전 궤적)
```

**(a) 를 반드시 함께 내라.** 옛 실패가 숫자로 재현되는지 확인해야 (b) 의 개선을 믿을 수 있다.

### 2-3. 재야 할 것

```
① 예측 오차 분포        p50 · p90 · 최대  (m 와 16m 기준 px 둘 다)
② 순위 편향            표시 간격 − 실제 간격의 **평균**
                       0 에서 멀수록 "한쪽이 일관되게 앞서 보인다"
③ 순위 역전 발생        나란한 구간에서 표시 순위가 실제와 뒤바뀐 프레임 비율
④ 적응 발행량          "예측이 임계를 넘을 때만 보낸다" 로 시뮬레이션했을 때 실제 발행 횟수
                       임계 = 0.1 / 0.3 / 0.5 m 각각
```

## 3. 【필수】 로그가 실험에 적합한지 먼저 밝혀라

**등속만 있는 로그로 예측을 평가하면 예측이 무조건 이긴다.** 축퇴 통과다.

착수하자마자 이것부터 보고하라.

```
3-1  각 로그의 속도 변화 폭 — 최소·최대·표준편차
3-2  급변 구간(|a| > 0.3 m/s²)이 몇 초나 들어 있는가
3-3  정지·재출발이 들어 있는가
```

**급변이 거의 없으면 결과는 낙관 편향이다.** 그 사실을 결론에 명시하고,
「급변 조건은 미검증」으로 남겨라. 없는 데이터를 있는 것처럼 쓰지 마라.

없다면 **합성 시나리오로 보완하라** — 리플레이 하네스에 급정거·급가속 열을 넣어
같은 실험을 돌리고, 실측과 합성을 **구분해서** 보고하라.
