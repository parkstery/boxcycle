## 수락된 방향과 범위

Chief의 “좋아 계속하자”는 직전 기호 버튼·개별 작은 표면·통짜 제어 배경 제거 방향을 이어가는 것으로 해석한다. 코드 작성 금지는 유지한다. 이전 배경 없는 HUD·제목 옆 단위·RTW 오른쪽 배치·전방 노선 시야 보호를 보존한다.

이번 대표 화면은 [준비](previews/prepare-v5-route-summary.png)와 [센서 설정](previews/prepare-v5-sensor-settings.png). 샘플 경로·수치이며 실제 앱 렌더나 실제 연결 결과가 아니다.

## 준비 화면

경로명, 짧은 출발·도착 요약, 거리, 입력 선택 상태를 좌하단의 내용 중심 패널에 모은다. 전체 행을 카드 안의 또 다른 카드로 만들지 않고 행·간격·얇은 구분선으로 읽는다. 상세 편집은 연필, 센서 설정은 상태 행으로 들어가는 제안이다. 경유지·재개 선택·거리 생성·이동 방식은 삭제하지 않고 상세 편집으로 연결해야 한다.

샘플은 '센서 없음'을 이미 명시 선택해 준비가 된 상태다. 미연결이면 무조건 시작할 수 있다는 뜻이 아니다. 시작 기호 활성, 일시정지/종료 비활성으로 준비 상태를 구분한다.

기존 소스는 시작·일시정지·종료의 위치와 순서를 고정한다. 앞선 두 버튼 시안이 이 계약까지 변경한 것으로 확정되지 않았다. 이번 확장에서는 3개 독립 기호를 같은 자리에 유지한다. 상태별 기능·핸들러 보존 검증이 구현 전에 필요하다.

## 센서 설정

준비 요약과 센서 패널을 겹쳐 쌓지 않고 같은 좌측 영역을 번갈아 사용하는 제안이다. 카드 하나만 열려 중앙 경로를 확보한다. 패널 배경은 읽어야 하는 설정 영역에만 불투명하게 사용한다. 주행 HUD까지 불투명 표면으로 되돌리지 않는다.

- 제목·연결 상태·닫기를 한 행.
- 센서 연결과 센서 없음의 명시적 선택을 한 행.
- 체험 속도의 제목 옆에 km/h, 숫자에는 단위 중복 없음.
- 체험 속도 조절을 한 행.
- 연결 중·오류·장치명·rpm·단절/재연결 등은 해당 상태에서만 추가. 이번 이미지에 없다고 기능을 없애지 않는다.
- 센서 선택 전/연결중/오류/연결완료의 상태별 화면, 폰 브라우저/Android 앱의 실제 지원 여부는 다음 검증 대상이다. 앱 패키징은 미결.

## Muse Free 결과와 Supervisor 검수

정확한 모델 opencode/muse-spark-1.3-contributor-free로 읽기 전용 조사 exit0. RouteDock.tsx, RideRoutePanel.tsx, CadenceSensorSheet.tsx를 부분 읽었다. Supervisor가 CadenceSensorSheet.tsx:61~216과 RouteDock.tsx:139~233을 독립 대조했다.

확인:
- 센서 검색·연결, 연결해제, 센서 속도 전환, 센서 없음 선택은 각각 다른 핸들러.
- 주행 중 수동 입력에서 최초 센서 설정을 여는 것은 제한됨. 주행 전 준비 화면 제안에 한정한다.
- 센서 없음은 onChooseManual의 명시적 선택이며 자동 fallback이 아님.
- 닫기와 상태/오류 표시 보존.
- 속도 조절은 조건부로 표시. 개발용 한시 예외를 최종 제품 정책으로 채택하지 않는다.
- RouteDock 시작 가능 여부에는 stage/canStartRide/routeLoading/editLocked 등이 관여. 상위 App의 산정·연결은 미조사라 '미연결 시작 가능' 전체를 검증 완료로 주장하지 않는다.

정정·주의:
- Muse는 task 파일 최초 Read에서 첫5줄만 읽은 로그를 남겼다. 범위 제한은 상위 prompt·지정3소스에 맞게 수행했으나 차후 지시 전체 읽기를 명시 확인한다.
- RideRoutePanel과 RouteDock 소유권에 대한 요약은 실제 전체 연결을 조사하지 않아 확정 구조도로 채택하지 않는다.
- 준비/센서 카드가 교체되는 동작은 설계 제안이며 기존 UI 계약 전체와 대조 전이다.
- 편집기 이동 방식·경유지 생성·재개 선택 등의 실제 도달 경로는 아직 새 시안에 표현되지 않았다.

## 이미지 검수·한계

두 이미지를 시각 확인했다. 지도 중심 시야, 밝은 읽기 패널 한 개, 기호 제어와 내용 계층, 센서 명시 선택 상태를 표현한다. 센서 초기 생성에서 출처 표시가 누락되어 별도 편집으로 복원했다.

생성 이미지에는 카드·버튼의 실제 CSS rect·44px 터치 영역·대비·점유율 검증이 없다. 긴 주소·작은 가로 viewport·키보드·에러 확장 시 높이·스크롤·숨은 조작과 초점·전체 카메라 상태는 미검증이다. 이미지가 배치나 지도·버튼 기하를 재해석하므로 픽셀 그대로를 구현 지시로 사용하지 않는다.

다음: 경로 편집·경로 탐색·주행 결과의 대표 화면을 동일 규칙으로 확장하고 기존 기능 진입을 표시한다. 구현 전에 공통 규격과 상태별 검증 항목을 고정한다. 코드·커밋·푸시·배포·운영 데이터 변경 없음.
