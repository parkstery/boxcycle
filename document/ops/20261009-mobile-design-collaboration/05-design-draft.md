## 확정 요구와 이번 결과

최종 사용은 안드로이드 앱·스마트폰 가로 화면. PC는 개발·검증 환경. 검정 바탕·주황색 중심 디자인에서 벗어나고, 패널 내부 공간·글자·컨트롤 위계를 새로 설계한다. 코드 작성 금지 유지. 실제 제공 화면은 위성 지도, 미니맵, 계기판, 경로 편집, 센서, 메뉴·기록 등이다.

이번 산출물은 동일한 주행 상태의 시각 방향 비교 이미지 두 장과 아래 배치 규칙이다. 이미지 생성 도구를 사용한 컨셉이며 실제 UI 렌더·실행 화면이 아니다. 이미지 안 수치는 설명용 데이터다. 앱 배포나 기능 완료로 표시하지 않는다.

- [A안 — 포슬린·청록](previews/ride-a-porcelain-teal.png): 밝은 불투명 표면, 청록 주요 행동, 절제된 둥근 모서리.
- [B안 — 실버·코발트](previews/ride-b-silver-cobalt.png): 회백색 불투명 표면, 파란 주요 행동, 각진 계기판 인상.
- 구조를 동일하게 유지하여 색·형태 비교를 돕는다. Supervisor 우선 제안은 A의 차분한 표면과 B의 명확한 수치 위계를 조합하는 것이다. 채택 아님.

## 배치 구조

| 영역 | 정보·역할 | 제안·이유 |
|---|---|---|
| 좌상단 | RTW·메뉴 | 누적 거리·계정 정보와 경쟁하지 않는 진입점 |
| 상단 | 속도, 진행 거리/경로 거리, 시간, 새 도로 | 한 장의 얕은 계기판, 라벨·수치·단위 정렬. 속도 수치 우선 |
| 중앙 | 지도·자기 위치·주행 시야 | 패널·주소·알림을 기본으로 겹치지 않게 한다 |
| 우측 | 카메라·지도 보기·위치 복귀 | 서로 다른 컨트롤 군을 하나의 정렬된 영역에 모은다 |
| 좌하단 | 미니맵 | 전체 경로 확인. 큰 지도와 중복인 모드에서는 접기 후보 |
| 우하단 | 센서 상태·일시정지·종료 | 실행 상태에 맞는 조작만 표시. 주행 중 비활성 재생 버튼 미표시 |
| 하단 중앙 | 지도 출처 표시 | 기존 서비스의 필요한 표시를 유지. 크기·표현은 구현 시 확인 |

평균 속도는 계기판 상세, 출발·도착 주소/경유지 편집은 경로 상세, 카메라 1~6과 관련 옵션은 카메라 펼침, 계정·기록은 프로필 진입으로 접근하는 제안이다. 기능 삭제·카메라 동작 변경·경로/인증/정복 인정 변경을 승인한 것이 아니다. 펼침 상태 화면과 현재 실제 이벤트 연결을 조사한 뒤 확정한다.

## 크기·공통 규칙 후보 (CSS px)

아래는 이미지에서 측정한 값이나 구현 통과 수치가 아니라 다음 정밀 설계 목표다. 기존 공간밀도 SoT를 대체하지 않는다.

| 항목 | 후보 |
|---|---|
| 기본 viewport | 740×300; 667×300, 844×390도 검토 |
| 안전 여백 | 앱에서 이용 가능한 영역의 가장자리 8~12; 시스템 안전 영역 별도 |
| 간격 | 4px 단위, 그룹 내부 4~8 / 그룹 사이 12 |
| 터치 타깃 | 최소 44×44; 시각 아이콘은 20~24, 숨은 터치 영역도 서로 겹치지 않음 |
| 속도 수치 | 28~32, 다른 주행 수치 20~24, 단위 13~14 |
| 라벨·본문 | 14~16. 글자를 줄여 우겨넣지 않음 |
| 계기판 | 높이 56~60 후보, 실제 내용으로 폭 결정, 동일 폭 네 칸 강제 금지 |
| 주행 제어 | 한 행, 주요 행동 하나 강조, 보조는 내용에 맞는 폭 |
| 패널 표면 | 불투명 밝은 색. 지도·뒤쪽 컨트롤이 글자를 통과해 보이지 않음 |
| 경계·그림자 | 가는 구분선, 지도와의 분리용 그림자 하나. 중첩 카드 금지 |
| 색 | A: 표면 #F7F9F8 / 글자 #203B3C / 강조 #087F80. B: #F0F3F8 / #26334D / #315FE9 |
| 지도 의미 | UI 강조색과 경로·내 도로망 색을 분리. 기존 의미 유지, 색상 일괄 변경 금지 |

## 검수와 미해결

- 첫 생성은 실제 앱에 없는 사실적 도로·라이더·하늘을 만들어 폐기했다. 제공된 위성 지도 참고로 A를 재생성, A를 편집해 B를 생성했다.
- 최종 두 안을 시각 확인했다: 가로 비율, 검정·주황 UI 탈피, 불투명 계기판, 한국어 라벨과 수치, 주소 패널 없는 중앙 시야, 출처 표시가 있다.
- 지도는 참고 이미지 기반 생성물이므로 정확한 지도 재현·지오메트리 보존을 보증하지 않는다. 실제 지도 품질 개선이나 3D 라이더 제거 결정이 아니다. 위성 시점 대표 화면에서 위치 점을 사용했다.
- 생성 이미지에서 터치 44px·명암 대비·CSS rect·점유율 통과를 주장하지 않는다. 실제 화면에 맞춰 크기·안전 영역·브라우저 높이 변화·패널 펼침을 검증해야 한다.
- 아이콘 버튼 3개와 주행 제어가 작은 가로 화면에서도 충돌하지 않는지 정밀 검증 필요. 짧은 화면에서 상단/하단 패널과 실제 주행 시야의 균형을 다시 측정한다.
- 긴 주소, 미연결 센서, 평균 속도/경로 상세, 카메라 펼침, 로딩·오류, 종료 확인, 결과·준비 화면은 다음 대표 화면 설계 대상이다.
- Android 패키징 방법이나 상태바/내비게이션바 숨김은 결정하지 않았다. 확보되지 않은 공간을 전제로 UI를 확대하지 않는다.
