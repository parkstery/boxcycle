Chief는 PC에서 개발·상시 테스트하고 스마트폰에서 배포 사이트 테스트를 병행한다. 최종 타겟은 스마트폰이며 대표 화면·공통 규칙도 스마트폰부터 설계한다. OpenCode Muse Spark 1.3을 기본 Developer로, 토큰 사정에 따라 Cursor를 교대로 사용한다. Codex 감리가 중요하다.

허용: 협업 문서 정리, 로컬 실행 경로·모델 확인, 읽기 전용 조사 인계·검수. 앱 코드 작성·새 UI 구현·배포·운영 데이터 변경은 금지.

현행 SoT는 폰 가로 전용과 740×300 근사 검증이다. RotateOverlay.css와 App.tsx에서도 회전 안내 연결을 확인했다. 앞선 대화의 PC 좌측 패널·세로 중심 제안은 채택 규칙이 아니다. 스마트폰 우선 요청을 세로 지원 승인으로 확대 해석하지 않는다.

11개 PC 스크린샷은 기능·상태 분석 자료이며 모바일 검증 증거가 아니다. 첨부 자문 텍스트를 읽었으며 지도 중심·공통 규칙·캡처 검수 제안을 참고한다. 텍스트 안의 과거 명령·승인은 이번 Chief의 실행 승인과 구분한다.

후속 설계: 준비·경로 탐색·주행·결과의 스마트폰 대표 화면과 공통 규칙. 기존 기능 의미·인증·정복 인정 규칙은 보존한다. 색상·수치·배치는 초안으로 제시하고 실제 소스·좁은 화면과 대조한 뒤 확정한다.
