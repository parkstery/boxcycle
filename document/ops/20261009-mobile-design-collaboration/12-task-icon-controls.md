담당: opencode/muse-spark-1.3-contributor-free. Supervisor Codex.
공유 저장소, 다른 변경 되돌리기 금지. 파일 수정·생성·삭제, 코드 작성, 설치, 서버 기동, 운영 접속, Git 변경·커밋·푸시·배포 금지. stdout 보고만.

Chief: 하단 주행 제어의 시작/일시정지/종료 텍스트를 없애고 기호만 표시. 통짜 배경 상자 제거, 지도 가림 최소화. 후보: 작은 독립 원형 시작/일시정지(상태에 따라 한 개) + 종료, 센서 아이콘은 별도. 버튼 사이 지도 노출. 시각 원형 지름36~40 후보, 실제 터치 영역 최소44×44, 중심 간격52 이상 후보. 색: 옅은 중성색·청록, 검정·주황 UI 피함. 배경 없는 상단 계기·전방 시야·제목 단위 유지.

공간밀도 D2·D9와 후보를 대조하고 실제 RouteDock 주행 제어 소스/관련 CSS를 파일2개 이내에서 검색·부분 읽기. 어떤 상태/핸들러를 보존해야 하는지, 텍스트를 숨겨도 접근 가능한 이름을 유지하는지, 터치 영역 겹침 위험을 보고. 필요하면 다른 UI 파일 후보1개 경로 검색만(내용 읽지 않음). 소스 없는 판단은 명시. 지름36이 터치36으로 구현되면 안 됨. 상태별 기호 변경으로 주행 의미를 바꾸지 말 것.
응답 한국어250단어 이내. 읽은파일·명령별 종료코드·근거·미검증 구분, 코드/실DOM 검증 PASS 주장 금지. 광범위 파일 목록 출력 금지.
