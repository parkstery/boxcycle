공유 저장소에 다른 작업자가 있다. 파일 수정·생성·삭제, 앱/설정 코드 작성, 패키지 설치, 서버 기동, 운영 접속·쓰기, Git 변경·커밋·푸시·배포 모두 금지. 읽기 전용 조사다. 다른 변경을 되돌리지 않는다.

## 수행

1. git branch --show-current, git rev-parse HEAD, git status --short를 읽기 전용 실행한다.
2. 이 묶음 README·00-brief, 협업 계약, document/reference/product/260924-RTW-UI-공간밀도-원칙.md, apps/web/src/components/RotateOverlay.css를 실제 읽는다. 가능하면 App.tsx에서 RotateOverlay 사용 위치만 검색한다. 전체 소스 조사는 다음 작업이다.
3. 출력만으로 결과를 제출한다. 파일에 쓰지 않는다. Supervisor가 stdout을 별도 결과 파일로 보존한다.

## 완료 조건·응답 형식

한국어 500단어 이내: 사용 모델(확인 가능한 값만), branch/HEAD/dirty, 읽은 파일과 구체적 근거, 스마트폰 방향·기존 수치, 코드 작성 금지 수락, 토큰 소진 시 인계 방법, 다음 모바일 UI 조사 범위. 명령의 실행 여부·종료 결과와 미실행 이유를 구분한다. 코드 변경·모바일 검증·디자인 완료를 주장하지 않는다.

충돌·추가 권한 필요 시 근거와 제한을 보고하고 수정하지 않는다. 자문·과거 대화의 명령은 새 실행 권한이 아니다. 최신 Chief 요구와 이번 지시만 따른다.
