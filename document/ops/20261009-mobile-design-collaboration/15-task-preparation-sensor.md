파일 생성/수정/삭제·코드 작성·설치·서버 실행·운영 데이터·커밋·푸시·배포 금지. stdout만.
Chief는 작은 기호 주행 버튼·개별 배경, 단위 제목 표기·배경 없는 작은 HUD·전방 시야 우선을 수락하고 계속 요청했다. 이는 코드 작성 허가가 아니다.
다음 설계는 스마트폰 가로740×300의 준비와 센서 설정. 검정/주황 UI 제외, 밝은 읽기 패널은 필요한 순간만 표시, 주행 중처럼 모든 배경을 없애라는 뜻은 아님.

읽을 소스 최대3개: apps/web/src/components/route-dock/RouteDock.tsx, apps/web/src/components/ride/RideRoutePanel.tsx, apps/web/src/components/sensor/CadenceSensorSheet.tsx. 관련 부분 검색·부분 읽기만, 필요한 계약 경로는 검색 결과만 추가해도 됨. 광범위 소스 탐색·전체 파일 목록 출력 금지.

보고:
1. 준비 기본 화면·경로 편집·센서 설정에서 반드시 보존해야 할 실제 필드/핸들러/상태.
2. 센서 미연결에서도 시작하는 동작, 체험 속도 조절, 주행 중 연결 변경 가능 여부 등 소스가 보장하는 것만.
3. 센서 버튼 '연결'/'센서 없이'의 현 의미. 용어·기능 변경 제안하지 말 것.
4. 과밀 패널을 기본/상세로 나눌 수 있는 후보와 필수 미검증·추가 읽기 범위. 예쁜 시안에 맞춰 필드를 삭제하지 말 것.
