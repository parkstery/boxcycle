# 지시 10 — 주행 종료 시 지도 정북 복귀

- 담당: Developer(Cursor CLI) · 보고: `03-result-10.md` · 커밋 **금지**
- 병행: 지시 06-2(`MapHud.*`)·09(`RideSummarySheet.*`) 진행 중 — 허용 파일 밖 금지, 되돌리기·stash 금지.

## Chief 결정 (2026-10-06)
주행 중에는 진행 방향으로 지도가 돈다. 종료 후에는 다음 경로를 고르는 지도이므로 **정북(bearing 0°)** 이 기본이어야 한다. 지금은 돌아간 채로 남아 사용자가 직접 돌려야 한다.

## 요구
1. **주행 종료(End)** 시점에 지도 bearing 을 0° 로 **부드럽게**(easeTo, 500~800ms) 복귀. **중심·줌은 유지**(fitBounds·재중심 금지).
2. 자동 heading 추적이든 사용자가 수동으로 돌렸든 **종료 시 동일하게** 복귀.
3. **일시정지(paused)에서는 복귀하지 않는다** — 재개 시 방향이 튀지 않게.
4. pitch 처리 규칙은 기존 그대로(이미 0 으로 되돌리는 경로가 있으면 bearing 을 **같은 easeTo** 에 합쳐 애니메이션이 두 번 돌지 않게).
5. 구현 위치는 **카메라 소유 계층**(주행 카메라 follow 를 해제하는 곳). UI 컴포넌트에 `setBearing(0)` 을 흩뿌리지 말 것. 먼저 「주행 종료 → follow 해제 → 카메라 상태」 흐름을 추적해 결과에 경로(파일:줄)로 적는다.
   - 단서: `components/map/rideCameraFollow.ts` ~481 `apply3DState(enabled=false)` 가 `easeTo({ pitch: 0 })`(3D 끔), 같은 파일 ~521 은 bearing 유지. `components/map/MapView.tsx` 1122·2698 호출부. 종료 전이를 다루는 지점은 직접 찾을 것.
6. 종료 직후 결과 시트·이어달리기 재개 흐름(RouteDock 「N%부터」)과 충돌하지 않을 것. 종료 후 사용자가 지도를 다시 돌리면 그대로 둔다(1회 복귀만).

## 허용 파일
`components/map/rideCameraFollow.ts`, `components/map/MapView.tsx`(카메라 전이 부분만), 필요 시 카메라 관련 `lib/map/*` 1개. 순수 판정을 분리하면 단위 테스트 신설 허용.
