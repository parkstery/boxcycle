# Spinatlas 3D View 보고서 — 지형 OFF·3D 최대 표시 확정

최종 갱신: 2026-11-26 · 작성: Claude Code(구현·측정 직접, Mapbox 요금 조회만 하위 에이전트) · 상태: **운영 배포(Hosting `595c3e3d`, 11-26)**

작업 폴더: `C:\20.HDev\boxcycle`. 이전 판: [11-23 3D View FPS 최적화 진행 보고서](20261123-fps-experiments-summary.md)(Codex, 지형 ON 실험).

## 결론

1. **지형 3D(Mapbox Terrain)를 켜면 10FPS 안팎에서 벗어나지 못하는 문제는 해결하지 못했다.** 건물·나무·글자를 모두 꺼도 같았다(11-23 판 참조). 그래서 11-24 Chief 결정으로 **주행은 지형을 끄고, 그 대신 나머지 3D 요소를 최대한 보여 주는 방향**으로 바꿨다.
2. 지형을 끈 주행 화면을 6단계로 채웠고, 11-26 Chief가 최종 조합 「길가 나무 켬 · 안개 끔 · 도로 메우기 켬 · 지형 3D 끔」을 「현재로서는 최선」으로 확정해 운영에 배포했다.
3. 지형 OFF 주행은 PC(GTX1660)에서 대체로 **30~40FPS**이고, Chief 화면에서 최저 35·p95 34.3ms로 합격 기준을 넘은 장면이 있다. 다만 장소·시점에 따라 미달 장면도 있고 **스마트폰은 아직 재지 않았다.**
4. 오르막·내리막의 입체감(지형 기복)은 이번 방향에서 포기한 부분이다. 대신 실제 표고로 그린 **먼 산 능선**과 표고 그래프로 지형을 보여 준다. 라이더만 기울이는 경사 자세 실험은 Chief 판단 「쓸모없다」로 뺐다.

합격 기준(종전과 같음): 10초 표본에서 최저 1초 24FPS 이상, 프레임 간격 p95 41.7ms 이하.

## 비용과 데이터

- 서버·Firestore·Rules 변경 없음. 배포는 Hosting만.
- 나무·건물 색·창문·도로 메우기는 이미 받는 지도 조각을 다시 쓴다(추가 요청 없음). 1km 시야로 건물 조각 수신량은 늘었다(정밀 측정 없음).
- 먼 산 능선은 Mapbox terrain-rgb를 주행 출발 때 최대 9장(장당 약 130KB), 600m 이동마다 다시 계산한다. Raster Tiles API는 월 75만 요청까지 무료(2026-11-25 공식 요금표).
- 지도 SDK는 3.23.1로 고정했다. 시야 확장·건물 외관이 SDK 내부 구조에 기대므로 버전을 올릴 때 재확인이 필요하다.

## 한계와 남은 일

1. **스마트폰 미확인(7단계).** 가로 화면 속도·20분 발열·데이터 사용량.
2. **Mapbox 토큰 주소 제한 없음.** 다른 사이트에서도 쓸 수 있어 비용 위험이 있다. 허용 주소 설정은 Chief 계정 작업.
3. 외벽 자료가 있는 도시(파리·뉴욕)에서 창문이 원래 외벽과 겹치는지 화면 확인 결과가 없다.
4. 지도가 넓은 길을 한 줄로 그린 곳은 실제보다 좁게 보이고, 가로수가 차로 자리에 설 수 있다(차로 수 자료 없음). 도로 메우기는 실제 중앙 화단도 도로색으로 칠한다. 300m 너머는 메우지 않는다.
5. 안개를 끄면 1km 끝에서 건물이 끊기는 경계가 보일 수 있다.
6. 시험용 주소 스위치(`?fps`·`?ridelook`·`?ridetrees`·`?ridequality`·`?ride3d`·`?viewdist`)는 12-24~25 만료 전에 정리한다.
7. 지형 ON 10FPS의 원인 분리(11-23 판의 남은 조사)는 보류 상태다.
