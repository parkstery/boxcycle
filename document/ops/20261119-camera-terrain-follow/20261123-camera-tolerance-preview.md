# 카메라 2 추적 허용 오차 비교 — 5218

## 11-23 후속: 지형 높이 0.1배

Chief 후속 검수: 0.1배/1.3배 모두 FPS 차이를 느끼지 못함. 배율 조정은 성능 해법으로 채택하지 않는다. 첨부 화면은 약8.9FPS이며 주소에terrainscale가 없어 해당 단일 캡처의 실제0.1배 적용은 확정할 수 없다. 기존 브라우저0.1배 실제적용 확인과 Chief 비교 관측은 구분한다.

Chief 요청으로 5218에 `terrainscale=0.1` 비교를 추가했다. 제품 기본은 1배이며 전용 빌드에서만 0.1/1/1.3을 허용한다. 공유 배율을 사용하므로 지도·카메라 지면/능선 보정·자동평면 복귀가 같은 배율을 참조한다. 센서/코칭 표고는 변경하지 않았다.

직접 열기: http://127.0.0.1:5218/?maxdpr=1.5&perflab=1&terrainscale=0.1

Ctrl+F5 → 같은 코스로 주행 → 카메라2 → Standard 낮 선택. 비교판의 실제 지형 ON 0.1배를 확인한다. 추적/배경/원거리는 모두 기본으로 두고 10초 측정, 지형 OFF에서 다시 측정한다. 높이 1배/0.1배 링크는 다른 URL로 이동하여 주행이 재시작된다. 1배 측정도 같은 코스·속도에서 한다. 결과 JSON selected.terrainScale 및 actual.actualTerrain.exaggeration으로 선택/적용을 기록하며 배율 불일치는 측정을 차단한다.

검증: 배율1/0.1/1.3 + 일반빌드0.1/1.3 무시의 총5조건×25건=125 통과. 측정판7/0, tsc·변경TS lint·프리뷰 빌드·HTTP200 통과. 기존 guard 시험의 원시10m 언덕은 0.1배에서 화면1m가 되어 안전한 지형이므로, 차폐 시험은 화면높이10m를 유지하도록 원시입력을 배율로 나눴다. 제품 guard 코드는 변경하지 않았다. 실제 브라우저 Standard/day·카메라2·ready=true·exaggeration=0.1 확인. 직접 성능 판정 대기.

Mapbox 공식 문서상 exaggeration은 DEM 높이에 곱하는 수다. 따라서 기복 완화 시험이며 타일/메시 해상도를 낮추는 시험은 아니다. 성능 개선은 미확정이다. [공식 terrain 사양](https://docs.mapbox.com/style-spec/reference/terrain/).

11-23 구현·프리뷰 빌드·실제 브라우저 전환 확인 완료. 최소 24FPS 달성 여부는 Chief 직접 주행 비교 대기다. 정적 지형/동적 레이어 분리나 화면 재투영은 이번에 구현하지 않았다.

## 동작과 범위

전용 프리뷰 빌드만 활성화한다. 카메라 2·지형 ON에서 방위 1.5도, 기본 pitch 0.8도, zoom 0.025의 작은 변화를 허용하고 경계를 넘으면 연속 추종한다. 지형 조준도 약 화면 4% 각도 범위를 허용한다. 이동 중심은 매 프레임 유지하며 카메라를 통째로 정지시키지 않는다. 높이 보정·지면 3m/능선 시선 안전 검사는 유지하고 상승 안전 보정은 즉시 적용한다. 큰 회전·수동 줌·긴 갱신 간격은 즉시 재설정한다.

화면의 완화 횟수는 제어 입력 완화의 증거이며 지형 캐시 재사용·GPU 작업 절약의 증거는 아니다. FPS 개선을 보장하지 않는다. 결과 JSON은 selected.followMode 및 actual.follow를 기록한다. 일반 제품 빌드에서는 비활성, 미커밋·미배포.

- 실제 브라우저 Standard/day·지형1배·카메라2에서 tolerant active=true, 완화 124/131 확인. 기본 복귀 시 active=false와 카운터 초기화, 재전환 시 active=true·완화 3/4 확인.
