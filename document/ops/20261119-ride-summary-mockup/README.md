## 제안

- 444px 두 열 → 344px 단일 열. 800×360에서 높이 약218px, 낮은 폰에서는 약196px. 닉네임은 제목 오른쪽(예시 Ridingman12).
- 주행 계기판은 종료 시점 수치로 고정해 스크림보다 위에서 표시. 결과 창은 계기판 아래 여유 공간의 중앙.
- 결과 창은 주행 이야기·순위·S/E 두 줄·경로명 편집·저장 버튼만. 거리/시간/평균/새 도로 별도 수치 표 제거. 스토리는 예시이며 실제 구현에서는 기존 사실 기반 스토리를 사용한다.
- 원래 주소처럼 보이던 줄은 실제 경로명 input이었다. 출발/도착은 별도로 보여주고 경로명 input은 버튼 바로 위에 유지. 긴 주소는 한 줄 말줄임과 전체값 title(실앱에서 폰용 전체 주소 확인 동작도 필요).
- 결과 닫힘과 함께 주행 계기 해제. RPM/센서 칸은 기존 상시 표시 계약 유지. 시안의 저장 버튼은 실제 저장 없이 닫힘만 모사.
- 칼로리는 시안 데이터가 없어 빈 안내를 생략했다. 실제 추정치가 있을 때의 배치, Guest 연결 안내·저장 중/실패·미완주 등은 구현 시 기존 기능을 보존하며 별도 확인해야 한다.

지도·수치·이름은 예시. 시안 지도는 SVG 배경이며 실제 Mapbox/주행 연결은 없다. 시안만 작성해 ride-verify 제품 수정 절차는 아직 적용하지 않았다. Chief 확인 후 실제 요약 컴포넌트/계기판 표시 수명에 적용한다.
