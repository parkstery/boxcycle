## 실행 정리

CLI Ctrl+C는 공용 서비스의 모델 작업까지 중지시키지 않았다. 원래 공용 서비스 세션이 두 제품파일을 구현하고 검증하는 것을 소스 mtime/서비스 로그로 확인했다. 별도 standalone 세션은 이미지/소스 읽기만 했고 쓰기 전에 CLI를 종료했다. **이 재지시는 원래 공용 서비스 세션 하나만 담당**한다. 다른 세션을 만들거나 별도 병렬 writer를 띄우지 않는다. 결과에 실제 담당 세션을 정확하게 기록한다.

## 시각 검수 결과·수정

Supervisor가 실제 앱+실 Mapbox 지도에서 667×275/667×300/740×300/844×390/1366×768/1440×900의 초기 구현을 확인했다. Mapbox 응답110건 모두200, 기존 카피/버튼 유지·가로overflow0·CTA44px·제목2줄·모바일하단설명숨김 PASS. [수치](evidence/initial-geometry.json). 아래만 재작업한다. 새 브라우저 검증은 Supervisor 담당이므로 실행하지 않는다.

1. **폰 제목/브랜드 가독성**: 실제 폰 font-size가 제목20.25px/워드마크19.575px/kicker8.37px로 작다. 가로 max-height480px 구간에서 제목 **24px**, 브랜드 **22px**, eyebrow **10px**, 마크28px로 명시한다(루트13.5px 영향을 받지 않게). body는 현재0.95rem보다 작게 만들지 않는다. CSS667×275에서 두 줄 제목·44px버튼이 화면 안에 들어오게 gap/padding을 합리적으로 조절. 내용/버튼/지도 가시성 유지, 밀어내기/문구삭제로 해결 금지.
2. **부제 균형**: 현재 폰은 둘째 줄에 「다.」만 남고 PC는 한 줄로 길게 늘어진다. **「실내 자전거로 실제 도로를 달리면,」 / 「달린 길이 내 지도에 남습니다.」**의 두 구절을 각각 block span으로 구성해 두 줄로 보여준다. 두 span 사이 `{" "}`를 넣어 textContent를 공백 포함 기존 문장과 동일하게 보존할 수 있다. 기존 전체 부제 의미/띄어쓰기를 유지한다. 좁은 폰에서도 각 구절이 한 줄에 맞는지 충분한 본문 폭을 사용한다(대략304px에서 가능).
3. **PC 하단**: 현재 왼쪽 하단3항목 세로 목록을 같은 영역 안의 **가로3단계**로 정돈한다. 각항목 01/02/03+짧은 기존문구, 기존 left content padding과 정렬. width1000/min-height600 조건 유지하고 폰에서는 숨긴다. 지도 전체를 가리는 footer배경을 만들지 않는다. 필요하면 번호와문구를 세로로 놓은3열도 가능하나3개 항목 자체는 한행이다.
4. **Mapbox 출처 접근성**: 모든 크기에서 Mapbox 로고 중심의 elementFromPoint가 `.app-intro` SECTION으로 나와 링크가 막힌다(기존에도 있었던 문제). 허용 CSS의 scoped selector `.app-shell--intro .mapboxgl-ctrl-bottom-left`와 필요시 `.mapboxgl-ctrl-bottom-right`에 z-index를 인트로40보다 높게 두는 등 **출처만** 위로 올려 해결한다. attribution/logo가 시각적으로 남고 클릭 대상에 닿아야 한다. 기존 지도 조작 차단·다른 컨트롤 노출규칙·지도 엔진은 유지. `.app-intro` 전체 pointer-events:none으로 지도 조작을 풀지 않는다. 이 CSS만으로 해결이 안 되면 사유를 보고하고 제품 파일 범위를 임의 확장하지 않는다.

허용 제품파일은 AppIntroScreen.tsx/.css 두 개 그대로. 다른변경 보존, 커밋/push/배포 금지. 기존 두 줄 제목 literal·props·콜백·button 접근성 이름 그대로 유지.

추가 마감: CTA의 흰 글자와 `#ef4438` 배경 대비는 실측3.78:1로 작은 버튼 글자에 낮다. 마크·제목의 코랄은 유지하고 **guest 버튼 배경/테두리만 `#d9362b`(흰색 대비4.65:1)** 또는 더 어두운 코랄로 조정한다. hover도 기본보다 어둡게. 흰 글자·버튼 크기·다른제품팔레트는 유지한다.
