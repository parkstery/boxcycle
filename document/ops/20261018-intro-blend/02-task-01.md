## 구체 디자인

1. 왼쪽은 `#0b1020` 계열 짙은 남색, 오른쪽은 기존 실제 지도 그대로. 데스크톱 왼쪽 약40~45%에 글자, 남색 그라데이션은 중앙에서 지도 쪽으로 부드럽게 투명해지며 오른쪽 지도·콜로세움에 집중할 수 있게 한다. 모바일은 텍스트 폭 약50~54%, 오른쪽 최소35~40%는 지도가 분명하게 보이게. 전체 배경을 단색으로 덮지 않는다. iframe/스크린샷 배경/가짜 지구본으로 지도를 바꾸지 않는다.
2. 브랜드는 코랄 원 안 흰 나침반 바늘(1.upgrade 참고)을 **작은 inline SVG**로 만들고 옆에 SPINATLAS 워드마크. 코드 native로 충분하며 래스터 이미지/새 폰트 필요 없음. 앱의 작은 점보다 명확한 브랜드 락업, 거대한 로고가 모바일 본문을 밀어내지 않게. PC는 mark40~44px+wordmark32~36px, 폰은 mark26~28px+wordmark22~24px 수준을 출발점으로 한다. SVG는 aria-hidden·focusable=false, 실제 텍스트 접근성 유지. 기존 font stack 사용.
3. 작은 eyebrow `INDOOR RIDE · REAL ROADS`(대문자 자간)로 실제 도로 정체성 전달. 장식적 UI를 늘리지 않는다.
4. 제목은 기존 두 줄 **「땀으로 그리는,」 / 「나만의 지구 지도.」** 유지. 따뜻한 흰색(`#f5f2ec`), 첫 글자 「땀」에 코랄 포인트는 CSS `::first-letter` 등으로 구현 가능. 제목 literal은 원본 JSX에 `/땀으로 그리는,/`로 남아 selector 계약을 보존한다. PC56px 정도, 폰24~26px 정도를 출발점으로 하되 폰 가로 두 줄에 맞춰야 한다. 크기/기능보다 과도한 여백이 우선하지 않는다.
5. 부제는 **「실내 자전거로 실제 도로를 달리면, 달린 길이 내 지도에 남습니다.」** 정확히 유지. PC는 2줄 정도, 모바일은 가독성 있는 크기(현행 .95rem보다 줄이지 않음)로 2~3줄. 낮은 대비 회색으로 묻히지 않게.
6. 주 행동은 코랄/빨강(`#ef4438` 근처) pill 버튼 **「게스트로 시작」**, 작은 오른쪽 화살표는 aria-hidden. 텍스트/접근성 이름은 유지하고 `onClick={onStartGuest}` 유지. 보조 버튼 **「로그인」**은 남색 바탕의 은은한 흰 윤곽, `onClick={onLogin}` 유지. 두 버튼은 한 행·각44px 이상, 키보드 focus 선명. 미승인 '첫 길 칠하기'로 행동을 바꾸지 않는다.
7. 충분한 PC 화면(예: min-width1000 + min-height600)에 한해 하단 얇은 선과 간결한 3단계 설명을 배치 가능: **01 페달을 밟고 / 02 실제 도로를 달리고 / 03 내 도로망을 쌓으세요**. 낮은 높이/폰에서는 이 보조 설명을 숨겨 제목·CTA와 지도 확보. 이는 장식 설명이며 새 버튼/동작을 만들지 않는다. 모바일에서 제목/CTA를 숨기거나 작게 줄여 이 설명을 우겨넣지 않는다.
8. 지도 위에 '방금 칠한 길', 라이더 수, 거리, 실시간 동료 경로 같은 **가짜 상태/동적 수치/색 경로**를 만들지 않는다. 레퍼런스의 globe·범례·live카드는 이번 제품 인트로 기능과 다르다. 지도 출처·Mapbox logo/attribution은 계속 보이고 클릭 가능해야 한다. 기존 지도 컨트롤 노출 규칙은 유지.
9. 좁은 가로667×300,740×300뿐 아니라667×275에서 제목·부제·CTA 잘림/겹침/가로 overflow 없음. 가능하면 전부 화면 안에, 더 낮으면 기존 좌측 스크롤로 접근 가능. safe-area inset과 reduced-motion 유지. 세로 회전 안내는 바꾸지 않는다. CSS는 `.app-intro` 계열에 한정한다.

## 검증·보고

먼저 `.agents/skills/ride-verify/SKILL.md`와 HARNESS를 읽는다. 콜백/region/버튼 접근성/제목 계약을 유지하므로 계약 파일을 고칠 필요가 없게 구현한다. 문구·동작을 바꿔 검사를 피해가지 않는다.

```powershell
Set-Location 'C:\20.HDev\boxcycle'
node apps/web/scripts/ride-verify/verify-selectors.mjs
npm run build
npm run lint
node scripts/check-document-system.mjs
git diff --check
```

기존 lint16건은 앞 작업으로 정리돼 현재 오류0/경고40이 기준이다. PowerShell 구형 호환(명령 분리/세미콜론), 실제 종료코드 구분, Unicode 출력/TEMP 재시도 금지. 로그 필요시 이 묶음 evidence JSON 사용. 명령은 추가 수정/실패 없으면 반복하지 않는다.

**Supervisor가 직접 브라우저 감리를 담당한다.** Developer는 별도 브라우저 fixture/캡처 스크립트를 만들지 않는다. 개발자는 위 검증 후 결과를 작성하고 종료할 것. Supervisor가 실제 앱 667×275/667×300/740×300/844×390/1366×768/1440×900·원본컴포넌트 콜백/키보드/focus/reduced-motion·지도출처/가로overflow를 검증하고 필요하면 재지시한다. 이 역할 구분은 독립감리를 위한 것이며 화면 검증 생략이 아니다.
