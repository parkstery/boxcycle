## 확정 구현(추가 설계 조사 불필요)

1. AppIntroScreen의 brand p를 현재 content 내부에서 **section 직속 header 영역**으로 옮긴다. absolute top/left safe-area 대응, PC x는 기존6vw·top24~40px, 폰 x4vw·top12~16px. 브랜드가 본문과 겹치지 않도록 scroll top은 header 아래(PC약90px/폰약60px). 본문 제목·부제·버튼·PC하단설명/지도/출처 유지. 폰667×275에서도 전부 접근 가능·44px CTA 유지. 하단 설명만 기존처럼 폰숨김.
2. 로고는 기존 흰 나침반을 없애고 **빨간 원 안 검은 완만한 S형 길**로 SVG 교체. 별도 이미지 읽기/생성 불필요. 예: viewBox32원(cx16 cy16 r15 fill#ef4438), path `M8 20 C11 13 14 15 18 15 C21 15 22 12 24 10` fill none, stroke#0b1020, strokeWidth3.2, strokeLinecap round. 공유 레퍼런스처럼 오른쪽 위로 흐르는 곡선. 마크만 첫 등장에 약900~1200ms 1회 회전 후 정지, 워드마크는 회전하지 않음. prefers-reduced-motion에서는 animation none. SVG aria-hidden/focusable=false 유지.
3. MapHudProps에 **optional visible?: boolean**(default true)을 추가하고, 모든 기존 hooks를 실행한 뒤 main JSX return 직전에 `if (!visible) return null;`로 HUD전체를 렌더하지 않도록 한다. hooks 전에 return 금지. 이 내부 UI표시 flag 추가는 Supervisor가 Chief 요청 범위의 통상 구현으로 판정했다. 기존 default/인증후 stage정책은 보존한다.
4. App.tsx의 **두 mapHud 객체(DebugMapStage/AppMapStage)** 모두 `visible: authInitialized && Boolean(user)` 전달. introDismissed나버튼클릭/busy해제를 인증완료로 삼지 않는다. 익명 Guest도 user가 있으면 표시, 인증복원대기·user null·로그아웃후에는 안보임. 기존 authGateVisualDismissed/실제stage/콜백·auth로직은 수정하지 않는다. MapHud클래스는 숨기는 CSS편법이 아닌 DOM에서 없게 하므로 키보드탭도 차단. Mapbox 법정출처 링크는 앱 컨트롤2개 제한의 예외로 계속 보인다.
