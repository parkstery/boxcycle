인터벌 시안 v2 — 총 운동 시간 추가

v1(사이클 도넛·사이클 1/5·라운드 1/3·회색 백분율 도넛)에 전체 운동 시간 「지난 시간 / 총 시간」(예: 6:12 / 35:00)을 더했습니다. 총 시간 = 준비+사이클+휴식+마무리 합계(설정 창의 「총 시간」과 같은 값). 지금 패널 높이에는 넣을 자리가 없어 두 가지로 그렸습니다. 카드 그림은 1.5배 확대.

A안 — 패널 아래에 전체 진행 줄 추가 추천

「전체」 + 진행 막대 + 6:12 / 35:00. 다음 안내는 그대로 두고, 패널 높이만 89 → 107px(+18px). 폭은 같음.

B안 — 패널 크기 그대로, 「다음」 줄을 전체 시간으로 교체

높이 89px 유지. 대신 「다음 · 회복 30초」 안내가 빠집니다(다음 단계는 전환 코칭 자막으로만 알림).
