# 감리 32 — 묶음3 최종 UI (OpenCode DeepSeek v4.1)

2026-10-24 KST · OpenCode `deepseek-v4.1-flash-free` 읽기 전용 감리 · Supervisor 정리

## 판정

**현재 목표 뷰포트 800×360·667×300은 PASS.** DeepSeek가 제품 소스·지시28·재지시30·Chief 고정1~10·최종 PNG를 대조하고, 별도 5021 하네스에서 DOM 실측과 자동 시험을 독립 실행했다. 제품 코드는 수정하지 않았다. 사용 한도 종료로 모델이 자체 보고서 파일을 쓰기 직전에 중단되어, 아래는 실제 명령 출력과 실측값을 Supervisor가 기록한 것이다.

## 독립 실행 증거

- `ui-redesign-batch3` + `ui-redesign-batch3-conquest`: **13/13 PASS** (16.8초).
- `ui-800x360.spec.ts`의 `800 기준`·`결과의 진행`: **2/2 PASS** (8.6초).
- 결과 시트 실측: 800×360에서 `740×324`, 667×300에서 `654×287`; 두 열 모두 수평·수직 overflow 없음.
- 새 도로 양수 상태: 지시30의 60px 이상 숫자·22px 단위 계약은 신규 conquest 시험으로 고정.
- 다음 주행: 실제 카드 폭 `291px`(320px anchor 안 컨트롤 여백 포함), 두 행동 버튼 모두 한 줄·40px 높이, 667×300에서도 동일.
- 접근성: DeepSeek 실측 당시 NextRide group 이름이 보이는 제목을 따라 `이어 가기`로 바뀐 것을 확인했다. 후속 RC13에서 기존 계약 회귀로 판정해 `aria-label="다음 주행"`을 복원하고 신규 화면 시험에도 단언을 추가했다. dismiss·resume·extend/map 버튼 이름과 결과 시트 최초 닫기 포커스는 유지된다.
- 5021 임시 하네스는 감리 종료 시 DeepSeek가 직접 종료했다.
