## 검증

selector 계약 → 변경 ESLint → 전체 연속주행7건. 실패 시 원인과 실제 diff를 확인하여 필요한 하네스 범위만 교정한다. 5분 무진전이면 같은 대기를 중단하고 프로세스·포트·로그를 확인한다. 완료 때 보호 파일 해시·기존 미커밋 diff·포트·HANDOFF/PROGRESS/README/결과를 확인한다.

ride-verify 절차에 따라 `scripts/ride-verify/entry-contract.mjs`에 결과판 내부 닫기 앵커를 추가한다(기존 계약 유지·강화). RC2의 처음부터 라디오는 현행 「이어 달리기 선택」 팝오버를 먼저 여는 사용자 동작으로 접근한다. 기존 주행·진행률·저장·정복 검증 단언과 시간 한도는 늘리지 않는다. 캡처는 `RIDE_CONTINUATION_EVIDENCE_DIR`, Playwright 출력은 `--output`으로 지시52 새 폴더에 분리한다.
