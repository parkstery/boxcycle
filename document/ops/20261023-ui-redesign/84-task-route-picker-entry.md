# 지시 84 — MENU 경로 진입 통합·출처 순서 변경

2026-10-26 · Chief 직접 지시 · Supervisor Codex 직접 구현

## 목표

- MENU의 `입문 경로`·`퍼블릭 경로`·`내 경로` 세 행을 **`경로 선택` 한 행**으로 통합한다.
- `경로 선택` 진입 시 기본 출처는 **내 경로**다.
- 경로 목록의 출처 탭 순서는 **내 경로 → 퍼블릭 → 입문**이다.

## 허용 범위

- `RideRoutePanel`의 메뉴 진입점·기본 `listSource`
- `RouteListSourceNav`의 표시 순서
- 위 동작을 직접 검증하는 selector·화면 시험
- Chief 고정 목록·결정 로그·ops 인계 기록

## 금지

- 고정 목록 5의 경로당 한 줄 구조·수단 아이콘·상태·거리 변경 금지
- 고정 목록 6의 흰 불투명 경로 목록판 변경 금지
- 입문·퍼블릭·내 경로의 조회·선택·저장·공개·이어 달리기 동작 변경 금지
- Firestore 경로·기존 코드 식별자의 일괄 rename 금지
- 기존 dirty 파일, `.out/`, `cdbox.bat` 변경 금지
- worktree·restore·clean·stash·브랜치 전환·커밋·푸시·배포 금지

## 완료 조건

1. MENU 경로 행은 `경로 선택` 하나다.
2. 누르면 `내 경로` 대화상자가 열린다.
3. 출처 탭 DOM·시각 순서는 `내 경로`, `퍼블릭`, `입문`이다.
4. 세 출처 왕복, 닫기 후 MENU 복귀, 기존 한 줄 목록 계약이 통과한다.
5. 타입·lint·selector·관련 Playwright·정적 게이트가 통과한다.
