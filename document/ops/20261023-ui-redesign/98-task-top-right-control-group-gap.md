# 지시98 — 우상단 지도 조작·서비스 기능 구획

## Chief 결정 (2026-10-27)

우상단 `야외 / + / − / 순위 / 계정`에서 지도 조작 3개와 서비스 기능 2개 사이의 간격을 늘려 의미 구획을 명확히 한다.

## 구현 계약

- `야외 / + / −`는 기존 `맵 제어` 그룹과 순서·크기·동작을 그대로 유지한다.
- `순위 / 계정`은 하나의 서비스 액션 그룹으로 묶는다.
- 지도 조작 그룹과 서비스 그룹 사이는 서비스 그룹 내부 간격보다 시각적으로 크게 한다.
- 800×360에서는 한 줄 배치를 유지하고, 667×300 반응형 줄바꿈에서는 각 그룹을 쪼개지 않는다.
- 로그인 상태에서는 계정 대신 로그인 버튼을 같은 서비스 그룹에 둔다.

## 금지

- 고정3: 야외/위성·줌 +/−를 주행·일시정지에서 숨기지 않는다.
- 고정4: 순위 칩의 원형·그래프 아이콘을 바꾸지 않는다.
- 고정20: 주행 중 계정 버튼의 닉네임을 숨기거나 머리글자만 남기지 않는다.
- 버튼 크기·색·순서·동작·접근성 이름 변경 금지.
- 현재 다른 작업의 dirty 변경 되돌림·정리·커밋·푸시·배포 금지.
