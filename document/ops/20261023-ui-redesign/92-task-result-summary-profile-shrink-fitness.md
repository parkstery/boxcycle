# 지시·결과 92 — 주행 결과 60%·프로필 수정 70%·체중 70kg 시작·「체력」 1~5

2026-10-26 · Chief 직접 지시 · Supervisor Claude Code(Opus 5.5) 직접 구현·검증

## 지시

1. 「주행 결과」 창이 필요 이상으로 커서 지도를 다 가리고 다른 창과 균형이 맞지 않는다 → 창 크기를 60%로 축소.
2. 「프로필 수정」도 지나치게 크다 → 70%로 축소.
3. 프로필 수정 체중 칸에 처음 보이는 값이 입력 범위 「30–300」이다 → 70kg 으로.
4. 「운동 강도」 5단계는 내가 고르는 운동 강도가 아니라 내 **체력(운동 수행 능력)** 수준이다 → 제목 「체력」, 왼쪽부터 1~5, `체력  약함 1 2 3 4 5 강함`.

## 구현

- `RideSummarySheet.css` 가로 판: 740×324 → **444×194**(60%). 왼쪽 열 268→150px, 간격·패딩·큰 숫자(새 도로 km 4.5rem→2.7rem)·버튼·닫기를 0.6배. 글자는 폰 가로에서 읽히도록 **10px 아래로 내리지 않음**(제목 11px·지표 숫자 11px). 줄 높이가 20px 이 되어 칼로리 「설정」 버튼의 44px 투명 확장은 위아래 줄을 덮으므로 뺐다. 좁은 폰 하단 시트(640px 미만)는 그대로.
- `ProfileEditSheet.css`: 폭 520 → **364px**(70%), 패딩·간격·입력(32→22px)·체중 숫자(26→18px)·±(30→21px)·체력 칩(30→21px)·저장/취소(34→24px)·닫기(36→25px)를 0.7배, 글자 하한 10px.
- 체중 시작값: `caloriesEstimate.ts` `WEIGHT_KG_INPUT_START = 70`. 체중이 비어 있으면 입력칸·슬라이더·± 기준이 70. **보이는 값이 곧 저장될 값** — 저장을 누르면 70kg 이 저장된다. 칼로리 산정이 저장 안 된 체중을 70kg 으로 가정하는 일은 여전히 없다(SoT 「70kg 가정 금지」 유지).
- 「체력」: `CALORIE_INTENSITY_OPTIONS` 라벨을 `1`~`5` 로. 저장 id(`very-light`…`very-hard`)와 MET(3·4·6·8·10)는 그대로 — 체력이 높을수록 같은 시간에 더 센 강도로 달린다고 보고 잇는다. 데이터 이전 없음.
  - 프로필 수정: `체력  약함 [1][2][3][4][5] 강함`, 버튼 접근성 이름 「체력 N」.
  - 같은 목록을 쓰는 곳도 맞춤: 가입 카드(`체력 약함 1~5 강함`), 주행 설정 요약(「· 체력 3」), 주행 결과 칼로리(「체중·체력 입력 후 표시」·「체중·체력 설정」).
- 미리보기 `preview.tsx`: `variant=guest-full`(게스트 안내+칼로리 설정+저장 줄 동시), `variant=no-calorie`(체중·체력 미입력).
