# 지도 스타일 버튼 아이콘 — 지시

2026-10-29 Chief: 맵 선택 버튼의 「위성」「야외」 글자를 위성·지도를 뜻하는 이미지로 대체한다.

- 실제 MapHud 버튼에 인공위성/접힌 지도 SVG를 표시한다. 표시하는 것은 기존 텍스트와 동일한 현재 스타일이다.
- 기존 토글 콜백·접근성 이름·tooltip·주행/일시정지 표시·카메라2~6 야외 잠금·줌 조작은 보존한다.
- 제품의 기존 SVG/선 아이콘 방식으로 구현한다. 별도 이미지 생성·패키지 추가는 필요하지 않다.
- 기존 캡처 도구의 텍스트 기반 스타일 판별을 아이콘 상태 판별로 갱신한다.
- 타입·변경 lint·기존 관련 화면 계약·폰 가로 아이콘 표시/토글·겹침 확인. 기존 증거는 보존하고 이번 증거는 별도 경로에 기록한다.
- 커밋·푸시·배포는 이번 요청에 포함하지 않는다. [결과](100-result-map-style-icons.md)에 명령·통과/실패/미실행을 구분한다.
