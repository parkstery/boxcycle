## §1 실측 — 남는 세로 (두 뷰포트)

지시01 의 「169.9 − 125 ≈ 45」 외삽은 **dock 이 하단 고정**이라 성립하지 않는다.
높이가 100px 줄면 남는 세로도 **약 100px** 줄어든다(TL·dock 앵커가 뷰포트 양끝에 붙음).

| 항목 | 900×400 | 740×300 |
|---|---|---|
| 좌상단 bottom → 접힌 dock top 세로 여유 px | **270.7** | **170.7** |
| 미니맵 rect (top, left, w, h) | 47.3, 8.1, **264×148.5** | 47.3, 8.1, **264×148.5** |
| 미니맵 면적 / 화면 | **10.89%** (≈1/9.2) | **17.66%** (≈1/5.7) |
| 경로 등축: bbox 가로:세로 | 42.353 | 42.353 |
| 그려진 경로 가로:세로 | 42.353 | 42.353 |
| 등축 상대오차 | ~0 (1e-15) | ~0 |
| 좌표 수 원본/샘플 | 41 / 41 | 41 / 41 |
| 진척 50% 점↔경로 거리 px | **≈0** (6.9e-12) | **≈0** |

- 세로 상한: CSS `min(avail, 11rem)`. 두 뷰포트 모두 avail > 11rem 이라 **148.5px** 로 캡.
- 면적: 740×300 에서 **≈1/5.7** (1/6에 근접). 900×400 은 11rem 캡 때문에 **1/9.2** — 1/6 미달을 정직 보고(dock 침범 없이 더 키우면 900에서도 avail 여유 있음 → 감리 판단).
- 접힌 dock 과 미니맵 간격(740): dockTop 207 − mmBottom 196 ≈ **11px** (침범 0).
