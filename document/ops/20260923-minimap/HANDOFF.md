## 남은 문제 2건 (우선순위 순)

### 1. 폰에서 미니맵이 RouteDock 에 안 붙는다 — `보류02`

- **증상**: PC 는 붙어 보이는데 **실기 폰에서는 중간에 뜬다**(Chief 실기 확인)
- **원인(특정 완료)**: `RouteDock.css:562` 의 `@media (max-height:560px)` 가
  `--mapbox-logo-clearance` 를 `0.35rem` 으로 낮춰 dock 을 더 내린다.
  `RouteMinimap.css` 는 그 값을 `2.875rem` 으로 **복사**해 두고 미디어쿼리가 없다 → 약 34px 차이.
  실기에는 루트 글꼴(13.5px) · `env(safe-area-*)` · 모바일 주소창(visualViewport) 변수가 더 있다
- **고치는 방향**: 식을 맞추지 말고 **dock rect 를 실측**해 거기 붙인다. 재측정 시점은
  resize · orientationchange · visualViewport resize/scroll · 마운트 rAF · `fonts.ready`
- ⚠ **하네스가 이 버그를 재현하지 못한다**. `minimap-harness.html` 이 dock CSS 를 손으로 베꼈고
  문제의 미디어쿼리가 사본에 없다 — **항상 통과하는 게이트**였다.
  제품 CSS 파일을 그대로 불러오게 고치고, **먼저 버그를 재현(before)** 한 뒤 고쳐라

### 2. 미니맵 배경이 검다 — 실제 지도(Outdoors)가 나와야 한다 — `보류01`

- 감리 설계 오류였다. 「SVG 한 장」으로 확정할 때 지도 타일 자리를 만들지 않았다
- **방향**: 두 번째 GL 인스턴스가 아니라 **Static Images API 정지 이미지 1장**.
  경로 bbox 는 주행 내내 불변 → **요청 1회**. 움직이는 현재 위치만 SVG 로 위에 얹는다
- ⚠ **투영을 Web Mercator 로 바꿔야 한다.** 지금은 `cos(위도)` 등거리 근사라
  타일 위에 얹으면 경로가 미끄러진다. 이미지 요청과 SVG 가 **같은 center·zoom** 을 써야 한다
- 정합 검산: Static API 핀 ↔ SVG 점 픽셀 거리 **2px 이내**
- 밝은 지형 위 가독을 위해 선 색을 뒤집어야 한다(지금은 검은 배경 전제)
