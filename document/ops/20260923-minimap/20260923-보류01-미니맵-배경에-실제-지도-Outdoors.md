맞다. 지금 미니맵 배경은 어두운 판때기다. **감리 설계 오류**다 — 지시02 §0 에서

## §1 방식 — 두 번째 GL 지도가 아니라 **Static Images API 한 장**

선택지는 셋이었다:

| 안 | 내용 | 판정 |
|---|---|---|
| A | 두 번째 Mapbox GL 인스턴스 | ❌ 폰에서 GL 컨텍스트 2개 — 이 앱은 이미 3D 라이더 GLB + 메인 지도를 돌린다 |
| B | **Static Images API 정지 이미지 1장 + 그 위에 SVG 경로·현재 위치** | ✅ **채택** |
| C | 래스터 타일 직접 이어붙이기 | ❌ 직접 만들 이유 없음 |

**B 가 싼 이유**: 미니맵이 보여 주는 것은 **경로 전체**이고, 그 bbox 는 한 주행 동안
**변하지 않는다**. 즉 이미지 요청은 **주행당 1회**다. 움직이는 것은 현재 위치 점 하나뿐이고
그건 지금처럼 SVG 로 위에 얹는다.

```
https://api.mapbox.com/styles/v1/mapbox/outdoors-v12/static/
  {lon},{lat},{zoom},0,0/{w}x{h}@2x?access_token={MAPBOX_TOKEN}&attribution=false&logo=false
```

- 스타일은 **사용자가 고른 `mapStyle` 을 따른다**(기본값이 이미 `outdoors-v12` 다 —
  `lib/appSessionKeys.ts` `MAP_STYLE_OPTIONS`). 미니맵만 다른 지도를 보여 주지 마라.
  스타일 URL(`mapbox://styles/{user}/{id}`)을 Static API 경로로 변환하는 함수를 두어라
- `@2x` 로 요청하고 CSS 크기는 논리 px — 폰 고해상도에서 흐려지면 안 된다. 상한 1280px 유의
- `logo=false&attribution=false` 는 **같은 화면의 메인 지도가 이미 Mapbox·OSM 저작자
  표시를 하고 있기 때문에** 허용된다. 그 근거를 코드 주석에 남겨라
- 토큰 없음·요청 실패·오프라인이면 **지금의 어두운 배경으로 폴백**한다.
  미니맵이 사라지거나 깨진 이미지 아이콘이 뜨면 안 된다(`onError` 처리)
- 요청은 `useMemo`(기하 bbox + 상자 크기 + 스타일)로 고정한다. **주행 중 재요청 0회**를
  보고하라(개발자도구 네트워크 탭 또는 `performance.getEntriesByType('resource')` 로 센다)

## §2 ⚠ 투영을 **Web Mercator 로 바꿔야 한다** — 지금 것으로는 어긋난다

현재 `routeMinimapProjection.ts` 는 `cos(위도)` 보정 등거리(equirectangular) 근사다.
**Mapbox 타일은 Web Mercator 다.** 배경 이미지를 깔면서 지금 투영을 그대로 쓰면
**경로가 지도 위에서 미끄러진다.** 위도 37°·수 km 범위에서 수 px 어긋난다.

바꿀 것:

```
x = (lng + 180) / 360
y = (1 − ln( tan(φ) + sec(φ) ) / π) / 2        (φ = 위도 라디안)
zoom  = log2( min( w / (512·Δx), h / (512·Δy) ) )   ← 여백(6px) 반영
px    = (x − x_center) · 512 · 2^zoom + w/2
py    = (y − y_center) · 512 · 2^zoom + h/2
```

- **이미지 요청에 쓰는 center·zoom 과 SVG 가 쓰는 center·zoom 이 같은 값**이어야 한다.
  둘을 각자 계산하지 말고 **한 함수가 돌려준 값을 둘 다 쓰게** 하라
- 등축 왜곡 없음은 Mercator 에서 자동으로 지켜진다(x·y 배율이 같다)

### 정합 검산 (눈이 아니라 숫자로)

같은 요청에 **Static API 의 마커 오버레이**를 얹어 우리 SVG 점과 비교하라:

```
/static/pin-s+ff0000({시작lng},{시작lat}),pin-s+0000ff({종점lng},{종점lat})/{lon},{lat},{zoom},0,0/{w}x{h}
```

- 검산 캡처에서 **핀 끝점 픽셀 좌표 vs 우리 SVG 시점·종점 점 중심**의 거리를 재라.
  **2px 이내**면 합격. 이 검산용 마커는 제품 코드에 남기지 마라(캡처 전용)

## §3 밝은 지도 위에서의 가독 (배경이 검정에서 밝은 지형으로 바뀐다)

- 경로 선은 **메인 지도가 쓰는 경로 색과 같은 색**을 써라 — 미니맵의 선과 큰 지도의 선이
  다른 색이면 같은 경로로 읽히지 않는다. 색 상수를 새로 만들지 말고 기존 것을 import 하라
- 밝은 타일 위에서는 **흰 외곽선 + 진한 선**이 맞다. 지금은 반대(어두운 배경 전제)다.
  외곽선은 흰색 계열로 뒤집고, 현재 위치 주황 점은 **진한 테두리**를 둘러 유지한다
- 미니맵 틀의 어두운 반투명 배경은 **제거**한다(지도가 배경이 된다). 1px 테두리·라운드는 유지
