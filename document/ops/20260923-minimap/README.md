## 1. 파일 이름 규약

```
20260923-지시01-<내용>.md              ← 감리가 쓴다
20260923-지시01수행결과-<내용>.md       ← 개발팀장이 쓴다
20260923-지시01수행결과02-<내용>.md     ← 같은 지시를 재작업했을 때
```

- 번호는 **지시에 종속**된다. 수행결과는 자기 일련번호를 갖지 않는다
- 날짜 접두어 `20260923-` 는 이 묶음 개시일로 **고정**(작성일이 아니다)

## 3. 이 묶음의 고정 규칙

- `git commit` · `git push` **금지**. 커밋은 감리 승인 후 별도 지시한다
- **한 라운드 = 화면 변화 하나.** 문서만 도는 라운드를 만들지 않는다
- 감리는 수행결과를 읽기 **전에** `git diff --stat -- apps/web/src` 를 본다. 0줄이면 내용과 무관하게 반려
- 감리는 앱을 직접 띄우지 않는다 — **개발팀장의 캡처로만 판정**한다.
  그러므로 캡처 목록은 지시서가 미리 못 박고, 빠지면 반려한다
- 이미지는 **폴더 경로를 통째로** 준다(`.out` 은 gitignore 라 파일 링크가 안 열린다).
  한글 경로에서 headless 크롬이 hang 한 전례가 있으므로 ASCII 미러 경로를 함께 쓴다
- 검증 예산: 한 주행 검증 5분 · 같은 수정 3회면 접근 전환 · 브라우저 5분 무진전이면 정적 하네스로 전환 ·
  e2e/에뮬레이터 프로세스를 남기지 않는다
