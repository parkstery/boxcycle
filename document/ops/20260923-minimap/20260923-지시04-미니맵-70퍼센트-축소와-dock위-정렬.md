## §1 ⚠ 먼저 알아 둘 것 — Chief 가 본 화면은 폰 가로가 아니다

Chief 의 캡처는 데스크톱 브라우저 창이다(뷰포트 약 **1161×870**, 종횡비 **1.33:1**).
네 공식은 상자 종횡비를 화면비에 맞추므로, 그 창에서는 **세로로 큰 상자**가 된다
(폭 42% ≈ 488px → 높이 ≈ 366px). 폰 가로(2.47:1)에서는 같은 코드가 **311×126** 이다.

→ **「70%」는 그 창에서의 눈 판단**이다. 그래도 **70% 를 적용하되**, 폰 가로에서
100% 와 70% 를 **나란히 놓은 비교 사진**을 제출하라. 최종 선택은 Chief 가 한다.

## §2 크기 — 선형 70%

```
A      = innerWidth / innerHeight
width  = min(0.294 × innerWidth, availH × A)      ← 0.42 × 0.7 = 0.294
height = width / A
```

- **선형 70%**(가로·세로 각각 0.7배)다. 면적은 0.49배가 된다. 면적 70% 가 아니다
- 비율은 상수로 빼고 한 줄 주석을 달아라 — 예:
  `const MINIMAP_WIDTH_RATIO = 0.294; // 0.42 × 0.7 (2026-09-23 Chief 실기 판단)`
- 가독 최소값은 **그대로 지킨다**: 밝은 선 ≥ 1.5px · 외곽선 ≥ 3px · 현재 위치 점 지름 ≥ 7px.
  상자가 작아졌다고 선까지 줄이면 「아무것도 안 보이는 미니맵」이 된다

## §3 위치 — RouteDock 바로 위(하단 기준)

지금은 **상단 기준**(`top = TL 아래`)이라 상자 크기가 바뀌면 아래쪽 여백이 출렁인다.
**하단 기준으로 바꾼다.**

```
bottom = (RouteDock 의 bottom 오프셋) + (접힌 dock 높이) + 간격(0.35rem)
```

- RouteDock 의 bottom 계산식(`--route-dock-pad` + `env(safe-area-inset-bottom)` +
  `--mapbox-logo-clearance`)과 **같은 값을 공유**하라. 두 벌로 베껴 쓰면 한쪽만 바뀐다.
  공유가 어려우면 왜 어려운지 한 줄 적고 상수를 한 곳에 모아라
- 좌측 정렬은 유지 — RTW · RouteDock 과 **같은 왼쪽 여백**에 세로로 줄이 맞아야 한다
- 상단 기준 `top` 계산은 제거한다. 남는 세로(`availH`)는 **여전히 상한**이다
  (좌상단 블록을 침범하면 안 된다)
- 펼친 dock 과의 겹침은 **허용**(dock z-index 6 > 미니맵 4). 다만 실측 px 를 보고하라
