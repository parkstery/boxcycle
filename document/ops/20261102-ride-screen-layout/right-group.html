오른쪽 버튼 묶음 시안 v4 · 2열 4줄, Chief 지정 배치

v4에서 바뀐 것: 오른쪽 묶음을 2열 4줄로 되돌리고 Chief가 정한 칸에 놓았습니다 — 1줄 CAM | 지도 스타일, 2줄 ＋ | －, 3줄 INT | 순위, 4줄 ⏹ | ⏸·▶. ⚙ 주행 설정은 왼쪽 메뉴 패널 안으로(반달 탭을 눌러 보세요), 미니맵은 원래의 접기·펼치기 버튼(미니맵 왼쪽 위 28px)으로 되돌렸고, 계정 버튼은 오른쪽 위 모서리에 그대로 둡니다.

인터벌과 왼쪽 아래: 인터벌이 시작되면 미니맵은 펼친 채, 경로 카드는 접힙니다. 인터벌이 펼쳐져 있는 동안은 경로 카드·미니맵 중 하나만 펼칠 수 있고, 먼저 펼친 쪽이 자리를 지킵니다(다른 쪽을 누르면 안내만 뜸). 인터벌을 접으면 둘 다 펼칠 수 있습니다. 아래 화면에서 경로 손잡이·미니맵 버튼·인터벌 패널을 눌러 볼 수 있습니다.

화면 상태

배치 규칙

  • 2열 4줄 [1열 | 2열]: 1-1 CAM, 1-2 지도 스타일 / 2-1 ＋, 2-2 － / 3-1 INT, 3-2 순위 / 4-1 ⏹, 4-2 ⏸·▶.
  • 빈 칸: 주행 전 = CAM·⏹, 주행 중 = INT(주행 중 인터벌 변경 불가, 10-30 결정), 일시정지 = 없음. 다른 버튼이 빈 칸으로 옮겨 오지 않습니다(「칸 번호」를 켜면 점선으로 보임).
  • 크기: 주행 전 계정 버튼 아래(위 40px)에도 4줄이 들어가는 값을 세 상태에 똑같이 씁니다 — 800×360 64px(지금과 같음), 300px 폰 58px, 699×273 51px.
  • 계정 버튼: 오른쪽 위 모서리 그대로(실앱처럼 주행 전에만 보임). 주행 전 순위 목록은 그 아래에서 시작.
  • ⚙ 주행 설정: 왼쪽 메뉴 패널 안 항목. 주행 중에도 반달 탭 → ⚙ 두 번 누르면 열립니다.
  • 미니맵: 원래 방식 — 미니맵 왼쪽 위 28px 버튼으로 접기·펼치기. 접으면 28px 버튼만 남고 경로 손잡이가 그만큼 내려옵니다.
  • 인터벌 펼침 중 하나만: 시작 시 미니맵 펼침·경로 카드 접힘. 둘 중 하나가 펼쳐져 있으면 다른 쪽 버튼은 흐려지고, 누르면 「○○을 접거나 인터벌을 접으면 펼칠 수 있어요」 안내. 인터벌을 접은 동안 둘 다 펼쳤다가 인터벌을 다시 펼치면 나중에 펼친 쪽이 접힙니다.
  • 그대로인 것: 센서 LED·RPM은 계기판 맨 앞 칸, 순위 목록은 오른쪽 가장자리 고정(순위 버튼으로 열면 2초 뒤 묶음 숨김), 5초 자동 숨김은 오른쪽 묶음만.

정해 주실 것

  1. 「먼저 펼친 쪽이 우선」의 뜻: 시안은 나중 쪽을 막고 안내합니다(흐린 버튼). 반대로 「나중 쪽을 누르면 펼치되 먼저 쪽을 접는다」는 바꿔치기 방식도 됩니다 — 어느 쪽인지 확인 부탁드립니다.
  2. 699×273 51px: 계정 버튼이 주행 전에만 보이므로, 주행 중·일시정지에만 위 여백을 8px로 줄이면 59px까지 키울 수 있습니다. 대신 주행을 시작할 때 버튼 크기가 51→59px로 바뀝니다. 시안은 세 상태 같은 크기.
  3. 지도 핀(경로 목록): 8칸에 자리가 없어 v3처럼 주행 전 경로 카드 머리줄에 두었습니다.
  4. 5초 자동 숨김: 오른쪽 묶음만 숨기고, 경로 손잡이(40px)·미니맵 버튼(28px)은 남깁니다.

화면별 버튼 크기(계산값)

계산: 버튼 = (화면 높이 − 위 40px(계정 버튼 32 + 8) − 아래 8px − 간격×3) ÷ 4줄, 최대 64px. 간격은 높이 312px 이상 8px, 미만 6px. 세 상태가 같은 크기입니다.
