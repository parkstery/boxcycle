## 정한 것(11-02 Chief 「네가 제안한 방안을 수용한다」)

1. 「이 Trail 공개/비공개」 전환 위치 — 제안: 메뉴 패널에 남기고 주행 중엔 일시정지에서 연다.
2. 자동 숨김 때 ⏸도 숨길지 — 제안: 모두 숨김(지도 한 번 탭으로 나타남). 대안: ⏸만 작게 남김.
3. 왼쪽 반달 탭의 의미 — Trail 목록이 오른쪽으로 가면 왼쪽 탭은 메뉴 패널(검색·설정·로그인)만 연다.
4. 숨김까지의 시간 — 제안 5초.

## 단계 (각 단계마다 캡처 보고 → 승인 → 다음)

1. **목록 자리 통합(D5·D6)**: 오른쪽 순위 목록에 「순위 \| Trail」 탭과 Trail 줄(번호·짧은 이름·km·주행 중/합류) 추가, 10줄. 메뉴 패널의 Trail 목록은 제거하거나 링크로 축소. 파일 후보: `LeaderboardGlance*`, `TrailHubPanel.tsx`, `MapHud.tsx`, App 배선. 계약: 10줄·탭 전환·합류 동작·현재 Trail 강조.
2. **오른쪽 조작 레일(D1·D2)**: 우상단 가로 구름 버튼(카메라·지도 스타일·＋·－)을 세로 레일 64px로. 계정 버튼은 주행 중 숨김. 파일 후보: `MapHud.tsx`·`CloudMapControls.css`·`CameraViewMenu.*`(트리거 크기·메뉴 펼침 방향). 고정 20·30·43·52·56·59·61 갱신.
3. **왼쪽 아래 주행 버튼 줄(D1·D2)**: RouteDock 접힘 도구(⚙·⏸·⏹)를 64px 줄로, 미니맵 버튼 추가. 주행 중 주소 카드·RouteDock 펼침 숨김(일시정지에서 표시). 고정 12·29·42·45·46·48·53·59 갱신.
4. **자동 숨김과 목록 이동(D3·D4)**: 주행 중 무입력 N초 → 레일·버튼 줄 숨김, 지도 탭 → 표시. 순위 목록 x 이동 0.3초. 지도 제스처(끌기·확대)는 표시만 하고 지도 조작은 그대로. 고정 7·14·41·57·58 갱신.
5. **전체 회귀·낮은 폰**: 800×360·736×300·699×273·667×300 캡처, e2e(ui-800x360·compact-controls·toolbar-trail-style·ride-interval·route-dock-tools·sensor-dock) 정리.

## 위험

- 고정 목록 30건 가까이가 걸린다. 단계마다 해당 고정 항목을 같은 커밋에서 갱신한다.
- 버튼 2배는 낮은 폰(273px)에서 레일 4칸이 안 들어간다 → 3칸으로 줄이는 규칙을 계약으로 고정.
- 자동 숨김은 처음 쓰는 사람에게 버튼이 「없어진」 것처럼 보일 수 있다 → 첫 숨김 때 「화면을 누르면 버튼이 나타나요」 한 번 안내.
- 지도 출처·mapbox 로고는 가리지 않는다(약관).
