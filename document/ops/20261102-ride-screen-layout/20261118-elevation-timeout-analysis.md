# 표고 조회 실패 증가 분석·센서/RPM 순서 교환

**2026-11-22 Chief 결정: 60초 대기 연장안은 채택하지 않는다. 해당 함수와 회귀시험의 60초 변경을 철회해 기존 15초 제한을 유지했다. 아래는 당시 실험 기록이며 현행 방침이 아니다. 느린 표고 조회의 원인과 사용성 문제는 미해결이다. 센서 단추→RPM 변경만 별도 커밋한다.**

수행: Codex, 2026-11-18. Chief: 기존에 되던 지역도 표고 조회가50% 이상 실패한다는 관찰의 원인 분석, 센서 버튼과 RPM 숫자 위치 교환.

## 확인한 회귀

직전 제품 커밋 `e0d2acfe`에서 `fetchElevationsForCoords`의 제한 없던 HTTP fetch에 **15초 timeout**을 추가했다. 이는 유효한 늦은 응답도 실패 처리한다. 이번 실제 브라우저 조회에서15초를 넘는 정상 응답을 확인했으므로 지역 데이터 부재로 분류할 수 없다.

| 요청 | 관측 결과 |
|---|---|
| 원주 인근37.35,127.90→37.36,127.91,2개 균등 좌표 | HTTP200, **23,293ms**, 값2개 `[101,115]` |
| 같은 범위72개 균등 좌표(앱과 같은 샘플 수) | HTTP200, **23,424ms**, 값72개 |
| Florida 인근26.10,-80.15→26.11,-80.14,72개, 당시15초 실제 함수 | 정상72개, **138ms** |
| 위와 같은 URL,60초까지 기다리는 별도 fetch | HTTP200,72개·모두 유한수, **334ms** |

- 앞선 원주 요청은 진단용60초 제한으로 정상 응답까지 기다렸다. 배포 코드의15초 제한이었다면 그 응답을 받기 전에 종료된다. Florida 비교는 빠른 정상 응답도 있다는 증거이며, 같은 요청에서15초 실패/60초 성공을 동시에 재현했다는 뜻은 아니다.
- 이번 요청들에서는429·빈 배열·길이 불일치가 관측되지 않았다. 강화된 응답 개수/유한수 검증을 만족하는 정상72개 응답이었다. 따라서 검증 조건 완화/0m 대체는 필요 없다.
- 요청 지연의 세부 단계(DNS·연결·서버 대기)는 cross-origin Resource Timing에서 requestStart/responseStart/transferSize 등이0으로 제공돼 이번 기록만으로 특정하지 못했다. 초기 연결/공급원 응답 지연의 어느 쪽인지는 단정하지 않는다.
- 사용자 보고의50%를 통계적으로 재측정한 것은 아니며, 실패 전체가 timeout이라는 결론도 아니다. **실패를 늘릴 수 있는 최근 회귀 한 가지는 실제 정상 지연과 가상시간 회귀시험으로 확인**했다.

## 캐시·조회 경로

기존 순서는 세션 캐시→Firestore 공유 저장소→Open-Meteo. 캐시 적중은 HTTP 제한의 영향을 받지 않지만, 신규 경로/다른 기하의 캐시 미적중은 외부 요청을 거친다. 같은 지역이라도 다른 경로는 캐시 키가 달라진다. 실패 응답은 캐시에 기록하지 않으므로, 느린 요청을15초에 중단하면 성공 캐시도 남지 않아 반복 조회에서도 실패가 재발할 수 있다.

공유 저장소는 읽기/쓰기 실패를 삼키고 외부 조회로 진행한다. Firestore 자체 대기는 HTTP timeout과 별개다. 이번에는 운영 인증/실패한 특정 경로의 Firestore 요청을 조사하지 않았으므로, 실제 사용자 요청의 공유 캐시 적중률이나 권한 실패는 미확인이다. Rules·공급원·캐시 범위는 바꾸지 않았다.

## 로컬 수정·검증

- HTTP 제한 **15초→60초**. 미수신 작은 표시/수동 재시도·429 구분·응답 검증 유지. 대기 중 자동 재시도는 추가하지 않음.60초보다 늦거나 네트워크가 실패하는 요청까지 성공을 보장하는 조치는 아니다.
- 센서 칸의 하단을 **단추→RPM 숫자**로 교환. RPM 라벨도 오른쪽 숫자 위에 맞추고,62px 칸·30px 단추·13px LED·클릭/상태 동작은 유지. 숫자 오른쪽으로 기존 거리/시간 계기가 이어짐. 고정81 갱신.
- 통과: 표고 관련 단위 **20/20**(가상시간15,001ms에도 pending,23.5초에 유효 응답 수신·요청1회), 센서 화면 **10/10**(가로800·736·699·667×주행 전/중/일시정지/경로 없음, 단추→숫자·라벨 정렬), tsc·변경TS/TSX ESLint·Vite build·진입 셀렉터21/21·diff check. 기존 대형chunk 경고만 남음.
