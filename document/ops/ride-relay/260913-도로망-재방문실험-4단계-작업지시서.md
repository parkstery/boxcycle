## 0. 역할

- **수퍼바이저**: Cursor(본 세션) — 지시·감리·Chief 보고. **제품 코드 직접 작성 금지.**
- **개발팀장**: 창 이름 **`260910-개발팀장`** (또는 동일 역할 에이전트) — 본 지시서만 구현·PR.
- 제출 즉시 수퍼바이저 감리. **동일 작업 FAIL 최대 3회** 후 중단·Chief 보고.

## 1. 목표

소규모 재방문 실험을 **시작할 수 있는 준비물**을 만든다. 실제 모집 발송·4주 관찰 운영은 Chief/운영 — 이번 PR에 포함하지 않는다.

## 2. 이번 PR 완료 항목

1. **측정 배선 (최소)**  
   - 후보 이벤트(이름 확정 가능): `ride_summary_viewed`, `ride_summary_resolved`, `next_ride_selected`  
   - 기존 Ride 기록으로 가능한 지표는 재사용. **신규 Firestore 컬렉션/외부 SaaS 도입 전** 저장 위치·보유 기간·접근 권한을 문서+코드 주석에 명시.  
   - 이벤트에 좌표·주소·이메일 금지. uid/rideId는 최소 범위.  
   - 배선이 no-op(로컬/콘솔)이어도 계약 테스트로 호출·페이로드를 고정할 것.

2. **호환 조합 안내**  
   - 검증된(또는 현재 권장) OS·브라우저·센서(케이던스) 조합을 사용자가 볼 수 있는 표면 1곳(예: 센서 시트·도움 문구·짧은 정적 문서 링크)에 정리.  
   - 미검증 조합을 보장처럼 쓰지 말 것.

3. **실험 운영 초안 문서** (`document/ops/` 또는 `document/archive/` 초안)  
   - 테스트 사용자 모집 **문안·인원(약 20)·포함 기준** (발송 실행 금지)  
   - 고정 주제·시간대 동행 운영안 1페이지  
   - §5 측정 표와 연결(첫 사용 성공 / 다른 날 재사용 등)

**금지:** 실제 모집 메일/DM 발송 · 결제·유료 실험(5단계) · Journey · Conquest 인정 변경 · nextRideTarget 파생 변경 · 카메라 전면 교체 · Modelling/GLB · 6A 센서 칩 대규모 이동 · 2·3단계 Hosting 회귀를 깨는 idle/주행 UI 재설계.

## 3. 수용 기준

| ID | 기준 |
|---|---|
| E1 | 세 이벤트(또는 동등 3종)가 제품 경로에서 호출되며, 페이로드에 PII/좌표 없음 — 계약 테스트 pass |
| E2 | 저장 위치·보유·접근이 문서에 명시(미정이면 「미정·이번 PR no-op」과 후속 게이트를 명시) |
| E3 | 호환 조합 안내가 UI 또는 사용자 접근 가능 문서에 존재 |
| E4 | 모집·동행 운영 초안 문서 존재(발송 증거 불필요) |
| E5 | `npm run test:next-ride` fail 0 + 신규 이벤트 계약 테스트 fail 0 |
| E6 | PR → main2 (배포는 Chief 승인 후). **머지·배포는 개발팀장 금지** |
