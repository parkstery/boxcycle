## 1. 개발팀장에게 내리는 지시

**앱을 다시 열었을 때 사용자가 ‘어제 멈춘 길’을 첫 화면에서 읽고, 한두 번의 조작으로 이어 달리거나(데이터 없으면) 입문 코스로 들어가게 한다.**

이번 PR에서 아래 세 가지를 완료한다.

1. `NextRideCard`가 있을 때 **초기 지도 범위**를 재개 앵커(또는 남은 구간)에 맞춘다. 사용자가 이미 지도를 움직인 뒤에는 다시 점프하지 않는다.
2. 카드 **가독성·위계**를 높이고, 카드가 보일 때 좌하단 idle 힌트(「MENU → 입문 경로」)와 경쟁하지 않게 한다.
3. 다음 주행 후보가 없는 **첫 사용자(또는 기록 없음)** idle에서 기존 입문 코스 진입을 **1급 CTA**로 제공한다(MENU 딥링크만으로 끝내지 않는다).

**파생·저장·Go 게이트는 바꾸지 않는다.** `resolveNextRideTarget` / SavedRoute 진행률 진실 / CTA는 prepare까지만 / Journey 신규 모델 / Conquest 파이프라인 / 카메라 시점 전면 교체는 범위 밖이다.

## 3. 화면 계약

### 3.1 후보가 있을 때(재방문)

```text
[지도: 재개 앵커 또는 남은 구간이 보이도록 프레이밍됨]

좌하단 「다음 주행」 카드 (기존 CTA)
  · resume_route: 이어 달리기 / 지도에서 보기 …
  · extend_from_ride: 이 지점에서 새 경로 …

(idle 「MENU → 입문」 힌트는 숨김)
```

- 프레이밍은 카드가 **처음 안정적으로 보일 때 1회**. `rideId`가 바뀌면 다시 1회 허용.
- 사용자가 pan/zoom 한 뒤에는 자동 재프레이밍하지 않는다.
- Route를 자동으로 올리지 않는다. CTA 「이어 달리기」만 Route를 준비한다(기존 계약).

### 3.2 후보가 없을 때(첫 사용자·기록 없음)

```text
좌하단 「시작하기」류 카드(또는 NextRide 슬롯 재사용)
  입문 코스로 달려 보기
  [입문 코스 열기]  → 기존 Official intro 로드 경로
```

- GuestEntry·AuthGate는 기존대로 선행. 인증 전 기능 불가.
- 입문 geometry·Publication은 기존 카탈로그만 사용. 새 시드·임의 20분 약속 금지.
- 용어: Trail/Trailhead, Guest, 내 도로망 — Ontology 준수. Room/Lobby/z20 UI 금지.

### 3.3 회귀로 깨지면 안 되는 것

- 결과 시트 → 닫기 → idle 에서 NextRideCard 재노출
- Route 로드 시 카드 사라지고 RouteDock 표시
- Go·센서 준비 게이트
- km 표기 소수 2자리(`formatRideDistanceKmNumber`)
