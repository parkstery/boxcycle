## 1. 지시

달리는 중에도 **지금 어디까지 왔는지**가 한눈에 읽히고, 편집·설정 UI가 주행을 가리지 않게 한다. 추천 코스 제목·목적지는 기존 Publication 데이터를 쓰되 표현만 정리한다.

이번 PR 완료 항목:

1. **라이브 궤적/진행률 위계** — 주행 중 HUD·지도에서 세션 진행(거리·남은 구간·재개 마커 등 기존 자산)이 주변 크롬보다 우선 읽히게 정리. 새 메트릭/새 파이프라인 금지.
2. **주행 중 편집 UI 접기** — ready/running/paused 에서 경로 편집·불필요 dock 노출을 줄여 Go·종료·센서 재연결만 남긴다(기존 6A·센서 칩과 충돌 시 6A 우선, 중복 이동 금지).
3. **추천 코스 표기** — 제목·목적지 문자열을 Ontology 용어로 정리(Room/Lobby/course 신규 UI 금지). geometry·Publication 없는 가짜 약속(「20분 도착」·도시 %) 금지.

**금지:** Journey 신규 · Conquest 인정 규칙 변경 · `nextRideTarget` 파생 변경 · 카메라 시점 전면 교체 · 라이더 GLB/Modelling · 새 도로 HUD 재작업.

## 2. 수용 기준

| ID | 기준 |
|---|---|
| H1 | 센서 준비 → Go → running → 종료 → (해당 시) 재개 전체 흐름이 깨지지 않음 |
| H2 | running 중 경로 편집·불필요 설정 표면이 접히거나 진입이 1탭 이상 깊어짐(기존 동작 회귀 없음) |
| H3 | 좁은 가로 화면에서 HUD·궤적·Go/종료가 겹쳐 조작 불능이 아님 |
| H4 | 추천/입문 코스 제목·목적지가 Ontology 용어·기존 데이터만 사용 |
| H5 | `npm run test:next-ride` fail 0 + 관련 기존 회귀(ride-entry/selector 등 변경 시 해당 스위트) |
| H6 | PR → main2 (배포는 Chief 확인 후) |
