Chief가 대화에서 흐름을 확인하고 「진행해」로 구현 승인했다. Supervisor는 아래 작은 설계를 확정한다. Developer Cursor AI·CLI는 구현·시험 담당. 설명·질의·결과는 한국어로 작성한다. 다른 담당과 공용 저장소이므로 기존 dirty(이전 인트로·preload·문서 포함)를 보존하고 승인된 후속 부분만 수정한다. 이전 2초 자동 전환은 최신 요구로 대체한다. 큰 재설계 금지.

## 확정 동작

1. 첫 인트로의 제목·사진·출처는 유지하고 「게스트로 시작」「로그인」 버튼을 둔다(44px 이상, 폰 가로·키보드·오류/대기 고려). 2초 자동 전환은 제거한다. 정상 첫 진입에서 기존 「세계에 참가하기→시작」 카드를 다시 요구하지 않는다. 인증 복원 대기·설정 없음·명시 로그아웃·탈퇴 안내·로그인 실패/취소의 안전한 회복은 보존한다.
2. 어떤 버튼이든 클릭하면 인트로를 즉시 닫아 이미 뒤에서 실행 중인 Mapbox 지구본을 드러낸다. 새 지도 인스턴스를 만들지 않는다. 게스트는 기존 beginAuthenticatedSession, 로그인은 기존 handleGoogleSignIn을 클릭 핸들러에서 바로 호출한다. 특히 Google popup은 permissions.query/geolocation을 await한 뒤 호출하면 브라우저가 막으므로 첫 클릭에서 즉시 실행한다. async 인증 실패는 unhandled rejection 없이 기존 오류 UI에서 재시도 가능하게 한다. 위치 선택이 인증 방식·uid·회원 연결을 바꾸지 않는다. 기존 인증 복원된 사용자는 새 익명 계정을 자동으로 만들지 않는다.
3. 지구본은 위치 선택·조회 동안 유지하고 최종 목적지가 정해지면 기존 flyTo 연출로 확대한다. 기본 목적지는 MAP_FALLBACK_CENTER 콜로세움/줌15. 앱 mount 시 Mapbox 생성/스타일 로딩은 인증/위치 결정을 기다리지 않는다. 과거 localFirst geolocation/search 저장만으로 현재 권한·목적지를 단정하지 않는다. 이번 시작에서 콜로세움을 선택했는데 자동 localFirst 카메라 effect가 저장된 서울 등으로 다시 덮지 않게 한다. 사용자가 진입 이후 명시 검색/재개하는 기존 기능은 보존한다.
4. 위치 권한은 navigator.permissions.query({name:'geolocation'})로 확인하되 미지원·거절·예외를 안전하게 처리한다. 진입 버튼 전에는 getCurrentPosition 호출·권한창 자동 요청 금지. 이미 granted면 getCurrentPosition 1회로 현재 좌표 확인 후 이동한다. navigator.geolocation 없거나 위치 실패/타임아웃/잘못된 좌표면 콜로세움으로 진행하고 짧은 한국어 안내를 남긴다. watchPosition 금지, 좌표 로그·분석·서버 전송·새 저장 키 금지.
5. prompt/unknown이면 지구본 위에 다음 안내: 제목 「어디에서 시작할까요?」, 설명 「위치를 공유하면 내 주변 지도에서 시작합니다. 공유하지 않아도 로마 콜로세움에서 시작할 수 있습니다.」, 버튼 「내 위치에서 시작」「콜로세움에서 시작」. 내 위치 클릭 때만 getCurrentPosition으로 브라우저 권한 요청. 이미 denied이면 브라우저 설정에서 위치를 허용해야 한다는 설명과 콜로세움 선택을 제공하며 무한 권한 재요청 금지. 위치 조회중에도 「콜로세움에서 시작」으로 빠져나갈 수 있게 하고, 그 후 늦은 위치 callback이 사용자를 다시 이동시키지 않게 request token/cleanup 가드. 위치조회는 8초 정도 유한 timeout, 다중 클릭·StrictMode·unmount 안전. Permissions query 자체도 무기한 진입 정지하지 않게 한다.
6. 복원된 Guest/등록 사용자도 위치 정책을 적용한다. 기존 인증을 유지한 채 앱 진입 시 granted면 현재 위치, 아니면 동일 위치 안내를 보이며 권한 없는 사용자도 콜로세움으로 진행할 수 있게 한다. 별도 인증 버튼 클릭을 강제하거나 원치 않는 새 계정 생성 금지. 외부 공개 링크/실주행 재개를 임의 파괴하지 말고 경합 발견 시 결과에 보고한다.
7. reduced motion은 기존 동작 줄이기 설정을 존중한다(애니메이션 대신 목적지 즉시 표시 가능). 정상 motion은 지구본이 실제 보인 다음 확대한다. Mapbox attribution을 가리거나 제거하지 않는다.

## 구현 경계·소유

필요한 제품 파일만: App.tsx, AppIntroScreen.tsx/css, 신규 작은 위치 안내 컴포넌트와 hook/geo helper(예: useEntryLocation 및 순수/브라우저 위치 helper), MapView.tsx의 기존 bootFlyHold/목적지 처리. 공용 MapView props 추가는 이번 승인된 목적지 연결에 필요한 최소 하나의 bootFlyTarget 정도로 허용한다. 지도는 기존 하나를 계속 사용하고 기존 externalCameraJump/검색·재개/주행을 바꾸지 않는다. mapBootCenter 기존 resolve 계약을 통째로 바꾸기보다 App 진입 초기값·부트 목적지로 분리해 기존 명시 지역 기능과 회귀를 지킨다. GuestEntryCard는 회복/탈퇴 안내 등 필요한 예외에만 사용하며 정상 통합 진입과 중복 렌더하지 않는다. AuthSessionGate는 부트·오류·취소 회복 유지, 필요 최소 연결 수정 가능. useAppAuth는 기본적으로 변경 금지(필요 시 이유를 보고). 기존 인트로 사진/HTML preload는 이번에는 유지한다.

시험 소유: scripts/ride-verify/entry-contract.mjs를 먼저 새 UI 계약에 맞추고 e2e/rideEntryHelpers.ts와 ride-entry.spec.ts를 함께 갱신한다. 공용 helper를 부르는 스펙이 다수이므로 이름/시그니처는 유지하고 새 guest 버튼→선택적 위치 안내 콜로세움 선택→인증 완료를 처리한다. helper가 이미 인증된 화면을 잘못 클릭하거나 인증 대기 status를 성공으로 오인하지 않도록 한다. 위치 흐름에 meaningful tests를 scripts/identity 또는 scripts/map 아래 *.test.*로 추가한다. 테스트 전용 제품 쿼리·백도어 금지.
