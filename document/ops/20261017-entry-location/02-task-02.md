지시01의 확정 동작·범위·검증을 그대로 수행한다. 결과 경로만 `03-result-02.md`로 바꾼다. Cursor 실행은 stream-json으로 Supervisor가 진행을 확인한다. 첫 실행은 출력·새 편집 없이 중단되었으므로 완료를 추정하지 말고 현 diff로 확인한다. 잔여 작업을 한 번에 구현·시험하고 결과를 기록한 뒤 종료하라. 지시/색인 편집과 commit/push/deploy/browser/server/subagent는 계속 금지다. 지정 소유 파일만 apply_patch로 수정한다. 기존 다른 작업 dirty를 보존한다.

추가 허용: 현재 운영 진단 스크립트 `apps/web/scripts/perf/run-real-gpu.mjs`에 폐기된 소개 「시작하기」 클릭 두 곳이 남아 있다. 진입 UI 소비자이므로 이번 새 게스트→선택적 콜로세움 위치 안내 계약에 최소 수정한다. 과거 ops/archive 스크립트는 수정하지 않는다.

새 디버그 코드·주소 스위치·스크립트를 만들면 `apps/web/dev-tools.json` 에 등록한다(분류·목적·켜는 법·만료). 운영에서 켜지는 도구 화면은 동적 import 로 분리한다.
