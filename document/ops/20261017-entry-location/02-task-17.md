## 조사 후 추가 범위 — 첫 지도 load 카메라 경합

실제 앱 native 허용결과 후 대화상자는 닫혔으나 로마잔류가 1회 재현됐다. 추적상 2D 초기화 apply3DState의 pitch0 easeTo는 같은 load시작 위치 flyTo를 취소할 수 있다. 기존 카메라 시험에 실제 helper와 실제 MapView effect 순서를 실행하는 실패회귀 추가(수정전 FAIL). 소유 rideCameraFollow.ts의 이미 pitch0일 때 중복easeTo만 생략, 3D→2D 전환은 유지. 기존 DOM fixture에도 실제helper·earlygranted 케이스를 포함해 실Mapbox 도착을 검증한다. 주행 카메라/동행 로직 확장 금지.
