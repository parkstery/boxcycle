# 지시05 — 2단계 위치 선택 hook·안내

Supervisor가 정한 아래 작은 API를 구현한다. 현재 단계만 수행하고 App/MapView는 조사·편집하지 않는다. 기존 dirty 보존. 안내는 한국어, 편집은 apply_patch. commit/push/deploy/server/browser/subagent 금지.

## 소유 파일과 API

- 신규 `apps/web/src/hooks/useEntryLocation.ts`: `useEntryLocation(enabled: boolean)` 반환은 `{ phase, permission, target, notice, chooseRome, chooseCurrent }`. phase는 idle/checking/choice/locating/ready, permission은 granted/prompt/denied/unknown. target은 null 또는 `{ center: [number, number], zoom: number }`. 기본 상수는 기존 lib/map/mapBootCenter의 MAP_FALLBACK_CENTER/ZOOM을 import한다. 필요시 순수 helper는 신규 lib/geo/entryLocation.ts 하나에 분리한다.
- 신규 `apps/web/src/components/auth/EntryLocationDialog.tsx`/css. props는 phase, permission, onChooseRome, onChooseCurrent. notice는 App에서 표시하므로 dialog는 ready/idle에서 null. dialog aria-label과 h2는 「어디에서 시작할까요?」. prompt/unknown 설명 「위치를 공유하면 내 주변 지도에서 시작합니다. 공유하지 않아도 로마 콜로세움에서 시작할 수 있습니다.」, 두 버튼 「내 위치에서 시작」「콜로세움에서 시작」. denied는 「위치 공유가 차단되어 있습니다. 내 주변에서 시작하려면 브라우저 설정에서 위치를 허용해 주세요.」와 콜로세움 버튼만. checking/locating은 짧은 진행 설명과 콜로세움 탈출 버튼. 44px 버튼, 폰667×300에서 스크롤 가능, 지도 출처 가리지 않기.
- 신규 scripts/identity/entry-location.test.ts 등 meaningful test. 테스트는 *.test.* 등록 제외. 제품 디버그 스위치 추가 금지.

## 동작 상세

enabled가 true가 될 때만 권한 확인. false에서는 지리 API 호출 금지. query는 1500ms watchdog, 지원 없음/실패/미응답이면 unknown choice. granted만 getCurrentPosition 즉시1회. prompt/unknown은 명시 내 위치 버튼 때만 요청. denied에서는 재요청 금지. geolocation 미지원은 fallback ready+한국어 notice. getCurrentPosition timeout8000ms와 자체 watchdog, 성공 좌표 유한/범위검사. 실패·거절·timeout·invalid는 fallback ready와 짧은 한국어 notice. watchPosition·좌표 저장/로그/전송 금지.

콜로세움 선택은 즉시 pending query/geolocation의 generation을 무효화하고 ready fallback. 늦은 콜백은 무시. 다중클릭은 진행중 중복 호출 금지. unmount·enabled=false cleanup에서 timer와 late callback 무효화. StrictMode effect 재실행에도 비동기 query 결과 generation 가드로 오래된 요청이 geo를 시작하지 않게 한다. 완료된 target은 안정된 객체 참조를 유지한다. 인증은 전혀 다루지 않는다.

새 시험에서 granted/prompt/denied/미지원/실패/invalid/late callback/cancel/watchdog를 의미 있게 검증한다. 기존 s42/register-vite-env 로더를 사용할 수 있다. 변경 파일 eslint 및 새 테스트 명령/exit를 `03-result-05.md`에 기록하고 종료한다. App 연결 전이므로 전체 빌드는 다음 단계에 수행한다.
