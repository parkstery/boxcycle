# 지시06 — 3단계 App·MapView 연결과 소비자 시험

지시04 버튼과 지시05 위치 API에 기존 App/MapView를 연결하는 단계다. 원 요구·금지 범위는 지시01을 유지한다. 새 구조 설계나 전체 재조사를 하지 말고 아래 접점만 구현한다. 기존 dirty 보존, 한국어 안내, apply_patch 편집. commit/push/deploy/subagent/server/browser 금지.

## 소유와 확정 연결

소유: App.tsx, MapView.tsx, entry-contract.mjs의 App 연결 부분, e2e/rideEntryHelpers.ts, e2e/ride-entry.spec.ts, scripts/perf/run-real-gpu.mjs 두 폐기 클릭. 지시04·05 소유 파일은 필요시 타입 연결상 최소 수정만 가능하나 API를 바꾸기 전에 원 지시를 따른다.

- AppIntroScreen의 props onStartGuest/onLogin은 인트로를 즉시 dismiss하고 entryRequested=true로 설정한 뒤, 해당 기존 인증 함수를 클릭 동기 구간에서 즉시 호출한다. await query/geo 뒤에 popup을 호출하지 않는다. 반환 rejected promise는 catch해서 기존 auth 오류 상태로 회복하고 unhandled rejection 없게 한다. 기존 사용자 복원 시 새 인증 호출 금지.
- APP_INTRO_DURATION_MS와 2초 effect 제거. 정상 first entry에서 GuestEntryCard 중복 표시 금지. 탈퇴·오류·로그아웃·취소·설정 없음 회복 유지. useEntryLocation(enabled)는 항상 같은 hook 순서에서 호출. enabled는 configured/authInitialized, introDismissed의 명시 버튼 진입 또는 복원 user, !userSignedOut, idle 주행 조건으로 계산. 단순 auth busy가 위치 안내를 막지 않게 한다. 위치 pending 때 AuthSessionGate/GuestEntryCard가 동시에 위에 덮지 않게 하고, ready 뒤 필요하면 auth 대기/오류 회복 표시. 닉네임 카드도 위치 안내와 동시 겹침 방지.
- App 초기 mapBoot를 저장 지역 해석 대신 MAP_FALLBACK_CENTER/ZOOM 상수로 고정. 초기 스타일 satellite. mapBootCenter 기존 resolve 함수 계약 자체는 변경하지 않는다. MapView는 현재처럼 항상 mount되어 intro 뒤에서 로딩한다. 초기 map center/zoom과 localFirst 지역 저장을 혼동하지 않는다.
- MapView에 bootFlyTarget?: {center:[number,number];zoom:number} 최소 prop를 추가. hook target 연결. bootFlyHold는 첫 인트로/인증 복원 대기/위치 미결정 동안 true, 위치 ready면 auth busy/user null이어도 false. 로그인 방식과 위치 목적지는 독립이다.
- MapView 초기 bootFlyTargetRef는 pending 목적지를 보유하고, 새 prop 값은 아직 부트 이동 전일 때만 반영한다. 일반 모션은 초기0.6 지구본→hold해제 후600ms pause→3500ms fly. reduced motion은 위치 결정 후 jumpTo 목적지(처음 표시가 바로 Rome여도 허용). 완료 후 prop 변화가 기존 검색·주행을 덮지 않게 하고 explicit camera action/user gesture 취소 유지. mapZoom prop 일반 반영 effect의 바깥/내부 callback/RAF에서 pending 부트 목적지가 있으면 건너뛰어 줌15가 지구본을 먼저 덮지 않게 한다. 부트타이머 cleanup과 StrictMode map 재생성 안전.
- localFirst 복원 자동 camera effect가 이번 선택을 덮지 않게 한다. 저장된 초기 region.at는 초기 ref에서 이미 처리한 것으로 간주하거나, 이번 진입이 소유한 동안 자동 복원만 차단하는 작은 가드를 둔다. 이후 사용자의 명시 검색·지역선택·실주행 재개 externalCameraJump는 보존한다.
- hook notice는 지도를 가리지 않는 한국어 status로 한 번 표시. 위치 좌표 로그/저장 추가 금지.

## 소비자·검증

계약 App 앵커를 실제 새 연결과 일치시킨다. e2e helper 이름·시그니처 보존. 첫 게스트 버튼 클릭→선택적 위치 안내의 콜로세움 버튼 클릭→기존 인증 완료 대기를 처리하고 대기 status를 인증 성공으로 오인하지 않는다. 복원 사용자와 이전 회복 카드도 처리한다. spec와 perf 두 클릭도 동일 새 계약.

검증 순서: `node scripts/ride-verify/verify-selectors.mjs`, 새 위치 시험, auth-session-gate-render.test.mjs 기존4, 기존 map-boot-center6(s42 loader), 변경 파일 eslint, `npm.cmd run build`, `npx.cmd playwright test ride-entry --list`, git diff --check. 실 Firebase E2E 실행 금지. 실제 App fixture와 실제 Mapbox 로컬 스타일 브라우저 검수는 Supervisor가 수행한다.

`03-result-06.md`에 실제 파일/명령/exit/실패와 미실행을 기록하고 종료한다. 제품 전체 완료라고 미리 쓰지 않는다.
