## 확정 계획

- `src/components/map/MapView.tsx`의 첫 목적지 effect: 최초 생성자 center/zoom은 수정하지 않는다. normal motion은 현재 카메라와 목적지가 다를 때 `map.flyTo({center:target.center,zoom:target.zoom,duration:1000,curve:1.42,essential:false})`로 한 번 비행. 기본 Mapbox 비행곡선은 장거리에서 높이 줌아웃→목적지 줌인한다. 별도의 globe 대기/단계별 timer 추가 금지. 이미 같은 위치/zoom(기본위치 선택)이면 불필요한 비행 없이 기존jump 또는 no-op. getReducedMotionSnapshot=true이면 jumpTo.
- 이동 중 HUD/mapZoom 후속effect/rAF·주행follow가 비행을 끊지 않는지 점검하고 필요한 경우 기존 suppressCameraFollowUntilRef를 1000ms+작은 여유로 사용. 사용자 gesture·명시검색/주행 externalCameraJump는 기존대로 중단 가능. 비행 종료 뒤 이전 목적지 재적용·zoom복귀·상태불일치 금지. 타겟ref/moved guard 유지. 공유권한·앱UI·인증·저장/API 변경 금지.
- 필요한 경우 `src/lib/map/mapBootCenter.ts`에 ENTRY_LOCATION_FLIGHT_MS=1000 작은 상수 허용(그 외 새 제품 helper파일 불필요). 전체 공용 인터페이스 재설계 금지.
- 소유 시험: scripts/map/entry-location-camera.test.mjs, scripts/identity/entry-location-dom.test.mjs. 기존시험을 재사용하고 별도하네스 금지. 단위시험 normal flyTo duration1000·curve·현재위치 목적지, reduced jump, 초기콜로세움zoom15 유지, 같은위치 처리, 1회호출 검증.
- 브라우저 시험은 이미 실제React/native 위치결과→실제Mapbox+MapView소스effect를 실행한다. 이를 확장: 실제 Mapbox `move`/`movestart`/`moveend`에서 시간/center/zoom을 샘플해 **초기Romezoom15→중간zoom하강(장거리 고고도)→최종Seoulzoom15**, 중간좌표 존재, 약1초 종료를 assert한다(헤드리스 부하 여유 대략0.7~2초). 최종점만 assert하면 안 된다. 1000ms 요청값과 실제측정값/최저줌/샘플수를 결과에 기록. 최초위치는MapView실제생성자 AST회귀 유지.
- 브라우저fixture에 getReducedMotionSnapshot 및 flight 상수를 외부 effect 실행 context와 맞춰 연결. 실제 브라우저 네이티브 위치결과는 테스트권한/서울가상좌표로만 사용, 개인 위치는 기록금지. DOM시험은 headless 단일worker. 외부타일은 필요없고 기존token없는 단색스타일로 카메라 검사(토큰경고 기존한계). 시간이 남으면 reduced motion/같은위치 browser 검사도 추가 가능하나 필수는 node회귀.
- `evidence/13-entry-flight-metrics.json`에 측정치와 대표샘플(가상좌표) 보존. 테스트가 JSON 생성 가능. 운영query/debug코드 추가 금지.
