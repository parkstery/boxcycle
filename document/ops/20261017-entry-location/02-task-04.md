# 지시04 — 1단계 인트로 버튼만 구현

지시03까지 조사만 길어져 실제 제품 편집 없이 중단했다. 새 Cursor 세션에서 작은 구현 단위로 진행한다. 이번 단계의 소유 파일은 `apps/web/scripts/ride-verify/entry-contract.mjs`, `apps/web/src/components/auth/AppIntroScreen.tsx`, 동일 css 세 개뿐이다. 다른 파일을 편집하거나 전체 설계를 다시 조사하지 않는다. 기존 dirty 보존. 코드 편집은 apply_patch를 쓴다. 한국어로 안내한다.

1. 계약의 app-intro/app-intro-gate 부분만 먼저 갱신한다. 소개가 두 콜백 props를 받고 「게스트로 시작」「로그인」 두 버튼을 가진다는 계약으로 바꾼다. 2초 자동 전환 앵커는 삭제한다. App 연결 앵커는 다음 단계에서 검증할 예정이라 지금 새 콜백 존재를 기록하고 실패를 숨기지 않는다. 나머지 단계 계약은 보존한다.
2. AppIntroScreen props를 `onStartGuest: () => void`, `onLogin: () => void`로 변경한다. 각 버튼 onClick에 연결한다. 부수효과·인증·타이머를 컴포넌트에 추가하지 않는다. 기존 사진·문구·출처 그대로 유지.
3. 기존 support 문구 아래 actions에 두 버튼을 둔다. 버튼 최소 높이44px, 게스트는 teal 주 버튼, 로그인은 테두리 보조 버튼. 좁은 폰 가로 화면에서 콘텐츠 스크롤과 출처를 보존한다.
4. 위 세 파일만 편집 후 `03-result-04.md`에 파일·작업 내용·시험 미실행(다음 단계 연결 전)을 기록하고 즉시 종료한다. 빌드·브라우저·서버·commit/push/deploy/subagent 금지. 이것은 중간 단계이며 최종 완료가 아니다.
