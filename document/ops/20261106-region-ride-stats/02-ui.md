## 구현

1. **타입·변환**: `StoredRideSession` 에 선택 필드 `regionDistances?: { country: string | null; admin1: string | null; meters: number }[]`. `loadRideSessionsForStatsFromFirestore` 가 주행 문서의 `regionDistances` 를 안전하게 파싱해 담는다(배열이 아니거나 원소 형식이 틀리면 필드 없음, `meters` 는 음수·비유한값 제외). 로컬 저장 세션 흐름은 건드리지 말 것(필드가 없어도 동작).
2. **순수 모듈** `src/lib/ride/regionStatsFilter.ts`(신규, React·Firestore import 금지) + 단위 시험 `scripts/region-stats-filter.test.ts`(node:test, 실행 `node --experimental-strip-types --import ./scripts/s42/register-vite-env.mjs --test scripts/region-stats-filter.test.ts`):
   - 키 타입 `RideRegionKey = { country: string | null; admin1: string | null }`(둘 다 null = 세계).
   - `regionShareOf(session, key): number | null` — 이 주행의 지역 거리 몫 비율(0~1). 세계 → 1. 국가 → `country===key.country` 원소 meters 합 ÷ `distanceMeters`, 행정구역 → `admin1===key.admin1` 합 ÷ distanceMeters. `regionDistances` 없음·합 0·`distanceMeters<=0` → null(제외). 비율은 1 을 넘지 않게 clamp.
   - `applyRegionShare(session, key): StoredRideSession | null` — 위 비율로 `distanceMeters`·`elapsedSec`(반올림)·`caloriesEstimate`(null 이면 null) 를 비례해 새 객체로. 평균 속도(`avgSpeedKmh`)는 그대로. null 이면 null.
   - `filterSessionsByRegion(sessions, key)` — 위로 변환해 null 은 제거. 세계는 원본 그대로 반환.
   - 시험: 세계 원본 유지, 국가 합, 행정구역 합, 없는 주행 제외, 합이 distance 초과 clamp, 시간·칼로리 비례, 칼로리 null, 비율 0 제외.
3. **누적(지역)**: `src/lib/conquest/repo/firestoreConquest.ts` 에 `loadRideRegions(userId, scopeCodes?)` 류를 추가 — `conquest/{uid}/rideRegions` 문서(`scopeType`·`meters`·`sec`·`rideCount`)를 읽는다. **읽기 절약**: 국가를 고를 때만 그 국가 문서(`getDoc`, 문서 id = 국가 코드)와 행정구역을 고를 때 그 행정구역 문서(`getDoc`)만 읽는다(컬렉션 전체 읽기 금지). 실패하면 null. 훅(`src/hooks/useRideRegionTotals.ts`, 기존 `useConquestRegions.ts` 의 「같은 계정·주행 합계가 그대로면 다시 읽지 않기」 패턴 재사용 — `props.mileage?.totalMeters` 가 바뀌면 다시)로 연결. 세계를 고르면 읽지 않는다.
4. **계정 창 연결** `UserInfoSheet.tsx`(App.tsx 는 건드리지 말 것 — 줄 수 한도): 현재 선택(`regionPick`·`admin1Active`)에서 `RideRegionKey` 를 만들고,
   - 왼쪽 오늘·주간·월간·연간 통계와 `periodStats`·기간별 「주행 N회」: `filterSessionsByRegion(statsSessions, key)` 로 거른 세션으로 계산(세계면 지금과 완전히 같게).
   - 마지막 주행: 거른 세션에서 `pickLastRide`.
   - 누적(거리·횟수·시간): 세계는 `props.mileage` 그대로, 지역이면 3번의 `rideRegions` 문서 값(거리 m·횟수·시간 sec). 문서가 아직 없으면(소급 전 등) 「0」이 아니라 거른 세션(400건 한도) 합으로 대체하지 말고 **숫자를 「—」로** 표시(거짓 0 금지).
   - 지역을 고르면 이 모든 줄에 이미 있는 줄 라벨처럼 지역 이름을 표시해 어떤 범위인지 알게 한다(예: 「누적 · 대한민국」은 기존 「내 도로망 · 대한민국」 줄 규칙과 같게, 폭이 좁은 699×273 에서 줄이 넘치지 않게 — 라벨은 이미 있는 「내 도로망」 줄에만 붙이고 다른 줄은 숫자만 바뀌게 해도 된다. 감리가 폰 가로에서 확인한다).
   - 지역에 해당 주행이 하나도 없으면 빈 상태(숫자 0/「—」)가 자연스럽게 나오게. 기존 레이아웃 고정(고정80 등 `document/reference/product/261024-RTW-Chief-지정-디자인-고정.md`)을 어기지 말 것 — 칩·단추 모양과 위치는 그대로.
5. **의존 방향 등록**: 새 `src/lib/**` 파일은 `apps/web/dep-layers.json` 의 `assign` 에 올바른 도메인으로 추가한다(ride → `ride`, conquest repo → 기존 목록 옆). 위에서 금지한 규칙 완화는 아니다. 확인: 루트 폴더에서 `node scripts/check-dep-direction.mjs`(미지정 0건·위반 0건).
6. **코드 정련 래칫**: 반복 코드를 새로 만들지 않는다(메뉴·훅 패턴은 재사용). `node scripts/check-code-tidy.mjs`(루트)가 「기준선 이내」여야 한다.
