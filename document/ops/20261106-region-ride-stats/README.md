# 지역별 주행 통계 (G5 후속) — 공통 계약

작성 2026-11-06 Supervisor Claude Code · 상태: **진행 중** · 앞 단계 [00-plan §4.4.1](../20261103-global-geo-data/00-plan.md)

## 왜

Chief 11-06: 계정 창에 국가·행정구역 칩을 둔 이유는 「내가 달린 길을 국가별·지역별로 얼마나 달렸는지 보는 것」이다. 지금은 「내 도로망」 km 하나만 바뀐다. 칩을 고르면 계정 창의 **왼쪽 기간 통계(오늘·주간·월간·연간)·누적(거리·횟수·시간)·마지막 주행·내 도로망**이 모두 그 지역 기준으로 바뀌어야 한다. 지도의 내 도로망을 지역별로 거르는 것은 이번 범위 밖.

## 결정(Chief 11-06 승인)

- 거리: 달린 **모든 셀**(이미 소유한 셀 포함)의 거리 `m` 를 묶음(z12) 중심점 지역으로 합산한다. 셀 거리 합 = 주행 거리(운영 최근 51건 대조 비율 1.000).
- 시간·칼로리: 지역 거리 ÷ 주행 거리 비율로 나눈 **근사값**. 횟수: 지나간 지역마다 1회(국가 횟수 합이 전체보다 클 수 있음).
- 셀 정보가 없는 주행(운영 최근 60건 중 9건)은 지역을 알 수 없어 지역 집계에서 빠진다(「세계」에는 그대로).
- 국경·행정구역 경계 묶음은 중심점 지역으로 몰린다(최대 수 km 오차) — 기존 G5와 같다.

## 데이터 계약 (서버와 화면이 반드시 같게)

1. **`rides/{rideId}.regionDistances`** — 배열. 원소 `{ country: string|null, admin1: string|null, meters: number }`.
   - `country`: ISO 3166-1 alpha-2(`KR`), 바다·판정 불가는 `null`. `admin1`: ISO 3166-2(`KR-11`), 없으면 `null`.
   - `meters`: 정수, 같은 (country, admin1) 쌍은 하나로 합친다. 합계 = round(셀 거리 합).
   - **필드 자체가 없음** = 지역을 모름(옛 주행·셀 없음·상한 초과·판정 실패). 빈 배열 `[]` 은 쓰지 않는다(없음과 구분 불가).
   - 서버(Admin SDK)만 쓴다. 화면은 읽기만.
2. **`conquest/{uid}/rideRegions/{scopeCode}`** — 사용자별 지역 누적. `scopeCode` = 국가 코드(`KR`) 또는 행정구역 코드(`KR-11`).
   - 필드: `scopeType: "country"|"admin1"`, `meters`(정수 누적), `sec`(정수 누적, 근사), `rideCount`(그 지역을 지나간 주행 수).
   - 서버만 쓴다(`increment`). 본인만 읽는다(Rules). 바다(country null)는 문서를 만들지 않는다.
3. **상한(안전장치, 기존 G5와 같은 값)**: 새로 합산할 묶음 160 초과·국가 6 초과·행정구역 20 초과면 그 주행은 `regionDistances`·`rideRegions` 를 **쓰지 않는다**. 지역 계산이 던져도 주행 저장·마일리지·도로망은 계속(try/catch 격리).

## 화면 규칙

- 칩 선택 키: 세계 / 국가 `KR` / 국가+행정구역 `KR-11`. 주행이 그 키에 속하면: 국가 → `regionDistances` 중 `country===KR` 합, 행정구역 → `admin1===KR-11` 합. 속하지 않거나 `regionDistances` 없음 → 제외.
- 주행 한 건의 지역 몫: 거리 = 위 합, 시간 = `elapsedSec × 지역거리 ÷ distanceMeters`(반올림), 칼로리 = `caloriesEstimate × 비율`(null 이면 null).
- 「누적」은 지역을 고르면 `rideRegions` 문서(거리·횟수·시간)를 쓴다(주행 400건 한도와 무관한 전체 합).

## 비용(요약)

모두 사용자별 문서(공통 문서 없음). 주행당 쓰기 +2~4건(rideRegions 국가+행정구역), 주행 문서 update 1건은 기존 `mileageApplied` update 에 합친다. 화면 읽기는 지역을 고를 때만 몇 건 늘고, 기간 통계는 이미 읽은 주행 400건으로 계산(추가 읽기 0).
