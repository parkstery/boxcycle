# 지시 04 — 「내 경로로 저장」 진행률 기록 · 미완주 등록 · 미완주 찾기 쉽게

- 담당: Developer(Cursor CLI) · 보고: `03-result-04.md` · 커밋·푸시 **금지**
- 병행: 지시 03이 `functions/` 를 고친다. **이 지시는 `apps/web/` 만** 수정한다.

## 원인 (Supervisor 확정)
경로를 바로 만들어 달린 뒤(ad-hoc) 결과 화면 「내 경로로 저장」:
- `hooks/useSavedRoutesWorkspace.ts` `handleSaveAdhocAsUserRoute` 가 `saveRouteToFirestore` 후 **무조건 `promoteSavedRouteInFirestore`**(completed=1) — 몇 %를 달렸든 「완주」. 같은 경로 재저장(dedupe)이면 기존 미완주도 완주로 덮는다.
- ad-hoc 컨텍스트(`setLastEndedWasAdhoc`: `lib/ride/rideEndPersistence.ts` ~387, `hooks/useRideEndAndPersistence.ts` ~624)에 **진행률·완주 여부가 실리지 않는다.**
- 반면 저장 경로를 불러와 달린 경우는 `progressToSave`·`rideCompletedRoute` 로 정상 처리된다(`rideEndPersistence.ts` §5). **같은 값·같은 규칙을 재사용**한다.

## 요구 A — 저장 시 진행률 기록 (Chief 결정)
1. `LastEndedAdhocState` 에 `progressRatio`(0..1)·`completedRoute`(boolean) 추가. 두 `setLastEndedWasAdhoc` 지점에서 그 시점의 `progressToSave`·`rideCompletedRoute` 를 그대로 싣는다(새 계산 금지 — 완주 임계 `ROUTE_COMPLETION_RATIO_THRESHOLD` 0.98 은 기존 산출을 따른다).
2. `handleSaveAdhocAsUserRoute`:
   - `completedRoute` → 종전대로 promote.
   - 아니면 promote **하지 않고** `updateSavedRouteProgressInFirestore`(transaction · 낮추지 않음 · completed 유지)로 `progressRatio`·`rideId` 기록. `rideId` 가 null 이면 진행률 기록은 하되 `rideId` 처리 방식을 결과에 명시.
   - dedupe(기존 문서) 도 같은 규칙 — 기존 완주는 완주 유지, 기존 진행률보다 낮으면 유지(정책 함수가 보장).
   - 로컬 state 갱신도 서버 반환값 기준(기존 §5 패턴과 동일).
   - 저장 완료 문구: 미완주면 「내 경로에 저장했습니다 — 미완주 NN%, 다음에 이어 달릴 수 있어요.」
3. 순수 판정(완주→promote / 미완주→progress, dedupe 병합)을 테스트 가능한 함수로 분리하고 단위 테스트(기존 `apps/web` 단위 계약 테스트 — 예: `route-list-sort-contract.test.ts` — 와 같은 방식·실행 명령을 찾아 따른다). 케이스: 30% 저장→미완주 0.30 / 99%→완주 / 기존 완주 재저장 30%→완주 유지 / 기존 60% 재저장 30%→60% 유지. **사보타주**: 무조건 promote 로 되돌리면 실패하는지 확인·원복·기록.

## 요구 B — 미완주를 찾기 쉽게 (`SavedRoutesPanel.tsx`/`.css`)
1. 미완주 경로(`completed!==1 && lastProgressRatio>0`)는 선택하지 않아도 진행률(%)을 카드에 항상 표시(기존 진행률 바/라벨 재사용, 선택 시 동작은 유지). 대기(0%)는 표시 안 함.
2. 선택한 경로가 미완주면 툴바 「열기」 라벨을 「이어 달리기」로(동작은 그대로 — 불러오기 시 `loadedSavedRouteProgressRef` 로 재개됨을 코드로 확인해 결과에 근거 기재). `title` 도 맞춘다.
3. 빈 목록 안내의 「미주행 7일 후 자동 삭제」 → 실제 값(`SAVED_ROUTE_EXPIRY_MS` 90일)에 맞게 「미완료 경로는 90일 후 자동 삭제」.
