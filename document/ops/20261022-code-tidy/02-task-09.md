## 할 일

목록의 CSS 파일에서, 목록에 있는 클래스를 **포함하는 선택자**를 지운다.

1. 규칙의 선택자가 하나뿐이고 그 안에 목록 클래스가 있으면 → 규칙 블록 `{ … }` 통째 삭제(바로 위 주석이 그 규칙만 설명하면 주석도).
2. 쉼표로 묶인 선택자 목록(`.a, .b, .c { … }`)이면 → 목록 클래스가 든 선택자만 빼고, 남은 선택자와 본문은 그대로.
3. 그래서 비게 된 `@media`·`@supports`·`@container` 블록은 지운다.
4. `.live .dead`, `.dead:hover`, `.dead::before`, `.x.dead` 처럼 목록 클래스가 **어디에라도** 들어 있는 선택자는 어떤 요소에도 맞지 않으므로 같은 방식으로 지운다.

## 금지

- 목록에 없는 클래스·파일 수정, 속성값 변경, 포맷 정리, 줄 순서 변경.
- `:root` 변수(`--…`)·`@keyframes`·`@font-face` 는 클래스가 아니다 — 건드리지 않는다. 지운 규칙에서만 쓰이던 변수라도 남긴다.
- TS/TSX·시험·설정 파일 수정. git commit·push·stash·checkout·restore·clean·worktree.
