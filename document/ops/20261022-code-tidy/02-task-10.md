# 지시10 — P6 디버그 화면을 운영 기본 청크에서 분리

2026-10-22 · task · 담당 **opencode MiniMax M3.1 Flash** · 감리 Claude · 보고 `03-result-10.md`

## 배경

감리 측정(소스맵): 운영 기본 청크 `index-*.js` 에 디버그성 소스 19파일·약 97 KB 가 들어 있다. 대부분은 `dev-tools.json` 에 `permanent` 로 등록된 계측기(주행 중 호출되는 `note…` 함수)라 그대로 둔다. **화면(컴포넌트)** 만 규칙 「운영에서 켜지는 도구 화면은 동적 import 로 분리한다」를 어기고 있다.

## 할 일 (이 두 곳만)

1. `apps/web/src/App.tsx` — `DebugMapStage`(→ 안에서 `DebugWorldLightMap` 을 씀)의 정적 import 를 `React.lazy(() => import("./features/map-overlays/DebugMapStage").then(m => ({ default: m.DebugMapStage })))` 로 바꾸고, 렌더 자리를 `<Suspense fallback={null}>` 로 감싼다. 렌더 조건·props 는 그대로.
2. `apps/web/src/features/map-overlays/AppMapStage.tsx` — `ActivityWorldLodDebugPanel` 을 같은 방식으로 lazy + `Suspense fallback={null}`. `useAppMapOverlays.ts` 의 `import type` 은 그대로 둔다(타입 import 는 번들에 안 들어간다).

이미 lazy 로 쓰는 예: `src/components/devLabs/DevLabPanels.tsx` 를 먼저 읽고 같은 형태를 따른다.

## 금지

- 시험·설정·baseline 수정. git commit·push·stash·checkout·restore·clean·worktree.
