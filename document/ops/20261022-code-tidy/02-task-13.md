## 원칙 — 훅 순서 보존

React 는 훅을 호출 순서로 구분한다. 그래서 **연속된 구간을 통째로 새 커스텀 훅으로 옮기고, 그 훅을 원래 구간이 있던 자리에서 한 번 호출**한다. 구간 안 훅의 순서·의존성 배열·초기값은 그대로. 구간이 바깥 변수를 쓰면 인자로 받고, 바깥이 구간의 변수를 쓰면 객체로 돌려받아 같은 이름으로 구조 분해한다. 이렇게 할 수 없는 구간(앞뒤 코드와 얽혀 연속으로 떼어지지 않음)은 억지로 하지 말고 보고에 적는다.
