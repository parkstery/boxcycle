## 2. 남은 실패 ① — 루프 3 에서 Start 승계가 깨진다 (진짜 발견)

```text
Error: 루프 3: Start ≠ sessionEndLngLat
1 failed, 1 passed (3.2m)
```

루프 1·2 는 통과하고 **3회차에서만** 깨진다. 단계 C 의 핵심 주장이 3회차에서 성립하지 않는다.

### 2.1 먼저 시험/제품을 가른다 (여기부터, 추정 금지)

spec 은 `readLatestRideSessionEnd(uid)` 로 **「가장 최근 Ride」** 를 읽는다. 3회차에는 Ride 가 3개 쌓여 있으므로 **정렬 기준이 틀리면 엉뚱한 Ride 를 최신으로 집는다.** 루프 1·2 만 통과하는 패턴이 이 가설과 맞는다.

다음을 **한 번에** 찍어 비교한다.

1. 루프 3 시점에 Firestore `rides` 에 있는 **모든 Ride 의 id·정렬키·`sessionEndLngLat`**
2. `readLatestRideSessionEnd` 가 고른 값
3. 그 시점 Route 의 실제 `start`

- (2) 가 (1) 의 진짜 최신과 다르면 → **시험 결함**. 정렬키를 고친다(생성 시각 tie·미기록 여부 확인).
- (2) 가 진짜 최신인데 (3) 이 다르면 → **제품 결함**. anchor 고정이 1회성인지, 3회차에서 `anchorFixedStartRef` 가 풀리는지 본다.

### 2.2 예산

**이 판별에 브라우저 실행 1회, 수정 후 확인 1회 — 총 2회를 넘기지 않는다.** 초과하면 멈추고 찍은 수치를 그대로 보고한다.

## 3. 남은 실패 ② — `test:distance-auto-route` 는 제품 회귀가 아니다

```text
distance-auto-route-contract.test.ts:173
assert.match(APP_SOURCE, /type === "start"[\s\S]{0,400}setStartLngLat\(lngLat\)/)
```

**App.tsx 의 소스 텍스트를 정규식으로 검사**하는 시험이다. 3K-R1 이 그 사이에 `setDistanceDirectionMode(false)` 를 넣어 400자 창을 넘겼다. 제품은 정상이고 **시험이 정당한 코드 변경에 깨진 것**이다.

### 3.1 수정 — 창을 넓히지 말 것

400 → 800 으로 늘리는 건 다음 변경에서 또 깨진다. **소스 문자열 대신 동작을 검사**하도록 바꾼다.

- 이 assert 가 지키려던 계약은 「지도에서 start 를 찍으면 `setStartLngLat` 가 호출된다」이다. 그 계약은 이미 phase-c e2e 와 phase-a 스크립트가 실제로 검증한다.
- **중복이면 삭제**하고, 삭제 근거를 커밋 메시지에 한 줄 남긴다. 남길 가치가 있으면 순수 함수 수준으로 옮긴다.
- `APP_SOURCE` 를 정규식으로 검사하는 assert 가 이 파일에 더 있는지 확인하고, 같은 기준으로 정리한다. **소스 텍스트 매칭 시험을 새로 만들지 않는다.**

## 4. [정책] 브라우저 시험 실행 빈도를 줄인다

이번 구간의 브라우저 실행 7회를 되짚으면 제품 결함을 잡은 것은 2회(결과 시트 미개방·루프 3)뿐이고, 나머지 5회는 하네스 문제(포트 충돌·URL 배선·IndexedDB·측정 순서)를 고치는 데 들어갔다. 비용이 잘못된 곳에 쓰였다.

**앞으로 다음을 지킨다.**

1. **반복 개발 중에는 빠른 시험만** 돌린다 — `test:next-ride` · `test:distance-auto-route` · `test:distance-auto-route-replay` · functions/web build. 합쳐 1분 안쪽이다.
2. **브라우저 e2e 는 수용 게이트에서 1회.** 단계 완료를 주장할 때만 돌린다. 중간 확인용으로 돌리지 않는다.
3. **사용자 검수 PASS 난 기능은 브라우저로 재확인하지 않는다.** 거리·방향 자동 Route 생성이 여기 해당한다 — 회귀 목록에는 두되 화면으로 다시 보지 않는다.
4. **하네스 수리는 1회 시도.** 한 번에 안 되면 멈추고 수치와 함께 보고한다. 3~4단계 끌지 않는다.
5. 새 시험을 만들 때 **소스 텍스트 매칭·화면 문구 매칭을 쓰지 않는다.** `data-*` 속성·`data-testid`·순수 함수 계약을 쓴다.
