## 5. 다음 UI 단계 요구사항 잠금 — 이번에는 구현 금지

다음 요구사항은 checkpoint 검수 후 별도 작업지시서로 처리한다.

1. `목표 거리로 End 자동 찾기` 제거: 현재 역할은 숨겨진 form을 펼치는 것뿐이므로 불필요한 진입 클릭이다.
2. 기본 지점 선택 popup과 자동 Route popup을 하나의 상태형 인터페이스로 통합한다.
3. 목표 거리를 선택·입력하면 즉시 방향 선택 모드로 전환한다.
4. 그 상태의 다음 지도 클릭은 수동 End가 아니라 방향으로 해석하여 바로 Route 탐색을 시작한다.
5. `지도에서 방향 선택` 전체 폭 버튼을 제거한다. 별도 확인 클릭을 요구하지 않는다.
6. 거리 미선택 상태의 지도 클릭만 기존 수동 End 선택으로 유지한다.
7. Token 문구는 `경로 생성 잔여 Token N개` 한 줄로 축약하고 `경로 생성 시 1개 사용`은 제거한다.
8. `이동수단` 제목을 제거하고 자동차·자전거·도보 아이콘 선택만 유지한다.

11. Route 생성 완료 후 별도 큰 확인 popup과 불필요한 `확인` 클릭도 재검토한다.
