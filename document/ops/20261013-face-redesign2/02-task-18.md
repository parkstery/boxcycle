## 구현

1. 현재 메뉴는 top:0/bottom:0 및 내부 flex:1 때문에 아래 빈 배경이 남는다. bottom 고정을 없애고 내용 높이로 끝나게 한다. 폰 가로 높이 상한은 100dvh와 100vh fallback으로 두어 긴 내용은 기존 scroll 경로로 접근 가능해야 한다.
2. menu-panel/body/직계 ride-panel의 flex 연결을 내용 높이 기준으로 조정하되 overflow가 실제로 동작하게 한다. 상단 헤더는 줄어들지 않고, 내용이 많을 때 본문만 스크롤. 기존 왼쪽 anchor/폭은 유지. 작은 아래 모서리 radius를 주어 카드 끝을 분명히 해도 된다.
3. 화면에 내용이 많으면 높이 상한까지 사용해도 된다. 높이를 임의 값으로 고정하지 않는다. 폰트/버튼을 줄이거나 내용을 숨겨 달성하지 않는다.
4. 반복 주소 제거/목록 선택 흐름 변경은 이번 제외. 작고 안전한 첫 시각 단위로 마감한다.
