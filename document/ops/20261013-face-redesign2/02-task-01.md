## 컬러 규칙

기본 바탕 #FFFFFF, 본문 #1F2937, 보조 #475569, 보조 바탕 #F1F5F9, 테두리 #CBD5E1, 실행/선택 #2563EB, 선택 버튼 글자 #FFFFFF, hover #EFF6FF 또는 주요 버튼 #1D4ED8, 오류/삭제 #DC2626. 시작·도착 등 지도와 대응하는 의미색은 보존. warning은 의미 보존. disabled는 기존 동작/opacity 보존하고 읽을 수 있는 중립색으로 처리.
주황색 실행·선택을 파랑으로, 짙은 패널 바탕을 흰색으로 바꾼다. background/border/outline/box-shadow/gradient는 컬러 성분만 바꿀 수 있다. 그림자 offset/blur/spread, alpha, backdrop-filter, opacity, border 두께/style, gradient stop 위치, animation은 보존한다. 투명 배경을 흰색으로 바꾸는 대상 패널은 불투명 흰색 허용.
배치/좌표/폭/높이/padding/margin/gap/radius/font/line-height/DOM/문구/이벤트/기능/selector 계약 변경 금지. 작은 터치 타깃 등 기존 문제 발견 시 보고만 하고 고치지 않는다.

## 증거와 완료 조건

변경 전후 동일한 실제 컴포넌트·상태·viewport로 캡처. 우선 800×360(Chief 첨부 기준), 좁은 가로 667×300에서 비교. 첫 핀 전/후 및 거리 자동설정 활성/비활성·이동수단 선택 등의 실제 가능한 상태를 확인. screenshot은 실제 앱 실행을 우선하고 불가능할 때 정확한 사유와 대체 fixture 여부를 명시; fixture를 실제 앱이라고 보고 금지.
전후 panel 및 자식들의 rect/줄바꿈/scroll 크기 동일 여부를 기록. 소스 CSS 컬러 제거 후 비색상 속성 비교 등 의미 있는 검사로 비색상 변경 0 증명. 가짜 성공/skip PASS 금지.
전역 기능 테스트 전체 실행 불필요. 관련 검증, diff --check, 필요한 typecheck 및 실행 화면 확인. 브라우저 5분 무진전 시 프로세스/서버/로그 확인 후 대체. 기존 서버를 오인하지 않게 새 worktree용 독립 포트(예:5013)를 사용. 종속성·env는 존재 여부만 확인하고 비밀 출력 금지. 가능하면 서버를 켜두어 Chief가 바로 확인할 URL 제공.
커밋/push/배포 금지. 앱 코드 실제 변경과 증거를 제출하고 멈춘다. 다음 패널 변경 금지.
