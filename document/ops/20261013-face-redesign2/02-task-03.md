## 검증 효율·증거

각 단위 CSS diff의 비색상 보존을 자동 검사한다. 실제 앱에서 여는 데 필요한 조작만 수행하고 설정 저장·삭제·공개 등록·회원가입 등 운영 쓰기 동작은 하지 않는다. 창 열기/선택/로컬 임시 상태로 확인. 대표800×360, 좁은667×300. 전후 원본 CSS를 browser style overlay로 적용해 동일 DOM에서 비교하면 소스 원복/HMR 흔들림 없이 빠르고 안전하다. 원본 전체 앱에서 geometry는 그대로여야 한다. 모든 단위에 대형 시험이나 16장 캡처를 반복하지 않는다. 기본 1장/단위 + 중요한 선택·hover·오류만 확인; 실제로 열 수 없는 인증/결과 상태는 CSS/inline style 정적 감리 근거와 미검증 범위를 표시. fixture로 확인한 것을 실앱 PASS로 표기 금지.

전역 함수/타입/빌드 검증은 마지막 1회로 충분: apps/web cwd node C:/20.HDev/boxcycle/node_modules/typescript/bin/tsc -b --pretty false, git diff --check. CSS AST(이미 설치된 parser 사용 가능)로 전체 변경 declaration의 property/value를 대조하여 비색상 속성0, selector geometry0 확인. border/background/shadow/filter 등 축약값 속에서 컬러 외 부분 변조도 검사. 승인 hover 컬러 selector 추가는 허용.
