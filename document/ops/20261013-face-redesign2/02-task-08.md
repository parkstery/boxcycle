## 첫 단위: 사용자 정보창·로그아웃·탈퇴 확인

UserInfoSheet.css만 수정. TSX/문구/폰트 크기/컬러/기능 변경 금지. 기존 버튼의 역할과 경고 내용, 탈퇴 확인 입력·disabled 조건 유지. 주된 문제는 터치 높이뿐 아니라 내용에 비해 넓게 늘린 버튼/카드, 불필요한 독립 행과 패딩이다.

- 기간 탭은 flex:1로 폭 전체를 균등 채우지 않고 내용+최소 패딩에 맞는 폭으로 모은다. 최소44px 터치 높이는 유지하되 큰 색상 면적을 만들기 위한 가로 확장은 제거한다.
- Free/업그레이드 행의 빈 면적을 줄인다. 좁은 내용에 비해 큰 박스를 두지 않는다. 공용구조 변경 없이 CSS로 가능한 범위 우선. 배치를 바꾸려 TSX가 필요하면 구현 전에 Supervisor에게 근거 보고.
- 로그아웃 확인의 취소·로그아웃 버튼 flex:1 전폭 확장을 제거한다. 내용 폭 버튼을 한 행에 모아 행 전체와 내부 빈 여백을 줄인다. 동작·설명은 유지.
- 탈퇴 확인의 취소·탈퇴도 내용 폭으로 모은다. 설명 line-height/글씨를 줄여 압축하지 않는다. 설명·입력·버튼 사이 여백만 절제. 확인 입력은 숨기지 않고 터치 접근성을 확보한다. 긴 경고로 필요한 스크롤은 유지하되 다른 곳 낭비로 늘어나는 스크롤은 줄인다.
- 확인 패널의 padding/border를 중첩하여 불필요한 덩치를 만들지 않는다. 800x360/667x300 실제 렌더에서 모든 컨트롤에 도달 가능해야 한다. 일반 계정, 로그아웃 확인, 탈퇴 확인 각각 before/after를 비교한다.
- 핵심은 세로 행 수 감소다. Free/업그레이드와 기간 선택을 CSS grid 등으로 같은 행에 담을 수 있는지 검토하여 글씨 축소 없이 가능한 경우 적용한다. 자산 두 칸/통계 데이터/안내·확인문은 보존. 기본 상태 콘텐츠 수직 점유를 지시07 완료본 대비 최소15% 감소 목표로 한다. 불가능하면 원인과 실제 감소를 보고한다. 고정44px 박스만 반복하여 목표 달성한 척하지 않는다.

허용 파일은 UserInfoSheet.css 하나 및 결과03-result-08.md. 앱 브라우저/QA는 Supervisor 담당. 구현은 작게 한 번 적용한 뒤 git diff --check 한 번만 수행하고 즉시 결과를 기록하고 종료한다. tsc는 Supervisor가 정확한 apps/web cwd에서 실행하므로 Developer 반복 검사 금지. 이전 실패한 도구 호출을 무한 반복하거나 하위 에이전트에 다시 넘기지 않는다. 파일 편집 도구 실패가 두 번 반복되면 오류를 보고하고 종료한다. 서버/다른 파일/다른 창은 건드리지 않는다.
