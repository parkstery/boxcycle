## 반드시 보정

1. MapHud.css의 hero/정복 수치/coach/R1 `color:var(--rtw-trace)` 6개는 UI 강조색이므로 #2563EB로 교체. 지도 궤적·trace-owned·LED·S/E 의미색은 보존한다. 키라인/투명 바탕/그림자 geometry 그대로. 일반 배경 없는 지도 HUD 값과 시계는 기존 흰색 그대로. 전역 text 토큰 변경으로 짙은색이 되지 않도록 참조를 확인한다.
2. RotateOverlay.css는 스크림이 아니라 스마트폰 세로 방향에서 사용자가 보는 전체 안내 화면이다. background를 #FFFFFF, color를 #1F2937, 아이콘 border/background를 #2563EB로 변경한다. animation/크기/배치 그대로. 실제 360x800 화면에서 확인하되 브라우저 한 번만.
3. MapView.css 축척 박스에서 새로 중복 추가된 border 선언을 없애 기존 선언 하나만 #CBD5E1로 유지한다. 원본 geometry 그대로.
4. MapViewSheet 닫기 버튼 및 selected:hover 대비를 실제 확인한다. 주요 선택칩이 hover의 옅은 바탕에 흰글자로 남으면 기존 크기/모양 없이 진파랑 hover로 보정.
5. 공통 tokens.css/boxcycle-theme.css 정리 후 밝은 panel에 희미한 글씨, 파랑 버튼의 어두운 글씨가 남지 않게 확인. 지도 trace 토큰을 UI 때문에 바꾸지 않는다.
6. RouteMinimap.css 전체를 지도 의미색으로 제외한 것은 잘못이다. 경로/핀/펄스 의미색은 보존하지만 .route-minimap__milestone 안내 띠는 UI이므로 흰 배경/파란 강조로 교체한다. MapView.css의 activity popup도 지도 경로선이 아니라 정보창: wrapper/tip 흰색, 테두리 연회색, 본문 짙은글씨. activity 의미 강조는 빨강 계열로 유지한다. 확대/축척/지도 스타일 자체 변경은 하지 않는다.
