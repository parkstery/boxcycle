# Spinatlas

실내 자전거로 실제 지구의 도로를 달리는 앱의 화면 규칙. 지도가 주인공이고, 그 위에 뜨는 판(창)은 **조용하고, 숫자 하나가 또렷해야** 한다. 기준 화면은 2026-10-23 Chief 가 고른 리더보드 시안(C 패널 + B 강조)이다.

대상 기기는 **폰 가로(800×360)**. 판 하나가 화면 대부분을 쓰므로, 판 안에서 모든 것이 한눈에 들어와야 하고 스크롤은 마지막 수단이다.

> **이 규칙보다 [Chief 지정 디자인 고정 목록](../../../reference/product/261024-RTW-Chief-지정-디자인-고정.md)이 먼저다.** 규칙과 부딪히면 목록을 따른다(예: 주행 시작은 녹색 원형 아이콘, 경로 목록은 흰 박스).

## 한 줄 원칙

> 판 하나에 주인공 숫자 하나. 강조색은 파랑 하나. 선은 줄 사이에만, 상자는 판 하나만.

## 상태별 원칙 — 지도 위 vs 판 (2026-10-23 Chief)

- **지도 위(주행 중·대기 중 계기판, 순위 목록, 코칭 문구):** 바탕 없이 흰 글자 + 검은 윤곽선(`-webkit-text-stroke` 3~4px, `paint-order: stroke fill`). 값은 `#52C9FF`, 주인공 값·「나」는 `#A8DCFF`, 새 도로는 초록 `#6EE7A0`. 지도를 가리지 않는 것이 우선이다. 지금 앱의 계기판 방식이 기준.
- **판(메뉴, 경로 목록, 주행 결과, 설정, 리더보드 전체 보기):** 흰 판. 읽기가 우선이다. 위의 「한 줄 원칙」·「두 칸 판」은 판에만 적용한다.
- **버튼·칩(주행 시작, 순위 칩, 위성 등):** 손가락으로 누르는 것이라 작은 바탕을 둔다.

## 화면의 뼈대 — 두 칸 판

- 판 폭 `sheet-w`(740px)·높이 324px, 바깥 모서리 `radius-lg`, 그림자 `shadow-panel`. **판 안에는 다른 상자를 두지 않는다.**
- 왼쪽 `pane-w`(268px)는 `surface-tint` 의 **요약판**: 탭 → 기간 → 주인공 숫자(`num-hero`, `accent`) → 두 번째 숫자(`num-lg`) → 한 줄 설명 → 하단 규칙 설명(`caption`).
- 오른쪽은 `surface` 의 **목록·세부**: 제목(`title`)과 닫기 버튼 한 줄, 그 아래 목록 줄(`row-h`, 줄 사이 `line` 1px).
- 판에 요약할 「나」가 없으면 한 칸 판으로 쓴다. 그때도 상자 안의 상자는 없다.

## 색

| 역할 | 토큰 | 규칙 |
|---|---|---|
| 강조 | `accent` | 그 화면의 주인공 하나(큰 숫자), 1~3위 번호, 선택된 탭, 주 버튼. **다른 강조색은 없다.** |
| 「나」 | `surface-tint` | 요약판, 목록의 내 줄. 한 화면에 한 영역. |
| 상태 | `live`·`live-bg`·`warn`·`warn-bg` | 「지금 달리는 중」, 상승, 점검 경고에만. 강조로 쓰지 않는다. |
| 글자 | `ink` > `ink-2` > `muted` > `subtle` | 작은 글자(11px 미만)는 `muted` 까지만. `faint` 는 생략 기호·큰 글자에만. |

빨강·주황 버튼, 색 테두리 카드, 그라데이션은 쓰지 않는다.

## 글자

- 본문 `sans`(Gothic A1), 숫자 `num`(Saira Condensed). **숫자는 언제나 숫자 글꼴**, 단위는 그 뒤에 작게(`num-unit`), **언제나 소문자**: km · km/h · kg · kcal (2026-10-23 Chief — KM·Km 금지).
- 숫자 위 이름표는 `label`(작은 글자, 자간 0.12em, `subtle`).
- 크기는 토큰 단계만 쓴다: 72 / 26 / 17 / 15 / 13 / 11 / 10 px. 그 사이 크기를 새로 만들지 않는다.

## 문구

- **단위를 끝까지 적는다.** 「11분」「5.0 km/h」「0.19 km」. 「11m」처럼 분과 미터가 헷갈리는 표기 금지.
- **빈 값은 「—」로 두지 않는다.** 무엇을 하면 채워지는지 말한다: 「체중 입력 후 표시」, 「이번 주 센서 주행이 없어요」.
- **개발용 문구는 사용자 화면에 없다.** 「최근 400건 기준」, 영어 도움말(「Close menu」) 금지.
- 게스트에게는 「로그인」이 아니라 **「회원 등록」**(기록이 그대로 이어진다).
- 존댓말 해요체, 한 문장 한 가지. 버튼은 무엇이 일어나는지 동사로(「같이 달리기」「회원 등록」).

## 부품

| 부품 | 쓰임 |
|---|---|
| **Panel** | 지도 위 판. 두 칸 또는 한 칸. |
| **Segmented** | 판 맨 위 탭(주행 거리·개척, 오늘·주간…). 흰 트랙 안 `accent` 선택. |
| **Button** | 주(`accent` 바탕, 한 판에 하나), 보조(흰 바탕 `line-control` 테두리, 알약), 글자(로그아웃·더 보기), 아이콘(닫기: `surface-sunken` 원). |
| **Stat** | 이름표 + 숫자 + 단위 + 한 줄 설명. 주인공(`num-hero`)은 판마다 하나. |
| **ListRow** | 순위·이름·(칩)·값. 1~3위 번호만 `accent`, 내 줄은 `surface-tint` + 굵게. |
| **LiveChip** | 「● 같이 달리기」. 지금 달리는 사람에게만. |
| **EmptyState** | 빈 목록·데이터 없음. 한 문장 설명 + 할 일 하나. 큰 빈 상자 금지. |

## 하지 말 것 (지금 앱에서 반복된 것)

1. **상자 안의 상자** — 판 → 테두리 묶음 → 테두리 버튼. 묶음은 여백과 줄로 나눈다.
2. **버튼 모양 섞기** — 한 줄에 테두리 알약·회색 원·흰 원이 함께. 같은 줄의 버튼은 같은 종류.
3. **강조 여러 개** — 파란 상자 + 파란 숫자 + 주황 글씨 + 빨간 버튼. 주인공은 하나.
4. **같은 정보 두 번** — 문장 「합계 0.99km예요」 바로 아래 큰 0.99 km.
5. **위험한 버튼을 앞에** — 「계정 탈퇴」는 프로필 수정 안 맨 아래 작은 글자 버튼.
6. **빈 상태를 크게** — 「TRAIL / 없음」 상자가 판의 절반.
7. **hover 를 폰에 남기기** — hover 스타일은 `@media (hover: hover)` 안에만, 폰은 `:active`.

## 아이콘

인라인 선 아이콘(선 굵기 1.6~1.7, 둥근 끝), 색은 `ink-2`. 이모지·그림 아이콘·색 아이콘은 쓰지 않는다. 아이콘만 있는 버튼은 `aria-label` 을 단다.
