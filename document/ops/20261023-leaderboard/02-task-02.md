범위: `apps/web/` 만. 서버는 다른 실행자가 동시에 만든다 — 계약대로 코딩한다.

## 기준 그림 — 반드시 먼저 연다

`mockups/leaderboard-1-distance.html`(회원), `leaderboard-2-pioneer.html`(개척 탭), `leaderboard-3-guest.html`(게스트). 이 파일의 색·글꼴·크기·여백을 **그대로** 옮긴다(파일 안 `zoom: 2` 는 2배 그림용 — 실제는 1배 숫자). 글꼴: 본문 Gothic A1, 숫자 Saira Condensed(Google Fonts — `apps/web/index.html` 의 기존 폰트 로딩 방식을 먼저 확인해 같은 방식으로).

## 할 일

1. `src/services/leaderboardApi.ts` — 기존 `src/services/adminDashboardApi.ts` 와 같은 방식(ID 토큰 GET, 한국어 오류)으로 `getLeaderboard`.
2. `src/components/leaderboard/LeaderboardSheet.tsx` + `.css` — 기존 `src/components/admin/AdminDashboardSheet.tsx` 의 시트 틀(scrim·포커스·Escape·닫기)을 따른다. 왼쪽 판: 탭(주행 거리·개척), 기간 버튼(누르면 이번 주→이번 달→전체 순환), 범위는 「세계」 글자만(1단계), 내 순위(큰 숫자)/게스트 안내/순위 없음 안내. 오른쪽: top 10 → `⋯` → around(내 줄 강조). `liveTrailId` 가 있으면 「● 같이 달리기」 버튼.
3. 「같이 달리기」: App 의 기존 Trail 합류 경로를 찾아 연결한다(`rg -n "trailId" src/App.tsx src/hooks/useTrailSession.ts`, 주소 `?trail=` 처리 등). 찾지 못하면 버튼은 그리되 동작 연결은 하지 말고 보고에 적는다.
4. 게스트 「Google 계정으로 회원 등록」 버튼 → 기존 Google 연결 함수(`src/hooks/useAppAuth.ts` 의 게스트 Google 연결)를 호출.
5. 진입: MENU 패널(`src/components/MenuPanel.tsx`)에 「순위」 항목. 시트 열기·닫기는 `src/app/useAppSheetNavigation.ts` 방식(관리자 시트 추가된 방식 그대로).
6. 폰 가로 800×360 에서 한 화면, hover 는 `@media (hover: hover)` 안에만.
7. 금지: `UserInfoSheet`·`ProfileEditSheet` 수정(다른 지시), 시험·설정·baseline 수정, git 명령.

검사(apps/web): `npx tsc -b --noEmit`, `npx eslint <고친 파일>`, `npm run test:quick`, 루트 `node scripts/check-code-tidy.mjs --check`.
