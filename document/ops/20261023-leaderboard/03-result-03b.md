# 03b 결과 — 계정 패널(UserInfoSheet) 시안 맞춤 재작업

대상: `apps/web/src/components/UserInfoSheet.tsx` · `UserInfoSheet.css` (ProfileEditSheet·리더보드·App·MenuPanel·시험·설정·기준선은 건드리지 않았다)

## 무엇을 바꿨나

- **판 틀**: 위에 붙은 우측 슬라이드 시트를 버리고, 리더보드와 같은 가운데 두 칸 판으로 바꿨다. 740×324, 반경 18px, 그림자 `0 6px 24px rgba(0,0,0,.28)`, 스크림, 왼쪽 268px 요약판(`#EEF3FC`). 800×360에서 가운데에 놓이고 667×300에서도 여백 0.5rem만 남기고 들어간다. 페이지 스크롤 없음(문서 높이 = 뷰포트 높이로 확인).
- **상자 안의 상자 제거**: 통계 카드·자산 카드 2개·마지막 주행 카드·플랜 상자·아바타·로그아웃 확인 상자를 모두 없앴다. 오른쪽은 줄(내 도로망 / 누적 / 마지막 주행 / 플랜)과 줄 사이 1px `#EEF0F3` 선만 쓴다.
- **왼쪽 요약판**: 기간 탭(흰 트랙 + 파랑 선택) → 이름표(「10월 23일 · 주행 2회」, 자간 0.12em) → 고른 기간의 거리(Saira Condensed 72px, 파랑, 단위 KM) → 「11분 · 평균 5.4 KM/H」 한 줄 → 칼로리 안내 한 줄.
- **오른쪽**: 이름(15px 굵게) + 이메일, 닫기 원형 아이콘 버튼(`#F2F3F5`, 34px). 내 도로망 값만 파랑. 숫자는 숫자 글꼴·단위는 작은 대문자(`KM`, `KM/H`, `KCAL`), 한글 단위(분·시간·회)도 작게.
- **버튼 종류 정리**: 보조(흰 바탕·`#C9D6EE` 테두리·알약) 「프로필 수정」「관리」, 주(파랑·40px) 「회원 등록」(게스트만), 글자 「로그아웃」. 빨강·옅은 빨강 배경 모두 제거. 로그아웃 확인(주행 중일 때)은 같은 자리에서 문장 + 「취소」(보조) + 「로그아웃」(주).
- **문구**: 「FREE 미구독」 → 「Free 플랜 · 업그레이드」(유료는 「Paid 플랜 · 구독 중 · 구독 관리」, 게스트는 「게스트 · 회원 등록하면 어느 기기에서나 이어져요」). 게스트 버튼은 「회원 등록」.
- **빈 값 처리**: 「0분 / 0.0 km/h / 0」 제거. 기간에 주행이 없으면 큰 숫자 자리에 「오늘 주행이 없어요」(이번 주·이번 달·올해)와 「달리면 여기에 거리가 쌓여요」. 마지막 주행이 없으면 「아직 주행이 없어요」. 칼로리가 전부 미산정이면 「칼로리는 체중 입력 후 표시」(체중 입력은 프로필 수정으로 연결). 최근 주행 목록의 완주율 「—」는 줄에서 뺐고, 마지막 주행의 칼로리도 값이 없으면 뺀다.
- **개발용 문구 제거**: `title="Close/Edit profile/Admin dashboard/Recent rides/Resume this route/..."` 영어 툴팁 전부 삭제. 통계 폴백 안내(「클라우드 미설정: …」「통계 전용 불러오기 실패: …」)는 「화면에 보이는 최근 기록만 집계했어요.」류로 바꿨다. 「옛=거리환산 · 새=페달·체중」「미산정 N회」 삭제(대신 근사값이면 「추정 칼로리」).
- **hover**: 모든 hover 스타일은 `@media (hover: hover)` 안에만 있고, 폰용 `:active`를 따로 뒀다.
- **최근 주행 목록**: 「마지막 주행」 줄을 누르면 오른쪽 줄 영역이 목록으로 바뀐다(내 도로망·누적·플랜 줄은 잠시 숨김, 목록은 그 안에서만 스크롤). 판 크기는 변하지 않는다.

## 「?」 버튼의 정체

버튼이 아니었다. 아바타 동그라미 안의 이니셜이 `props.user == null`일 때 「?」로 나오는 것이었다(검수 하네스가 `user={null}`을 넘겨서 그렇게 보였다). 기능은 없었다. 시안에 아바타가 없으므로 아바타 자체를 삭제했다.

## 유지한 것

props·훅·데이터 소스 전부 그대로: 통계 계산(`aggregateRideStatsForPeriod`)·기간 탭(role=tab, aria-selected)·마지막 주행 줄(`.user-info-sheet__last-ride`, aria-expanded/controls)·`#user-info-sheet-history-list`·행 액션(지도에서 보기/이어 달리기/활성 경로 확인/여기서 새 경로)·관리자 확인(`isRouteReviewer`) 후 「관리」 노출·프로필 수정·`onServiceExit` 로그아웃·`onLinkGoogle` 회원 등록·구독 결제/포털. 계정 탈퇴는 ProfileEditSheet 안에 그대로 있다. 기존 e2e가 쓰는 클래스(`__stats`(자식 div 3개), `__stats-hero`, `__stats-story`, `__last-ride`, `__item`)도 유지했다.

## 계획·지시와 다르게 한 점 / 판단

1. **구독 불러오기 실패 문구를 화면에서 뺐다.** 종전엔 서버 오류 문장(`e.message`)이 플랜 줄 아래에 그대로 나왔다. 읽기 실패는 사용자가 할 일이 없으므로 숨기고 업그레이드/구독 관리 행동만 감춘다(플랜 줄은 「Free 플랜」으로 남음). 사용자가 누른 결제·포털 실패 문구는 그대로 보인다.
2. **게스트 이용 중 「Google 계정으로 회원 등록」 → 「회원 등록」** (구글 마크 제거 — 파란 바탕 위에 색 마크가 맞지 않음, 지시의 「회원 등록」 문구를 따름).
3. 하네스(임시 파일)를 고쳤다: `__design-check.tsx`가 실제 `User` 객체(멤버/게스트)를 넘기게 했고, `__design-check.spec.ts`는 구독 API를 모킹하고 Firestore 차단을 풀었다(차단하면 통계가 비어 보였다). 이 두 파일은 커밋하지 말고 감독이 지울 것.

## 시안과 남은 차이 / Chief 결정이 필요한 것

- **주행 스토리 문장이 거리를 한 번 더 말한다.** 「오늘 2번 페달을 밟으셨어요. 합계 0.99km예요.」가 왼쪽 판 아래에 작게(11px, 2줄 제한) 남아 있다. 디자인 규칙 「같은 정보 두 번」과 시안(C)에는 없는 문장이다. 기존 기능(주행 스토리 M4)과 e2e(`ride-story-shots`가 `.user-info-sheet__stats-story`를 확인)를 깨지 않으려고 남겼다. 빼려면 이 e2e도 함께 바꿔야 한다.
- 시안 C의 「마지막 주행」에는 칼로리가 없다. 구현은 값이 있을 때만 끝에 붙인다.
- 시안은 이름 옆 헤더만 있고 「프로필 수정」이 하단 버튼이다 — 같다. 「관리」는 관리자일 때만 보인다(하네스 스크린샷에는 관리자가 아니라 안 보임).
- 첫 탭에 포커스 링(파란 외곽선)이 보인다: `useDialogFocus`가 열릴 때 첫 버튼에 포커스를 주는 기존 동작이며 리더보드도 같다.
- 시안은 `Space Grotesk`지만 앱 토큰(`Saira Condensed`)을 따랐다(B 강조 + 디자인 시스템 지시).
- `e2e/account-deletion-ui-shots.spec.ts`는 UserInfoSheet.css의 옛 `__logout-confirm-row`·`__confirm-input`·`__btn--danger` 클래스로 정적 HTML을 그리는 시험이다. 탈퇴가 ProfileEditSheet로 옮겨 간 뒤 이미 낡았고, 이번 CSS 정리로 그 클래스 스타일이 사라져 촬영 결과가 달라진다(시험은 건드리지 않았다).
- 라이브 e2e(`account-panel-tidy`·`ride-story-shots`·`calorie-profile-sync` 등)는 에뮬레이터가 필요해 돌리지 않았다. 선택자(탭·`.stats`·`.last-ride`·`#user-info-sheet-history-list`·「프로필 수정」 버튼 이름)는 정적으로 맞춰 두었다.
