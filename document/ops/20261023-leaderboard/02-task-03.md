범위: `apps/web/src/components/UserInfoSheet.tsx`·`.css`, `ProfileEditSheet.tsx`·`.css`, 아래 문구 4곳. **리더보드 파일·MenuPanel·useAppSheetNavigation 은 건드리지 않는다**(다른 지시가 동시에 고친다).

## 기준 그림 — 반드시 먼저 연다

`mockups/account-C-panel.html` 의 **구성**(왼쪽 연한 파랑 판 = 기간 탭 + 고른 기간의 거리 하나 크게, 오른쪽 = 내 도로망·누적·마지막 주행·플랜 목록 + 하단 버튼)에 `mockups/account-B-emphasis.html` 의 **강조 방식**(숫자 Saira Condensed 크게, 단위 대문자 작게, 이름표 작은 대문자 간격)을 입힌다. 리더보드 그림(`mockups/leaderboard-*.html`)과 같은 색·글꼴로 맞춘다.

## 할 일

1. `UserInfoSheet` 를 위 구성으로 다시 짠다. **데이터·동작은 그대로**(기존 props·훅·통계 계산을 쓰고 표시만 바꾼다). 단위는 끝까지(「11분」「5.0 km/h」), 칼로리가 없으면 「체중 입력 후 표시」 링크(기존 프로필 수정 열기), 「최근 400건 기준」 같은 개발용 문구 제거, 강조색은 파랑 하나.
2. 「계정 탈퇴」를 첫 화면에서 빼고 `ProfileEditSheet` 하단의 작은 글자 버튼으로 옮긴다(기존 탈퇴 흐름·확인 단계 그대로). 「종료」는 「로그아웃」 글자 버튼으로(동작 그대로).
3. 「관리」 버튼(관리자만)은 그대로 유지하되 새 스타일로.
4. 게스트에게 보이는 「Google 로그인 시 …」 문구를 **「회원 등록」** 으로: `src/components/ride/RideHistoryPanel.tsx`(「Google 로그인 시 모든 기기의 기록이 유지됩니다」 → 「회원 등록하면 모든 기기에서 기록이 유지됩니다」), `src/components/ride/SavedRoutesPanel.tsx`, `src/lib/account/userTier.ts`, `src/lib/route/repo/publicRouteRequests.ts` 의 같은 뜻 문구. 이미 회원인 사람에게 보이는 「로그인」 은 그대로.
5. 폰 가로 800×360 한 화면, hover 는 `@media (hover: hover)` 안에만.
6. 금지: 통계 계산·인증·탈퇴 로직 변경, 시험·설정·baseline 수정(단, 문구를 고쳐 깨지는 계약 시험이 있으면 고치지 말고 보고), git 명령.
