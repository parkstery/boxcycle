## 허용 파일·수정 방향

1. `apps/web/scripts/ride-result/ride-result-f2-boundary.test.ts`: 미사용 `resumeMeters`, `geometryLength`. 기존 의미를 보존하며 값에 의미 있는 검증을 추가하거나 실제 불필요 계산만 제거. 0.97 cap·두 길이 fixture가 실제로 검증되도록 유지한다.
2. `apps/web/scripts/ride-result/ride-result-f2-card-resume.test.ts`: 미사용 `geoLen` 한 곳. 실제 geometry 길이와 routeDistance가 다름을 assertion에 사용하거나 불필요 계산만 제거. card/Go 동등성 assertion은 유지한다.
3. `apps/web/scripts/ride-result/ride-result-s1-timers.test.ts`: 미사용 `subscribeCount`, `mockRideWriter`와 명시적 `any` 9곳(총11오류). `subscribeCount`는 구독 호출1회 같은 기존 시나리오 검증에 사용 가능. `mockRideWriter`는 실제 연결이 없으면 불필요 선언만 제거하되 기존 assertion·구독·재조회 경로는 보존. Firebase mock 타입은 제품에서 export한 `RideConquestSubscriptionDeps`와 Firebase 타입 등을 이용해 좁은 test helper/type 또는 mock 경계의 명시적인 `unknown` 경유 cast로 정리. `any`→다른 느슨한 타입의 무분별 치환이나 lint disable 금지. 제품 타입은 바꾸지 않는다. overloaded subscribe callback·snapshot 형태를 확인한다.
4. `apps/web/scripts/ride-result/ride-result-s2-end-snapshot.test.ts`: 미사용 `persistedData`, `asyncSave`. 비동기 저장 경로를 실제 await하고 캡처된 저장값을 assertion하도록 최소 보완한다. 스냅샷 복사·뒤늦은 UI 변경·저장 시점의 의미와 기존 assertion은 유지. 타이머를 삭제해 시험을 공허하게 만들지 않는다.

테스트 수·시나리오·assertion을 삭제/skip하거나 핵심 검증을 약화하지 않는다. 별도 새 테스트 파일·새 스크립트는 불필요하다. 위 범위에서 합리적인 세부 구현은 자율 선택한다. 제품 코드 변경이 필요하다면 구현하지 말고 사유를 보고한다.

## 검증

Supervisor가 수정 전에 아래 시험 명령을 실행해 **17시험·4suite·17PASS·종료0**을 확인했다. 제품 변경 없이 lint만 교정해야 한다.

```powershell
Set-Location 'C:\20.HDev\boxcycle\apps\web'
node --experimental-strip-types --import ./scripts/s42/register-vite-env.mjs --test scripts/ride-result/ride-result-f2-boundary.test.ts scripts/ride-result/ride-result-f2-card-resume.test.ts scripts/ride-result/ride-result-s1-timers.test.ts scripts/ride-result/ride-result-s2-end-snapshot.test.ts
```

각 명령의 실제 종료코드·PASS/FAIL/미실행 이유를 별도 기록한다. 전체 lint 오류0/종료0가 완료 조건이며 기존 경고는 그대로 보고한다. 관련 시험17개 유지·통과, build 통과, 다른 변경 보존이 필요하다. 제품 UI는 변경하지 않으므로 브라우저·실주행·Firebase 에뮬레이터는 불필요하다.

PowerShell 구형 호환을 위해 `&&` 대신 별도 명령 또는 `;`를 쓰고, 종료코드는 실행 직후 보존한다. **터미널 Unicode 캡처를 반복하지 말 것.** 출력이 깨져도 종료코드·읽을 수 있는 수치·소스 diff로 확인하고, 필요하면 이 묶음 `evidence/`의 JSON에 저장한다. TEMP 외부 경로 읽기를 반복하지 않는다. 전체 lint는 수정 후 한 번 실행하고 추가 변경/실패 없으면 반복하지 않는다.

새 디버그 코드·주소 스위치·스크립트를 만들면 `apps/web/dev-tools.json` 에 등록한다(분류·목적·켜는 법·만료). 운영에서 켜지는 도구 화면은 동적 import 로 분리한다.
