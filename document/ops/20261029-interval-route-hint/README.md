## Chief 지시 원문 (2026-10-29)

> 일반주행 + 인터벌에서 추가할 사항이 있다. 25km/h를 기준으로 경로 거리가 인터벌 설정 시간에 의한 거리보다 짧은 경우 이에 대한 안내를 한다.
> 1. 인터벌 설정을 먼저 한 경우 : 경로 설정할 때 거리가 짧으면 이에 대해 안내 메시지 내보낼 것(경로 거리를 여유있게 설정하도록 유도- 최소 거리(km) 제시한다.)
> 2. 경로 설정을 먼저 한 경우 : 인터벌 설정 값에 의해 경로 거리가 짧은 것이 판정되면 안내 메시지 표시를 통해 경로 거리가 몇 km이상을 권유한다.)

## 계산

- 최소 거리(km) = 인터벌 총 시간(초) × 25 ÷ 3600. **0.1 km 단위로 올림**한다. 예: 15분 → 6.25 → **6.3 km**, 30분 → 12.5 km
- 「짧다」는 경로 거리(이어 달리기면 남은 거리)가 최소 거리보다 작을 때다
