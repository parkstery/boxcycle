# Cursor CLI 저장소 조사 지시

| 항목 | 내용 |
|---|---|
| 문서 유형 | execution — Codex Supervisor → Cursor CLI |
| 최초 작성 | 2026-10-05 |
| 독자 | AI |
| 상태 | READY_FOR_DEVELOPMENT — 읽기 전용 조사 |

담당: Cursor CLI. 토큰 절약을 위해 결과는 2000자 내외로 핵심 증거 중심으로 답한다. 파일 수정·커밋·push·rename 금지. 다른 작업 변경을 건드리지 않는다. 조사 결과는 stdout으로 전달하고 Supervisor가 결과 기록을 남긴다.

1. 마스터 비전·상태보드·Conquest와 Ready Ride/이어 달리기/새 도로 결과 UI를 확인해, 이미 있는 운동 지속 루프와 아직 빠진 경험을 구분한다. 로드뷰 없이 의미 있는 장소/다음 목표를 제공하는 실구현이 있는지 확인한다. 제품 의미 변경 제안은 제안일 뿐 채택으로 기록하지 않는다.
2. calorie 계산 코드의 수식·표시·저장·집계 경로를 근거 파일:행으로 제시한다. 왜 30kcal/km인지 주석/결정/기록/테스트 근거를 rg로 찾는다. 신체중·시간·저항·와트·심박 사용 여부, 속도 슬라이더/센서 케이던스/미페달링 체험이 calorie를 만드는 조건을 확인한다. 최소 5/10km·30분15/20/30kmh 값을 계산하고, virtual speed와 생리 에너지 연결의 한계를 정리한다. 코드 바꾸지 않는다.
3. RTW/브랜드명 변경 영향의 큰 범주만 확인한다. boxcycle 리포/Firebase 식별자는 유지할 전제다. 일괄 rename 계획을 실행하지 않는다.

검증: 실제 코드/rg 증거. 실행 테스트가 불필요하면 미실행 이유를 명시. 완료 기준: 사실과 추론 구분·calorie 30 상수의 명시된 근거 유무·사용자 다음 주행 동기 경험의 구현/미구현 구분. 외부 과학·브랜드 검색은 Supervisor 담당.
