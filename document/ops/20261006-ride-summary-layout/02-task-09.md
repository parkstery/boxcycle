# 지시 09 — 주행 결과 시트 히어로 정리

- 담당: Developer(Cursor CLI) · 보고: `03-result-09.md` · 커밋 **금지**
- 병행: 지시 06이 `MapHud.*`·`App.tsx` 를 고치는 중 — **허용 파일 밖 수정 금지**, 되돌리기·stash 금지.

## 현상 (Chief 캡처, 폰 가로 추정)
`RideSummarySheet` 히어로 줄이 [새 도로 +0.10] [0.25 / 0.45] [31% → 56% 배지] **3열**이라, 배지 열이 폭을 먹어
- 「새 도로」 라벨이 「새/도/로」 **세로 3줄**로 깨지고
- 「0.25 / 0.45」 가 **2줄**로 줄바꿈된다.
Chief: 「주행 퍼센티지를 컬럼에 배치하지 말고 row 에 배치해.」

## 요구
1. 진행률/완주 배지(`31% → 56%`, 완주 배지 포함)를 히어로의 **열에서 빼서 별도 행**으로 둔다. 위치: 히어로 두 칸 **바로 위 또는 아래 한 줄**(헤더 「주행 결과」 줄 오른쪽이 비어 있으면 그 줄도 후보) — 가장 적은 높이로 들어가는 쪽을 택하고 결과에 이유 기재.
2. 히어로는 **[새 도로][주행/전체 거리] 2칸**만. 각 칸의 라벨·값은 **한 줄**로(「새 도로」 가로 한 줄, 「0.25 / 0.45」 한 줄, 단위 km 표기는 기존 규칙 유지).
3. 보조 줄(시간·평속·칼로리·「체중·강도 설정」)은 그대로 두되, 히어로 정리로 생긴 여백 때문에 어색해지면 정렬만 맞춘다.
4. 헤더 옆 작은 「km」 같은 떠 있는 단위 표기가 의도된 것인지 확인하고, 의도와 다르면 결과에 보고(임의 삭제 금지).
5. 새 도로 칸이 없는 경우(`confirmed_zero` 등)·완주 경우·진행률 없는 경우의 배치도 깨지지 않을 것.
