## §2 현재 상태 (감리가 확인함)

`apps/web/src/lib/riderPrototype/preservedRiderLayer.ts:41-48` 에 광원 셋이 하드코딩돼 있다.

```ts
this.scene.add(new AmbientLight(0xffffff, 1.25));
this.scene.add(new HemisphereLight(0xdcecff, 0x657080, 1.7));
const key = new DirectionalLight(0xffffff, 2.4);
key.position.set(-3, 8, 5);
```

값을 바꾸려면 **코드 수정 → 빌드 → 배포**를 돌아야 한다. 그걸 없앤다.

## §3 ⚠ 가장 중요한 제약 — Chief 는 **배포본**에서 본다

`import.meta.env.DEV` 로 막으면 **Chief 에게 보이지 않는다.** 그분은
`boxcycle-dc2df.web.app`(프로덕션 빌드)에서 테스트한다.

> **URL 쿼리 파라미터로 연다: `?lightlab=1`**
>
> - 파라미터가 없으면 **렌더 자체를 하지 않는다**(`null` 반환). 일반 사용자에게 흔적이 없어야 한다
> - `import.meta.env.DEV` 게이트를 쓰지 마라 — 이번엔 그게 틀린 도구다

## §4 만들 것 — 조명 조절판

### 조절 항목 (즉시 반영, 재로드 없이)

| 항목 | 범위 | 현재값 |
|---|---|---|
| Ambient 강도 | 0 ~ 3 | 1.25 |
| Hemisphere 강도 | 0 ~ 3 | 1.7 |
| Key(Directional) 강도 | 0 ~ 4 | 2.4 |
| Key 방위각(azimuth) | 0 ~ 360° | 현재 `(-3, 8, 5)` 에서 역산해 초기값으로 |
| Key 고도각(elevation) | 0 ~ 90° | 위와 같음 |

- 슬라이더를 움직이면 **다음 프레임에 즉시** 반영된다. 새로고침·재시작 없이
- 색(hemisphere sky/ground)은 이번 범위 **밖**이다. 강도·방향 다섯 개만

### 프리셋 버튼 (한 번에 비교하기 위한 것)

| 이름 | 의도 |
|---|---|
| 기본 | 현재 값 (1.25 / 1.7 / 2.4) |
| 진한 색 | 밝은 면이 흰색으로 날아가지 않게 — 전체를 낮춤 |
| 입체 | Ambient 를 낮추고 Key 를 살려 음영 대비를 키움 |
| 평평 | Ambient 를 올리고 Key 를 낮춰 만화풍으로 |

프리셋 값은 **네가 실제로 화면을 보고 정하라.** 숫자를 지어내지 말고 캡처로 근거를 남겨라.

### 값 내보내기 (이게 핵심이다)

마음에 드는 상태를 찾았을 때, **그 값을 코드에 그대로 붙여넣을 형태**로 보여 주고
**복사 버튼**을 둔다. 예:

```
AmbientLight(0xffffff, 0.90)
HemisphereLight(0xdcecff, 0x657080, 1.20)
DirectionalLight(0xffffff, 1.60) · position(-3, 8, 5)
```

> Chief 가 「이걸로 해」라고 값만 주면 감리가 코드에 굳힌다. 조절판은 **선택 도구**이지
> 최종 저장소가 아니다.

## §5 규칙

- **UI 공간 밀도 원칙 D1~D7 적용**([SoT](../../260924-RTW-UI-공간밀도-원칙.md)) —
  단위 반복 금지, 라벨 2~4자, 접을 수 있게. 폰 가로에서도 지도를 다 덮지 마라
- 패널 터치가 **지도로 새지 않게** 하라(`pointerdown`·`touchstart` 차단) — 이 리포에서 반복된 함정
- 값은 `localStorage` 에 기억시켜도 좋다(새로고침 후에도 유지). 실패해도 앱이 죽지 않게 try/catch
- **제품 조명 기본값을 바꾸지 마라.** 이번 라운드는 도구를 만드는 것이지 값을 바꾸는 게 아니다
- 라이더 렌더 경로(`preservedRiderLayer`)의 **구조를 갈아엎지 마라** — 광원 참조를 잡아 두고
  강도·위치만 갱신할 수 있게 하는 최소 변경
