주행 화면 배치 방안: 오른쪽 조작 레일

A안(오른쪽 조작 레일)으로 정했습니다. 이번에 더한 것은 두 가지입니다. ① 순위 목록은 버튼이 숨으면 오른쪽 가장자리에 붙고, 버튼이 나오면 레일 폭만큼 안쪽으로 밀려납니다. ② 메뉴 패널 안에 있던 Trail 목록을 순위 목록처럼 지도 위 줄 목록으로 꺼내는 방법 세 가지를 비교합니다. 시뮬레이터 화면을 누르면 실제처럼 버튼이 나타나고 숨습니다.

버튼 Trail 목록 화면 버튼 크기

제 생각: ① 왼쪽 가장자리추천

  • 왼쪽 = Trail, 오른쪽 = 순위. 지금 반달 탭도 왼쪽이 Trail 메뉴, 오른쪽이 순위라 손이 기억하는 자리와 같습니다.
  • 목록은 버튼에게 자리를 내줍니다. 순위는 옆으로 밀려나고, Trail 목록은 아래쪽 주행 버튼 줄이 나오면 아랫줄부터 접혀 「+2」로 줄어듭니다. 버튼이 숨으면 다시 펴집니다.
  • 주행 중엔 버튼이 숨어 있는 시간이 대부분이라, 평소엔 두 목록이 다 보이고 누를 때만 잠깐 줄어듭니다.
  • Trail 줄은 순위처럼 한 줄씩: 번호·짧은 이름(도로·동 이름)·km·「주행 중」 또는 「합류」. 줄 전체가 합류 버튼입니다. 지금 내 Trail은 순위의 「내 줄」처럼 파란 띠.
  • 패널에 남길 것: 「이 Trail 공개/비공개」 전환과 검색·로그인 같은 드문 일은 메뉴 패널에 그대로 둡니다. 주행 중엔 일시정지에서 엽니다.
  • 낮은 폰(273px)에선 버튼이 나올 때 Trail 목록이 머리줄 「Trail 4 ▸」만 남습니다. 대신 버튼이 숨으면 4줄이 다 보입니다.

② 오른쪽 탭 공유

  • 오른쪽 목록 자리 하나를 순위·Trail이 나눠 씁니다. 머리줄 「순위 | Trail」을 눌러 바꿉니다.
  • 왼쪽이 비어서 화면이 가장 넉넉하고, 낮은 폰에서도 그대로 동작합니다.
  • 대신 두 목록을 동시에 볼 수 없습니다. 순위를 보다가 Trail로 바꾸면 순위는 안 보입니다.

③ 아래 가로 칩

  • Trail을 화면 아래쪽 가로 칩 한 줄(「440 이태원로 3.0km」)로 보여 줍니다.
  • 세로 공간을 거의 안 씁니다.
  • 대신 2~3개만 보이고 나머지는 옆으로 넘겨야 합니다. 응원 자막과 자리를 다퉈 자막이 위로 올라갑니다.
