# 지시 06-2 — 폰 가로 주행 중 우상단 줄이 계기판을 가리는 문제

- 담당: Developer(Cursor CLI) · 보고: `03-result-06b.md` · 커밋 **금지**
- 전제: 지시 06 결과(미커밋) 위에서. 되돌리기·stash 금지. 지시 09(RideSummarySheet) 병행 중 — 허용 파일 밖 금지.

## 문제 ([검수 06](04-review-06.md))
690×275 주행 중 `[1–6][야외 − +][계정]` 줄(≈363px)이 왼쪽으로 길어져 상단 계기판(거리·시간·평균·속도·**새 도로**)의 오른쪽 칸을 덮는다. 1000×640 은 정상.

## 요구
1. **겹침 0**: 주행 중 우상단 줄의 bounding rect 와 계기판(각 stat 요소) rect 가 교차하지 않을 것 — 690×275, 740×360(일반 폰 가로), 844×390, 1000×640 에서 계측.
2. 해법 우선순위(Chief 배치 의도 = 카메라와 계정 사이 한 줄 — 최대한 유지):
   a. 좁은 폭에서 카메라·맵 버튼의 **시각 폭만** 줄인다(간격·글자 크기·패딩). 터치 44px 는 `::after` 확장으로 유지.
   b. a 로 부족하면 좁은 폭에서만 맵 제어(야외 − +)를 **카메라 줄 바로 아래 줄**(계정 아래 아님)로 내린다.
   어느 쪽을 택했는지와 각 폭의 계측치를 보고.
3. 계기판 쪽은 수정하지 않는다(읽기만).
4. 타입 검증은 **`cd apps/web && npx tsc -b --noEmit`**(pre-push 와 동일). `tsc --noEmit -p .` 는 빈 검사라 금지.
