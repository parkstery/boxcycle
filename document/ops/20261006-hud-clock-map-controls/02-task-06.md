# 지시 06 — 시계 HUD 우하단 이동 · 맵 스타일/줌 버튼 상시 표시

- 담당: Developer(Cursor CLI) · 보고: `03-result-06.md` · 커밋·푸시 **금지**
- 전제: 다른 묶음(20261006-saved-route-integrity)의 미커밋 변경 위에서 작업 — 되돌리기·stash 금지.

## Chief 요구 (2026-10-06)
1. 화면 우상단의 **날짜·시계 HUD**(`MapHud.tsx` `hud-clock`)를 **우하단 고도/축척 바 바로 위**로 옮긴다.
2. **맵 스타일 토글(야외/위성)·− / +** 버튼(현재 주행 중에만 카메라 버튼 아래 보조 행)을 **항상** 표시한다.
3. 그 위치는 **시계가 있던 자리** — 카메라 버튼들과 계정 버튼 **사이**(우상단 한 줄). 대기(idle) 화면처럼 카메라 버튼이 없을 때는 계정 버튼 바로 왼쪽.

## 현재 구조 (Supervisor 조사)
- `components/maphud/MapHud.tsx`: `quickCamera` prop(주행 `running|paused` 일 때만 App 이 넘김) 안에 `mapControls`(styleLabel·onToggleStyle·onZoomOut/In·disabled). 시계는 ~600 `<time className="hud-clock">`. `map-hud__tr-under--with-ride-controls` 가 「맵」 트리거를 내린다.
- `App.tsx` ~2920: `quickCamera: rideStatus === "running" || "paused" ? {…, mapControls: {…}} : null`. 주행 중 ± 는 카메라 모드에 따라 `rideCameraDistanceM` 조정 또는 `setMapZoomStepRequest`(mapZoom 스텝).
- 고도·축척: 우하단(20261005-ride-map-controls 지시 07 「축척 왼쪽 고도」). 실제 요소·클래스는 grep 으로 확인.

## 구현 지침
- `mapControls` 를 `quickCamera` 에서 **분리**해 MapHud 의 독립 prop 으로 받는다(카메라 유무와 무관하게 렌더). 주행 중 동작(± 의미)은 **그대로** 유지.
- **대기(idle)** 의 ± = 일반 지도 줌 −1/+1 — 기존 `setMapZoomStepRequest` 경로를 재사용(새 줌 체계 금지). 줌 한계에서 disabled 는 가능한 범위에서(어려우면 활성 유지, 결과에 기록).
- 스타일 토글 = 기존 `nextOutdoorsSatelliteMapStyle` 그대로(대기에서도 같은 맵 상태).
- 시계: 우하단 고도/축척 묶음 **위**에 오른쪽 정렬로. 미니맵·고도 그래프·지도 저작권 표기·Mapbox 기본 컨트롤과 겹치지 않을 것.
- 「맵」 트리거·우측 Mapbox 줌 컨트롤 등 **다른 컨트롤 위치가 밀리면** 기존 `tr-under` 보정 규칙을 새 배치에 맞게 정리(주행/대기 모두).
- 폰 가로 전용 앱(세로는 회전 오버레이) — **690×275 에서 한 줄에 들어가야** 한다. 넘치면 결과에 측정치로 보고(임의로 버튼 숨기지 말 것).
- 터치 목표 44px 규칙(`::after` 확장, 기존 D2)을 유지.
