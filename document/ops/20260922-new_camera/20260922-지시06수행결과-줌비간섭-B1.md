### `zoom.json` (유한수 · M0 통과)

```json
{
  "z0": 23.24755247272007,
  "z_user": 23.99999999106828,
  "z3": 24,
  "z_repress": 23.25098566009164,
  "f5_samples": [23.99999981987449, 23.999999871283112, 23.999999929794303],
  "abs_z_user_minus_z0": 0.7524475183482089,
  "abs_z3_minus_z_user": 8.93e-9,
  "abs_z_repress_minus_z0": 0.0034331873715700567
}
```

합격: `|z3−z_user|≪0.05`, `z_repress≈z0`.

방법 주석: Playwright `mouse.wheel` 은 이 환경에서 맵 줌을 거의 바꾸지 못해,  
`map.fire('zoomstart', {originalEvent})` + `jumpTo` + `zoomend` 로 **사용자 기원 경로**를 탔다.

## §1 구현 요약

1. 사용자 `zoomstart`(originalEvent 있음) → `zoomend` 에서 거리 역산 → `rideCameraDistanceM` + `spanFloorMode=userZoom`
2. tick 은 그 거리·floor 모드로 framing 계속
3. QC/시트 preset 재적용 시 `spanFloorMode=preset` + 5/60m
4. **B1**: `rideSpanM(..., "userZoom")` 는 floor 없이 `spanM=distanceM`
5. `topDown`/`north`/`keep`: 사용자 줌을 앱 `mapZoom` 에 동기화
6. `__RTW_MAP__` 를 항상 노출(캡처 M0)
