**지시10 은 합격이다.** 이제 마지막 변경 하나와 이력 정리를 한다.

## §1 변경 — 1번 3단의 세 번째 단계를 5m 상공으로

> 「1번 버튼 3가지 순환 모드 가운데 **10m 상공을 5m 상공으로 변경**」(Chief)

```
1 클릭 → 전체 경로(Route Fit)
1 클릭 → 60m 상공
1 클릭 → 5m 상공      ← 10m 에서 변경
1 클릭 → 전체 경로 …
```

- 상태 이름·라벨·주석의 `aerial10` 계열을 **`aerial5`** 로 함께 바꿔라.
  이름이 값을 배신하지 않게 한다(이번 작업의 출발점이 그 문제였다)
- **floor 확인**: `aerial` 은 pitch 0 이라 `margin(0)=1.12` → floor ≈ **1.79m** 다.
  5m 는 여유롭게 그 위이므로 클램프에 걸리지 않는다. **네가 직접 재확인하고 수치를 보고에 적어라**
- 버튼의 단계 표시(현재 `10` 뱃지)도 **`5`** 로 바뀌어야 한다. 폰 가로에서 잘리지 않는지 확인
- 그 외 QC 2~5(6m)·60m·거리 범위는 **건드리지 마라**

## §3 커밋 · 푸시 · 병합 — 이번에는 **명시적으로 허용**한다

Chief 지시: 「커밋 푸시 병합 진행하자」

1. **커밋** — 아직 커밋되지 않은 지시10·지시11 변경분을 정리해 커밋한다.
   릴레이 문서·`.cursor/rules`·`.claude/skills/ops-relay` 등 **이번 작업으로 생긴
   인프라 파일도 포함**한다(누락 없이). 메시지 예:

```
feat(camera): QC 버튼 150% · 터치 전파 차단 · 1번 3단 상공 5m

- QC 버튼 크기 1.5배(gap 유지), 폰 가로에서 Account·HUD 지표와 겹침 없음
- pointerdown/touchstart stopPropagation + pointer-events/touch-action 으로
  버튼 터치가 지도로 새던 문제 해결(Chief 실기 확인)
- 1번 3단 순환의 3단계를 10m → 5m 상공으로 변경(aerial10 → aerial5)

Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>
```

2. **푸시** — `main2` → `origin`
3. **병합** — `main2` 를 **`main`** 에 병합하고 `main` 도 푸시한다.
   충돌이 나면 **임의로 해결하지 말고 멈춰서 보고**하라
4. 끝나면 `main2` 로 돌아와 작업 상태를 원래대로 둔다
