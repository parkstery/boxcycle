## §0 현상 (Chief, 2026-09-23 실기 확인)

> 「1번 카메라 클릭으로 토글모드 On 되면 경로 전체를 보여준다. 하지만 **1초도 지나지
>  않아서 자동으로 토글 OFF 가 되는 것 같다.** 상공 60m 뷰로 바로 전환되고 있다.」

나머지 기능은 의도대로 동작한다고 확인받았다. **이것만 고친다.**

## §1 감리 진단 — 상태가 풀리는 게 아니라 **팔로우 틱이 되돌린다**

`App.tsx` `handleQuickCameraSelect` 의 Route Fit 분기:

```ts
if (nextRouteFit) {
  … setExternalCameraJump({ bbox })   // fitBounds 1회 — 여기까진 맞다
  setFollowMode("topDown");           // ← 원인
}
```

`topDown` 은 **팔로우 모드**다. `fitBounds` 직후 억제 창
(`suppressCameraFollowUntilRef`, 1700ms / reduced-motion 120ms)이 끝나는 순간
`tickRideCameraFollow` 가 매 프레임 `jumpTo` 로 카메라를 **라이더 중심·앱 줌**으로
되돌린다. Chief 가 본 「1초 만에 OFF」는 토글 상태가 뒤집힌 게 아니라
**Route Fit 프레이밍이 팔로우에 덮인 것**이다.

`camera1RouteFit` 값은 그대로 `true` 일 것이다 — 다시 눌러 보면 Aerial 로 가므로
상태는 살아 있다. 그 사실이 이 진단을 뒷받침한다.

## §2 고칠 것

Route Fit 은 **추적하지 않는 상태**다(원안 §11: 지속 auto-fit loop 가 아니며 사용자
줌을 허용한다). 따라서 Route Fit 분기는 팔로우를 **끈다**:

```ts
setFollowMode("free");   // topDown 이 아니다
```

- `activeQuickCamera === 1 && camera1RouteFit` 인 동안 팔로우 틱이 카메라를 만지지
  않아야 한다. `free` 는 `tickRideCameraFollow` 가 early return 하는 유일한 경로다
- Aerial 분기(`setFollowMode("aerial")` + 60m)는 **그대로 둔다** — 그건 추적이 맞다
- MapViewSheet 칩이 `free` 로 보이게 되는데 **그게 사실이다.** 숨기지 마라

### 반증 조건 — 고치기 전에 확인하라

> "`free` 로 바꿨는데도 1초 뒤 프레이밍이 되돌아가면 팔로우 틱이 원인이 아니다."

그 경우 범인은 `MapView.tsx` 의 **앱 `mapZoom` → 지도 적용 effect**(3481 부근)다.
`shouldSyncMapZoomToApp` 이 `free` 에서 `true` 가 되므로 억제 창이 끝난 뒤 앱 줌이
지도 줌을 덮을 수 있다. 그때는 `fitBounds` 의 `moveend` 가 앱 줌을 **지도 값으로
동기화**하는지(`syncZoomFromMap`) 확인하고, 안 되면 그 동기화를 고쳐라.
