# 센서 없는 주행의 순위 임시 허용

2026-10-29 Chief 요청: 테스트 중 센서 없는 주행 기록도 순위에 포함. 출시 전 센서 전용으로 원상 복구.

- 주행 거리·개척의 주/달/전체 집계, 주행 중 순위와 종료 결과를 일치시킨다.
- 회원/Guest 정책, 기록 유효성, conquest tier·인정 거리 자체는 보존한다.
- 서버 설정을 단일 복구 지점으로 두고 응답 rule.sensorOnly에 화면을 맞춘다.
- 조건 변경 전 캐시는 재사용하지 않는다. 과거 기록 변환·재기록은 하지 않는다.
- 출시 체크리스트에 복구·검증·배포 순서를 남긴다.
- 고정4/41/46의 순위 위치·크기·참가자 표시 수와 다른 작업 변경을 보존한다.
- 커밋·푸시·배포는 이번 요청에 포함되지 않는다.

검증: 서버 전체 시험, 웹 타입/빌드, 변경 lint, 기존 순위 시험+임시/출시 조건 회귀, 실제 컴포넌트 안내 렌더, 의존/정련/diff.
