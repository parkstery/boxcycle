✓ location-choice — 최초 위치 컨트롤 클릭은 브라우저 위치 허용으로 직접 연결. 앱 중간 확인 없음.
✓ app-intro — 최초 인증 전 앱 소개 — onStartGuest·onLogin 두 콜백과 「게스트로 시작」「로그인」 버튼. 이 화면은 인증·타이머를 하지 않는다.
✓ app-intro-gate — 소개는 최초 진입 또는 이용 종료 후 표시하며 메모리 dismiss 전일 때만. 2초 자동 전환은 없다. 게스트·로그인 버튼은 인트로를 닫고 기존 인증을 바로 호출한다. 정상 첫 진입은 게스트 카드를 다시 띄우지 않는다. 탈퇴·로그아웃·설정 없음·오류 회복은 위치 안내와 겹치지 않는다.
✓ guest-entry — 게스트 진입 카드 — 익명 인증 '시작' 버튼
✓ auth-session-state — 인증 세션 게이트 — 설정 없음, 부트·서명·busy 대기(실패/선택 버튼 없음, stale error 숨김), 이용 종료 뒤와 실제 실패 모두 로그인·게스트로 시작, 복원 전 오프라인만 재시도, idle 선택. App 은 이 컴포넌트에 같은 상태를 연결한다.
✓ cadence-chip — 케이던스 센서 칩 — 센서 상세 설정 트리거. 펼친 RouteDock 한 곳에만 있다. 접힘·무경로는 경로 패널 LED가 펼친 뒤 칩을 누른다. 셀렉터는 자리에 의존하지 않는 역할·접근성 이름이므로 이동해도 그대로 쓴다.
✓ cadence-chip-slot — 센서 칩 자리 판정 — dock 과 우상단에 동시에 뜨면 getByRole 이 strict 위반으로 깨진다. 어디에도 안 뜨면 「센서 없음」에 닿지 못해 Go 가 영영 잠긴다.
✓ input-readiness — 주행 입력 준비 — 센서 상세 설정에서 '센서 없음' (Go 사전조건)
✓ session-speed-slider — 세션 속도 슬라이더 — **센서 시트 안**에 있다. 2026-08 경에 경로 도크에서 옮겨 왔고, 스펙은 도크를 계속 뒤지다 죽었다. 자리가 또 바뀌면 여기서 먼저 깨져야 한다.
✓ session-speed-control — 세션 속도 컨트롤 — 슬라이더·숫자 입력의 접근성 이름
✓ go-precondition — Go 사전조건 — 센서 연결 **또는** 수동 속도 입력이 준비돼야 눌린다(2026-08-27). 이것을 모르면 「버튼이 보이는데 안 눌린다」로 죽는데, 원인이 잘 안 보인다.
✓ open-menu — HUD Trail 메뉴 — 포커스 시 드러나는 대안(지도 알약·에지 탭 없음)
✓ open-basic-courses — RideRoutePanel '경로 선택' → 내 경로 기본 모달 → 입문 출처
✓ course-modal — 입문 코스 모달 — dialog + 코스 항목 버튼(Load course)
✓ start-ride — 우하단 주행바·경로창 재생 — 동일한 준비 조건과 콜백으로 주행 시작
✓ next-ride-card — 지도 위 「다음 주행」 카드 — 이어 달리기·새 경로 연결 CTA(RIDE-CONTINUE-1 §3.1)
✓ ride-result-progress — 주행 결과 시트 — 오늘 거리 + 전체 진행(이전→신규) + 완주/진행률 배지(RIDE-CONTINUE-1 §3.5)
✓ ride-running-proof — 주행 중 확정 — HUD 주행 지표 그룹 + 누적 거리
✓ ride-end-control — 주행 종료 — 독립 주행바(Stop/Pause)
