# 感理 보완 — 펼친 상태 기존 접기 버튼 복원

01 지시의 명확화이자 필수 요구 불일치 수정이다. Chief는 'RouteDock이 펼쳐지면 … RouteDock 축소버튼을 표시'하도록 요청했다. 펼친 상태에도 점멸 LED가 남는 구현은 불합격이다.

- **접힘**: 현재 새 흰/녹 점멸 LED 펼침 버튼 유지.
- **펼침**: 기존 `RouteOverviewFoldToggle`의 route 모양·28×28 접기 캐럿 버튼을 사용. 센서 상태 LED 토글은 없어야 한다. 패널 안 기존 센서 알약은 유지.
- 기존 01 소유/금지/증거보존 규칙 그대로. 제품코드는 Cursor가 수정, Codex는 감리만.
- `sensor-dock.spec.ts`가 펼친 상태에서도 `.route-dock__led-toggle`가 있다고 기대하는 부분은 실제 요구에 맞게 수정. 펼친 상태 LED토글0, 기존접기버튼1과센서알약1, 접고LED1의회귀를 명시적으로 단언. 4개가로크기.
- 포커스: 접힘 LED와 펼침 접기 버튼이 교체될 때 키보드 Enter/Space 이후 포커스가 body로 사라지지 않도록 접기/펼치기 현재 버튼으로 포커스 유지. 캡처로 기존 접기 도안 확인.
- `RouteDock` 상태 연결·실제 App 호출자·기존더티보존 유지. 대상 타입/린트·selector·신규화면시험을 다시 실행하고 `05-result-review-fix.md` 작성.
- `02-result-cursor.md`와 이 보완의결과를분리. 커밋푸시배포금지.
