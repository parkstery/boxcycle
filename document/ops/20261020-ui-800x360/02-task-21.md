# 거리 안내 원 방사상 화살표

2026-10-22 · execution. Chief 구현 승인, 토큰절약을 위해 Cursor AI 사용. Supervisor Codex 검수. 기존 dirty/ops/evidence 보존. Git/배포 금지.

기존 지도 거리 안내 파선원에 정적인 바깥방향 화살표12개(30도 간격)를 추가. PNG는 모양 참고이며 다운로드/서버호출/외부의존 추가 금지. 출발 위치·반지름이 바뀔 때만 계산, 기존 Mapbox map/GeoJSON에 벡터 선분으로 표현. 각 화살표는 원 바로 안쪽에서 원 둘레로 향하도록 몸통+날개2개. 기존 원/경로/원fitBounds 의미 불변. 원 제거시 화살표도 제거, style reload/재진입 누락 방지. 터치 타깃/DOM마커/애니메이션 추가 금지. 모바일에서 과도하게 크지 않게 반지름대비 합리적인 길이. 지도pitch/회전과 함께 그려짐.

허용 파일: apps/web/src/components/map/MapView.tsx(거리 안내원 effect 범위), 기존 apps/web/src/lib/route/distanceAutoRoute.ts(필요시 순수geometry helper 추가), apps/web/scripts/distance-auto-route/distance-auto-route-contract.test.ts(새 geometry 동작시험 필요시). 다른 파일 수정금지. 구조상 더 좋은 기존 파일이 있으면 결과에 설명하되 범위 확장하지 말 것.
