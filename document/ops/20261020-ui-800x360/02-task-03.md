# 지시03 — 우선 릴리스 이후 Cursor 재개 · 가장자리 드래그 패널

2026-10-20 Chief 추가 요구. 담당 Cursor AI/CLI, Supervisor Codex. 지시02와 감리01의 미완 범위를 모두 이어서 구현한다. 지시02 실행은 우선 릴리스 때문에 Ctrl+C 중지했으며 제품 구현 결과가 없었다. 기존 GLM 구현은 보존한다. 지시02 및 05-release-first-and-edge-panels.md를 먼저 읽는다. 한국어 보고.

## 추가 허용·제품 원칙

- 지시02 허용 파일에 MapHud.tsx 및 src/components/ui/EdgePanelHandle.tsx/css(또는 동일 역할의 작은 모듈), App.tsx의 **가장자리 핸들 결선 및 패널 상호배제만**을 추가한다. 기존 인증·주행·저장·위치 결정·동기화 변경 금지. hooks/lib 도메인 수정 금지. 기존 미니맵24px 캐럿은 이번에 변경하지 않는다.
- 적합한 패널에 실제 가장자리 안쪽 드래그를 적용한다. 최소 좌측→우측의 기존 메뉴, 우측→좌측의 기존 지도 설정. 현재 위치/트리거와 어긋나면 새 표면을 만들지 말고 적절한 기존 패널에 연결하고 이유를 결과에 기록. 네 방향을 억지로 모두 채우지 않는다. 주행 제어/결과/입력 모달의 저장 내용을 임의 드래그 닫기로 잃게 만들지 않는다.
- 화면 전체 투명 드래그 레이어 금지. 지도 중앙의 pan/pinch/rotate는 지도에 남긴다. 드래그 시작 전용 보이는 좁은 핸들(예: 실제44×64px, 안전영역 + 12px 안쪽)을 사용. 클릭/Enter/Space로 동일 열기, aria-label/expanded/controls 제공. 양쪽이 겹치거나 브랜드/계정/맵버튼과 충돌하지 않는 세로 위치 선택. 인증 전 HUD가 숨으면 핸들도 숨긴다. 핸들의 hit영역을 이웃 위 pseudo로 덮지 않는다.
- Pointer Events와 pointer capture 사용, down에서 위치 저장, 주축 방향+직교축 우세 판정, 거리 기준(약48px) 또는 의도 확인 후 속도 기준으로만 열기. 반대방향·짧은 드래그는 원상복구. pointercancel/lostcapture/resize에서 drag상태 정리. 핸들만 touch-action:none. 열린 패널 헤더/전용그립에서 바깥 방향 드래그 닫기, 본문 스크롤은 그대로. 멀티포인터 무시/안전취소. 클릭 중복 실행 방지.
- 드래그 도중 패널 이동량을 시각 피드백으로 표시(열림끝에서만 전환하는 가짜 제스처 지양), 완료/취소에 짧은 transition. reduced-motion은 즉시 전환. 기존 버튼 열기·명시적 닫기·Escape 대안 보존. 모달 focus trap/복원과 숨은 자식 inert 처리. 메뉴 내 목록의 중첩 scrim도 지시02대로 해결.
- 조밀한 화면에서 지도 공간을 남기되 글자/타깃 축소로 해결하지 않는다. 800×360 기본,667×300/844×390에서 패널 viewport 내 스크롤. 기존 runtime 계약과 aria 앵커 보존.
