## 구현

1. 800×360에서 HUD 라벨 최소11px, 일반 숫자18px 이상, 거리/속도 주요 숫자22px 전후, 단위10px 이상. 667×300에서도 겹침/잘림 금지. 기존 작은 캡슐을 정돈하되 상단 전체를 패널로 덮지 않는다. 거리/시간/평균/속도/새 도로 의미·순서, 카메라 프리셋·계정 유지. 긴 거리/동행 고려. 루트font-size는 바꾸지 않는다.
2. RouteDock 시작·재개·일시정지·종료 최소44×44px. 기존 세 버튼 순서/위치/disabled 계약 보존. 시작·재개에 짧은 보이는 텍스트(시작/재개), aria-label 주행 시작/재개/일시정지/주행 종료 유지. 주소와 조화, dock전체폭300px 이내 목표.
3. 센서 높이44px, 글자11~12px 이상. SENSOR 대신 센서. aria 계약과 LED/센서/수동 기능 유지.
4. RouteDock 캐럿 실제44px 터치영역. 이웃을 덮거나 overflow hidden에 잘리는 pseudo 확장 금지. 실제44px 폭 사용 가능. 주소와 삭제행44px 높이, 주소11~12px 이상. diet·접힘·이어달리기 로직 불변.
5. light/blue 공통 역할 토큰(--rtw-ui-surface/ink/muted/primary/border 등)을 정의해 이 범위에서 사용. 골드/보라 trace·Mapbox 색 변경 금지. 기존 CSS를 정리하며 무작정 override append 금지.
6. 미니맵 최신24px 캐럿·RouteDock 상하관계 수정 금지. 모바일 항목 임시숨김으로 통과 금지.
