## 순차 구현 — 실제 동작을 보존한 UI 개선

### 선행 GLM 결과의 감리 보완 (추가 쓰기 허용)

GLM 완료 후 MapHud.css·RouteDock.css는 아래 실제 측정 결함을 수정할 때만 추가 허용한다. 원래 지시01 결과는 보존하고 감리 보완으로 기록한다. Supervisor fixture `/scripts/ui-800x360/preview.html?state=riding&long` 800×360에서 계기판 x116~600/y11~67와 카메라 x372~535/y11~41가 겹쳤다. 계기판을 브랜드 아래 독립 행으로 배치하고 카메라를 계기판 영역과 겹치지 않는 오른쪽 자리로 옮기는 CSS 개선이 필요하다(667×300도 확인). 그룹/정보를 숨기거나 글자를 다시 줄이지 않는다. 시작 라벨이44px 정사각 안에서 '시/작' 두 줄로 깨졌으므로 시작·재개는 내용폭+최소패딩/nowrap를 적용하고 모바일44px강제width override를 해소한다. 주소 삭제는16px폭×44높이에 머무르므로 flex-basis/width/min-width44px로 실제44×44를 확보한다. 이웃 위 pseudo 확장 금지. 키보드·단위·기존상태 불변.

1. 첫 진입 위치 다이얼로그 중 LocalFirstEntryCard가 동시에 보이지 않도록 entryLocationPrompt 조건을 카드 노출에 적용. 기존 중앙 버튼 접근성 이름·인증/위치권한/기본 지역 선택 및 재시도 로직은 유지. Ready Ride에 짧은 '거리를 고르면 경로를 찾습니다' 안내, Km→km. 위치선택 완료 뒤 정상 카드 복귀.
2. 줌 중복 제거: MapZoomGlobeControl에서는 기존 HUD에 있는 확대/축소를 없애고 지구 전체 보기만 남긴다. globe/나침반은 유지, HUD 줌 기능 불변. 미사용 생성 코드 제거. CSS 숨김만 하지 말 것.
3. 경로 고르기에서 세 출처를 한 모달 안에서 전환할 수 있도록 공통 RouteListModalShell에 **optional** 출처 내비게이션 slot/props를 추가하고 Official/Saved 모달이 전달하게 한다. RideRoutePanel이 출처 상태를 소유하고 intro/public/saved가 동시에 열리지 않도록 통합. 새 API·데이터조회모델 없이 기존 목록/내경로 액션/대기 필터/공개 요청 후 복귀/출처 버튼 aria 계약 유지. 같은 화면에 메뉴 scrim과 목록 scrim이 겹치지 않게 메뉴를 일시 inert/비표시(보존한 상태)로 처리하되 내비게이션을 닫으면 돌아온다. CSS :has 또는 optional onModalOpenChange 같은 최소 결선 사용. 메뉴 트리거는 유지.
4. 목록 타이포 제목12~13px, 보조11px 이상, 행 최소32px 기존 Chief예외 유지. 내용길이 따라 높이 허용. 실제 title 원문·검색·정렬·등록자·기록 데이터 보존. 표시에 한해 입문 Basic N 접두어를 덜어 지역명 중심, 중복 설명 최소화. 원문 title에 보존. 소요시간·상승고도처럼 없는 수치를 만들지 말 것. 카테고리명 '퍼블릭'은 Ontology그대로. profile 메타 의미 혼동은 '도로 기준' 보조설명 또는 tooltip으로 해결, 주행 수단/데이터 의미 불변.
5. 맵 설정: free→자유, POI→장소 이름, Outdoors/Satellite 표시만 야외/위성으로. OSRM 비교와 임시 POI/정밀거리 튜닝은 접힌 '고급 설정'에 넣고 목적 설명, 개발어를 기본 표면에서 제거. 데이터값/콜백 불변. 내도로망/지도/시점 기본 그룹은 읽히게. 카메라 8선택 기능 유지하며 줄바꿈 또는 고급 접기로 정돈. 패널 본문13px전후, 작은라벨11px이상. 실제 버튼 타깃44px 확보(필요한 스크롤 허용), 패널전체max-height뷰포트-16px. top-right 패널 기존 위치 원칙은 유지.
6. 주행 설정: '추정 칼로리', '센서 주행 시 체중과 운동 강도를 바탕으로 계산합니다.'로 설명. 체력→운동 강도, TTS→음성 안내/BGM→배경 음악. 계산 id/정책/센서 gating불변. 헤더에44px 명시적 닫기 버튼. 체크박스 label 타깃44px 높이, 읽히는11~13px. 기존 좁은 체중/강도 입력22px 예외는 유지(전체 버튼 무차별 확대 금지), 이름 길면 wrap. sheet중앙하단 위치 유지.
7. 사용자 정보: Guest UID문자열 기본 노출 제거, 짧은 '게스트로 이용 중' 표시. Guest에 미구독보다 Google연결로 기록보존 안내. 내 도로망은0일 때도0km 및 '첫 라이딩으로 나만의 길을 남겨보세요.' 표기(loading/null을 확인된0으로 오해시키지 않게 로딩 구분). 누적·통계·구독·탈퇴·Google 동작은 불변. 타이포11~13px 이상, 상태/값 위계, 전체viewport내 스크롤. 2열 계정구조 유지.
8. 결과 시트: 스토리·새도로·진행률 중심 위계 보존. 시간 숫자 앞 '시간', 평속 값 앞 '평균' 등 짧은 라벨을 추가해 해석 가능. 기존 km그룹단위 반복 금지 원칙 보존. 새도로 positive/zero/loading/error/timeout 상태로직,저장/중복확인/취소동작/자동구독변경 금지. 800×360에서 내용12px전후,지표22px전후,확실한닫기/스크롤.
9. 공통 흰 패널/파랑은 지시01의 --rtw-ui-* 역할 토큰 사용(fallback 허용), 제목을 버튼 같은 테두리칩으로 꾸미지 않는다. border/rounding/shadow 일관. 닫기 모양 통일. 메뉴·설정·목록은 닫힐때 숨은 버튼으로 Tab 이동 안 되게 inert/조건부렌더, 모달 열기시 focus·닫기후 트리거복귀·Escape 처리. 공용 훅이면 작고 독립, 모든 훅은 조건부 호출 금지.

## 검증 및 보고

결과 시트의 기존 `zoom: 0.8`는 글자와 터치까지 다시 축소한다. 이번 가독성 개선에서는 zoom을 제거하고 내용폭·padding·max-height·개별 실제px로 작고 읽히는 시트를 만든다. getComputedStyle 숫자만이 아니라 실제 렌더 크기를 확인한다.

읽기전용 기존 src/App.tsx/미니맵/MapHud 변경 보호. 실행해본 명령/종료코드/미실행을 구분. 브라우저는 Supervisor가 담당하니 전체 e2e/에뮬레이터/운영 API를 실행하지 않는다. 작은 스타일변경에 구현복제 테스트 추가 금지. 이 작업은 동작 변경도 있으므로 관련 회귀 확인.
