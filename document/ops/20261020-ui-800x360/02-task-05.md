2026-10-21 Supervisor Codex. 앞선 LOCAL_VERIFIED는 자동시험만 충족했으며 Chief의 디자인 기준을 충족하지 못해 **디자인 반려**. 이번 지시가 01~04의 44px 확대·브랜드 아래 계기판·노출 핸들 지시보다 우선한다. 담당 Cursor CLI Composer2.5. 별도 새 세션으로 실행하고 결과05 작성 후 종료한다. 기존 다른 변경 보존, 커밋·푸시·배포 금지.

## Chief 기준·완료조건

지도 가림 면적 최소화, 중심에서 먼 가장자리 배치, 패널 안 빈 공간 최소화, 중복 컨트롤 제거. 주 화면 800×360. 667×300/844×390 회귀. 실제 지도와 실제 App 결선까지 Supervisor 검수 예정.

1. **양쪽 흰 상자·파란 막대 제거**. 보이지 않는 18~20px 폭의 화면 좌/우 에지 제스처 띠(상/하 안전영역 제외)에서 안쪽 드래그하면 메뉴/맵뷰 등장. 띠는 정확히 화면 좌우0에 붙이고 safe inset을 이유로 안으로 이동 금지. 메뉴/모달/인트로 중 비활성. 일반 탭으로 갑자기 열리지 않음. 중앙 지도 pan/zoom·기존 Mapbox/도크 컨트롤을 침범하지 않게 시작대상 interactive controls 제외 또는 stacking 처리. 포인터캡처 유지·취소/회전/짧은/수직/반대/멀티터치/빠른훑기 처리. 기존 hook 재사용 가능.
2. **중복 SPINATLAS 메뉴 버튼과 「맵」 버튼 제거**. 키보드/스크린리더 대안은 상시 시각 면적0의 포커스 시 드러나는 버튼으로 제공한다. 브랜드 필요하면 열린 메뉴 안에 표시하며 지도에 알약 하나 더 남기지 않는다. 'Trail 메뉴' aria 계약을 접근 가능한 대안에 유지하거나 entry-contract와 ride-entry를 함께 갱신. 서브경로 modal entry도 동작 유지.
3. **계기판 상단 복귀**. 브랜드 삭제한 자리, 상단 safe area+4px 정도에 붙인다. 두 번째 행으로 내리지 않는다. 800×360 실제 주행지표(새 도로 포함)와 QuickCamera1~6·스타일±·계정이 겹치지 않아야 한다. 지표 내용 폭·패딩 재설계(거리 약124,시간54,평균64,속도64,새도로72px 근사). 폰트 무작정 축소 금지: 일반 지표16~18px/거리18~20px, 라벨10~11px, 단위9~10px 범위에서 균형. 카메라 등 덜 중요한 조작은 오른쪽 가장자리에 한 덩어리로 필요 최소 행 배치(중앙 침범 금지), 667도 중첩 금지. 기존 수치/새도로 의미 유지.
4. **좌하단 주소·주행 도크 압축**. 기존 실제 약275×153→목표220×100 이하(대표 출발+도착+제어). 캐럿44px 넓은 빈 열 제거: 약16~20px, 주소행26~28px(삭제22~26px), 상단센서/주행28~30px, 패딩2~4px. 내용 폭에 맞게 주소·제어 공통 너비 정렬, 오른쪽 빈 면 제거. 센서도28~30px. 시작 전 비활성 일시정지/종료는 정책상 이미 숨김 가능하면 숨겨 불필요한 폭 제거하되 주행중 종료/일시정지·재개 기능 유지. 세로길이를 줄이라는 Chief 명시 요청을 이 상시 컨트롤에 적용(이전 일반44 규칙 예외), 투명44 확장끼리 겹쳐놓는 편법 금지. RouteDock 상단이 화면중앙에 올라오지 않도록 하단 가까이 앵커(저작권/미니맵은 유지).
5. 자체 검증: selector19, tsc, 관련 정적 contracts. UI fixture/e2e를 새 디자인에 맞게 갱신 가능(기존 무조건44px·최소18px 단언 대신 지도 가림/상단위치/도크<=220×100/중복트리거0/에지 실제20px 안쪽드래그/탭안열림/중앙pan을 검증). 기존 실패를 숨기지 말고 새 Chief 기준을 명시한다. 긴주소/큰수치도 확인.
