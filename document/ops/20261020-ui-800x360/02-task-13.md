# 계기판 글리프 외곽선

| 항목 | 내용 |
|---|---|
| 문서 유형 | execution |
| 작성 | 2026-10-22 |
| 상태 | 구현 후 로컬 검수 |

Chief 요청: 공유한 지도 계기판 이미지처럼 박스 전체를 검정/흰색으로 채우지 않고 글자 모양에만 외곽선을 적용한다. 앞선 반투명 배경 마스크는 제거한다.

범위: MapHud.css의 계기판 배경·색·글자 외곽선. 하늘색 운동 지표, 연파랑 거리, 초록 새 도로. 기존 가로 배치와 크기 계약 유지. paint-order로 stroke 뒤 fill을 그려 글자 속을 보존한다.

완료 조건: 배경 투명·가상 배경 없음, 800×360 캡처 직접 확인, 기존 3폭 준비/주행/일시정지 겹침·잘림 시험. 배포는 이번 작업에 포함하지 않는다.
