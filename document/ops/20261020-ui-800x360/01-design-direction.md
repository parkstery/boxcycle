# 800×360 UI 진단과 개선 방향

2026-10-20 Codex Supervisor. 실컴포넌트 fixture와 localhost 화면·코드에 근거한 작업용 디자인 판단. 운영 데이터/실기기 검증과 구분한다.

## 전체 방향

Spinatlas의 주인공은 지도가 아니라 **내가 달려 남긴 도로**다. 지도는 계속 보이되 준비 단계는 다음 행동, 주행 중은 수치, 종료 후는 새 도로와 누적 성과가 먼저 읽혀야 한다. 모든 조작을 한꺼번에 노출하기보다 맥락에 따른 기본 표면과 필요할 때 여는 패널로 분리한다. 접는 기능 자체가 디자인의 목적은 아니다.

기준은 가로800×세로360 CSS px. 흰 표면·짙은 정보·파란 주요 행동·작은 중립 테두리의 역할 토큰을 통일한다. 버튼처럼 보이는 제목칩과 과도한 캡슐을 줄인다. 일반 본문12~13px, 보조11px, 주요 수치18~22px, 일반 타깃44px 이상. 승인된 목록행32px/체중강도 입력22px 예외는 별도로 유지한다. 실제 렌더 크기와 이웃 충돌을 측정하며 CSS zoom으로 축소하지 않는다.

## 가장자리 인터페이스

왼쪽→중심은 기존 메뉴/Trail·경로. 오른쪽→중심은 기존 지도 설정을 우선한다. 네 방향 모두를 채우지 않는다. 저장/입력/결과 모달은 제스처닫기보다 명시적 확인 경로를 유지한다. 미니맵의 이미 승인된24px캐럿은 이번 범위에서 유지한다.

최외곽 OS 뒤로가기 영역을 피한 안쪽의 표시된 핸들에서만 drag를 소유한다. 중앙 map pan/pinch/rotate에 투명전면레이어를 씌우지 않는다. 방향·거리·속도·취소·멀티포인터·화면회전복구, 열린패널그립의 반대방향닫기, 내부스크롤, reduced-motion, 키보드/탭 대안을 실제 회귀로 검증한다. 에뮬레이션 결과를 Galaxy 실기기 체감검증이라고 보고하지 않는다.

1. 기존수정 릴리스 완료 후 새 UI재개.

3. selector19·타입·lint·build·관련시험,800×360 준비/주행/일시정지/설정/센서/목록/결과/긴값/오류.
4. 667×300·844×390, 포커스·타깃·겹침·잘림·중앙지도조작 보존.
5. 로컬검수와 운영배포/실센서/실기기 확인을 별도 보고. 새 UI배포는 이번 이전수정릴리스와 섞지 않는다.
