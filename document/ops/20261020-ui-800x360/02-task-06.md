## 최소 재작업

비노출 에지는 DOM을 덮는 pointer-events 레이어 대신 document capture 단계에서 시작좌표(clientX<=20 또는 innerWidth-clientX<=20)를 판별하는 방식으로 변경한다. interactive element(button/a/input/textarea/select/[role=button]/Mapboxcontrol/RouteDock 등)에서 시작하면 무조건 양보. 활성 view·모달 조건은 App에서 기존대로. 제스처중 pointercapture를 지도 canvas 또는 시작 element에 걸고 document pointermove/up/cancel capture에서 처리. 정당한 에지 drag만 지도 pan/click을 막고, 중앙은 전혀 방해하지 않는다. 일반탭은 패널을 열지 않는다. pointercancel/resize/두 번째 터치때 초기화, 리스너정리 정확히. 반환 DOM은 제스처 띠가 어디인지 시험조회할 수 있는 pointer-events:none·aria-hidden 표식 정도만 허용. CSS touch-action은 Mapbox canvas에 이미 있으므로 전면 touch-action:none 레이어 금지. 헤더닫기 유지.

키보드/스크린리더 대안은 기존 focus-visible 버튼 유지. 현재 여백·도크 압축·계기 상단 유지. 좁은667 주행중 camera metrics겹침은 지시05의 남은 실패도 함께 해결: 상단계기는 움직이지 않고 오른쪽 edge의 컨트롤그룹만 좁은폭에서 2행배치 가능. 컨테이너union bbox 대신 실제 그룹/버튼 별 중첩을 측정해야 한다.
