Chief: UI 작업 전의 자잘한 수정들을 먼저 커밋·푸시·병합·배포. 그 다음 UI 작업 지속. 적합한 패널은 스마트폰의 상하좌우 가장자리에서 화면 중심 방향으로 드래그하면 메뉴·버튼이 등장하는 인터페이스를 구현한다.

Cursor 지시02 실행 `04f135d5-40b0-4468-96e3-0332452300ab`는 우선 릴리스를 위해 Ctrl+C로 종료(exit1). 현재 dirty 전체를 배포하지 않는다. UI 직전 src baseline과 기존 검사4파일·미니맵 묶음·브랜드 안내를 분리 체크아웃에서 검증한다. main2가 개발 통합선이고 main은 최종 안정선이라 이번 병합도 main2에만 한다.

이후 UI 지시03: 기존 지시02와 감리01을 이어 진행하며 가장자리 제스처를 추가한다. 좌측→중심은 경로/Trail 메뉴, 우측→중심은 내 정보/지도 설정 중 현재 가장 적합한 표면, 아래→위는 주행 제어·센서 상세 등 맥락별 패널. 네 방향을 반드시 모두 채우지 않는다. 지도 중심부 드래그·핀치·회전은 지도 소유. 가장자리의 표시된 좁은 손잡이에서 시작한 제스처만 소유하고, OS 뒤로가기용 최외곽과 충돌하지 않게 안전영역 안쪽에 둔다. 방향·거리·속도 임계값, 반대방향 닫기, pointercancel/회전 복구, 내부 스크롤과 충돌 방지, 단순 탭·키보드 대안, reduced-motion를 검증한다. 타이핑/저장확인 같은 모달은 자동 제스처 닫기로 내용을 잃지 않도록 기존 확인 경로를 사용한다.

기준 800×360. 기존 접기·펼치기 캐럿 형태를 디자인 요구로 고정하지 않으며 기능과 접근성 계약을 보존하면서 적합한 패널 방식으로 바꿀 수 있다. 운영 데이터·도메인·동기화·인정 규칙은 수정하지 않는다.
