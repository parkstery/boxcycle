## 2. 확정된 사실 (다시 조사하지 마라)

- **폐합 성공률 실측: 논현동 10% · 서울 0% · 수도권 20곳 5%.** 실 Mapbox 호출로 측정
- 실패 원인은 자기중복이 아니라 **고정 5방위 표본 + ±20% 거리 오차 허용치**
- **한강을 가로지르던 직선 경로는 제품 결함이 아니었다** — 지시02·03 캡처 스크립트가
  지어낸 synthetic geometry 였다. 실 함수는 같은 좌표에서 96점·3,535m 정상 경로를 반환한다
- 하네스 가짜 Mapbox는 프로덕션에서 켜질 수 없다(3조건 AND, fail-closed)
- Mapbox 토큰 누락 시엔 throw 한다 — 가짜로 낙하하는 경로는 없다

## 4. 이 묶음에서 실제로 데인 것 (반복 금지)

1. **인터셉트 캡처로 두 라운드가 실증 없이 통과했다.** 경로 기하가 보이는 캡처는
   **반드시 실 백엔드 호출**로 찍어라. synthetic 측정은 감리가 인정하지 않는다
2. **synthetic 측정이 성공률을 75%로 보이게 했다. 실측은 5%였다.** 숫자를 낼 때는
   측정 경로를 먼저 밝혀라
3. **축퇴값 주의** — 항상 같은 값이 나오는 판정은 게이트가 아니라 자동 통과 장치다.
   계측기 자체가 동작함을 같은 표에서 증명하라(지시01의 권한 계수 0/1/0 이 좋은 예)
4. **`PROGRESS.md` 는 UTF-8 로 써라.** CP949 로 덧붙여 두 번 깨졌다
5. 임시 계측 코드는 **`import.meta.env.DEV` 가드 안**에 넣어라. 프로덕션 번들에
   `navigator.geolocation` 몽키패치가 들어갈 뻔했다
