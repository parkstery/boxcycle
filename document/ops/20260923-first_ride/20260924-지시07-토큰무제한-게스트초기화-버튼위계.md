# A. Route Token 무제한 (Chief 결정 2026-09-24)

> 「route token 의 적정 부여 및 소모에 대해 고민이 필요하다.
>  현재 시점에서는 **모두 무제한**으로 설정하라.」(Chief)

## §A1 서버 — 새 코드를 쓰지 마라

`spendRouteGenerateToken`(`functions/src/routeTokenCore.ts:218`)은 **`cost === 0` 이면 차감을
건너뛰는 분기를 이미 갖고 있다.** 할 일은 값 하나다.

- `document/config-routeTokenEconomy.seed.json` 의 `generateCostBase` : `1` → **`0`**
- **운영 `config/routeTokenEconomy` 문서 쓰기는 Chief 실행 영역**이다. 직접 쓰지 마라.
  네가 할 일은 **Chief 가 그대로 따라 할 수 있는 절차**(Console 경로 또는 명령, 되돌리는 법)를
  보고서에 한 블록으로 정리하는 것까지다
- 토큰 시스템 코드를 **삭제하지 마라** — 원장·적립·온보딩 지급은 그대로 둔다
- `costOverride` 를 호출부에서 0 으로 박는 식의 **우회로 금지**. 진실은 config 한 곳이다

## §A2 클라이언트 — 문구를 내린다

무제한인데 잔액·부족 문구가 남아 있으면 거짓말이 된다.

- 지점 팝업 제목 행의 **「경로 생성 잔여 토큰 N개」**(09-16 신설)에서 토큰 부분 제거
- 토큰 부족 경고·차단 문구·잔액 표시 전반
- **조건은 config 파생이어야 한다**(생성 비용 0 ⇒ 표시 안 함). `if (false)` 로 박지 마라 —
  복원할 때 되살릴 곳을 못 찾는다
- 계정 시트의 「보유 토큰」을 어떻게 할지는 네 판단. **무엇을 왜 내렸는지 적어라**

# B. 게스트 초기화 — 테스트마다 계정이 쌓이지 않게

## §B1 배경

오늘 하루 동안 Chief 가 **익명 계정 371개 · Firestore 문서 5,435건**을 수동으로 지웠다.
접속할 때마다 새 익명 계정이 생기고, 브라우저의 IndexedDB 세션은 새로고침으로 지워지지 않는다.

**익명 사용자는 `user.delete()` 로 자기 계정을 스스로 지울 수 있다.** 이걸 쓰면 초기화할 때마다
서버 계정이 남지 않는다 — 누적 문제가 사라진다.

## §B2 구현

- 자리: **계정 시트**(사용자 정보) 안. 「게스트 초기화」
- **익명(Guest)일 때만 노출한다.** 구글 등 provider 계정에는 **절대 노출하지 마라** —
  실계정 삭제는 사고다. 판정은 `user.isAnonymous`
- 동작 순서:
  1. **확인 다이얼로그** — 「이 게스트의 기록이 사라집니다」. 기본값은 취소
  2. `user.delete()` (익명 계정 삭제)
  3. 로컬 정리 — `rtw.localFirst.region`, `boxcycle_web_saved_routes_v1` 등 이 앱이 쓴 키와
     Firebase Auth IndexedDB
  4. `location.reload()` → 새 게스트로 시작
- **주행 중에는 막아라**(`riding`·`paused`). 진행 중 기록이 날아간다
- `user.delete()` 가 실패하면(토큰 만료 등) 그 사실을 사용자에게 알리고 **로컬만 정리**한 뒤
  리로드한다. 조용히 실패하지 마라

# C. 카드 버튼 위계 — 주 행동이 작고 보조가 크다

## §C1 문제

경로가 생성되면 주 행동은 **주행 시작(`Go`)** 인데, 그건 RouteDock 안 작은 버튼이고
카드의 **큰 주황 버튼은 `[다른 경로]`** 다. 「이제 뭘 눌러야 달리지?」가 한눈에 안 온다.

## §C2 방향

- **경로 생성 성공 후**에는 카드에서 주황(주 강조)을 **빼라**. `[다른 경로]`·`[다시 고르기]` 는
  보조 스타일(테두리)로 낮춘다 → 화면에서 유일한 주황이 `Go` 가 된다
- 경로 생성 **전**(거리 고르는 단계)에는 종전대로 `Ready Ride 시작` 이 주황이다
- **`Go` 자체를 옮기거나 키우지 마라** — RouteDock 계약을 건드리면 회귀 위험이 크다.
  이번엔 **카드 쪽 강조를 내리는 것만** 한다
