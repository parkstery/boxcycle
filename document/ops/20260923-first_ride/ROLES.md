# 역할 분담 — 커서 → 클로드 코드 내부 체계 (2026-09-24 전환)

> **왜 바꿨나.** 커서(별도 앱)를 개발팀장으로 두니 **일을 하고 있는지 확인되지 않았다.**
> 실제로 지시02 착수 선언 후 30분 가까이 아무 흔적이 없었고(로그·코드·캡처·프로세스 전부 0),
> 파일 신호로는 그 프로세스를 깨울 방법이 없었다. 관측 불가 + 기동 불가가 겹치면 지휘가 성립하지 않는다.
> → 「작업 진행이 매끄럽지 못하다 … 커서를 쓰지 말고 클로드 코드의 하위 모델과 역할을 분담하라」(Chief)

---

## 1. 누가 무엇을 하는가

| 역할 | 주체 | 하는 일 | **하지 않는 일** |
|---|---|---|---|
| **감리 (Supervisor)** | 메인 세션 (Opus) | 요구 기준 확정 · 지시서 작성 · **판정(PASS/재작업)** · 커밋 승인 · Chief 보고 · 결정 로그·Ontology·상태보드 갱신 | **제품 코드를 직접 쓰지 않는다** |
| **개발팀장 (구현)** | `impl-standard` 서브에이전트 (Sonnet) | 라운드 하나를 구현 · 스스로 검증(tsc·build·eslint) · 캡처·수치 산출 · 수행결과 문서 작성 | 설계 재결정 · 범위 확장 · **커밋·푸시** |
| **단순 작업** | `impl-simple` 서브에이전트 (Haiku) | 문자열 일괄 치환 · 파일 이동 · 보일러플레이트 · 기계적 패턴 적용 | 판단이 필요한 일 전부 |
| **조사** | `Explore` 서브에이전트 | 넓은 탐색(어디에 무엇이 있나) | 수정 |

### 감리와 구현을 왜 갈라 두는가

한쪽이 발주와 검수를 겸하면 **자기가 의도한 대로 읽어서 오해가 그대로 통과한다.**
그래서 구현은 **컨텍스트를 물려받지 않은 새 에이전트**에게 보낸다 — `fork`(내 대화를 상속)를 쓰지 않는다.
구현자가 지시서만 보고 만들 수 있어야 그 지시서가 옳은 것이고, 감리는 **캡처·수치·diff 로만** 판정한다.

## 2. 한 라운드가 도는 방식

```
감리: 지시NN 파일 작성  (document/ops/20260923-first_ride/)
   ↓  Agent 발주 (impl-standard, 지시서 경로를 넘긴다)
구현: 지시서 정독 → 구현 → 검증 → 캡처 → PROGRESS.md 한 줄씩 → 지시NN수행결과-*.md
   ↓  완료 알림이 감리에게 자동으로 온다
감리: git diff → 캡처 육안 → 수치 검산 → PASS / 재작업
   ↓
   PASS → 다음 지시 발주 · 재작업 → 같은 번호로 재발주(수행결과02)
```

**커서 때와 달라진 것:** 착수·완료가 **알림으로 확정**된다. 조용히 멈추는 구간이 없다.
멈추면 완료 알림이 오지 않으므로 그 자체가 신호다.

## 3. Chief 가 보는 것 (그대로 유지)

```bash
node scripts/ops-relay/watch-status.mjs document/ops/20260923-first_ride
```

라운드 · 진행 로그 · `git diff --stat` · 신규 파일 · 캡처가 한 화면에 뜬다.
구현 에이전트가 `PROGRESS.md` 에 10분에 한 줄씩 남기므로 **작업 중에도 안이 보인다.**

## 4. 릴레이 폴더 규약은 그대로다

지시서·수행결과 파일명, 캡처 목록, 커밋 금지, 검증 예산(5분·3-strike) — 전부 유지한다.
**바뀐 것은 「누가 지시서를 읽고 실행하는가」 하나뿐이다.**

폐지: `await-next.mjs` 로 개발팀장이 블록 대기하던 수신 방식(커서 전용).
감리가 Agent 를 직접 발주하므로 수신 대기가 필요 없다.
`poll-next.mjs`(감리용 1회 조회) · `check-amend.mjs`(라운드 중 정정) · `watch-status.mjs`(Chief 상황판)는 유지.

## 5. 발주할 때 지켜야 할 것 (감리용 체크리스트)

- **새 에이전트로 발주한다** — `fork` 금지(컨텍스트 상속 시 오해가 통과한다)
- 프롬프트에 **지시서 경로**를 주고 "전문을 읽어라"고 명시한다. 요약해서 넘기지 않는다
- **정정 블록이 있으면 그 사실을 프롬프트에 따로 적는다** — 본문만 주면 놓친다
- 커밋 금지 · 범위 고정 · 3-strike · 잔여 프로세스 0 을 매번 넣는다
- `PROGRESS.md` UTF-8 로 10분에 한 줄을 매번 넣는다
- 난이도가 구조적 판단에 걸치면 `impl-standard` 대신 **감리가 설계를 더 못 박거나** 상위 모델로 올린다
