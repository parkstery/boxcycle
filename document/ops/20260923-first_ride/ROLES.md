## 1. 누가 무엇을 하는가 (현재)

| 역할 | 주체 | 하는 일 | **하지 않는 일** |
|---|---|---|---|
| **감리 (Supervisor)** | 감리 세션 | 요구 기준 확정 · 지시서 작성 · **판정(PASS/재작업)** · 커밋 승인 · Chief 보고 | 제품 코드를 직접 쓰지 않는다 |
| **개발팀장 (구현)** | **커서 세션** | `await-next` 로 지시 수신 → 즉시 구현·검증·캡처·수행결과 | 설계 재결정 · 범위 확장 · **커밋·푸시** |

### 자동 착수

```bash
node scripts/ops-relay/await-next.mjs document/ops/20260923-first_ride --timeout 14400 --interval 20
```

세션이 이 프로세스를 `notify_on_output` (`^NEXT `) 로 감시한다. `NEXT` 가 찍히면 Chief「계속」없이 착수한다.
다른 팀장이 미완 지시를 마무리 중이면 `--ignore-open-at-start`.

규칙·스킬: `.cursor/rules/ops-relay-auto.mdc` · `.cursor/skills/ops-relay-auto/SKILL.md`

## 1b. (기록) 2026-09-24 오전 — 클로드 코드 내부 체계로 잠깐 전환했던 이유

> 커서(별도 앱)를 개발팀장으로 두니 **일을 하고 있는지 확인되지 않았다.**
> 실제로 지시02 착수 선언 후 30분 가까이 아무 흔적이 없었고(로그·코드·캡처·프로세스 전부 0),
> 파일 신호로는 그 프로세스를 깨울 방법이 없었다.
> → 당시: 감리=메인 Opus, 구현=`impl-standard` 서브에이전트 발주. `await-next` 폐지.

지금은 커서 + `await-next` notify 로 **수신 즉시 착수**가 다시 기본이다.

### 감리와 구현을 왜 갈라 두는가

한쪽이 발주와 검수를 겸하면 **자기가 의도한 대로 읽어서 오해가 그대로 통과한다.**
감리는 **캡처·수치·diff 로만** 판정한다.

## 2. 한 라운드가 도는 방식

```
감리: 지시NN 파일 작성  (document/ops/20260923-first_ride/)
   ↓  await-next 가 NEXT 출력 → 커서 세션 자동 착수
구현: 지시서 정독 → 구현 → 검증 → 캡처 → PROGRESS.md 한 줄씩 → 지시NN수행결과-*.md
   ↓
감리: git diff → 캡처 육안 → 수치 검산 → PASS / 재작업
   ↓
   PASS → 다음 지시 발주 · 재작업 → 같은 번호로 재발주(수행결과02)
```

## 2b. 감리는 착수와 판정을 **눈에 보이게** 남긴다 (2026-09-24 Chief)

커서는 채팅이 아니라 **파일로 보고**한다. 그래서 Chief 는 보고가 올라온 사실도, 감리가 도는지도 모른다.
상태 변화가 화면에 없으면 **사람이 확인하러 오게 된다.** 그 몫은 감리가 메운다.

| 시점 | 남기는 곳 |
|---|---|
| 수행결과 감지 즉시 | 터미널 한 줄 + `PROGRESS.md` 에 `HH:MM \| [감리] 지시NN 감리 착수 — diff·캡처·수치 확인 중` |
| 감리가 길어질 때 | 중간 한 줄(「캡처 확인 중」) |
| 판정 | 터미널 + `PROGRESS.md` 에 `HH:MM \| [감리] 지시NN PASS — 근거 · 커밋 <해시>` 또는 `재작업 — 사유` |

Chief 상황판(`watch-status.mjs`)이 `PROGRESS.md` 를 읽으므로, 이 한 줄이 곧 신호다.

## 3. Chief 가 보는 것 (그대로 유지)

```bash
node scripts/ops-relay/watch-status.mjs document/ops/20260923-first_ride
```

라운드 · 진행 로그 · `git diff --stat` · 신규 파일 · 캡처가 한 화면에 뜬다.
구현이 `PROGRESS.md` 에 10분에 한 줄씩 남기므로 **작업 중에도 안이 보인다.**

## 4. 릴레이 폴더 규약

지시서·수행결과 파일명, 캡처 목록, 커밋 금지, 검증 예산(5분·3-strike) — 전부 유지한다.
`poll-next.mjs`(감리용 1회 조회) · `check-amend.mjs`(라운드 중 정정) · `watch-status.mjs`(Chief 상황판)는 유지.
