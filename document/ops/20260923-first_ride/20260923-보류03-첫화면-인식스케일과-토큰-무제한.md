## §1 이 라운드의 한 줄

> 지시01 이 만든 첫 화면이 **아직 「내가 아는 곳」으로 열리지 않는다.** 그것을 고치고,
> 같은 화면에서 **토큰 문구를 내린다.**

## §2 A — 첫 화면을 인식 가능한 스케일로 연다

### 2.1 문제

지시01 캡처 `02-S0-740x300.png` 에서 첫 화면은 **스케일바 10m, 이름 없는 골목**이다.
「여기 내가 아는 곳인데」를 목표로 한 화면의 첫인상이 그것이면 앞뒤가 맞지 않는다.

> 「자기가 아는 곳을 인식할 수 있는 스케일로 한다.」(Chief, 09-24)

### 2.2 요구

- **S0(지역 미정) 상태의 초기 카메라**가 시·구·동 라벨이 읽히는 스케일로 열린다
- 판정 기준은 줌 숫자가 아니라 **폰 가로(740×300)에서 라벨이 읽히는가** 다.
  지시01 이 지역 확정 후 **13** 을 같은 기준으로 채택했다 — 같은 계열로 맞춰라
- **위치(중심 좌표)는 이번에 바꾸지 마라.** 스케일만 문제다. 중심을 임의의 도시로 옮기는 것은
  별개 결정이며, 잘못 건드리면 「마지막에 보던 곳」을 잃는다

### 2.3 먼저 조사하고 보고할 것 (구현 전)

| 질문 | 왜 |
|---|---|
| 첫 화면 초기 center·zoom 이 **어디서** 오는가 | 상수인지, 마지막 뷰 복원인지, Mapbox 기본값인지에 따라 고칠 자리가 다르다 |
| 마지막 카메라 위치를 저장·복원하는 경로가 있는가 | 있으면 그것을 존중해야 한다 — 줌만 하한을 두는 방식이 맞다 |
| `localFirstRegion` 이 있는 사용자는 어디로 열리는가 | 지시01 이 이미 S1 복원을 구현했다. **그 경로는 건드리지 마라** |

### 2.4 경합 금지 (이 리포에서 카메라는 여러 주인이 있다)

- `NextRideCard` 앵커 점프(zoom 14) · 재개 프리뷰
- 주행 카메라(`topDown`, `RIDE_START_ZOOM` 17.5) · Quick Camera 1~6
- 지시01 의 지역 확정 점프(1회 가드)

**첫 화면 한 번의 초기값 문제**이지 카메라 시스템 변경이 아니다. 위 넷 중 하나라도 동작이 달라지면
그건 이번 라운드의 실패다. 각각 캡처로 무변경을 보여라.

## §3 B — Route Token 무제한

> 「route token 의 적정 부여 및 소모에 대해 고민이 필요하다. 현재 시점에서는 **모두 무제한**으로
>  설정하라.」(Chief, 09-24)

### 3.1 서버 — 새 코드를 쓰지 마라

`spendRouteGenerateToken`(`functions/src/routeTokenCore.ts:218`)은 **`cost === 0` 이면 차감을
건너뛰는 분기를 이미 갖고 있다.** 따라서 할 일은 값 하나다.

- `document/config-routeTokenEconomy.seed.json` 의 `generateCostBase` : `1` → **`0`**
- **운영 `config/routeTokenEconomy` 문서 쓰기는 Chief 실행 영역**이다(샌드박스가 배포를 막는다).
  네가 할 일은 **명령·경로·되돌리는 법을 보고서에 한 블록으로 정리**하는 것까지다. 직접 쓰지 마라
- 토큰 시스템 코드를 **삭제하지 마라** — 원장·적립·온보딩 지급은 그대로 둔다. 한 값으로 껐다 켠다
- `costOverride` 를 호출부에서 0 으로 박는 식의 **우회로 금지**. 무제한의 진실은 config 한 곳이다

### 3.2 클라이언트 — 문구를 내린다

무제한인데 잔액·부족 문구가 남아 있으면 거짓말이 된다.

- 지점 팝업 제목 행의 **「경로 생성 잔여 토큰 N개」**(09-16 신설) — 무제한일 때 토큰 부분을 뺀다
- 토큰 부족 경고·차단 문구·잔액 표시 전반
- **조건은 config 파생이어야 한다**(비용 0 ⇒ 표시 안 함). `if (true)` 로 박지 마라 —
  복원할 때 되살릴 곳을 못 찾는다
- 계정 시트 등 「보유 토큰」 표시를 어떻게 할지는 네 판단으로 하되, **무엇을 왜 내렸는지 적어라**

### 3.3 하지 않을 것

tier **quota**(생성·저장 **수량** 한도)는 별개 축이며 이번 결정 범위가 **아니다.** 건드리지 마라.
