## §2 고칠 것 — 제목 오버플로

`01/02/04` 캡처 모두에서 **제목 텍스트가 카드 패널의 오른쪽 경계를 넘어 지도 위로 나간다.**

```
┌──────────────┐
│논현동 · 여기서 첫 Ready Ride (km)   ← 패널 밖으로 넘침
│ [2][3][5][10]│
│ [시작][지역] │
└──────────────┘
  입문 경로        ← 이것도 패널 아래 경계 밖처럼 보인다
```

카드 폭을 292 → 168px 로 줄이면서 제목이 넘쳤다. **지도 위에 글자가 겹쳐 읽기도 나쁘다.**

### 요구

1. **모든 내용이 패널 안에 들어온다.** 제목·링크가 경계를 넘지 않는다
2. 제목은 **줄바꿈하거나 줄여라**. 예: 지명만 크게 + 나머지는 작게, 또는 두 줄
   - 「Ready Ride」는 Ontology 등재 명칭이라 **지우지 마라**
   - `(km)` 는 D1 의 핵심이라 **유지**한다
3. **카드 폭을 다시 키우는 것으로 해결하지 마라** — 9.5% 면적을 되돌리면 이 라운드가 무의미하다
4. 「입문 경로」 링크도 패널 안에 들어오게 하라
