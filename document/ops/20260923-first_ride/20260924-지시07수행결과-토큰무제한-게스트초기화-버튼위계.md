## A. Route Token 무제한

### 서버(값만)

| 파일 | 변경 |
|---|---|
| `document/config-routeTokenEconomy.seed.json` | `generateCostBase`: **1 → 0** |
| `functions/src/routeTokenCore.ts` `DEFAULT_ROUTE_TOKEN_ECONOMY` | **0**(문서 없을 때 폴백) |

`spendRouteGenerateToken` 의 `cost===0` 분기는 **그대로**. 우회로·코드 삭제 없음.

### Chief 운영 반영 절차(직접 쓰지 않음)

1. Firebase Console → 프로젝트 `boxcycle-dc2df` → Firestore  
   문서 `config/routeTokenEconomy` → 필드 `generateCostBase` 를 **0** 으로 저장  
2. 되돌리기: 같은 필드를 **1** 로  
3. 시드 원본: `document/config-routeTokenEconomy.seed.json`  
4. 배포·CLI 쓰기 불필요(문서 필드 한 줄). 클라이언트는 이 문서를 구독한다.

### 클라이언트

- `routeTokenEconomyClient.ts` — Firestore 구독 + `isRouteTokenGenerateMetered(cost)`  
- `cost===0` ⇒ 잔액 부족 차단·「잔여 토큰 N개」 미표시(제목「경로 생성」만)  
- DEV `window.__rtwForceGenerateCostBase` 로 A2 복원 증명  
- **계정 시트 「보유 토큰」**: 원래 UI에 없음 → 추가 숨김 없음(팝업·부족 문구만 내림)
