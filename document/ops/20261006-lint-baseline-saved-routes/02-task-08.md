# 지시 08 — `useSavedRoutesWorkspace` set-state-in-effect 오류 제거

- 담당: Developer(Cursor CLI) · 보고: `03-result-08.md` · 커밋 **금지**
- 병행: 지시 06이 `MapHud.*`·`App.tsx` 를 고치는 중 — **허용 파일 밖 수정 금지**, 되돌리기·stash 금지.

## 대상
`apps/web/src/hooks/useSavedRoutesWorkspace.ts` ~181:
```ts
useEffect(() => {
  if (user) return;
  setSavedRoutes([]);
}, [user]);
```
eslint `react-hooks/set-state-in-effect` **error**. 로그아웃(`user` → null) 시 내 경로 목록을 비우는 동작.

## 요구
- 같은 동작을 effect 없이 구현한다. 이 코드베이스의 관례 = **「이전 값 비교」 렌더 중 갱신**(예: `SavedRoutesPanel` 의 `prevFocusPendingSignal`, `RideRoutePanel` 의 `prevOpenSavedTabSignal`). `savedRoutes` 는 이 훅의 지역 state 라 렌더 중 갱신이 허용된다.
- 의미 보존: `user` 가 없어지는 순간 목록을 비운다. 초기 렌더에서 `user` 가 null 이면 이미 `[]` 이므로 동일. 위 effect 를 지우되, 다른 effect(로드·백필)의 `cancelled` 처리와 경합하지 않는지 확인해 결과에 적는다.
- 주석 한 줄로 이유.
