# 계기판 스타일 확장 시안

2026-10-30 Chief: 「우리 페이지 가운데 이런 디자인이 적용될만한 게 더 있을 거야 시안을 쭉 뽑아 봐.」

범위: 승인된 체험 속도 시안의 색·숫자 위계·아이콘·버튼을 기존8화면에 확장한 이미지4장. 제품 구현·디자인 고정 변경·커밋·배포 없음. Codex 직접 조사·제작·눈검수.

| 시트 | 기존 화면 | 스타일 적용 지점 / 보존할 계약 |
|---|---|---|
| A | 01 인터벌 운동 / 02 케이던스 센서 | 총시간·준비/고저/마무리 단계 / 큰 실제 rpm·연결 상태. 인터벌 직접 조절 접힘·프리셋·사용 스위치·간편 인터벌+설정 적용 보존. |
| B | 03 사용자 정보 / 04 주행 결과 | 기간 거리·시간·평균 / 새 도로와 오늘 성과 숫자. 계정520×250·왼쪽164, 마지막주행 인라인, 결과444×194·주소 저장버튼 윗줄. |
| C | 05 거리·방향 경로 만들기 / 06 내 경로 목록 | 큰 거리 입력·단정한 수단 아이콘 / 선택 상태·정렬. 창228·아이콘 제목·거리방향 모드·수단3개·녹색원형재생 보존. 목록690·26px 한줄·이름12⅓px 유지. |
| D | 07 주행 설정 / 08 프로필 수정 | 기능별 선 아이콘·파란 스위치 / 큰 체중·5단계 체력. 설정276·두열·5기능만, 프로필364·닉네임/체중70kg/체력 약함1~5강함 유지. |

핵심: 모든 곳에 게이지를 추가하지 않는다. 실제 수치/상태/조작만 표현하며 새 기능·새 지표·새 데이터 의미를 만들지 않는다. 지도 위 계기판·코칭·순위 오버레이는 이번 범위 밖이다. 이미지 내 샘플 데이터는 설명용.

제작: built-in image_gen, 승인된 체험 속도 원본 이미지를 스타일 참조. 프롬프트는 prompts.json. 결과는 mockups/.

완료: A~D 4장·8화면 생성/저장, 한국어 제목·핵심 숫자·연결/선택 상태·녹색 원형 시작 버튼·한줄 경로목록 눈검수. `index.html`에서 연속 비교 가능. 우선 추천:01·02·03, 다음04·08,06·07은 조작 외형 위주.

시안 해석: 생성 이미지는 CSS 픽셀 실측 산출물이 아니다. 실제 구현에서는 표의 고정 크기·행밀도를 유지한다. 05의 나침반 모양은 방향을 설명하는 시각적 표현이며 새 방향 조작 기능으로 승인된 것이 아니다. 08의 약함/강함은 선택값이 아닌 양끝 설명글자로 구현한다. 인터벌 막대는 준비/고저 반복/마무리의 실제 시간비로 렌더링한다. 테스트·브라우저 실행 미실행(제품 코드 변경 없는 이미지 시안); 실폰·실데이터 검증 범위 아님.
