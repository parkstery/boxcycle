# 간편 인터벌 주행 — 1단계

상태: 01·01-B 운영 배포 완료. 운영 코드 기준은 `9ff9b78f`, 검증 기록은 [01-B 구현·검증](02b-result-codex.md)이다. 후속 작업은 아래 인계 항목에서 최신 상태를 확인한다.

## 요청

지금은 인터벌 운동을 하려면 경로 설정과 인터벌 설정을 따로 해야 한다. 경로가 짧으면 인터벌을 마치기 전에 주행이 끝난다. 「간편 인터벌 주행」을 누르면 저장된 인터벌 설정에 맞는 길이의 경로를 거리/방향 자동 경로 기능으로 무작위 방향에 만든다. 사용자는 주행 버튼만 누르면 된다.

## Chief 확정(권장안)

| 항목 | 값 |
|---|---|
| 목표 거리 | 인터벌 총 시간 × **25 km/h × 1.3**(여유분). 0.5~120 km 범위로 제한. 기준 속도는 `resolveIntervalBasisKmh()` 한 곳에서 정한다(2026-10-29 Chief 「인터벌은 모두 25km/h」, [계획](00-plan.md)) |
| 출발 지점 | 마지막 유효 주행의 종료 지점. 없으면 「출발 위치를 맵에서 클릭하세요」 안내 후 사용자가 클릭한 지점 |
| 방향 | 무작위. 탐색이 실패하면 다른 방향으로 다시 시도하며 **최대 3회**. 실패한 탐색은 서버가 토큰을 환불한다(확인함) |
| 시작 | **자동 출발 없음.** 경로를 지도에 보여 주고 사용자가 주행 버튼을 한 번 누른다 |

## 1-B 확정 (2026-10-29 Chief)

- 「간편 인터벌 주행은 사용자의 라이딩 목적이 인터벌에 특화된 주행이므로 추가적인 일반 주행을 하지 않는다.(목적지 도착하면 자른다)」
- 「현재 상태의 일반 주행 내 인터벌 시행은 그대로 유지한다.」

| 주행 종류 | 인터벌 완료 시 | 저장 경로 |
|---|---|---|
| 간편 인터벌 주행 | 자동 종료 | 종료 지점에서 잘라 「완주」로 저장(결과 화면 「경로 저장」 버튼) |
| 일반 주행 + 인터벌 | 자유 주행 계속(고정 40, 변경 없음) | 변경 없음 |

Supervisor 기본값(Chief가 바꿀 수 있음): 저장은 버튼으로만 한다. 주행 기록의 계획 거리·진행률은 바꾸지 않는다. 사용자가 중간에 직접 끝내도 끝낸 지점에서 자른다.

## 확인 순서(구현 후)

폰 가로 화면에서 「INT」 → 「간편 인터벌」 → (기록 없으면 출발지 클릭) → 경로 표시 → 주행 버튼. 인터벌이 끝나면 결과 화면에서 「내 경로로 저장」을 선택해 달린 구간을 완주 경로로 남길 수 있다.

## 다른 계정의 Codex에 인계

2026-11-20 재인수 당시 로컬 이정표 코드·자산 확인, 회귀 635개·셀렉터 21개·타입 검사·E2E 4개 통과. 후속 `542d04cb`로 이정표·FINISH 커밋·배포 완료. 실폰·실물 센서 확인은 남아 있다. 범위·재실행 명령·검증 한계는 [이정표 인수 기록](03-milestone-handoff-codex.md)을 본다.

후속 콘솔 오류 제보: FINISH 접근·일시정지·재개·도착 E2E 1개 추가 통과. 제보한 `Maximum update depth`는 재현하지 못했고 원인 스택 확인 대기다. 제품 수정 완료로 판정하지 않는다(같은 인수 기록의 후속 절).

2026-11-20, Codex. 운영 주소는 [Spinatlas](https://boxcycle-dc2df.web.app/)이다. 간편 인터벌 자동 종료와 구간 저장은 구현·배포됐다. 일반 경로에서 인터벌을 완료하면 주행이 계속된다. 앞서 배포한 강도 선택·단계별 추정 열량·수행/체감 기록·기간 통계도 운영에 포함된다.

- **실폰·센서 확인 대기.** 폰을 가로로 두고 위 순서대로 자동 종료·구간 저장을 확인한다. 사용자 정보의 「인터벌 기록」에서 해당 수행과 기간 조회를 확인한다. 실물 케이던스 센서 연결·끊김·재연결 시 페달 확인 시간과 추정 kcal 표시를 살핀다. 실제 소비 열량과의 비교는 수행하지 않았다.
- **지도 이정표 후속 작업은 로컬에 있다.** 최신 로컬 HANDOFF에는 포트 `5199`, 이정표 e2e 1개, 관련 회귀 374개, 타입 검사 통과로 적혀 있다. 이번 문서 작업에서 시험을 다시 실행하지 않았다. 구현은 `App.tsx`, `useRideMilestoneMap.ts`, `rideMilestoneLayer.ts`, `rideMilestones.ts`에서 시작해 확인한다. 관련 시험은 `apps/web/scripts/geo/ride-milestones.test.ts`와 `apps/web/e2e/quick-interval-end-cut.spec.ts`의 이정표 사례다. 시작 3D, 표고, 거리 안내 등 다른 변경이 같은 작업 트리에 있으므로 범위를 확인한다.
- **작업 트리 인계.** 같은 `C:\20.HDev\boxcycle` 폴더를 다른 계정에서 열면 기존 파일 변경을 확인할 수 있다. 새 복제본에서는 미커밋 이정표 코드와 로컬 캡처를 볼 수 없다. 원래 폴더와 다른 경우, 이정표 변경을 찾을 수 있는 위치 또는 별도 커밋을 먼저 확인한다.
