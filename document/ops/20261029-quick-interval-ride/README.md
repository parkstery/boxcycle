## 요청

지금은 인터벌 운동을 하려면 경로 설정과 인터벌 설정을 따로 해야 한다. 경로가 짧으면 인터벌을 마치기 전에 주행이 끝난다. 「간편 인터벌 주행」을 누르면 저장된 인터벌 설정에 맞는 길이의 경로를 거리/방향 자동 경로 기능으로 무작위 방향에 만든다. 사용자는 주행 버튼만 누르면 된다.

## Chief 확정(권장안)

| 항목 | 값 |
|---|---|
| 목표 거리 | 인터벌 총 시간 × **25 km/h × 1.3**(여유분). 0.5~120 km 범위로 제한. 기준 속도는 `resolveIntervalBasisKmh()` 한 곳에서 정한다(2026-10-29 Chief 「인터벌은 모두 25km/h」, [계획](00-plan.md)) |
| 출발 지점 | 마지막 유효 주행의 종료 지점. 없으면 「출발 위치를 맵에서 클릭하세요」 안내 후 사용자가 클릭한 지점 |
| 방향 | 무작위. 탐색이 실패하면 다른 방향으로 다시 시도하며 **최대 3회**. 실패한 탐색은 서버가 토큰을 환불한다(확인함) |
| 시작 | **자동 출발 없음.** 경로를 지도에 보여 주고 사용자가 주행 버튼을 한 번 누른다 |

## 1-B 확정 (2026-10-29 Chief)

- 「간편 인터벌 주행은 사용자의 라이딩 목적이 인터벌에 특화된 주행이므로 추가적인 일반 주행을 하지 않는다.(목적지 도착하면 자른다)」
- 「현재 상태의 일반 주행 내 인터벌 시행은 그대로 유지한다.」

| 주행 종류 | 인터벌 완료 시 | 저장 경로 |
|---|---|---|
| 간편 인터벌 주행 | 자동 종료 | 종료 지점에서 잘라 「완주」로 저장(결과 화면 「경로 저장」 버튼) |
| 일반 주행 + 인터벌 | 자유 주행 계속(고정 40, 변경 없음) | 변경 없음 |

Supervisor 기본값(Chief가 바꿀 수 있음): 저장은 버튼으로만 한다. 주행 기록의 계획 거리·진행률은 바꾸지 않는다. 사용자가 중간에 직접 끝내도 끝낸 지점에서 자른다.
