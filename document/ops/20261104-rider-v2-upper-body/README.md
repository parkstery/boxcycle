## 0. 한 줄 결론

현재 모델은 **디테일이 "보이지 않는 곳"에 22% 몰려 있고(헬멧 15.9% + 손가락 6.3%), 운동이 필요한 상체는 한 덩어리**입니다. 새 모델은 **부품 예산을 재배분**(헬멧·손가락·브레이크 케이블에서 회수 → 얼굴·어깨)하고 **상체만 8관절 스킨**으로 바꾸면, **삼각형 29,604 → 24,000(−19%), 드로우콜 14 → 11, 자산 245 KB → 약 200 KB**로 **비용을 줄이면서** 어깨·팔·골반 운동역학을 얻습니다.

## 2. 현황 진단 (실측)

### 2.1 화면에서 실제로 보이는 크기

| 화면 | 라이더 높이 | 머리(헬멧 포함) | 판독 가능한 최소 디테일 |
|---|---|---|---|
| 720p 캡처(현행, `shot-none.png`) | ≈ 230 px | ≈ 32 px | ≈ 2 px |
| 스마트폰 360p 가로(제품 기준) | ≈ 115 px | ≈ 16 px | ≈ 3~4 px |
| 줌 < 19 (LOD2) | ≈ 20 px | ≈ 3 px | 없음 |

→ **손가락·통풍구·브레이크 패드·케이블은 제품 화면에서 원리적으로 판독 불가**입니다. 여기에 예산이 쓰이고 있습니다.

## 4. 모델 아키텍처 3안

| 안 | 내용 | 드로우콜 | 운동 | 구현 공수 | 판정 |
|---|---|---:|---|---:|---|
| **A. 재질·디테일만** | 현행 병합 유지, 헬멧/손 감축 + 얼굴 추가 | 14 | ✗ | 2~3일 | **탈락**(R3·R4 미해결) |
| **B. 리지드 분절** | 상완·전완·손을 별도 노드로 분리, 어깨·팔꿈치 회전만 | 16~18 | △(이음새·어깨 변형 없음) | 5~6일 | 차선 |
| **C. 상체 8관절 스킨** | 몸통+머리+팔+헬멧+저지를 **1개 스킨 메시**로. 골반·척추·흉곽·목·어깨·팔꿈치 8본 | **11** | ✅ | 7~9일 | **권장** |

**C를 권장하는 이유**
1. **드로우콜이 늘지 않습니다.** 리지드 분절은 팔마다 노드가 늘지만, 스킨은 한 메시 안에서 관절을 만들므로 1콜을 유지합니다. 늘어난 4콜은 다리 메시 병합으로 상쇄합니다.
2. **어깨 접합부가 자연스럽습니다.** 리지드 분절은 어깨·겨드랑이에 계단 이음새가 생깁니다(과거 헬멧 5회 반복 실패와 같은 유형).
3. **이미 있는 IK 수식을 그대로 씁니다.** 리지드 분절이면 본 회전을 메시에 직접 적용해야 해서 예외 처리가 늘어납니다.

**C의 유일한 부담**은 상체 정점 스키닝 비용입니다. 13k tri ≈ 7k 정점 × 8본이므로 표준 GPU 스키닝으로 프레임 비용은 0.05 ms 미만으로 추정합니다(P0에서 실측 확정).

### 5.3 스키닝 구현 방식

- **상체**: glTF 표준 스킨(`skins:1`, `JOINTS_0/WEIGHTS_0`, 본 8개) + three `SkinnedMesh`. 앱이 매 프레임 본 쿼터니언만 갱신. → 커스텀 GLSL 없음, CPU 폴백 불필요.
- **다리**: 기존 DQ 커스텀 스킨 **불변**(`uSkinDQ`, `?skin=cpu|gpu`). 상체 표준 스킨과 프로그램이 분리되지만 머티리얼 인스턴스는 공유.
- **대안(보수적)**: 기존 `onBeforeCompile` 경로에 `uArmBones[8]` + `_ARMW` vec4 LBS 를 추가. 셰이더 실패 시 CPU 폴백을 유지할 수 있으나 코드량이 늘어남.
- **AO**: 팔레트 재질은 UV 디테일이 없으므로(128×16 색 칸), **AO 를 `COLOR_0` 정점색으로 베이크**하고 `material.vertexColors = true`. 자산 +약 28 KB, 런타임 비용 0, 팔레트 키트 색과 곱연산으로 공존.

### 5.4 운동역학 설계 (앱 계산)

```
phaseRev ──► 다리 IK(기존, 불변) ──► 다리·페달·발
     │
     └─► effort(케이던스·속도)
           ├─► 골반 롤        ±1.5°   (좌/우 다리 하강 위상)
           ├─► 척추 카운터롤  ∓1.0°
           ├─► 흉곽 회전      ±0.8°
           ├─► 목·머리        ±0.5° (코너 시 요 5~8° 추가)
           └─► 어깨 위치 변화 → 팔 2-bone IK(후드 고정) → 상완·전완 회전
```

| 값 | 제안 | 근거 |
|---|---|---|
| 골반 롤 | ±1.5° | 실측 로드 사이클링 좌우 록 범위의 하한 |
| 척추 카운터롤 | 골반의 −65% | 흉곽이 머리를 안정시키는 방향 |
| 흉곽 회전 | ±0.8° | 기존 전신 sway(0.5°)를 상체로 이관 |
| 어깨 진폭 | IK 결과(약 1~2°) | 손 고정이므로 자동 유도 |
| 진폭 계수 | 케이던스 60~100 rpm 에서 0.6→1.0 | 저케이던스 고토크에서 크게 흔들림 |
| 목 요 | 코너 lean 의 40%, 최대 8° | 시선이 진행 방향 유지 |

**검증 가능성**: 손 고정 오차·팔꿈치 각·골반 롤을 위상 8점에서 수치로 계약화할 수 있습니다(기존 `rider14-equivalence` 방식).
