## 2. 구현 전 조사(보고에 요약 필수)

수퍼바이저 사전 단서(재확인·보완할 것):

| 주제 | 힌트 경로 |
|---|---|
| Authoritative 맵 위치 | `App.tsx` → `liveForMap`(경로 폴리라인 위 점; `rideMetrics.liveLngLat` 직접 사용 주의 주석) → `MapView` `liveLngLat` |
| 3D 라이더 | `glbModelLayer.ts` `ensureRiderGlbLayer` / `syncRiderGlbModels` · `MapView.tsx` |

| Giant | `riderPrototype/config.ts` `RIDER_GIANT_SCALE_FACTOR`(현재 1) — **이번 해결책으로 쓰지 말 것** |
| Zoom | model-scale은 지리적 m — 소축척에서 작아 보임 → **별도 screen-space Marker**가 적합 |

개발팀장은 위표를 검증한 뒤 「가장 작은 변경」안을 택한다.

## 3. 권장 구현 방향(강제 디자인 아님)

- `mapboxgl.Marker`(DOM, CSS px)로 **나 전용** self-location marker — zoom과 무관하게 화면 크기 유지에 유리.
- Halo/pulse·외곽선·선택적 방향(bearing이 이미 있으면) — 기존 HUD/토큰 색과 조화.
- live nametag와 **별 요소**. nametag 대체 금지. peer marker와 class/색 구분.
- 위치는 `liveForMap`과 **동일 좌표**로 `setLngLat` — 위치 파이프라인 복제 금지.
- Conquest paint·route·저장·resume·peer sync **변경 금지**.
