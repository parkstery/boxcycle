계획 §6의 권장안(⑤ 「3D 뷰」 숨김, ⑥ 라이더 평면·경사는 표고 그래프)대로 했다.

| 기능 | 처리 |
|---|---|
| 「3D 뷰」 버튼(고정 35) | 주행 카메라 메뉴에서 숨김. 코드는 보존하고 `?ride3d=1`로 다시 보인다. 카메라 1~6과 줄 배치는 그대로이고 버튼 자리는 빈칸이다 |
| 라이더 경사(고정 34) | 지형이 꺼지면 이미 평면으로 처리되고 있어 바꾸지 않음(기존 시험이 지킴) |
| 고도 표시 | 보이는 글자는 그대로. 마우스를 올리거나 읽어 줄 때의 안내만 지형에 따라 「지면 기준/해수면 기준」으로 바꿈. 평지에서 해수면 기준은 틀린 말이었다 |
| 도착 연출 | 0단계에서 지형과 분리 완료 |
| 표고 그래프·코칭의 오르막 안내 | 별도 표고 자료라 영향 없음, 유지 |
| 지형 이상 자동 2D(고정 36)·카메라 지형 회피(고정 86) | 지형이 켜졌을 때만 쓰임. 코드 보존 |
| 야외·위성 지도의 건물 | 지형과 분리돼 있어 주행 중 계속 표시 |
