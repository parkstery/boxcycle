# 3단계 시안 — 가로수·숲

2026-11-24 · Claude Code 직접(위임 없음) · 상태: **Chief 선택 대기. 제품 코드 미구현**(실제 앱 화면에 시험 도구로 얹은 그림)

- 시안 1 모양: `evidence\tree-option-1-shape.png` — A 둥근 나무 / B 각진 나무
- 시안 2 빽빽함: `evidence\tree-option-2-density.png` — ① 여유 / ② 보통 / ③ 빽빽+관목

## 어떻게 심었나

- 실제 지도 자료로 계산: 숲·공원 면, 도로, 건물, 물, 기존 나무. 건물·물·도로·경로 위와 기존 나무 6m 안에는 심지 않는다. 위치는 세계 격자로 정해 조각 경계에서 이어지고 매번 같다. (계산 도구: `tools\trees\placement.mjs`)
- 자체 제작 모델 7종, 각 48~132삼각형·5~12KB. 외부 자산 없음. (`tools\trees\gen-tree-glb.mjs`)
- 카메라 주변 450m. 여유 900·보통 1,500·빽빽 2,500그루 상한. 남산은 세 밀도 모두 상한에 걸려 먼 숲이 잘린다.
- 파리처럼 실제 나무가 많은 곳은 107~274그루만 더해졌다.

## 비용

한 주행 안에서 나무 켬/끔을 4초씩 바꿔 쟀다. 남산 켬 14.4~16.5/끔 14.1~16.8, 뉴욕 10.7~14.2/12.7~15.2, 파리 10.9~15.4/12.9~15.6FPS. **12쌍 중 10쌍에서 켬이 낮았고, 쌍별 평균 차이는 −1.5~+1.7FPS, 전체 평균 약 −0.7FPS(약 5%)다.** 이때는 Chief의 Edge 창이 CPU·GPU를 함께 쓰고 있어 절대값이 낮았다. **나무 비용은 조용한 PC에서 다시 재야 확정된다.**

## 구현 때 반드시 확인할 것

- 교량 위(난간 밖 물 위)·터널·교차로 시야. 시안은 교차로 이격을 아직 넣지 않았다.
- 숲이 짙은 곳은 먼 건물이 가려진다. 굽은 길에서 나무가 카메라와 라이더 사이에 들어오지 않는지 연속 주행으로 확인.
- 시야 확장의 「앱 GeoJSON 300m」 규칙에서 나무 소스를 예외로 둘지 결정.
- 글자가 나무에 가리는 정도.
- 카메라 이동에 따른 나무 다시 심기(타일 단위)와 메모리.

Mapbox 기본 나무를 확대 배치한 안은 가까이에서 줄기만 크게 보이고 일부 모델이 표시되지 않아 시안에서 뺐다.
