Chief 최신 지시: 기본 구현 담당은 Cursor AI·CLI. OpenCode는 별도로 요청할 때만 GLM-5.3으로 사용하고 불가 시 Cursor로 돌아온다. 이번 작업은 Cursor로 실행한다. 안내·질의·권한 요청·결과는 한국어로 작성한다.

지시01의 제품 범위·금지 범위·완료 조건·검증 명령은 동일하다. 담당은 Cursor, 결과 경로는 `03-result-02.md`로 대체한다. Supervisor의 독립 검수는 `04-review-02.md`이다. 작업은 index.html 사진 preload 한 건만이며 지시01은 과거 기록으로 보존한다. 초기 제품 변경은 없으며 과거 Muse 실행은 모델 사용 불가(exit1), Cursor 실행은 사용자 중단으로 완료 근거가 없다. 다른 담당의 변경을 보존하고, 작업 결과를 추측하지 않는다. commit/push/deploy/server/browser/subagent 금지.

새 디버그 코드·주소 스위치·스크립트를 만들면 `apps/web/dev-tools.json` 에 등록한다(분류·목적·켜는 법·만료). 운영에서 켜지는 도구 화면은 동적 import 로 분리한다.
