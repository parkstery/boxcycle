Chief의 선택 `2`는 기존 사진을 HTML 단계에서 선요청하는 방안의 구현 승인이다. Supervisor Codex / Developer 기본 Muse Spark 1.3, 한도·실행 문제 시 Cursor 교대. 기준 main2 HEAD `1f226f19ac465aef390998bd9ccc99b3e138abe3`. 다른 담당과 함께 쓰는 저장소이다. 기존 archive 색인 및 프로세스·메모리 보고 변경은 사용자 소유이므로 보존하고 타인의 편집을 되돌리거나 포함하지 않는다.

## 범위

제품 소유 파일 `apps/web/index.html` 하나. head에 `rel="preload" as="image" fetchpriority="high" referrerpolicy="no-referrer"` 링크 한 건을 추가한다. href는 `AppIntroScreen.tsx`의 `INTRO_SATELLITE_SRC`와 완전히 같은 기존 URL이다. HTML `&amp;`는 파싱 후 원 URL과 동일해야 한다. `type="image/jpeg"`는 선택. 기존 img에 crossorigin가 없으므로 preload에도 추가하지 않는다. 짧은 한국어 주석으로 URL·referrer 정책을 컴포넌트와 함께 유지해야 함을 설명한다.

결과 소유 파일 `03-result-01.md`에 모델·세션·branch/HEAD/초기 dirty·변경·검증 명령/exit·한계를 기록한다. 지시·공용 색인·기존 결과는 수정하지 않는다.

이미지 다운로드·저장·재배포·교체, 문구/CSS/인증 게이트/지도 초기화/앱 분리/의존성/서버 API 변경 금지. commit/push/deploy/server/browser/subagent 실행 금지. 상시 테스트나 진단 코드를 새로 만들지 않는다.

## 완료 조건과 검증

1. 기존 원격 이미지가 React 및 인증 초기화 이전에 HTML에서 발견된다.
2. 원 URL·정책 일치, 중복 preload 없음, 기존 화면·시작 동작 유지.
3. `npm --prefix apps/web run build`, `git diff --check -- apps/web/index.html` 실행하고 실제 exit 기록. 빌드 산출물은 커밋하지 않는다.
4. Supervisor가 빌드 HTML과 컴포넌트의 URL/정책을 대조하고 headless 브라우저에서 앱 모듈을 지연시켜 이미지 요청이 먼저 시작되는지, 동일 img 삽입 시 요청 한 건을 재사용하는지 독립 검증한다. 통제된 지연 및 공개 이미지 fixture 검증은 실제 서비스 속도 개선 수치와 구분한다. browser/page는 하나, 짧은 기한을 둔다.

HTML에서 무조건 선요청하므로 인트로가 생략되는 진입에도 배경 요청이 발생할 수 있다. 이 비용과 외부 서비스 응답 지연 자체는 남는다는 점을 결과에 기록한다. 실기기·운영 속도 개선을 단정하지 않는다. 이미지 소스/저장 정책·인증 의미·아키텍처·배포 변경은 범위 밖이며 확장하지 말고 보고한다.

새 디버그 코드·주소 스위치·스크립트를 만들면 `apps/web/dev-tools.json` 에 등록한다(분류·목적·켜는 법·만료). 운영에서 켜지는 도구 화면은 동적 import 로 분리한다.
