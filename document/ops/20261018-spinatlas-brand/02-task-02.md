Supervisor 독립 검증에서 새 카피·실제 앱 4뷰포트·인트로 CTA 콜백·HUD 4상태 배치는 통과했다. `node apps/web/scripts/ride-verify/verify-selectors.mjs`는 **소개 제목 `/달린 길이,/` 앵커 실종**으로 실패했다. 이는 기존 위치 변경 탓이 아니라 이번 제목 변경으로 생긴 검증 계약 불일치다. 이전 결과에서 잘못 분류했다면 새 결과에 정정한다.

1. `.agents/skills/ride-verify/SKILL.md`와 `apps/web/scripts/ride-verify/HARNESS.md`를 읽는다. `apps/web/scripts/ride-verify/entry-contract.mjs`의 소개 제목 앵커만 새 제목 `/땀으로 그리는,/`로 맞춘다. 기존 위치 관련 미커밋 변경을 보존한다. `apps/web/e2e/ride-entry.spec.ts` 및 관련 spec/helper에 옛 제목 기대가 있는지 검색하고 있으면 해당 기대만 수정, 없으면 변경하지 말고 결과에 확인 사실을 적는다. 실패 검사를 삭제하거나 약화하지 않는다.
2. `apps/web/src/components/RotateOverlay.tsx`의 `Spinatlas 는`을 자연스러운 `Spinatlas는`으로 수정한다.
3. 위 셀렉터 검증을 재실행해 전체19단계 통과·실제 종료코드0 확인. 수정 파일 lint와 `git diff --check`, `node scripts/check-document-system.mjs` 확인. 이번 수정은 실행 동작을 바꾸지 않으므로 이미 통과한 build·전체 화면을 불필요하게 반복하지 않아도 된다.
4. `03-result-02.md` 별도 작성, 이전 결과 보존. 명령·종료코드·실패 원인 정정·변경 파일·검증 한계를 적는다. README 최신 결과 링크 갱신. 커밋·push·배포 금지, ops 공용 색인·Supervisor 검수 파일은 수정 금지.

새 디버그 코드·주소 스위치·스크립트를 만들면 `apps/web/dev-tools.json` 에 등록한다(분류·목적·켜는 법·만료). 운영에서 켜지는 도구 화면은 동적 import 로 분리한다.
