## 작업 계획·허용 범위

1. 작은 조사: 아래 허용 파일과 사용자 표시 RTW 잔존 위치를 확인한다. 내부 RTW 상수·프로브·저장 키와 실제 표시 문자열을 구분한다.
2. UI보다 먼저 기존 Ontology §0.1 뒤에 브랜드 규칙을 짧게 추가한다: 현재 제품 표시명 **Spinatlas**(한글 호칭 스핀아틀라스), RTW / Ride the World는 과거 브랜드. 내부 식별자·경로·프로젝트 ID와 과거 문서 파일명은 유지. '내 도로망'의 기능 의미는 변경하지 않으며 '내 지도'는 이번 인트로의 감성 카피다.
3. 결정 로그의 최신 표 위쪽에 2026-10-18 `[Ontology]` `[Product]` `[UI]` 한 행 추가, 이 지시를 근거로 연결한다. 기존 미커밋 행을 보존한다.
4. `apps/web/src/components/auth/AppIntroScreen.tsx`: 브랜드를 **Spinatlas**로 표시. `RIDE THE WORLD` 보조 행은 제거한다(Spinatlas 중복 행이나 미승인 영어 모토를 추가하지 않는다). 제목은 두 span으로 **땀으로 그리는,** / **나만의 지구 지도.**. 부제는 정확히 **실내 자전거로 실제 도로를 달리면, 달린 길이 내 지도에 남습니다.**
5. `GuestEntryCard.tsx`, `AuthGateCard.tsx`, `components/maphud/MapHud.tsx`의 제품명 표시 RTW를 **Spinatlas**로 변경. `apps/web/index.html` title도 **Spinatlas**. `apps/web/src/lib/map/rtwMapConfig.ts`의 사용자 노출 스타일 선택지 `RTW Dark`는 **Spinatlas Dark**로 변경하되 상수·URL·동작은 유지한다. 다른 사용자 노출 브랜드를 발견하면 보고하고 같은 표시 문자열만 변경할 수 있다. 내부 코드명·주석의 전역 치환 금지.
6. 해당 컴포넌트 CSS만 이름 길이·긴 부제 수용에 필요한 최소 조정 가능. 기존 색·지도·CTA·인증/위치 흐름·카메라·타이머·회전 안내·44px 터치 영역·출처 표시를 보존한다. 폰 가로 우선. 이름을 자르거나 줄임표로 대체하지 않는다. HUD의 길어진 브랜드와 계기판 충돌도 점검한다.
7. 루트 README·CLAUDE.md·AGENTS.md에 현재 브랜드 설명이 있으면 해당 한 줄만 일관되게 수정(파일명·역사 기록·다른 역할 계약 변경 금지). 영향 문서 대량 rename·일괄 치환 금지. 기능 구현 상태는 변하지 않으므로 상태보드 기호를 임의 변경하지 않는다.

## 완료·검증 기준

- 정확한 브랜드·두 줄 제목·부제, 옛 영어 모토 제거, 브라우저 title 반영. Guest·로그인 CTA와 기존 셀렉터/콜백 유지.
- 새 테스트를 카피 문자열만 확인하도록 만들지 않는다. 기존 검증과 실제 화면 증거 사용. 기존 시험이 옛 문구를 계약으로 잡았다면 의미를 보존하며 기대값만 수정할 수 있다.
- PowerShell 실행 위치와 명령을 기록한다:

```powershell
Set-Location 'C:\20.HDev\boxcycle'
npm run build
npm run lint
node scripts/check-document-system.mjs
node apps/web/scripts/ride-verify/verify-selectors.mjs
git diff --check
```

- selector 명령의 실제 파일 존재·package script를 먼저 확인하고 실제 명령이 다르면 올바른 기존 명령을 기록한다. 각 명령의 종료 코드와 PASS/FAIL/미실행 이유를 구분한다. 기존 실패를 이번 성공으로 보고하지 않는다.
- 기존 서버·포트를 먼저 확인해 재사용한다. 실제 인트로를 667×300, 740×300, 844×390, PC1366×768에서 확인. 전후 스크린샷, 제목·부제/브랜드 rect·잘림·가로 overflow·CTA 터치 영역·스크롤 접근성을 보고. HUD 브랜드와 계기판도 적어도 좁은 가로에서 확인. 민감한 인증을 실행하지 않고 컴포넌트 fixture로 확인하면 실제 앱 확인과 구분한다. 실기기 미검증 명시.
- 브라우저 단계가 5분간 무진전이면 중단하고 프로세스·서버·포트·로그 점검 후 headless·단일 worker·기존 서버 재사용·정적 검증으로 전환. 같은 대기를 반복하지 않는다.
