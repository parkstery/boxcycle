## 2. UI/UX 불변 규칙 — 어기면 되돌아온다

### 2.1 디자인 토큰이 단일 진실

`apps/web/src/tokens.css`. 색·간격·라운딩·타이포를 **여기서만** 가져온다. 새 색을 즉흥으로 만들지 않는다.

- **골드 `--rtw-trace #E8A33D` 는 세 곳에만** — 궤적 · 핵심 강조 숫자 · Primary 액션. 그 외에 쓰면 강조가 죽는다.
- **내가 달린 길은 BlueViolet `#8A2BE2`** (`--rtw-trace-owned`). 지도 레이어의 SoT 는 `lib/rtwMapConfig.ts` 의 `RTW_TRACE_OWNED_COLOR` 이고 토큰은 지도 밖 UI 용 사본이다 — **함께 바꾼다.**
- danger `--rtw-danger` 는 로그아웃·삭제·종료 전용.
- 숫자(속도·거리·시간)에는 `.rtw-numeric`(tabular-nums)을 붙인다.

### 2.2 폰 가로가 기준 화면

- 앱은 **폰 세로에서 「화면 회전 안내」 오버레이**를 띄운다. 세로 레이아웃을 설계하지 않는다.
- `@media (max-height: 560px)` 에서 **루트 폰트 16 → 13.5px**. rem 기반 치수가 전부 0.84배로 줄어든다 — 계정 시트 레일 `min(20rem, 92vw)` 이 320px → 270px.
- **터치 타깃 44px 이상.** rem 으로 주면 가로에서 같이 줄어드니 **px 로 고정**한다.
- e2e 뷰포트는 가로(예: 932×430)로 잡는다. 세로로 잡으면 오버레이가 클릭을 가로채 시험이 통째로 실패한다.

### 2.3 용어

UI 문자열은 [Ontology](260714-RTW-Ontology.md)를 따른다. 자주 틀리는 것:

- Room·방·Lobby ❌ → **Trail·Trailhead**
- z20·셀·블록·타일 UI 노출 ❌ → **내 도로망**·**새 도로 +N km**
- "비로그인 사용자" ❌ → 인증 전 / **Guest**(익명 인증 완료)

### 2.4 정복 표면의 금기 — 분모를 만들지 않는다

「이 지역 N% 완성」·「남은 N km」류 **완성률 표시를 만들지 않는다.** 사용자가 지도를 할 일 목록으로 읽는 순간 운동이 숙제가 된다. [Conquest §3.4](260703-Conquest-정복-레이어-설계.md)의 탐험도·비율 판정 금지, OQ-2 보류와 같은 줄기다.

허용되는 표현: 「새 도로 +N km」(증분) · 「내 도로망 N km」(누적). 금지: 「N% 달성」 · 「남은 N km」 · 경계가 뚜렷한 면(面) 레이어.

### 2.5 접기와 지우기는 다르다

「지도를 가리지 않게 접어라」는 **접기**이지 **정보 삭제**가 아니다. 2026-09-14 에 RouteDock 이 이 둘을 섞어 펼친 패널이 빈 껍데기가 됐다. 패널을 접을 때는 `autoCollapse`(접기)와 내용 가시성을 **항상 분리**한다.

## 3. 최근 바뀐 표면 — 건드릴 때 주의

이번 세션(09-14~15)에 손댄 곳이다. 관련 계약 시험이 붙어 있으니 **고치기 전에 그 시험부터 읽는다.**

| 표면 | 무엇이 바뀌었나 | 계약 |
|---|---|---|
| **계정 시트** `UserInfoSheet` | 블록 12→7. 플랜 3중복 → 한 줄, 일일 주행을 기간 탭(`오늘·주간·월간·연간`)으로 흡수해 통계 타일 **한 벌**, 거리 히어로, 마지막 주행 카드 = 최근 목록 입구 | `e2e/account-panel-tidy.spec.ts` · `scripts/ride-stats/ride-stats-aggregate-contract.test.ts` |
| **RouteDock** 주행 중 | 접기는 유지, 경유지·주소는 펼치면 보임, 삭제만 잠금(`lockStopEditing`) | `e2e/route-dock-riding-content.spec.ts` · `scripts/ride-hierarchy/route-dock-riding-contract.test.ts` |
| **지도 — 내 도로망** | 줌아웃 LOD 집계 광채(`boxcycle-conquest-traces-halo`, z13에서 0). 세기 조절은 `rtwMapConfig.ts` 세 줄(width·blur·opacity) | `e2e/conquest-lod-shots.spec.ts`(대조 촬영) |

**아직 실데이터로 육안 확인이 안 된 것:** 계정 시트의 자산 2열(내 도로망·누적). 검증 스크린샷이 게스트 계정이라 비어 있었다.

## 5. 검증 — 착수 전 기준선, 완료 후 회귀

```
cd apps/web

npx tsc -b                     # 타입 (exit 0 기대)
npx eslint src/<변경파일>       # error 0 기대. 경고 7건 안팎은 기존 baseline
npm run test:next-ride         # 단위 계약 215건 (fail 0 기대)

npm run test:e2e:account-panel # 계정 시트 계약
npm run test:e2e:route-dock    # 주행 중 RouteDock 계약
npm run test:e2e:ride          # 주행 진입 시퀀스
```

e2e 는 Firebase 에뮬레이터를 **자동 기동**한다(`run-with-functions-emulator`). 별도 준비 불필요.

화면 증거가 필요하면 위 spec 들이 `apps/web/.out/<name>/` 에 스크린샷을 남긴다(gitignore 됨). **Chief에게 보여줄 때는 파일 경로 링크가 아니라 파일 자체를 전송한다** — `file:///` 링크는 이 환경에서 열리지 않는다.

## 6. 환경 함정 (이번 세션에서 실제로 걸린 것들)

| 함정 | 증상 | 대처 |
|---|---|---|
| **포트 혼동** | 5000 에 다른 워크트리/구 코드 서버가 떠 있으면 변경이 반영 안 된 화면을 보게 된다. Playwright 도 `reuseExistingServer` 로 그 서버를 재사용한다 | 확인할 포트를 명시하고, 다른 포트로 띄울 땐 `RTW_DEV_PORT` + `--port` 를 **둘 다** 준다 |
| **배포 차단** | `firebase deploy` 는 샌드박스가 막는다(Production Deploy) | 명령을 만들어 Chief가 실행한다. 경로는 `\` 대신 **`/`** 로 쓴다 — 셸이 백슬래시를 먹는다 |
| **폰 세로 오버레이** | e2e 가 「화면 회전 안내」에 클릭을 가로채여 타임아웃 | 뷰포트를 가로로 |
| **Go 잠김** | e2e 에서 「주행 시작」이 `disabled` | 센서 시트에서 「체험 속도로 준비」를 먼저 고른다(SENSOR-2 §1.4) |
| **pre-commit 훅** | 파일 전체에 eslint — 대형 파일의 기존 baseline 경고가 뜨지만 error 0 이면 통과한다 | 경고는 무시, error 만 본다 |
| **`three` 버전** | `npm install` 을 돌리면 라이더 GLB 파이프라인의 three 가 0.134 → 0.175 로 바뀐다 | **UI 작업 중에는 `npm install` 을 돌리지 않는다.** 필요하면 렌더 before/after 비교를 먼저 (§조사 결과는 결정 로그 09-15 참조) |

## 7. 작업 규율

- 개발 base 는 `main2`. 짧은 브랜치 → 병합.
- **주요 결정은 [결정 로그](260707-RTW-결정-로그.md)에 한 줄 append**(최신이 위), **기능 상태 변경은 [상태보드](260707-RTW-기능-인벤토리-상태보드.md) 기호 갱신.**
- 화면을 바꿨으면 **그림으로 보고**한다. 코드가 통과했다는 말은 그림의 대체가 아니다.
- 목업·아티팩트는 **최소 2배 스케일**로 그린다. 실물 픽셀로 그리면 읽히지 않는다.
