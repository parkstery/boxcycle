## 1. 지금 어디에 있나

1. **달리는 기능은 한 바퀴 다 돈다.** 내 지역 선택 → 자동 경로(Ready Ride) → 센서 준비 → 주행 → 결과(새 도로 +N km) → 다음에 이어 달리기. 모두 배포됨.
2. **이름이 Spinatlas(스핀아틀라스)로 바뀌었다(10-18).** 화면에 보이는 이름만 바꿨고, 코드 안 이름과 Firebase 프로젝트 이름은 그대로 `boxcycle`.
3. **폰 가로 화면(800×360) 정리 2차가 진행 중이다(10-20~).** 지도를 가리는 것을 줄이고 경로 만들기 창을 다시 짰다. 10-22 의 지시30까지 모두 배포됐다. 실제 폰 확인이 여러 건 밀려 있다(§4).
4. **사람이 다시 오는지는 아직 재 본 적이 없다.** 재는 도구는 있는데 데이터가 0건이다.

## 2. 무엇을 향해 가나

**Ride = Claim** — 실내에서 달린 실제 도로가 「내 도로망」으로 영구히 쌓인다.
운동이 본체이고 정복은 보너스, 혼자서 성립하고 함께 달리기는 오래 쓰게 만드는 장치다. → [마스터 비전](reference/product/260511-RTW-마스터-비전-및-종합계획.md)

## 4. chief 가 결정할 것

| # | 질문 | 이게 정해져야 풀리는 것 |
|---|------|------------------------|
| 1 | 경로 생성 토큰과 경로 저장 한도를 하나로 합칠까, 역할을 나눌까 | 토큰 무제한 해제 값, 챌린지 보상 |
| 2 | 「개척자」는 공개 경로 등록자인가, 구간을 처음 완주한 사람인가 | 챌린지 설계 |
| 3 | 장기 목표의 「실시간 날씨·밤낮」을 살릴까 (08-27 에 날씨 표시는 지웠다) | 정복 C 단계 정의 |
| 4 | 비공개 Trail 을 유료로 돌릴까 (지금 무료) | 유료 기능 목록 |
| 5 | 위성지도를 계속 보여줄까 | 지도 정책 |
| 6 | 주행 중 체험 속도 조절: 되돌리기 / 개발용만 / 정식 기능 | 출시 전 확인사항 5 |

**chief 가 확인할 것(실제 폰, https://boxcycle-dc2df.web.app 새로고침 후)** — 배포는 됐고 눈으로 보는 확인만 남았다.

- 경로 만들기: 거리·방향으로 만들면 쓰인 이동수단 버튼이 파랗게 켜지는지, 결과 문구가 두 줄인지, 이동수단·재생·삭제가 한 줄인지(지시30)
- 출발·경유 3곳·도착 다섯 자리와 오른쪽 아래 둥근 주행 버튼(지시29)
- 출발을 안 정했을 때 길게 누르면 바로 출발점이 되는지(지시28), 지도 길게 누르기 0.5초가 손에 맞는지(지시18)
- 계기판 글자가 위성지도 위에서 읽히는지(지시13~14)

## 5. 최근 바뀐 것

**2026-10 (16~22일)**

- 이름: **Spinatlas** 확정, 인트로 문구 「땀으로 그리는, 나만의 지구 지도.」
- 첫 진입: 게스트/로그인을 고른 뒤 로마 콜로세움 지도에서 시작하고, 위치를 허락하면 1초 비행으로 내 위치로 간다. 지구본 연출은 접었다.
- 게스트: 로그아웃해도 기록이 남고 같은 게스트로 다시 들어온다. 30일 안 쓴 게스트만 서버가 매일 밤 정리한다.
- 지도 화면: 지구본·나침반 버튼과 가장자리 흰 손잡이를 없앴다. 계기판은 맨 위, 센서·주행 버튼은 오른쪽 아래에 따로 뒀다.
- 경로 만들기: 「출발·도착」과 「거리·방향」 두 탭. 이동수단을 누르면 바로 경로가 생기고, 지도 위치 선택은 0.5초 길게 누르기로 바꿨다(메뉴·지도 이동 때 창이 뜨던 문제).
- 새 도로 표시: 주행이 끝나면 오늘 달린 새 도로가 사라지던 문제를 고쳤다.
- 주행 화면 속도: 매 프레임 계산 7 ms → 2 ms, 라이더를 가벼운 모델(rider14)로 바꾸고 코너에서 부드럽게 기울며 돈다. 주행 중 지명은 남기고 장식 기호만 숨긴다.
- 작업 방식(10-22): Claude 가 수퍼바이저(계획·지시서·감리), 구현은 opencode(GLM-5.3-Flash)와 Cursor 가 나눠 맡는다. 단위 시험 1,341건이 푸시 때마다 돈다.

**2026-10 (10~15일)**

- 화면 얼굴 바꾸기: 흰 바탕·파란 강조. 메뉴·경로 목록·계정·주행 설정·센서·결과 창을 하나씩 줄이고 chief 가 창마다 채택했다.
- 경로를 정하면 주행 시작 버튼이 두 번 맥박처럼 커졌다 작아져 위치를 알려 준다. 접기 버튼은 얇은 꺾쇠(›) 하나로 통일.
- 처음 온 사람에게 콜로세움 위성사진 인트로 →「시작하기」. 위치를 알리지 않은 사람의 첫 지도는 콜로세움 주변.
- 로그인 대기를 「연결 실패」로 잘못 보여 주던 문제를 고쳤다(이제 「연결 중…」/「로그인 중…」).
- 작업 방식: 개발은 OpenCode Muse 기본·Cursor 교대, Codex 가 감리. 최종 기기는 스마트폰, PC 는 개발용.
- 단위 시험 1,076건. 지난 실험 작업 폴더(face-redesign2·mobile-ui-redesign)는 폐기 정리했다.

**2026-10 (1~9일)**

- 혼자 달릴 때 「페이서」 2명이 따라붙는다(끌 수 있음). 미니맵 배경에 실제 지도가 깔렸다.
- 칼로리: 체중·강도를 가입 때 한 번 받고, 기기를 바꿔도 다시 묻지 않는다.
- 계정: 탈퇴 기능, 프로필 수정(닉네임은 30일에 한 번). 이름 없는 라이더가 달리지 않게 이름 규칙을 하나로.
- 게스트는 짧은 체험 — 로그아웃하면 기록이 지워지고, Google 로그인을 앞세워 등록을 권한다.
- 개인정보: 누구나 읽는 문서에서 이메일·Google 사진 주소를 뺐다.
- 단위 시험 1,066건이 푸시 때마다 자동으로 돈다. 승인 후 배포는 AI 가 직접 하고 결과까지 확인한다.

**2026-09**

- 첫 화면이 「내 지역에서 첫 주행」으로 바뀌었다. 자동 경로 성공률 5% → 100%, 안 달린 길 우선.
- 주행 화면 정리: 계기판·결과 시트·메뉴를 줄여 폰 가로에서 지도가 더 보인다.
- 라이더 3D 모델을 새것으로 교체했다.
- 거리뷰(Mapillary) 제거, 토큰은 한시 무제한.
- 코드 구조 정리 완료(위반 0).
