# 출시 전 확인사항

출시(배포) 전에 테스트용으로 임시 변경한 설정을 원래 값으로 되돌려야 한다.

1. **유효 주행 폐기 기준 복원** : 테스트 `100m, 5초 이상` → 출시 `200m, 3분 이상`
   - **파일 2개를 반드시 함께 고칠 것** — 한쪽만 고치면 클라이언트는 남기고 서버는 버리는 주행이 생겨 **새로고침하면 사라지는 기록**이 된다(2026-09-04 실제 발생, 서버가 200m/3분에 멈춰 있었다)
     - `apps/web/src/lib/rideRecordPolicy.ts`
     - `functions/src/rideRecordPolicy.ts`
   - 두 파일 모두 `MIN_MEANINGFUL_RIDE_DISTANCE_METERS` 를 `100` → `200` 으로 복원
   - 두 파일 모두 `MIN_MEANINGFUL_RIDE_DURATION_SEC` 를 `5` → `3 * 60` 으로 복원
   - 복원 후 값이 같은지 확인: `grep -n "MIN_MEANINGFUL" apps/web/src/lib/rideRecordPolicy.ts functions/src/rideRecordPolicy.ts`
   - 서버 쪽은 복원 후 CF 재배포 필요 — `isDiscardableRideRecord` 는 conquest·mileage 집계가 쓴다

2. **Conquest Trust Tier 한도 복원(2026-07-03 개발 완화)** — [Conquest 설계 §3.2~3.3](260703-Conquest-정복-레이어-설계.md)
   - 파일: `functions/src/conquestOnRideCreated.ts`
   - `T0_SPEED_CAP_MPS` : `50 / 3.6` → `15 / 3.6`
   - `T0_DAILY_METERS` : `50000` → `5000`
   - 복원 후 CF 재배포: `firebase deploy --only "functions:conquestOnRideCreated"`

3. **퍼블릭 등록 최소 연장 복원(개발 편의로 100m 완화)** — [퍼블릭 경로 자동등록 정책 G1](260717-퍼블릭-경로-자동등록-정책.md)
   - `PUBLIC_ROUTE_MIN_LENGTH_METERS` 를 `100` → `5000` 으로 복원(두 파일 동기 유지 필수)
   - 파일: `apps/web/src/lib/publicRouteAutoReview.ts` (15행)
   - 파일: `functions/src/publicRouteAutoReviewCore.ts` (170행)
   - 복원 후 CF 재배포 필요(`autoReviewPublicRouteRequest` 등 관련 함수)

4. **Route Token 무제한 해제(2026-09-24 Chief 결정 — 한시)** — [결정 로그 09-24](260707-RTW-결정-로그.md)
   - 운영 `config/routeTokenEconomy` 의 `generateCostBase` 를 `0` → `1`(또는 재산정 값)로 복원
   - seed: `document/config-routeTokenEconomy.seed.json` 도 같이 되돌린다
   - UI 에서 내린 잔액·부족 문구를 다시 올린다(코드는 삭제하지 않았으므로 표시 조건만 복구)
   - ⚠ **복원 전에 「적정 부여·소모」를 먼저 정해야 한다** — 원래 값으로 되돌리는 것이 목표가 아니다.
     토큰 경제 재설계: [Route Token 경제](260518-Route-Token-경제-설계.md) · 상태보드 §4-1(quota 와 이중 체계 충돌)
   - 복원 후 CF 재배포 불필요(config 문서 읽기) — 단 캐시가 있으면 확인

5. **체험 속도 「주행 중 조절」 정리(2026-09-24 개발 편의로 한시 허용)** — [결정 로그 09-24](260707-RTW-결정-로그.md)
   - 종전 규칙: 「체험 속도는 Go 전에 정한다 — 주행 중 재튜닝 흐름은 만들지 않는다」([SENSOR-2 지시서](ops/sensor-relay/260827-BLE-케이던스-HUD-상태칩-작업지시서.md))
   - 개발 중 완주 확인에 2~3 km 를 실제로 달려야 해 시간이 과했다. 그래서 **주행 중 조절을 한시 허용**한다
   - 파일: `apps/web/src/components/sensor/CadenceSensorSheet.tsx` — `!cadenceMode && !props.riding` 조건
   - **출시 전에 최종 형태를 정한다**: 원복(Go 전에만) / dev 한정 유지 / 정식 기능 승격 중 택일
   - ⚠ 센서 연결 시에는 노출되지 않아야 한다(실제 케이던스가 진실) — 이 조건은 어느 선택지에서도 유지

속도 default 값을 18km/h로 설정, 속도 input 박스 제거, 속도 조절 +, - 버튼 클릭 인터벌 1초로 설정(갑작스런 속도 튕기기 불가 - 현실 속도 반영)
