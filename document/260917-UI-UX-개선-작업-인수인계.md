## 2. UI/UX 불변 규칙 — 어기면 되돌아온다

### 2.1 디자인 토큰이 단일 진실

`apps/web/src/tokens.css`. 색·간격·라운딩·타이포를 **여기서만** 가져온다.

- **골드 `--rtw-trace #E8A33D` 는 세 곳에만** — 궤적 · 핵심 강조 숫자 · Primary 액션.
- **내가 달린 길은 BlueViolet `#8A2BE2`**(`--rtw-trace-owned`). 지도 레이어 SoT는 `lib/rtwMapConfig.ts` 의 `RTW_TRACE_OWNED_COLOR` — 토큰과 **함께** 바꾼다.
- danger `--rtw-danger` 는 로그아웃·삭제·종료 전용.
- 숫자에는 `.rtw-numeric`(tabular-nums).

### 2.2 폰 가로가 기준 화면 — **rem 함정**

- 세로에서는 「화면 회전 안내」가 뜬다. 세로 레이아웃을 설계하지 않는다.
- `@media (max-height: 560px)` 에서 **루트 폰트 16 → 13.5px**. rem 치수가 전부 0.84배로 줄어든다.
- **터치 타깃 44px 이상.** rem 으로 주면 가로에서 같이 줄어든다.
  09-17에 HUD가 이 규칙을 어기고 있던 것이 발견됐다(선언 2.1~2.4rem → 실제 25~32px). 고친 방식은
  **보이는 크기는 그대로 두고 `::after` 투명 히트 영역만 44px** 로 넓히는 것이다(`MapHud.css` 맨 아래).
  새 컨트롤을 만들면 같은 처리를 해라.
- e2e 뷰포트는 가로(**690×430 또는 690×275**). 세로로 잡으면 오버레이가 클릭을 가로채 통째로 실패한다.

### 2.3 지도 위 오버레이는 기본이 `pointer-events: none`

`.map-hud` 의 규칙이다 — 「슬롯은 none, 내부 위젯만 auto → 빈 영역은 항상 맵 조작 가능」.
09-17에 표고 그래프만 이 규칙에서 빠져 **화면의 24.4%(386×120px, 하단 중앙)** 를 막고 있었다.
**지도 위에 무언가를 얹을 때 이 규칙부터 확인해라.**

### 2.4 용어

[Ontology](260714-RTW-Ontology.md)를 따른다. 자주 틀리는 것:

- Room·방·Lobby ❌ → **Trail·Trailhead**
- z20·셀·블록·타일 UI 노출 ❌ → **내 도로망**·**새 도로 +N km**
- "비로그인 사용자" ❌ → 인증 전 / **Guest**(익명 인증 완료)
- 신규 코드에 `course`/`courseId` ❌ → `route`/`publication`

### 2.5 정복 표면의 금기 — 분모를 만들지 않는다

「N% 완성」·「남은 N km」류 **완성률 표시를 만들지 않는다.** 허용: 「새 도로 +N km」(증분) · 「내 도로망 N km」(누적).
금지: 「N% 달성」 · 「남은 N km」 · 경계가 뚜렷한 면(面) 레이어. ([Conquest §3.4](260703-Conquest-정복-레이어-설계.md))

### 2.6 접기와 지우기는 다르다

「지도를 가리지 않게 접어라」는 **접기**이지 **정보 삭제**가 아니다. `autoCollapse`(접기)와 내용 가시성을 **항상 분리**한다.

### 3.1 지도 레이어 — 되돌림 이력이 있는 결정

내 도로망과 경로선의 **위아래는 단계마다 다르다**. 한 방향만 고정하면 반대편이 죽는다 — 실제로 두 번 뒤집혔다.

| 단계 | 순서 | 내 도로망 |
|---|---|---|
| 주행·일시정지 | 궤적이 위 | 0.95 |
| 경로 설정·확인 | **경로선이 위** | 0.6 + 폭 하한 7px |
| 경로 없음 | 궤적이 위 | 0.95 |

경로선에 **흰 테두리(casing)를 두르지 마라.** 시도했다가 테두리가 내 도로망을 통째로 덮어 폐기했다. 둘을 동시에 읽히게 하는 일은 **폭 차이**가 맡는다.

### 4.3 롱프레스를 하게 되면 (설계 메모)

- **데스크톱은 클릭 유지** — `pointerType === "touch"` 일 때만 롱프레스 요구.
- **발견 가능성** — 짧게 탭했을 때 「길게 눌러 지점 선택」 토스트가 없으면 「지도가 반응을 안 한다」가 된다.
- **임계값** — 400~500ms + 이동 허용 10px. 이동하면 팬이므로 즉시 취소.
- **브라우저 기본 동작** — 모바일 롱프레스는 컨텍스트 메뉴·텍스트 선택을 부른다. `contextmenu` 억제·`touch-action` 처리 필요.
- 지도 클릭 진입점은 `MapView.tsx` 의 `map.on("click", …)` 한 곳이다.

## 6. 이번 세션에서 실제로 데인 함정 — **읽어라**

### 6.1 그림을 보지 않고 수치만 보면 속는다

레이아웃 계측(폭·높이·면적)이 전부 통과했는데 화면은 깨져 있던 적이 두 번 있다.
**화면을 바꿨으면 스크린샷을 직접 열어 봐라.** 「시험 통과」는 그림의 대체가 아니다.

### 6.2 축퇴 게이트 — 항상 참이 되는 판정

실제로 겪은 것들:

- 좌하단 겹침을 쟀는데 **상자가 하나뿐**이라 「겹침 0」이 아무것도 증명하지 못했다 → 카드가 뜰 때까지 기다린 뒤 재도록 고침.
- 배지가 주소 요소의 **자식**이 된 뒤로 「주소와 겹친다」가 항상 참 → 글자의 `getClientRects()` 마지막 줄로 바꿈.
- 모달 「자리가 넓어졌다」를 현재 높이로 재려 했으나 게스트는 경로가 0개라 작게 나옴 → **최대 가용 높이**로 바꿈.
- CSS 선언(`max(100%, 44px)`)만 보면 실제 렌더 값을 모름 → `getBoundingClientRect` + `elementFromPoint` 로 확인.

**게이트를 쓰기 전에 「이 값이 0/상수/센티넬이라서 항상 통과하지 않나」를 먼저 물어라.**

### 6.3 계약이 산문에 걸린다

`hud.includes("cadence")` 로 「MapHud 에 센서가 없다」를 검사했더니 **주석 문장**에 걸렸다 — 설명을 지워야 시험이 통과하는 거꾸로 된 게이트. **코드 패턴으로 검사해라.**

비슷하게 `/A[\s\S]*?B/` 는 규칙 밖까지 열려 파일 아무 데나 걸린다. CSS 규칙 본문만 보려면 `/\.sel \{[^}]*prop/`.

### 6.4 e2e 에서 임시 스타일을 지울 때

`addStyleTag` 로 넣은 것을 **내용 문자열로 찾아 지우면 안 된다.** Vite dev 가 주입한 컴포넌트 CSS도 같은 문자열을 담고 있어 통째로 날아간다(실제로 이후 모든 스크린샷이 스타일 없는 상태로 찍혔다). `addStyleTag` 가 돌려준 **그 노드만** 지워라.

### 6.5 Mapbox 표현식 제약

`["max", <interpolate with zoom>, n]` 은 거부된다 — `"zoom"` 은 top-level `interpolate`/`step` 의 입력으로만 쓸 수 있다. 하한은 **stop 값에 직접** 걸어라. **단위 시험은 이걸 못 잡는다**(표현식을 직접 평가할 뿐 Mapbox 검증기를 안 거침) — `test:e2e:ride` 의 콘솔 오류 검사가 잡았다.

### 6.6 되돌림 이력이 있는 결정은 양방향을 고정해라

지도 레이어 순서가 그 예다(§3.1). 한 방향만 계약에 박으면 반대편이 다시 죽는다.

| **포트 혼동** | 5000에 다른 워크트리 서버가 떠 있으면 변경이 반영 안 된 화면을 본다 | `netstat -ano \| findstr :5000` 확인. 다른 포트는 `RTW_DEV_PORT` + `--port` **둘 다** |
| **배포 차단** | `firebase deploy` 는 샌드박스가 막는다 | 명령을 만들어 Chief가 실행. 경로는 `\` 대신 **`/`** |
| **`npx playwright` 직접 호출** | 수동으로 `node scripts/e2e/...` 를 쓰면 `playwright` 를 못 찾는다 | npm 스크립트로 돌리거나 명령에 `npx` 를 붙여라 |
| **폰 세로 오버레이** | e2e 가 「화면 회전 안내」에 가로채여 타임아웃 | 뷰포트를 가로로 |
| **Go 잠김** | e2e 에서 「주행 시작」이 disabled | 센서 시트에서 「체험 속도로 준비」 먼저 |
| **pre-commit 훅** | 파일 전체에 eslint — 대형 파일의 기존 baseline warning 이 뜬다 | warning 무시, **error 만** 본다 |
| **`three` 버전** | `npm install` 을 돌리면 라이더 GLB 파이프라인의 three 가 0.134 → 0.175 로 바뀐다 | **UI 작업 중에는 `npm install` 을 돌리지 않는다** |

## 8. 작업 규율

- 개발 base 는 `main2`. 이번 세션은 짧은 변경이라 main2 직접 커밋했다 — 범위가 커지면 짧은 브랜치를 끊어라.
- **주요 결정은 [결정 로그](260707-RTW-결정-로그.md)에 한 줄 append**(최신이 위), **기능 상태 변경은 [상태보드](260707-RTW-기능-인벤토리-상태보드.md) 기호 갱신.**
- 화면을 바꿨으면 **그림으로 보고**한다.
- Chief 지시가 이전 결정과 충돌하면 **그 사실을 먼저 말하고** 진행한다. 조용히 뒤집으면 반대편이 죽는다.
- 목업·아티팩트는 **최소 2배 스케일**.
